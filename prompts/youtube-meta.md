# 완성본 문서 생성 (METADATA 단계)

script.txt 완성 후 PD가 직접 수행하는 경량 단계. `output/` 완성본 폴더에 세 문서를 만든다:

- `02_썸네일제목.md` — 썸네일·제목을 만들 때 보는 작업 문서
- `03_업로드정보.md` — 업로드 폼에 그대로 붙여넣는 문서
- `04_타임스탬프.txt` — 챕터 목록만 담은 복사·붙여넣기용 파일

> 원본 파이프라인에선 영상 제작 단계(youtube-uploader)가 수행하던 작업 — 대본 배포본에는 영상 단계가 없으므로 여기서 만든다. 아직 영상이 없으므로 **챕터 타임스탬프는 대본 분량으로 계산한 추정치**로 넣는다 — 영상 완성 후 timestamp 스킬("타임스탬프 채워줘")이 전사 실측으로 교체한다.
> 두 문서는 사람(학생)이 직접 열어 읽는 파일이다 — 내부 용어(앵글, Phase, CTR 등)를 그대로 쓰지 말고 풀어 쓴다.

---

## 입력

- `{P}/_script/concept.md` — **확정 제목**, 앵글, 핵심 약속, 타겟 시청자, 핵심 메시지, 썸네일 텍스트 후보, 썸네일 이미지 컨셉
- `{P}/_script/_strategy_candidates.md` — (있으면) 전략 3안 → 대안 제목 소스
- `{P}/_script/outline.md` — 영상 구조, 파트별 내용, 핵심 약속
- `{P}/_script/verified-data.md` — 사용 데이터의 출처 (매체명 + 기사 제목 + URL) → 주요 출처 선별
- `{P}/_script/thumbnail-prompts.json` — 썸네일 이미지 프롬프트 (Phase 5 산출물)
- `channels/{channel}/config/settings.json` — 채널 메타 정보 (name 등) + `thumbnail.generate_images` 스위치

## 출력 ① — `{P}/output/02_썸네일제목.md`

````markdown
# 썸네일 · 제목 만들기

## 이 영상의 방향
- **핵심 각도**: {앵글 1~2문장 — 일상어로}
- **시청자에게 한 약속**: {핵심 약속 한 문장}
- **타겟 시청자**: {타겟 시청자 1~2문장}
- **핵심 메시지**: {핵심 메시지 한 문장}

## 제목 후보
1. **{확정 제목}** ← 추천 (대본이 이 제목 기준으로 작성됨)
   - {선정 이유 한 줄}
2. {대안 제목 1}
   - {이 제목이 어울리는 경우 한 줄}
3. {대안 제목 2}
   - {이 제목이 어울리는 경우 한 줄}

## 썸네일에 넣을 문구
1. **{확정 썸네일 텍스트}** ← 추천
2. {후보 2}
3. {후보 3}

## 썸네일 이미지 프롬프트
아래 영어 문장을 복사해서 이미지 생성 도구(ChatGPT, Gemini 등)에 붙여넣으세요.
한 번에 하나씩, 마음에 드는 그림이 나올 때까지 몇 개 시도해보면 됩니다.

### 1번 — {컨셉 한 줄 설명 (한국어)}
```
{프롬프트 원문 (영어)}
```

### 2번 — {컨셉 한 줄 설명}
```
{프롬프트 원문}
```

{... thumbnail-prompts.json의 장수만큼 반복 ...}
````

- "이 영상의 방향"은 concept.md에서 추출하되 **일상어로 번역**한다 (예: "앵글" → "핵심 각도")
- 제목 후보: 확정 제목이 1번(추천). 대안은 `_strategy_candidates.md`의 채택되지 않은 후보를 다듬어 1~2개 (없으면 확정 제목만)
- 썸네일 문구: concept.md의 썸네일 텍스트 후보 사용, 확정안이 1번
- 프롬프트: `_script/thumbnail-prompts.json`의 프롬프트를 순서대로, 각각 한국어 컨셉 한 줄과 함께 코드블록으로
- `thumbnail.generate_images`가 `true`인 채널이면 프롬프트 섹션 위에 한 줄 추가: "자동 생성된 이미지가 `output/썸네일/` 폴더에 있습니다. 마음에 안 들면 아래 프롬프트로 직접 만들어보세요."

## 출력 ② — `{P}/output/03_업로드정보.md`

```markdown
# 업로드 정보

아래 내용을 그대로 복사해서 유튜브 업로드 화면에 붙여넣으세요.

## 제목
{확정 제목}

## 설명글
{설명글 전체 텍스트}

## 태그
#태그1, #태그2, #태그3, ...

## 고정 댓글 (업로드 직후 직접 다는 첫 댓글)
{고정 댓글 텍스트}

---
💡 위 타임스탬프는 대본 분량으로 계산한 **예상 시각**입니다. 완성된 영상이 생기면 Claude에게 **"타임스탬프 채워줘"**라고 해보세요. 영상을 분석해 실제 시각으로 바꿔줍니다.
```

- **업로드할 때 필요한 것만** 넣는다 — 제목 후보·썸네일 관련 내용은 02에만 (여기 넣지 않는다)
- 저장 순서: **02 → 03** (03_업로드정보.md가 파이프라인의 DONE 마커 — 반드시 마지막에 저장)

---

## 생성 규칙

### 제목
- **concept.md의 확정 제목을 그대로 사용** (STRATEGY에서 이미 확정됨 — 새로 짓지 않는다)

### 설명글 — 다음 섹션을 순서대로 포함

> **서식 공통 규칙 (필수)** — 유튜브 설명글은 마크다운이 렌더링되지 않고 **줄바꿈만 그대로 보인다.** 빽빽하면 읽히지 않으므로 여백으로 구분한다.
> - **섹션과 섹션 사이는 빈 줄 하나**로 띄운다
> - **섹션 안에서는 줄바꿈만** 한다 — 다루는 내용 bullet, 타임스탬프 챕터는 한 줄에 하나씩 이어서 쓰고 그 사이를 빈 줄로 띄우지 않는다
> - 예외: **주요 출처만** 한 건(제목+URL)마다 빈 줄로 띄운다 — 두 줄짜리 항목이라 붙이면 경계가 안 보이기 때문
> - 들여쓰기(줄 앞 공백)를 쓰지 않는다 — 유튜브에선 그대로 노출돼 지저분해진다
> - `**굵게**`, `- ` 같은 마크다운 기호를 쓰지 않는다 (문자 그대로 보인다). 불릿이 필요하면 `·` 를 쓴다

1. **키워드** (맨 첫 줄): 핵심 키워드 5개를 `#키워드1, #키워드2, ...` 형식으로 — 검색 노출용
2. **한줄 요약** (1~2문장): 핵심 내용 압축 + 검색 키워드 자연스럽게 포함
3. **📌 이 영상에서 다루는 내용** (bullet **3~5개**): 영상이 무엇을 다루는지 **짧게** 요약한다. 한 줄에 한 항목, 각 줄 25자 안팎으로 끊는다. 파트를 하나하나 옮긴 목록이 아니라, 시청자가 훑자마자 "이 영상이 뭘 다루는지" 알게 하는 요약이다 (상세 목차 역할은 아래 ⏱ 타임스탬프가 담당한다)
   - 포맷 (**줄바꿈만 — 항목 사이에 빈 줄을 넣지 않는다**):
     ```
     📌 이 영상에서 다루는 내용
     · {한 줄 요약 1}
     · {한 줄 요약 2}
     · {한 줄 요약 3}
     ```
4. **⏱ 타임스탬프** (챕터 목록 — 대본에서 생성):
   - `_script/outline.md`의 파트 구조 + `_script/_draft_part{N}.md`의 **실제 글자수**로 각 챕터 시작 시각을 계산한다
     - part0(Hook & Intro)이 첫 챕터 → 반드시 `00:00`
     - 이후 챕터 시작 시각 = 앞선 파트들의 **누적 글자수 ÷ 분당 글자수** (profile.md 실측값 우선, 없으면 500자) → `MM:SS`로 반올림
   - 챕터 제목은 outline의 파트 제목을 **시청자용 문구로 다듬는다** — 내부 용어·스포일러 금지, 짧고 궁금하게
   - 유튜브 챕터 규칙 준수: 첫 챕터 `00:00` · 챕터 3개 이상 · 각 챕터 10초 이상 (너무 짧은 파트는 이웃 파트와 합친다)
   - 포맷 (**줄바꿈만 — 챕터 사이에 빈 줄을 넣지 않는다**):
     ```
     ⏱ 타임스탬프
     00:00 {챕터1 제목}
     {MM:SS} {챕터2 제목}
     {MM:SS} {챕터3 제목}
     ```
   - 이 시각은 대본 분량으로 계산한 **추정치**다. 영상 완성 후 timestamp 스킬("타임스탬프 채워줘")이 전사 실측으로 이 섹션을 통째 교체한다 — 그러므로 섹션 제목은 반드시 `⏱ 타임스탬프`로 쓴다 (교체 대상을 찾는 기준)
   - 설명글 본문에는 "예상"이라는 표기를 넣지 않는다 (그대로 유튜브에 붙여넣는 텍스트이므로) — 추정치라는 안내는 문서 하단 💡 줄이 담당한다
5. **🔗 주요 출처** (필수, **최대 10개 항목** — URL 유무와 무관하게 총 표기 수 기준):
   - verified-data.md의 출처를 전부 나열하지 않는다 — 대본에 실제 사용된 출처 중 **핵심 출처만 10개 이내**로 고른다 (전체 출처 기록은 `_script/verified-data.md`가 계속 보관하므로 유실되지 않음)
   - 선정 우선순위:
     1. 공식 1차 출처 (통계청·정부·협회·공시 등) — 대본의 핵심 수치를 뒷받침하는 것
     2. 제목·도입부의 핵심 주장을 지탱하는 보도
     3. 같은 내용을 다룬 기사가 여럿이면 매체 하나만 (신뢰도 높은 쪽 — 판단은 PD 재량). 단, 공식 1차 출처와 그것을 다룬 보도가 서로 다른 핵심 수치를 담당하면 둘 다 가능
   - **뉴스1·뉴시스 기사는 표기 금지** (URL이 news1.kr·newsis.com인 기사 포함) — 인용 제한을 요구하는 매체. 핵심 근거가 이 매체뿐이면 같은 내용을 다룬 다른 매체나 공식 1차 출처로 대체해 표기
   - 포맷 (매체명 — 기사 제목, 다음 줄 URL, **출처 한 건마다 빈 줄로 띄운다**, 마지막에 나머지 출처 요약 1줄):
     ```
     🔗 주요 출처

     {매체명} — {기사 제목}
     {URL}

     {매체명} — {기사 제목}
     {URL}

     {매체명} — {기사 제목}
     {URL}

     이 외 {N}건의 기사·자료를 참고해 사실 확인을 거쳤습니다.
     ```
   - URL 앞에 들여쓰기(공백)를 넣지 않는다 — 유튜브 설명글은 들여쓰기가 그대로 보여 지저분해진다. 구분은 빈 줄이 담당한다
   - 공식 통계·자료는 URL이 있어도 `{기관명} — {자료명} ({시점})` 형식으로 표기하고 다음 줄에 URL (URL이 없으면 그 줄 생략)
   - 마지막 요약 줄의 {N} = verified-data.md에 기록된 출처 수 − 위에 표기한 수 (대략이면 충분 — 대본과 정밀 대조하지 않는다. 남는 출처가 없으면 이 줄 생략)
   - 사용된 출처가 없으면 이 섹션 생략
6. **🔔 CTA** (1줄): 구독/좋아요 유도 문구, 채널 톤에 맞게

### 태그
- 주제 관련 키워드 10~15개, 대주제 → 소주제 → 관련 검색어 순서
- 각 태그 앞에 `#`, 쉼표(,)로 구분 (예: `#경제, #한국경제, #GDP`)

### 고정 댓글
- 크리에이터가 업로드 직후 직접 다는 첫 댓글 — 시청자 참여 유도 목적
- **1~3문장**, 짧고 임팩트 있게, 채널 톤에 맞는 말투
- 영상의 핵심 논점이나 가장 논쟁적/흥미로운 포인트를 건드려 **시청자가 자기 생각을 쓰고 싶어지게**
- 유형 (내용에 따라 자연스럽게 선택): 의견 질문 / 경험 공유 요청 / 선택지 제시 / 가벼운 어그로 / 반전·떡밥 / 퀴즈·예측
- "구독해주세요" 같은 CTA는 넣지 않음 (설명글 CTA와 분리)

## 출력 ③ — `{P}/output/04_타임스탬프.txt`

`03_업로드정보.md`의 `⏱ 타임스탬프` 섹션과 **같은 내용**을, 챕터 줄만 남겨 따로 저장한다.
설명글 전체를 붙여넣지 않고 챕터만 따로 쓰고 싶을 때(영상 편집 프로그램의 챕터 입력, 커뮤니티 게시 등) 바로 복사할 수 있게 하는 파일이다.

```
00:00 {챕터1 제목}
{MM:SS} {챕터2 제목}
{MM:SS} {챕터3 제목}
```

### 형식 규칙

- **챕터 줄만 넣는다.** 제목·머리말·설명·빈 줄 없이 첫 줄부터 바로 시작한다
- 첫 줄은 반드시 `00:00` (유튜브 챕터 규칙)
- 시각은 `MM:SS` — 분을 두 자리로 맞춘다 (`02:14`, `07:10`)
- 시각과 제목 사이는 **공백 한 칸**
- 챕터 제목은 `03_업로드정보.md`의 것과 **한 글자도 다르지 않게** 쓴다
- 챕터 수·제목·시각 계산은 03의 `⏱ 타임스탬프` 항목 규칙을 그대로 따른다
- 마지막 줄 뒤에 빈 줄을 남기지 않는다

### 주의

- 이 파일의 시각도 대본 글자수로 계산한 **추정치**다. 영상 완성 후 timestamp 스킬("타임스탬프 채워줘")이 `03_업로드정보.md`와 **이 파일을 함께** 실측값으로 바꾼다.
- 03과 04 중 한쪽만 고치면 안 된다. **둘은 항상 같은 내용이어야 한다.**
