## concept.md 포맷

concept.md는 STRATEGY 단계에서 한 번에 완성된다.
PD가 컨셉 + CTR을 단일 패스로 직접 작성한다 (`prompts/creative-strategy.md` 절차).

```markdown
# 영상 컨셉

## 앵글
{이 주제를 어떤 관점으로 풀어가는지 1-2문장}

## 핵심 약속
{한 문장}

## 타겟 시청자
{대상 설명}

## 서사 유형
{서사 유형명} — {선택 근거 1줄}

## 감정 전략
- 목표 감정: {감정}
- 감정 아크: {초반} → {중반} → {후반}
- 리텐션 접근: {방향}

## 핵심 메시지
{시청자가 가져갈 교훈 한 문장} — {도출 근거 1줄 (profile 방향 / 데이터 출처)}

## 제목 후보
1. {후보 1}
2. {후보 2}
3. {후보 3}

> **제목 형식 가이드**
> - `"따옴표 문구" 본제목` 형식 권장 (채널 pd-guide.md에서 필수 지정 가능)
> - 따옴표 형식: 전체 50~60자 이내 / 자유 형식: 30~45자 이내
>
> **따옴표 형식 사용 시:**
> - **따옴표 문구** (15자 이내): Hook/Intro에서 활용될 핵심 문장을 미리 설계
> - **본제목** (35~45자 이내): 주제 + "왜/이유/비밀" 등 호기심 유발 키워드
> - 예: `"배달비 무료라고요?" 시장 99%를 지배했던 배민이 무너진 소름돋는 이유`

## 확정 제목
{제목}

## 썸네일 텍스트 후보

1. {줄1} + {줄2} (+ {줄3} if applicable)
2. {줄1} + {줄2} (+ {줄3} if applicable)
3. {줄1} + {줄2} (+ {줄3} if applicable)

## 썸네일 이미지 컨셉

### 컨셉 A: {한줄 설명}
- 구도 패턴: {패턴명}
- 핵심 오브젝트: {1~2개}
- 색채/대비: {배경 톤 + 포인트 색}
- 감정 톤: {감정 1개}

### 컨셉 B: {한줄 설명}
- 구도 패턴: {패턴명}
- 핵심 오브젝트: {1~2개}
- 색채/대비: {배경 톤 + 포인트 색}
- 감정 톤: {감정 1개}

## 텐션 트라이앵글 시너지
- 제목: {역할}
- 썸네일 텍스트: {역할}
- 썸네일 이미지: {역할}
- 시너지 평가: {3요소 합작 효과}

## 선택 근거
{왜 이 패키지를 골랐는지 1~2문장. 데이터 출처 명시.}
```

### 상태 감지 기준
- `concept.md` 없음 또는 `hook-intro.md` 없음 → STRATEGY

### _strategy_candidates.md 포맷 (ask 모드용)

```markdown
# 크리에이티브 전략 후보

## 데이터 요약
- 레퍼런스 수: N개
- 최고 조회수: {영상명} ({조회수})
- 가장 뜨거운 감정: {감정}
- 핵심 팩트: {2-3개}

---

## 패키지 A: "{가제}"

### 컨셉
- 앵글: {1-2문장}
- 핵심 약속: {한 문장}
- 타겟 시청자: {상황 기반}
- 서사 유형: {유형명} — {근거}
- 감정 전략: {목표 감정} / {감정 아크} / {리텐션 접근}
- 핵심 메시지: {교훈 한 문장} — {도출 근거}

### CTR
- 확정 제목: {제목}
- 썸네일 텍스트: ① {세트1 요약} ② {세트2 요약} ③ {세트3 요약}
- 이미지 컨셉: A. {컨셉 A 요약} / B. {컨셉 B 요약}
- 텐션 트라이앵글: {시너지 요약}

### Hook & Intro
- Hook ({N자}): {원문}
- Intro ({N자}): {원문}

---

## 패키지 B / C (동일 구조)

---

## 추천
**추천**: 패키지 {X}
- 근거: {1~2문장}
```

## outline.md 포맷

```markdown
# 제목: {확정 제목}

## 1. 기획 뼈대
- 핵심 약속: ...
- 타겟 시청자: ...
- 썸네일 컨셉: ...
- 타겟 러닝타임: {N~M분} (목표 {N,NNN}자, 분당 {N}자 기준 — profile 실측치 우선, 없으면 500자)
- 핵심 메시지: {concept.md의 확정 메시지}
- 톤: ...

## 2. Hook & Intro
{hook-intro.md 내용}

## 3. 본문 구조

> 확정 제목: "{제목}"
> 제목이 암시하는 구조: {예: "3가지 이유" → 정확히 3섹션}
> 서사 유형: {concept.md에서 가져온 서사 유형}

### 파트 1: {제목} (~N~M분, N,NNN~N,NNN자 — {역할/중요도, 예: 핵심 파트})
- 시청자 질문: {이 파트 시작 시 시청자가 품고 있는 질문}
- 핵심 내용: ...
- 사용할 데이터: ...
- 비유/사례: {이 파트 전속 — 다른 파트에 배정된 비유/사례 재사용 금지}
- 감정 목표: ...
- 스테이크 레벨: {1~5}
- 리텐션 장치: {장치 유형 + 배치 위치 — 이 파트 전속. 문장은 집필 시 새로 작성}
- 다음 파트로의 전환: {오픈루프 또는 브릿지 — 예: "그런데 진짜 문제는 따로 있습니다"}

> 분량은 고정값이 아닌 **범위**로 배정한다. writer가 범위 안에서 자유 배분하고,
> 게이트는 전체 합계 밴드(90~115%) + 파트 하한(범위 하한의 70%)만 검사한다.

### 클로징 (~N분, NNN~NNN자)
- 핵심 요약: ...
- 메시지 완결: {핵심 메시지를 매듭짓는 방식}
- CTA: ...

## 4. 용어 순화
| 용어 | 비유 |
|------|------|

## 5. 차별화 포인트
- ...

## 6. 메시지 설계
- 핵심 메시지: {concept.md의 확정 메시지}
- 복선 배치 (중간 파트 1~2곳): 파트 {N} — {사례 속에서 어떻게 암시되는가}
- 완결 배치: 클로징 — {사례들이 어떻게 메시지로 수렴하는가. 설교식 나열 금지}

## 7. 리텐션 설계
- 감정 아크: {전체 감정 흐름 — 예: 충격→분석→공감→경각심}
- 재참여 포인트 (파트 전환 + 2~3분 간격):
  - ~N분 (파트1→2 전환): {새로운 궁금증 또는 스테이크 상승}
  - ~N분 (파트2 중반): {새로운 궁금증 또는 스테이크 상승}
  - ~N분 (파트2→3 전환): {새로운 궁금증 또는 스테이크 상승}
  - ... (타겟 러닝타임에 맞춰 2~3분 간격으로 배치)
- 스테이크 상승: {파트가 진행될수록 무엇이 커지는가}
- 참고할 레퍼런스 장치 (patterns.md의 구조 자산에서 — **유형 + 배치 위치만, 문장 발췌 금지**):
  - {장치 유형 — 어느 파트/타이밍에 쓰는지}
  - ...
```

## 완료 보고 포맷

```
=== 대본 제작 완료 ===

프로젝트: {프로젝트명}
채널: {채널명}

완성본 (output 폴더 — 번호 순서대로 쓰면 됩니다):
  - 01_대본.txt — 최종 대본 (영상 제작 사이트에 업로드)
  - 02_썸네일제목.md — 제목 후보 + 썸네일 문구·이미지 프롬프트
  - 03_업로드정보.md — 제목, 설명글, 태그, 고정 댓글 (출처 포함)

글자수: {N,NNN}자 → 예상 분량 ~{NN}분 ({분당 글자수}자/분 기준)

다음 대본은 새 세션에서 시작하세요. (/clear 입력 후 "대본 만들어줘")
```
