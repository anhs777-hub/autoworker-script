# 영어 대본 규칙 (해외 채널 · 현지화)

**적용 조건**: ① 채널 `profile.md`의 `## 언어`가 영어(English)일 때 — 파이프라인 전체에 적용 / ② 사용자가 기존 한국어 대본의 영어판을 요청했을 때(LOCALIZE — 절차는 `pd-script.md`).

**핵심 원칙: 번역이 아니라 현지화.** 한국어 문장을 영어로 옮기는 게 아니라, 같은 기획을 **미국 유튜브 채널의 작가가 처음부터 쓰듯** 쓴다. 자막·음성만 갈아끼운 직역 대본은 시청자가 3초 만에 알아챈다.

---

## 1. 재창작 원칙 (직역 금지)

- 의미는 유지하되 **영어 구어의 리듬**으로 다시 쓴다. 문장은 짧게, 축약형(it's, don't, that's)은 자연스럽게 사용
- **Hook·리텐션 문장은 번역하지 않는다** — 같은 감정(놀람·긴장·궁금증)을 주는 새 문장을 쓴다
  - 한국어 말장난·언어유희는 영어로 이월되지 않는다 → 영어권 관용구로 대체 (실전 예: "예고편" 말장난 → "That flood was only a **trailer**.")
- 한국어 어순 흔적("~라는 것입니다"식 만연체, 주어 생략)을 남기지 않는다 — 소리 내어 읽었을 때 원어민 나레이션처럼 들려야 한다
- 2인칭 "you"는 리텐션 지점에만 제한적으로 사용 (남발하면 싸구려 톤)

## 2. 문화 앵커 교체

한국인만 아는 비유·고유명사는 **현지 시청자의 머릿속에 이미 있는 것**으로 교체한다.

- 크기·규모 비유: "63빌딩 5개 높이" → "nearly one and a half times the height of the Burj Khalifa" — **교체 후 수치를 검산**한다 (오차 ±10% 이내, 과장되면 다른 앵커로)
- "축구장 N개 넓이" → "N football fields"
- 한국 연예인·TV 프로그램·지명·기업 비유 → 국제 인지도 있는 대상으로 교체하거나 일반화. 교체 불가능하면 짧은 설명을 붙인다 ("Samsung, Korea's biggest company," 식 동격 구문)
- 고유명사 영문 표기는 국제 문헌 표준을 확인한다 (임의 로마자 표기 금지)

## 3. 숫자 · 단위 · 통화

- **통화·단위 기호 금지** — `$100` ✗ → `100 dollars` ✅. finalize.py가 특수문자(`$`·`€` 등)를 제거하므로 기호로 쓰면 의미가 유실된다. 반드시 단어로 쓴다
- 원화는 달러로 환산해 말한다 — 대략 환산 + about/nearly/over ("약 3조 원" → "about 2 billion dollars")
- 온도는 **Celsius를 명시** ("0.3 degrees Celsius" — 미국 시청자의 화씨 오독 방지)
- 단위: 과학·다큐·글로벌 주제는 미터법 유지, 미국 생활 소재는 관용 단위(miles, feet)가 자연스럽다 — 채널 타겟 기준으로 하나를 골라 일관 유지
- 숫자는 아라비아 표기 유지 (영어 TTS가 자연스럽게 발화한다)

## 4. TTS-safe English (6개조 보완)

`tts-rules.md` 6개조에 더해 영어 대본에서 추가로 지킬 것:

- 세미콜론(;) 금지 — 마침표로 문장을 분리
- `e.g.` `i.e.` `etc.` 금지 — for example / in other words / and more 로 풀어 쓴다
- `vs` → versus, `&` → and (기호·약어는 TTS 발음 사고의 원인)
- 아포스트로피는 허용 (don't, it's — finalize.py가 보존한다)

## 5. 산출물 언어

| 산출물 | 언어 |
|--------|------|
| `script.txt` / `output/01_대본.txt` | **영어** (본문 전체) |
| `output/02_썸네일제목.md` | 제목 후보·썸네일 문구 = **영어** / 설명·안내 줄 = 한국어 (학생이 읽는 부분) |
| `output/03_업로드정보.md` | 제목·설명글·태그·고정 댓글 전부 **영어** |
| 내부 문서 (concept·outline·patterns·review 등) | 한국어 유지 — 단, **대본에 들어갈 원문**(확정 제목·Hook·썸네일 텍스트)은 영어로 기재 |

- **썸네일 문구는 1~3단어** — 해외 지식·스토리 채널 썸네일은 "WW2" 두 단어로 충분하다. 한국식 문장형 글자폭탄은 해외에서 역효과
- ask 모드 전략 3안 제시: 설명은 한국어, 제목·Hook 원문은 영어로 나란히 표기

## 6. 분량 환산 (영어)

- **1분 ≈ 900자** (공백 포함 — 영어 나레이션 약 150단어/분 기준). 한국어 기본값 500자/분을 쓰지 않는다
- `profile.md`에 영어 실측 분당 글자수가 있으면 그 값이 우선
- 적용 지점: outline 목표 글자수 환산 · `finalize.py --cpm 900`
- 이 설치본의 `finalize.py`는 **개행 제외** 글자수로 분량을 계산한다(한국어 기본값 470자/분). 영어도 같은 기준이므로 900은 어림값으로 쓰고, 실측 분당 글자수가 쌓이면 profile.md에 적어 그 값을 우선한다

## 7. 검수 관점 (reviewer 추가 항목)

- 직역 냄새: 한국어 어순·만연체 흔적, 사전식 단어 선택(consider/utilize 남발)이 없는가
- 문화 앵커: 한국 로컬 비유가 그대로 남아 있지 않은가 / 교체된 앵커의 수치가 맞는가
- 기호: `$`·`%`·`;`·`e.g.` 등 TTS 사고 요소가 없는가 (`%`는 percent로 쓰는 것을 권장)
- 이 파일의 규칙 위반을 치명적 항목으로 분류한다
