# 완성본 아티팩트 발행 (DONE 단계)

`output/` 4종이 모두 저장된 뒤, **완성본을 한 페이지로 묶은 아티팩트를 반드시 발행한다.**
파일은 정본이고, 아티팩트는 **업로드 작업용 화면**이다 — 폴더를 열어 파일 4개를 따로 여는 대신
브라우저 한 장에서 대본·제목·설명글·타임스탬프를 순서대로 복사해 쓰기 위한 것이다.

> **정본은 어디까지나 `output/`의 파일이다.** 아티팩트와 파일 내용이 다르면 파일이 맞다.

---

## 입력

| 파일 | 쓰임 |
|------|------|
| `{P}/output/01_대본.txt` | 대본 전문 |
| `{P}/output/02_썸네일제목.md` | 제목 후보, 썸네일 문구, 이미지 프롬프트 |
| `{P}/output/03_업로드정보.md` | 제목·설명글·태그·고정 댓글 |
| `{P}/output/04_타임스탬프.txt` | 챕터 목록 |
| `channels/{채널}/config/settings.json` | 채널명 |
| `{P}/_script/artifact-url.txt` | (있으면) 이전에 발행한 아티팩트 URL — 같은 주소로 갱신 |

---

## 절차

1. **`artifact-design` 스킬을 먼저 로드한다.** (페이지 작성 규칙·테마·레이아웃 계약이 거기에 있다. 건너뛰지 않는다)
2. 위 4개 파일을 Read한다.
3. 아래 구성대로 HTML 한 장을 작성해 스크래치패드에 저장한다.
4. **`{P}/_script/artifact-url.txt`가 있으면** 그 URL로 `action: "read"` 후 같은 URL에 업데이트 발행한다.
   없으면 새로 발행하고, 결과 URL을 `{P}/_script/artifact-url.txt`에 **한 줄로** 저장한다.
   - 새 발행 시 `favicon`은 채널 성격에 맞는 이모지 1~2개
   - `title`은 `{확정 제목}` (프로젝트명이 아니라 영상 제목)
   - `description`은 한 문장 — `"{채널명} · {프로젝트명} 완성본"`
5. 발행된 링크를 DONE 보고에 포함한다.

> **실패해도 파이프라인을 중단하지 않는다.** 발행이 안 되면 그 사실만 알리고 파일 경로 안내로 마무리한다.

---

## 페이지 구성

**헤더**
- 영상 제목(확정 제목) · 채널명 · 프로젝트명
- 글자수 / 예상 분량 (finalize.py 기준) · 챕터 수

**본문 — 4개 섹션, 업로드 순서대로**

| # | 섹션 | 내용 | 복사 버튼 |
|---|------|------|-----------|
| 1 | **대본** | `01_대본.txt` 전문. 문단 사이 여백을 살려 읽히게 | 전문 복사 1개 |
| 2 | **썸네일 · 제목** | 제목 후보 목록, 썸네일 문구, 이미지 프롬프트 | 제목별 · 프롬프트별 각각 |
| 3 | **업로드 정보** | 제목 / 설명글 / 태그 / 고정 댓글 | **네 블록 각각 따로** (유튜브 입력칸이 나뉘어 있다) |
| 4 | **타임스탬프** | `04_타임스탬프.txt` 내용 그대로 | 전체 복사 1개 |

**설계 규칙**
- 섹션 전환은 탭이나 앵커 네비게이션으로 — 한 화면에 전부 쏟아붓지 않는다
- **복사 버튼이 이 페이지의 존재 이유다.** 복사 대상은 파일 원문 그대로여야 한다
  (마크다운 기호·머리말을 섞지 않는다. 설명글 복사 = 설명글 본문만)
- 대본은 기본 접힘 또는 별도 탭 — 첫 화면을 대본이 점령하지 않게 한다
- 타임스탬프 옆에 **"이 시각은 추정치입니다. 영상 완성 후 '타임스탬프 채워줘'로 실측 교체하세요"** 안내 1줄
- 한국어 본문이므로 줄바꿈·자간이 깨지지 않는 폰트 스택을 쓴다
- 라이트/다크 양쪽에서 읽히게 한다 (`artifact-design` 계약 준수)

---

## 갱신 시점

| 언제 | 무엇을 |
|------|--------|
| DONE (최초) | 새로 발행 → URL 저장 |
| "대본 다시 써줘" 등 재실행 후 DONE | **같은 URL로 갱신** (새 링크를 만들지 않는다) |
| timestamp 스킬이 실측 교체한 뒤 | 타임스탬프 섹션 갱신 + 추정치 안내 문구 제거 |
