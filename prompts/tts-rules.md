# TTS 대본 규칙 — 대본 작성 가이드 6개조

⚠ 절대 원칙: 원본 내용(문장, 단어 선택, 어순, 의미)은 절대 변경하지 않는다. **형식만** 정리한다.
- 문장을 다시 쓰거나, 표현을 바꾸거나, 요약하거나, 순서를 바꾸지 않는다.
- 아래 규칙에 해당하는 형식 요소만 제거/수정한다.

> finalize.py가 같은 6개조를 기계적으로 보정한 뒤 실행되는 **이중 점검**이다.
> 기계 보정이 놓친 것(문맥이 필요한 판단)만 손본다.

## 6개조 (튜브워커 "대본 작성 가이드" 기준)

1. **문장 끝 온점(.) 뒤 반드시 띄어쓰기** — `했습니다.그런데` → `했습니다. 그런데`
2. **따옴표("") 사용 금지** — 발견 시 제거 (자막 지저분 + 음성 변환 오류)
3. **문단 구분은 줄바꿈으로** — 전체가 한 덩어리면 의미 단위로 빈 줄을 삽입해 문단을 나눈다 (문장 변경 없이 줄바꿈만)
4. **특수문자(※, ★, → 등)·이모지 금지** — 제거
5. **URL·이메일 주소 직접 삽입 금지** — 제거 (출처 안내는 03_업로드정보.md의 🔗 주요 출처가 담당)
6. **단어 뒤 괄호 금지** — 괄호와 내용을 함께 제거 (`클로드(Claude)` ✗ → `클로드` ✅)

## 추가 점검

- 나레이션이 아닌 텍스트(제목, 장면번호, 연출지시) 제거
- 탭·보이지 않는 공백·`[pause]`류 태그 제거
- 숫자·단위는 소리 나는 대로 읽어도 어색하지 않은지 확인 (어색하면 보고만 — 임의 수정 금지)
