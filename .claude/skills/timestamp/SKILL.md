# Timestamp Skill

대본으로 만든 **완성 영상**을 전사해, 유튜브 설명글용 챕터 타임스탬프를 실측으로 만든다.
대본 제작 시점에는 영상이 없어 시간이 나올 수 없다 — 영상을 만든 뒤 이 스킬로 채운다.

## 절차

### 1. 입력 확인
- **영상 파일**: 경로가 없으면 요청한다 — "완성된 영상 파일을 채팅창에 드래그하거나 경로를 알려주세요" (mp4·mov 등 영상, mp3·m4a 등 오디오 모두 가능)
- **프로젝트**: `output/03_업로드정보.md`가 있는 프로젝트 중에서 결정. 지정이 없고 여러 개면 최근 수정된 프로젝트를 제안하고 확인받는다
- 해당 프로젝트에 `03_업로드정보.md`가 없으면 중단하고 안내: 대본 파이프라인을 먼저 완료해야 한다 ("이어서 해줘")

### 2. 음성 인식 도구 준비 (첫 1회)
`{VENV_PYTHON} -c "import faster_whisper"` 가 실패하면:
1. 한 줄 안내: "첫 사용이라 음성 인식 도구를 설치할게요 (1~2분 걸려요)"
2. `{VENV_PIP} install faster-whisper`
3. 설치 실패 시 중단하고 안내: "음성 인식 도구 설치에 실패했어요. '점검해줘' 리포트와 함께 문의해주세요."

### 3. 전사
```bash
{VENV_PYTHON} scripts/timestamp.py --video "{영상 경로}"
```
- 출력: `[MM:SS] 문장` 목록. 첫 실행은 모델(~150MB) 자동 다운로드가 추가된다
- 전사는 영상 길이의 절반 정도 걸릴 수 있다 — **timeout을 10분 이상**으로 잡는다

### 4. 챕터 시작 시각 결정
- `{P}/_script/outline.md`(파트 구조)와 `{P}/_script/script.txt`(정본 대본)를 읽는다
- 각 파트의 **시작 문장**을 전사에서 찾아 그 줄의 시각을 챕터 시작 시각으로 삼는다
  - 음성 인식 오타("이른바"→"이름바" 등)가 흔하다 — **발음이 비슷하면 같은 문장으로** 판단하고, 애매하면 그 파트의 다른 문장들로 교차 확인
- 유튜브 챕터 규칙 준수: **첫 챕터는 반드시 00:00** · 챕터 3개 이상 · 각 챕터 10초 이상 (짧은 파트는 이웃 파트와 합친다)
- 챕터 제목: outline의 파트 제목을 시청자용 문구로 다듬는다 (내부 용어·스포일러 금지, 짧고 궁금하게)

### 5. 03_업로드정보.md 갱신
`## 설명글`의 "📌 이 영상에서 다루는 내용" 섹션 **아래**에 삽입한다:

```
⏱ 타임스탬프
00:00 {챕터1 제목}
{MM:SS} {챕터2 제목}
...
```

- 이미 `⏱ 타임스탬프` 섹션이 있으면 통째로 교체한다
- 다른 섹션(제목·태그·고정 댓글 등)은 건드리지 않는다
- 문서 맨 아래의 "💡 타임스탬프" 안내 줄이 있으면 제거한다 (이미 완료됐으므로)

### 6. 보고
챕터 표(시각·제목)를 보여주고 마친다: "03_업로드정보.md 설명글에 반영했어요 — 그대로 복사해서 쓰시면 됩니다."
