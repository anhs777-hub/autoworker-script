# Reset Skill

도구 파일이 수정·삭제·오염됐을 때 **현재 버전 원본으로 되돌린다**. 재설치가 아니다 — **채널 설정·대본 작업물(channels/)·가상환경(.venv)은 그대로 남는다.** 1기의 "전부 지우고 다시 설치"(작업물 분실)를 대체한다.

**언제 쓰나**: "점검해줘"가 파일 무결성 ❌를 보고했을 때 / prompts·scripts를 잘못 건드려 동작이 이상할 때 / "갈아엎고 싶어요" 요청

## 절차

### 1. 현재 버전 확인
루트 `VERSION` 읽기 → `{cur}` (VERSION조차 없으면 Downloads에서 찾은 zip의 버전을 보여주고 그걸 기준으로 진행할지 확인)

### 2. 현재 버전 zip 찾기
- Downloads에서 `autoworker-script*.zip` 검색 (update 스킬 2번과 동일 명령)
- 각 zip 내부의 `autoworker-script/VERSION`을 읽어 **`{cur}`와 일치하는 zip** 선택
- 일치하는 zip이 없으면:
  - 더 높은 버전 zip만 있음 → "그건 초기화가 아니라 업데이트입니다. '업데이트해줘'를 실행하세요" (사용자가 원하면 바로 update 절차로 연결)
  - zip이 아예 없음 → "오토워커 2기 드라이브에서 현재 버전(v{cur}) zip을 다시 받아 Downloads에 두고, 다시 '초기화해줘' 해주세요"

### 3. 사용자 컨펌 (필수 — 생략 금지)
> `.claude/`·`prompts/`·`scripts/`·루트 문서를 v{cur} 원본으로 되돌립니다. 채널 설정·대본 작업물(channels/)은 모두 보존됩니다. 진행할까요?

### 4. 적용
update 스킬 5번과 **동일한 메커니즘** (zip 검증 → 임시 해제 → 폴더별 `_old_` 백업 후 교체 → 루트 5파일 + `channels/_template.json` 복사 → 정리 → `{VENV_PIP} install -U -r requirements.txt`). 전부 Python(os·shutil·zipfile).

### 5. 보고
- 원복된 범위 요약 + "채널·작업물은 건드리지 않았습니다" 명시
- 문제가 계속되면: "'점검해줘'를 실행해 결과를 캡처해서 조교에게 보내주세요"
- 마지막 줄 고정:
  > 초기화 완료. **새 세션에서 다시 시작하세요** (`/clear` 입력 후 "대본 만들어줘").

## 안전 규칙

- zip 검증(update 스킬 3번과 동일) 통과 전에는 아무것도 지우지 않는다
- `channels/` 하위는 `_template.json` 외 어떤 것도 덮어쓰거나 삭제하지 않는다 (지워진 예시 채널을 되살리지도 않는다 — 학생이 의도적으로 지웠을 수 있음)
- 교체 중 오류 → 즉시 멈추고 현재 상태 보고 + 조교 캡처 안내
