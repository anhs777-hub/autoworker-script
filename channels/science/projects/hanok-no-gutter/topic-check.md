# 소재 확인 — 빗물받이 없는 한옥 (2026-10-26)

출발: 10/26 지식 채널 효율 스캔 — 원리상자 「빗물받이 없는 한옥, 천년을 버틴 이유」(qujaqCmUy-k, 2026-10-08, 9.2만 / 구독 250, 367배)

## 판정: 조건부 — 원리 각도는 경쟁작이 이미 다 다룸. 질문을 「북촌 한옥엔 왜 홈통이 달렸나」로 뒤집으면 집필 가능, 다만 썸네일 첫 줄 상식이 약해 ABS 편보다 후순위

## 경쟁작 해부 (자막 확인)

- 원리상자 9.2만(10/8, 약 4분): 홈통 없는 지붕 → 봉정사 극락전 1363년 지붕 수리 기록 → 적 셋(쏟아지는 물·틈으로 스미는 물·벽 때리는 물) → 암키와 도랑 + 위가 아래를 덮는 겹침 → 수키와 + 홍두깨흙 → 기와 밑 적심·보토·강회 층이 「들어와도 버팀」(핵심 반전) → 긴 처마가 물을 멀리 던짐, 막새 → 대가는 무게·주기적 번와
- 알쓸신잡2 처마 곡선 37.7만: 처마는 기둥이 비 안 맞게, 추녀 들림은 햇빛으로 말리려고(위도 연결)
- 빈 곳: **근대 도시형 한옥에 홈통이 생긴 이유**, 낙숫물이 기단 밖에 떨어져야 해서 기단 폭이 정해진다는 설계 제약, 지역별 처마 길이(함경도 3자·제주 짧게)

## 이야기 뼈대 (차별안)

- 질문: 한옥은 원래 빗물받이 없이 수백 년을 버텼는데, 왜 서울 북촌 한옥 처마엔 초록 함석 홈통이 줄줄이 달렸을까
- 파트1 — 원래 한옥의 답: 처마 4자, 낙숫물은 반드시 기단 밖(기단 폭을 처마가 정함), 처마 깊이는 해 높이로 → 원리상자와 겹치는 기와·흙층은 한 단락으로 압축
- 파트2 — 지역별로 다른 처마: 함경도 3자·제주는 바람 때문에 짧게 → 처마는 기후에 맞춘 계산
- 파트3 — 1930년 전후 서울: 주택난 → 큰 필지 쪼개기 → 집이 어깨를 맞댐(정세권 등) → 함석이 싸지자 처마를 짧게 → 낙숫물이 기단 밖이 아니라 이웃 마당·벽으로 → 홈통
- 파트4 — 홈통의 대가: 막히면 역류해 목재가 썩는다(서울시 한옥지원센터) → 원래 한옥이 홈통을 안 단 이유가 거꾸로 보임
- 차별 2축 = **질문**(왜 홈통이 생겼나) + **한국 현장**(북촌·정세권·함석)

## 약점·주의

1. 썸네일 첫 줄 상식이 약함 — 「한옥엔 빗물받이가 없다」는 시청자가 평소 믿는 상식이 아니다(제주 생수 반대 사례와 같은 위험, pd-guide 7번 보완 후보). 안: 「{한옥}은 처마로 비를 막는데 / 왜 [북촌 한옥]엔 홈통이 달렸을까」
2. 「필지가 좁아져 낙숫물이 이웃집으로」는 사실 조합에서 나온 추론 — 직접 쓴 1차 문장은 아직 없음. 리서치에서 서울역사박물관 『북촌』 보고서·도시형 한옥 논문으로 확인 필요
3. 「천년을 버텼다」는 표현 금지 — 기와는 주기적으로 다시 이었다(봉정사도 수리 기록), 경쟁작 문장 차용 금지
4. 1자 = 약 30cm(영조척 30.8cm 등 자마다 다름) → 「4자, 약 1.2m」 표기 전 확인
5. 분량: 10분 채우려면 파트3 자료 보강 필수
