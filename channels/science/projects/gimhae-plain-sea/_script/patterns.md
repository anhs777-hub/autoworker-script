## 설계 원칙
1. 축: 「가야는 바닷가 나라였다」(흔한 답) → 「그런데 배가 나온 봉황동은 지금 바다에서 한참 떨어진 시내 한가운데」 → 빙하기 해수면이 훨씬 낮았고 강은 깊은 골짜기를 팠다 → 빙하가 녹아 바다가 골짜기로 밀려듦(해침, 약 7천 년 전 하구 골짜기 전체가 바다 영향) → 가야 사람이 본 바다(배·노·닻돌·창고·패총) → 낙동강 흙이 만을 메움(퇴적층 수십 m, 삼각주 전진) → 갈대밭 저습지 → 1910~30년대 수리조합·제방·수문 → 1976 공항·1987 하굿둑 → 지금도 무른 땅
2. 훅은 **질문형**(집에서 재현할 실물 시연 없음). 1번 썸네일 장면 = 훅 장면(초록 논 + 멀리 김해공항 + 땅 단면 속 배 부재·노·닻돌·굴 화석)
3. 중심 장면 = 「땅을 파면 바다가 나온다」 — 시추 코어 속 굴 화석·백합 화석 연대. 숫자는 이 장면과 해침 장면에 몰아 쓰고 앞뒤는 가볍게
4. 「바다였다」는 시간을 붙여 말한다 — 「언제 어디까지」가 불확실하면 확실한 범위(봉황동 남쪽이 물가)까지만, 지도는 「추정」
5. 금지 구역(사용자·topic-check 주의): 해수면 「지금보다 5~6m 높았다」, 배 크기 「30m×10m」 단정, 「퇴적 때문에 가야가 망했다」·멸망사, 오건환 1994 단정(「한 연구에서는」), 수문 연도(「1930년대」), 공항 자리 「가야 때 바다」 단정(「옛 만을 강이 메운 땅 위」), 해발 수치(1차 확인 전), 고김해만 해안선 단정, 비유(「땅의 나이테」「타임캡슐」류)

## 리텐션 장치 (profile 자산 — 유형·위치만)
- 오픈루프: 훅 「배가 왜 여기서 나왔나」 → 파트 1(해침)에서 반쯤 → 파트 2(가야 사람이 본 바다)에서 배·노·닻돌로 회수 → 「그럼 그 바다는 어디로 갔나」로 다시 열고 → 파트 3(퇴적)에서 완전 회수
- 반전 2단: ① 빙하기에는 오히려 바다가 지금보다 훨씬 멀었다(낙동강이 깊은 골짜기) ② 논이 된 건 강이 흙을 실어 와서만이 아니라, 사람이 둑과 수문으로 물을 막은 1930년대 이후의 일(지금 모습)
- 훅 「그런데」 회수: 봉황동 배 → 「처음에 말씀드린 봉황동 배도…」로 파트 2에서
- 기억 소환: 김해공항에서 비행기 탈 때 창밖 논 / 낙동강 하굿둑·을숙도 철새 소풍 / 부산 출장길 남해고속도로 — 1~2회, 실제 연결 확인된 것만
- 아는 한국 이름 재반등(pd-guide 6번): 김해공항·봉황동·대성동고분군·구포·을숙도·하굿둑·대저(대저 토마토)를 파트마다 하나씩
