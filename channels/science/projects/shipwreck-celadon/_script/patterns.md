## 경쟁 영상 · 수요 근거 (topic-check 사전 확인)
- 크랩 「주꾸미 덕에 찾은 고려시대 보물선」 116만, 5분 — **발견 일화** 중심
- 꼬꼬무 요약(신안선) 53만 — 발굴·도굴 **서사** 중심
- YTN 사이언스 「해저 유물이 부식되지 않은 이유」 1.1만, 2분 — 보존 원리 각도는 이것 하나(짧은 클립)
- → 일화·서사는 수요가 크게 확인됐지만 「왜 남았나」를 원리로 끝까지 판 영상 없음
- 차별 3축: **질문**(나무배가 왜 800년을 버텼나) + **대조 사례**(메리로즈 묻힌 쪽/드러난 쪽, 바사호) + **꺼낸 뒤 30년**(보존처리)
- 벤치마크 축(profile 「우리 땅·우리 일상의 숨은 이면」): 가 본 한국 장소(태안 안흥항·마도·신안 증도)의 「아래」에 감춰진 것

## 설계 원칙
1. 축: 「주꾸미의 뚜껑이 청자 접시」 → 「도자기는 원래 안 썩는다(흔한 답)」 → 「그런데 나무배와 볍씨까지 나왔다」 → 배좀벌레(바다 나무의 적) → 서해 펄 = 산소 차단 → 메리로즈·바사로 원리 두 방향 검증 → 도자기·나무·철 세 갈래 → 꺼낸 뒤가 더 위험(보존처리)
2. 훅은 **질문형**(실물 시연 불가). 1번 썸네일 장면 = 훅 장면(주꾸미 + 소라 껍데기 + 청자 접시 뚜껑)
3. **숫자·배 분리**: 고려청자·800년 = 태안선(12세기)·마도1호선(1208). 700년 = 신안선(1323, 원나라 배, 중국 도자기, 고려청자 7점). 한 문장에 섞지 않는다
4. 보존 원리 주축 = **산소 차단**. 저온은 보조, 수치 근거 없으면 말하지 않는다
5. 배좀벌레 = 「묻힌 나무에 새로 들어오지 못한다」(즉사·「펄 속에서 죽는다」 금지)
6. 금지 구역: 도굴·밀거래·밀수설·유물 가격·「수조 원」·「보물선」 금액 가치, 신안선 도후쿠지 설(확인 필요), 선체 34m

## 리텐션 장치 (profile 자산 — 유형·위치만)
- 오픈루프: 훅 「나무가 어떻게 800년을 버텼나」 → 파트 2(펄)에서 반쯤, 파트 3(대조 실험)에서 완전 회수
- 반전 2단: ① 도자기만이 아니라 나무·볍씨까지 남았다(훅) ② 꺼낸 순간부터가 더 위험하다(마지막 파트 — 박물관에서 더 빨리 늙는 철못)
- 훅 「그런데」 회수: 나무배·볍씨 → 펄 파트에서 「처음에 말씀드린 나무배가 남은 이유」로
- 클로징 연결: 펄은 「뚜껑」 — 비유 금지라 「주꾸미가 입구를 막은 것과 같은 원리」로 빗대지 않는다. 사실 대응(둘 다 입구·위를 막아 바깥 것이 못 들어오게 했다)만으로 잇거나 다른 연결을 쓴다
- 기억 소환: 서해 갯벌 체험·조개 캐기, 태안 안흥항·만리포 여행, 주꾸미 철 (1~2회)
