# 소재 확인 — 「공중화장실에 사람이 많으면 소변이 안 나오는 이유」 (2026-10-13, PD)

## 판정: 집필 가능 △ — 건강상식 규칙 위험이 가장 큰 소재 + 같은 제목 영상 있음

### 유튜브 (2026-10-13 검색)
- 한국어 같은 주제: 「주변에 사람이 있으면 오줌이 안나오는 이유」(은근한 잡다한 지식, 3분) 11.9만 — 마그마·총알에 이어 같은 채널 제목과 겹침
- 영어: SciShow 「Why Can't I Pee in Public Bathrooms?」 22.9만
- **검색 상위 대부분이 비뇨의학과·한의원 건강 채널**(「수줍은 방광 증후군 자가진단·해결법·치료법」) → 이 소재는 유튜브에서 의료·건강 콘텐츠로 묶이기 쉽다

### 채널 규칙 위험 (profile 「건강상식처럼 보이지 않기」)
- 진단명(수줍은 방광 증후군·배뇨 공포증)을 제목·썸네일·태그 전면에 쓰지 않는다
- 해결법·자가진단·치료·「병원에 가 보세요」 금지 → 몸 관련 소재라 실천 단락 자체를 넣지 않는다
- 원리·연구까지만: 「긴장하면 몸이 왜 소변을 붙잡는가」(자율신경), 실험 기록
- 전립선·중년 남성 배뇨 문제로 흐르면 바로 건강 채널이 된다 → 다루지 않는다

### 쓸 만한 재료 (리서치에서 1차 확인 필요)
- 1976년 미국 소변기 실험(미들미스트 외, 『성격·사회심리학회지』): 옆 소변기에 사람이 서 있을수록 소변이 나오기까지 더 오래 걸리고 보는 시간은 짧아졌다는 측정 — 칸막이 안 잠망경 관찰이라 연구 윤리 논란까지 붙은 유명 실험(수치·조건 확인 필요)
- 긴장·위협을 느끼면 교감신경이 방광을 붙잡는 근육을 조이는 원리
- 얼마나 흔한지(유병률 추정치는 출처마다 크게 다름 → 범위로만)
- 40~60대 기억 소환: 명절 귀성길 고속도로 휴게소 화장실 줄, 경기장·공연장 쉬는 시간
- 소변기 사이 칸막이·간격 설계 이야기(근거 있으면)
