# 공통 성공 패턴 — jeju-water-age

> 레퍼런스 4편: 004 한국백서 87.6만(구독자 471배) · 003 심층과학 55.7만(202배) · 002 스브스뉴스 24.1만(0.17배) · 001 과한리뷰 2.5만(2.9배)
> 인용은 분석 근거일 뿐 — outline·draft 반입 금지.

## 1. 반복되는 훅 공식

**관찰**
- 003(55.7만): 밟아 본 검은 돌 → 「우리는 ~라고 배웠습니다」 → 「그런데 아파트 30층쯤 내려가자」 모순 실물(조개). 공감 → 배운 것 뒤집기 → 장면.
- 004(87.6만): 아무도 모르는 낮은 언덕(48m) → 「그런데 깊이 뚫자」 330m. 작은 것 → 거대한 것 스케일 반전.
- 001: 질문 → 답(12,262m) → 「진짜 이상한 건 깊이가 아니라 시기」로 궁금증의 대상을 옮김.
- 002: 제목은 「오늘 ↔ 18년 전」 시간 대비로 끌었지만 훅은 해외 석회수 소문으로 시작 — 제목 약속을 받지 못함.
- 공통 역할: 시청자가 가 봤거나 손에 쥐어 본 것에서 출발 → 「그런데」 한 사실로 모순을 만들고 → 질문을 연다.

**설계 원칙**
1. 첫 장면은 시청자가 손에 쥐어 본 것(편의점 생수 한 병)으로 연다 — 가 본 장소·마셔 본 물이 고성과 두 편의 공통 출발점.
2. 「그런데」 사실은 시간 대비 하나: 손 안의 물 ↔ 31년(이전 18년). 숫자는 1~2개.
3. 답(31년)을 던진 뒤 궁금증의 대상을 「몇 년」에서 「어떻게 아나 / 왜 18년이 31년이 됐나」로 옮긴다(001 기법).
4. 훅에서 제목 숫자를 반드시 받는다(002 실패 회피).

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조: 003·001은 **수직 하강**(위 → 아래)으로 진행 위치를 알려 주며 내려간다. 004는 사례 나열(10개, 17분), 002는 브랜드 탐방.
- 고성과 둘(003·004) 모두 삼다수 나이를 **결과만** 말하고 측정법은 비웠다. 002는 「추정하기로」, 001은 「동위원소를 조사해 보니」 한 구절 — **4편 전부 「어떻게 재나」가 빈칸.**
- 숫자: 연구자·기관·연도를 붙여 말할 때 신뢰(003). 체감 환산(아파트 층수, 산방산, 1년 달력, 인생 시간)이 반복.
- 사례: 우연 발견 서사(003·004), 짧은 사람 일화(001 「26억 년 된 물을 맛봤다」).
- 비유는 레퍼 전부 다수 사용 — 우리 채널은 금지, 사실·환산으로 대체.
- 리텐션: 003의 장기 오픈루프(「재가 중요한 일을 한다 … 조금 뒤에」 → 10분 뒤 회수), 층 수를 세어 진행 위치 알림, 정직성 문장(「아직 뚫은 구멍은 없습니다」), 처음 장면으로 회귀(물 한 병).
- 위험: 001 댓글 「진도 나가기 어렵다」 — 원리 파트가 후반에 몰리면 이탈.

**설계 원칙**
1. 뼈대는 **빗방울을 따라 내려가는 하강 순서**(백록담 근처 고지대 → 현무암 틈 → 취수원) + **측정법 두 갈래(어디서 / 언제)**. 진행 위치를 말로 알려 준다.
2. 측정 원리(동위원소·삼중수소·프레온)는 영상 중반까지 끝내고, 후반은 비교·일상으로 돌린다.
3. 용어는 처음 나올 때 「쉽게 말하면요」로 한 번 풀고 바로 사실로 간다. 한 문장에 정보 하나.
4. 장기 오픈루프 1개: 훅의 「18년 → 31년」 차이를 파트 4에서 회수.
5. 정직성 문장: 「평균」의 뜻, 오차 범위, 연구 주체(제주개발공사·고려대)를 스스로 밝힌다 — 신뢰 + 광고 의심 차단.
6. 사례 6~7개, 각 사례에 역할 문장.

## 3. 감정 증폭 전략

**관찰**
- 가장 뜨거운 반응: 003 댓글 1위(17, 2위의 2배+) 「그래서 삼다수가 좋은 물이구나 32년전 빗물이 자연정화된 물」 — 18분 중 1분 미만 대목. 감정 = **경이 + 내 손의 물에 대한 친밀감.** 단, 해석이 「좋은 물」(수질·건강)로 흘렀다.
- 불신 반응: 004 「가짜뉴스」 「지하세계가 있나?」(판타지 과장), 002 「SBS도 가짜뉴스」 「삼다수 직원이세요?」(사실 오류·광고 의심).
- 체감 공감: 004의 「삐삐가 사라지고 아이들이 부모가 됐다」 인생 시간 환산.
- 자부심 정서(004)는 정치 분노로 번졌다.

**설계 원칙**
1. 목표 감정: **경이(내 손의 물이 내 인생만큼 오래 걸려 왔다)** → **납득(이렇게 쟀구나)**.
2. 경이는 초반 훅과 파트 2(빗방울의 길)에서, 납득의 쾌감은 파트 3~4(측정법·18→31)에서 터뜨린다.
3. 「좋은 물」 「자연정화」 해석은 대본에서 먼저 막는다 — 연구가 말한 것은 이동 시간이지 수질 평가가 아니다(건강상식·광고 규칙 동시 충족).
4. 과장·자부심·정치로 번질 문장 금지. 정직성 문장으로 불신 댓글을 선제 차단.
5. 감정 흐름: 의외(초반 20%) → 경이(중반 30%) → 납득(중반 30%) → 비교의 놀라움·여운(후반 20%).
