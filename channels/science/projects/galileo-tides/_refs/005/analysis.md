## 1. 주제 요약

달(과 태양)의 인력과 원심력이 합쳐진 기조력이 바닷물을 하루 두 번 밀었다 당겼다 하고, 달의 위상에 따라 대조·소조로 크기가 달라진다는 조석의 기본 원리를 4분 안에 교과서식으로 정리한 영상.

## 3. 훅 & 인트로 분석

**훅**
- 인용: 「바닷물이 빠져 드넓게 드러난 갯벌 … 우리나라의 전통적인 고기잡이 방식인 독살 … 물속에 잠겨있던 길이 드러난 순간 바다 위를 걷는 신기한 경험을 할 수 있습니다」
- 갯벌 체험·독살·바닷길(모세의 기적류) 세 장면을 영상으로 연달아 보여주는 Show Don't Tell형. 시청자가 가 봤거나 TV에서 본 우리 바다 장면이라 「내가 아는 그거」로 들어온다
- 효과: 「서로 달라 보이는 세 장면」을 먼저 깔고 공통 원인을 묻는 구조라, 짧은 영상치고 궁금증을 하나 거는 데는 성공한다

**인트로**
- 인용: 「다르게 보이는 3개의 현상에는 하나의 공통점이 있습니다 바로 달인데요 달이 바다와 어떻게 관계가 있는지 자세히 알아보겠습니다」
- 「공통점이 있습니다」로 오픈루프를 걸자마자 「바로 달인데요」로 즉시 닫는다. 답을 먼저 주고 「어떻게」만 남긴 약한 인트로다
- 흔한 답 → 부딪히는 사실 → 차이 질문이 없다. 「오늘은 ~ 알아보겠습니다」형 선언으로 바로 본문 진입

## 4. 본문 구조 분석

**전체 구조 요약**
1. 용어 정의: 밀물·썰물 → 만조·간조 → 조석 → 조차 (「서해안에서 8m 이상」)
2. 원인: 만유인력 + 공통 질량 중심 공전의 원심력 = 기조력
3. 왜 태양보다 달인가: 기조력은 질량에 비례, 거리 세제곱에 반비례 → 달이 훨씬 가까워서
4. 왜 하루 두 번인가: 달 쪽은 인력, 반대쪽은 원심력으로 물이 모여 만조 둘, 직각 방향은 간조 → 자전하며 하루 두 번
5. 대조·소조: 보름·그믐 때 일직선 → 기조력 최대(대조), 직각일 때 상쇄 → 최소(소조)
6. 서비스 안내: 국립해양조사원 140여 곳 조석 정보, 스마트 조석예보

- 패턴: 「현상 장면 → 용어 정의 → 원인 → 주기(하루) → 주기(한 달) → 기관 서비스 안내」. 교과서 단원 순서 그대로다

**전달 기법**
- 사례: 갯벌 체험, 독살, 바닷길 — 모두 한국 바다 장면
- 데이터: 「서해안에서 8m 이상」 「140여 곳」 두 개뿐
- 원리 설명: 「기조력은 천체의 질량에 비례하고 천체의 거리에 세제곱의 반비례」 — 공식을 말로만 전달
- 스토리텔링·인물·역사: 없다. 누가 언제 이걸 알아냈는지(뉴턴, 갈릴레이의 오답 등) 전혀 나오지 않는다

**리텐션 장치**
- 오픈루프(초반): 「다르게 보이는 3개의 현상에는 하나의 공통점이 있습니다」 — 곧바로 「바로 달인데요」로 회수
- 전환 멘트(초중반): 「그렇다면 바다의 규칙적인 운동인 밀물과 썰물은 어떻게 발생하는 걸까요」
- 전환 멘트(중반): 「달의 모습이 매일 조금씩 달라진다는 건 알고 계시죠」 — 대조·소조로 넘어가는 브릿지
- 확인 멘트(후반): 「이해가 되셨나요」 — 리텐션보다 수업 마무리 성격
- 패턴 인터럽트는 음악 삽입 정도. 4분 길이라 장치가 적어도 버틴다

**우리 영상에 중요한 내용 메모**
- 「하루 두 번」 설명이 「달 쪽은 인력, 반대쪽은 원심력」이라는 흔한 단순화다. 반대쪽이 왜 부푸는지(달 인력이 지구 중심보다 반대쪽 바다에 약하게 작용하는 차이)는 다루지 않는다. 우리 영상의 「한 단계 더」 재료이자, 이 설명을 그대로 옮기면 검수에서 짚일 수 있는 지점
- 「하루 두 번」이 정확히는 약 24시간 50분에 두 번이라 물때가 매일 늦어진다는 사실도 빠져 있다 — 시청자가 체감하는 「어제와 물때가 다르다」를 풀 기회

## 5. 감정 트리거

- **신기함·경이**: 「바다 위를 걷는 신기한 경험」, 제목·썸네일의 「마법」. 달이 수십만 km 밖에서 바다를 움직인다는 스케일감
- **친숙함(내 경험)**: 갯벌 체험·독살·바닷길 — 가족 나들이 기억을 건드린다
- **안심·실용**: 마지막 조석예보 안내로 「갯벌 갈 때 확인하면 안전하다」는 실용 감정
- 감정 흐름: 신기함(초반 장면) → 이해·정리(중반 원리) → 안심·실용(후반 서비스 안내)

## 6. 댓글 반응 분석

**시청자가 가장 강하게 반응한 포인트**
- 「마법」 「신기하다」 반복(1·2·9·10번) — 제목 문구를 그대로 받아 적은 댓글이 많다
- 갯벌 체험·조석예보 확인·안전(4·5·6·8·10번) — 영상 말미 서비스 안내에 반응
- 「어릴 때는 수업시간에 외우기만 해서 어렵게만 느껴졌는데 … 실생활에 접목해서 이해하니 훨씬 더 이해가 잘되는」(9번) — 교과서 기억 + 생활 장면 연결이 먹힌다는 직접 증거
- 주의: 댓글 대부분이 제목 복창·서비스 칭찬으로 비슷한 톤이라 기관 댓글 이벤트 참여 댓글일 가능성이 높다. 자발적 반응 지표로는 약하게 본다

**시청자 포지션**
- 아이와 갯벌 체험을 가는 부모, 학창 시절 「외우기만 했던」 조석을 다시 이해하고 싶은 성인

**우리 영상에서 반드시 다뤄야 할 포인트**
- 「학교에서 외우기만 했던 것」을 다시 이해시키는 프레임 — 지식대학 「배운 것 뒤집기」 문형(「우리는 ~라고 배웠습니다」)과 바로 맞물린다
- 갯벌·서해 물때처럼 40~60대가 실제로 겪은 장면(갯벌 체험, 바지락 캐기, 서해 바닷길)으로 열고 원리로 들어가기
- 이 영상이 비워 둔 것: 반대쪽 바다가 왜 부푸는지, 왜 매일 물때가 늦어지는지, 이 원리를 누가 어떻게 알아냈는지(갈릴레이의 오답 → 뉴턴). 댓글이 「원리를 정확하게 알아갈 수 있어서 유익」을 꼽은 만큼, 원리를 한 단계 더 정확히 푸는 게 차별점이다

## 7. 핵심 약속 역추적

**제목+썸네일이 약속한 것**
- "이 영상을 보면 달이 어떻게 밀물과 썰물을 만드는지 알게 될 것 같다"

**인트로에서 확인해준 것**
- 「달이 바다와 어떻게 관계가 있는지 자세히 알아보겠습니다」 — 제목의 약속과 일치. 더 구체화하거나 비틀지는 않았다

**본문이 실제로 전달한 것**
- 기조력의 정의, 달이 태양보다 영향이 큰 이유, 하루 두 번 만조·간조, 대조·소조까지 조석의 기본 개념 일체

**약속 이행 평가**
- 이행. 4분 안에 약속한 범위를 빠짐없이 다뤘다
- 오버딜리버리는 없다. 조석예보 서비스 안내가 덤이지만 기관 홍보 성격이다. 「반대쪽 만조」를 원심력 한 마디로 넘겨, 정말 궁금한 사람에게는 「왜 반대쪽도?」가 남는다 — 우리 영상이 이 빈칸을 채우면 같은 소재로 확실한 차별화가 된다
