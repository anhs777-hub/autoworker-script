# 공통 성공 패턴 — 고속도로 점선 편

> 레퍼 4편: 001 궁금한 건축 활주로 숫자(25.6만, 구독자 43배 — **유일한 성공작, 가중치 최상**) · 002 국토부 도로 숫자(20.6만, 기관 채널 평균 — 내용은 정책 홍보라 사실 재료 없음) · 003 YTN 사이언스 유리알(2만, 구독 대비 저조) · 004 1분 도시 점선 8m(439회 — **같은 소재 경쟁작**)
> 인용은 분석 근거일 뿐이다 — outline·draft 반입 금지.

## 1. 반복되는 훅 공식

**관찰**
- 001(최고 성과): 「창가 자리에서 이륙을 기다리다 활주로 바닥의 큰 숫자를 보신 적 있으신가요?」 — **봤지만 지나친 표시**를 겪은 장면으로 소환. 이어 이상한 점을 3겹으로 쌓고, 흔한 답(길이 3.3km?)을 꺼내 부정
- 002: 「지도로 볼 땐 안 멀어 보이는데 막상 가 보면 멀다」 — **보이는 것 vs 실제** 대비. 다만 답을 세 번째 문장에서 공개해 루프가 닫힘
- 004(같은 소재): 첫 10초에 「합치면 20m」를 공개 → 궁금증이 생기기 전에 닫힘. 「페인트가 아니라 자」라는 재정의는 은유라 약함
- 003: 훅 없음(도료 조건 나열로 시작)

**설계 원칙**
- 첫 문장은 시청자가 **실제로 본 장면**(고속도로 조수석·운전석에서 앞을 본 장면)으로 연다 — 001 방식, profile 훅 공식 1과 일치
- 흔한 답(「1~2m쯤」 「한 뼘」)을 꺼낸 뒤 「그런데 실제로는 8m」를 부딪히는 사실로 던진다. **8m는 훅에서 공개해도 된다** — 001도 답(방향)을 1분 안에 주고 「그럼 왜 그 방향?」으로 질문을 옮겼다. 우리 편의 진짜 질문은 「왜 짧아 보이나 / 왜 하필 8m인가」
- 004처럼 「20m 한 세트·100m = 다섯 개」를 훅에 쓰지 않는다(경쟁작이 이미 한 것, 안전거리 팁으로 읽힘)

## 2. 반복되는 본론 구조 & 전달 기법

**관찰 — 구조**
- 001: **사슬형** — 기호 해독 → 해독이 낳은 새 질문 → 원리 → 원리가 만든 규칙 → 설계 근거 → 예외 → 덤 반전(숫자가 바뀐다) → 일상 회수
- 004: 치수 공개 → 활용법 나열(거리·속도) → 실천 권유 — 원리 없는 생활 팁형
- 002·003: 목차·공정 견학형, 답이 중간에 묻힘

**관찰 — 전달 기법**
- 001은 시청자가 따라 할 수 있는 **계산 규칙**(방향 ÷ 10, 늘 18 차이)으로 「딱 맞아떨어지는」 쾌감을 줌 → 우리 편의 시속 100km ÷ 3.6 = 초속 27.8m, 8m ÷ 27.8 = 0.29초가 같은 역할
- 001의 통념 뒤집기는 단정 수위를 조절(「배운 게 완전히 틀린 건 아니다, 이유가 틀렸다」)
- 001 사례는 역할이 분명(김포 = 실제 기록, 제주 = 예외, 탬파 = 숫자가 바뀐다)

**관찰 — 리텐션**
- 001: 첫 답 직후 다음 질문을 건다 / 원리 파트가 길어질 때 「본 질문으로 돌아온다」 예고 / 정리 직전 마지막 반전
- 001 약점: 원리 파트가 길어 「제목은 건축, 내용은 유체역학」 반응

**설계 원칙**
- 뼈대는 001 사슬형: 8m 공개 → 왜 짧아 보이나(원근) → 달리면 더(속도) → 그럼 왜 하필 8m·12m인가 → **근거 기록이 없다**(2018 논문) → 실험해 보니 더 짧은 6m가 더 잘 보였다(권고) → 일상 회수
- 원근·속도 원리 파트는 끝마다 「그래서 점선이 ~」로 돌아오는 문장을 둔다(주제 이탈 방지)
- 계산은 「계산하면」으로 밝히고 가정값(눈높이 1.2m·차로 폭 3.6m)을 함께 말한다 — 시청자가 따라 할 수 있는 크기로
- 마지막 반전은 001의 「숫자가 바뀐다」 자리에 「더 짧은 게 더 잘 보였다」를 둔다

## 3. 감정 증폭 전략

**관찰**
- 001 댓글: 학교 통념 뒤집기(양력)가 압도적 반응, 「방향의 숫자였군요」 해소감, 지역 경험 연결(제주공항)
- 003 댓글: 「비 오는 밤엔 차선이 안 보인다」「누가 무슨 기준으로 정했나」 — 운전자 체감 불만과 기준 출처 궁금증
- 002 댓글: 「내가 다니는 길」에 닿을 때 반응
- 004 댓글: 연비·크루즈 질문 — 운전 팁 기대가 붙기 쉬운 소재

**설계 원칙**
- 목표 감정: **「매일 보던 게 이랬어?」 의외감 → 「아, 그래서」 해소 → 「정한 사람도 근거를 모른다고?」 두 번째 의외감**
- 감정 흐름: 의외감(훅·8m) 30% → 해소(원근·속도) 35% → 두 번째 의외(근거 미상·6m) 25% → 일상 회수 10%
- 경부·영동고속도로, 명절 귀성길·수학여행 버스 창밖처럼 40~60대가 실제로 본 장면을 1~2번 건다
- 운전 팁·안전거리는 감정 축으로 쓰지 않는다(004·국토부와 겹침)

- 고성과 비주얼: 묻는 대상(바닥 표시)이 **크게 실재**하고 내려다보기 시점
- 004는 점선을 짧은 토막으로만 그려 「짧아 보이지만 8m」 반전이 이미지에 없다 → 우리 편은 이 반전을 이미지로 보여 준다(운전석 시점 짧은 점선 vs 위에서 본 같은 점선 옆 승용차 두 대)

**제목**
- 001: 구체 지명 + 실제 숫자 + 「무슨 뜻일까?」 / 002: 숫자 기호 + 「무엇을 의미할까?」 / 004: 답을 다 공개한 선언형(실패)
- 숫자를 제목에 노출하는 것은 통했다(001·002). 답을 다 공개하는 선언형은 실패(004)

**설계 원칙**
- 썸네일 문구: 「{고속도로 점선}은 한 뼘처럼 보이는데 / 왜 실제로는 [8m]일까」 — 답(8m)을 드러내고 「왜」를 묻는 채널 성공 틀(산에서 소변 9.2%·다이아몬드 4.3%)
- 제목: 소재 이름(고속도로 점선) 맨 앞, 숫자 8m 노출, 질문형
- 이미지: 점선이 화면의 주인공, 내려다보기·스케일 대비로 8m를 체감시킨다. 비유 상징(혈관·자) 금지
- 역할 분담: 제목 = 질문(왜 짧아 보이나), 문구 = 보이는 것 vs 실제(한 뼘 vs 8m), 이미지 = 두 시점 대비

**인기 댓글 모음 (요지)**
- 001: 양력 원리 논쟁(좋아요 4~5, 통념 뒤집기 반응) / 「방향의 숫자였군요」(답 해소) / 제주공항 번호 변경 경험(지역 연결) / 「그래서 왜 방향을 알려줘야 하는데」(목적 미충족)
- 002: 「강원도, 경북 북부는 아직도 횡축 도로가 빈약」(38, 지역 민원)
- 003: 「일본은 고급형, 한국은 저가형이라 금방 지워진다」(11, 체감 불만 — 비교라 사용 안 함)
- 004: 연비·크루즈 질문(운전 팁 기대)

**구조 자산**
- 훅: `봤지만 지나친 표시 소환` — 이미 본 시각 기억을 꺼내 「그게 뭐였지?」를 만든다 (001)
- 훅: `흔한 답 꺼내 부정` — 시청자가 실제 떠올릴 답을 대본이 먼저 말하고 실제 숫자로 부딪힌다 (001)
- 구조: `사슬형 질문 이동` — 첫 답을 주자마자 그 답이 낳는 다음 질문을 건다 (001)
- 데이터: `따라 할 수 있는 계산` — 시청자가 머릿속으로 맞춰 볼 수 있는 나눗셈 하나로 해소감 (001)
- 리텐션: `본 질문 복귀 예고` — 원리 설명이 길어질 때 제목 대상으로 돌아온다고 미리 말한다 (001)
- 리텐션: `정리 직전 마지막 반전` — 다 끝난 듯할 때 새 사실 하나 (001)
- 감정: `기준 출처 궁금증` — 「누가 무슨 근거로 정했나」에 시청자가 반응 (003)
- 감정: `내가 다니는 길` — 구체 노선·지역에 닿을 때 반응 (002·001)
