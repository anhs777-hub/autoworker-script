# 공통 성공 패턴 — mosquito-vanish

> 레퍼런스 5편 교차 분석. 조회수 가중치: 001(29.6만) ≫ 005(4.2만) > 002(1.1만) > 003(4,777) > 004(3,141).
> 원문 인용은 근거용 — outline·draft 반입 금지.

## 1. 반복되는 훅 공식

**관찰**
- 5편 중 4편(001·002·003·004)이 **누구나 겪은 장면**(모기를 눈으로 쫓다가 놓침 / 불 켜면 사라짐)으로 연다. 장면을 그리는 강도가 조회수와 비례하지 않는다 — 001은 크레딧 고지로 시작하는데도 1위다. 001의 강점은 훅이 아니라 **인트로의 숫자 반박**(모기 시속 2.4~4.8km vs 눈 초당 700도)이다.
- 003은 3초 만에 결론(「반응 속도가 느려서」)을 공개해 끝까지 볼 이유를 없앴다 — 최저 성과(구독 대비 0.4%).
- 005는 시청자가 떠올릴 의심을 화면 속 사람이 먼저 던지고(「그게 비교가 돼?」), 곧바로 오해를 깬다.
- 공통 역할: 인트로에서 「모기가 빨라서」라는 상식을 **숫자로 먼저 부순다**(001·002). 이 부수기가 들어간 두 편이 모기 주제 상위 2편이다.

**설계 원칙**
1. 첫 10초는 **소리만 들어도 그려지는 장면**(불 끄고 누움 → 귓가 소리 → 불 켬 → 벽에 앉는 걸 봄 → 사라짐)으로 연다.
2. 30초 안에 「모기가 빨라서」를 **체감 비교 숫자 하나**로 부순다(걷는 속도와 비교). 답은 공개하지 않는다.
3. 인트로 끝에 **반전 예고 한 줄** — 「사라지는 순간은 모기가 날 때가 아니라 멈출 때」처럼 무엇이 뒤집히는지만 걸어 둔다(002·005 모두 이 예고가 없어 초반이 늘어졌다).

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조: 001 = 상식 반박 → 요인 3개 나열 → 종합 → 팁. 002 = 모기가 특별한가(가설) → 특별함 확인 → 그런데 느리다 → 원인은 내 눈·뇌. 005 = 눈은 카메라 → 한계 폭로(중심와·고릴라) → 뇌의 편집 폭로(단속 억제·맹점) 순으로 원인을 **대상에서 보는 사람 쪽으로 옮기는 반전**.
- 001의 약점: 「속도 문제 아니다」라고 해 놓고 요인①에서 다시 「순간 속도가 빠르다」로 돌아가 자기모순, 결론이 「여러 요인이 겹침」으로 흐려짐.
- 숫자: 002·003 모두 **속도 × 지연 시간 = 거리(cm)**로 바꿔 체감시킨다(0.1초 → 10cm). 소리 매체에 가장 잘 먹히는 방식.
- 비유: 005의 「주변은 덩어리로만 보인다」 「조각 사진 이어 붙이기」 「흔들린 장면 잘라내기」가 원리를 처음 잡는 비유로 가장 강하다. 001·002는 비유가 거의 없다.
- 체험: 005의 거울 실험(내 눈이 움직이는 걸 나는 못 본다)·맹점 카드, 002·003의 자 떨어뜨리기 — **시청자가 지금 따라 할 수 있는 실험**이 반전의 증거 역할.
- 리텐션: 반전 직후 「빠르지 않다면 도대체 왜?」로 질문을 되살리는 오픈루프(001·002), 「그럼 해결책은?」으로 마지막 팁까지 잡기(001).

**설계 원칙**
1. 뼈대: **뻔한 답 부수기(속도·반응) → 원인을 모기에서 내 눈으로 옮기는 반전 → 원리 3개를 조건으로 → 파생 질문(모기가 나를 알아채나) → 오늘 밤 팁.**
2. 원리 3개는 나열이 아니라 **한 장면 안의 연속**으로 묶는다: 모기가 선명 범위를 벗어남 → 시선을 옮기는 순간 → 착지해 멈춤. 「여러 요인이 겹쳤다」로 끝내지 않는다.
3. 원리마다 **일상 비유 1개 + 체감 숫자 1개 + 근거(연구팀·연도) 1개**. 결론 문장은 비유가 아닌 실제 조건으로(채널 규칙).
4. 체험 1개를 반전 직전에 둔다(거울로 내 눈 움직임 보기 등). 지시문은 소리만으로 따라 할 수 있게 짧게.
5. 「그런데 진짜 이상한 부분은요」는 「원인이 모기가 아니라 내 쪽」 반전 직전에 1회.

## 3. 감정 증폭 전략

**관찰**
- 댓글 1순위 감정: **공감형 짜증**(002: 모기 소리 6, 귀·발목 물림 2 / 게임 드립 10) — 영상 내용보다 모기 자체에 감정을 쏟는다.
- 2순위: **「처음 본다」 신기함**(002: 날갯짓 분석 13 — 최다), **내 몸에 속았다는 놀라움**(005: 「당연한 게 없구나」).
- 3순위: **생활 적용**(002: 「멀리 보고 잡아야겠네」, 005: 「그래서 파리를 뒤에서 잡을래도 도망가는구나」).
- **미해결 질문**: 002 댓글 1위 「잡으려고 생각하면 사라지는 이유가 알고픈 건데, 텔레파시라도 있나?」 — 모기가 나를 알아채고 피하는지는 5편 모두 답하지 않았다.
- 001은 댓글이 내용이 아니라 맞춤법(좇다/쫓다)·도서 홍보에 쏠림 — 「이거 알아?」 한 방이 없었다.

**설계 원칙**
1. 감정 흐름: 짜증 공감(0~1분) → 의외성(속도 반전, 1~2분) → 속았다는 놀라움(원리, 2~6분 절정) → 호기심 재점화(텔레파시 질문, 6~8분) → 실천 의지(8~10분).
2. 「보이는 모기는 이미 지나간 자리」처럼 **남에게 말하고 싶은 문장**을 원리 파트에 최소 1개 심는다.
3. 002 댓글 1위 질문을 「한 단계 더」 파트의 질문으로 그대로 쓴다(검증된 미해결 궁금증).
