## 터진 이유
1. **반박형 인용 제목**: 「"유럽 기술 베끼지 않았습니다"」 — 유럽 방식을 거절했다는 대비가 따옴표 한 줄에 들어 있음
2. **체감 숫자 2개**: 41만 평(축구장 190개), 40조 원
3. **썸네일**: 매립 공사 항공 실사 + 노랑/시안 2줄(「41만 평 바다를 메워 / 포스코 독자 수소제철」) + 좌상단 「40조 원을 건다고?!」
4. **서사 뼈대**: 1973 영일만 첫 쇳물(「실패하면 영일만에 빠져 죽자」) → 2021 1고로 종풍 → 탄소국경세 위기 → 유럽식 펠릿 함정 거절 → FINEX 30년 → 하이렉스 → 다시 영일만을 메운다(수미상관)
5. **과학 설명이 드라마의 반전 역할**: 가루는 바람에 날아간다 → 「그럼 날린 채로 반응시키자」(유동환원로), 수소 반응은 열을 빼앗아 로가 식는다(흡열) → 4단 직렬로 해결

## 확장 소재 — reason-economy(세상의 이유) 1순위 유형
| 소재 | 대비축 | 비고 |
|---|---|---|
| **유럽 수소제철이 멈춘 사이 포스코는 바다를 메웠다** | 해외 몰락(유럽 수소제철 프로젝트 철회·지연) → 한국 가속 | 경쟁 영상 「유럽이 줄줄이 멈춘 사이 일정을 앞당긴 이유」(코어포인트, 49회)가 이미 앵글을 잡았으나 포장 실패. **유럽 쪽 철회 사례(아르셀로미탈 독일 DRI 계획 등)는 리서치로 확인 필요** |
| 일본은 왜 수소제철에서 늦었나 | 일본 고로 vs 포스코 유동환원 | 「일본은 포기했다」류 제목이 이미 여러 개. 사실관계가 과장된 경우가 많아 검증 필수 |
| 1973 첫 쇳물 — 세계은행이 거절한 제철소 | 역사형 | 정치 댓글 많음 → profile 규칙 7(사실만) 적용 |

## 확장 소재 — science 채널(엉뚱한 질문)용
영상 속 과학 원리를 「엉뚱한 질문」으로 바꾼 것:
| 질문 | 연결되는 원리 |
|---|---|
| **내 몸의 철을 다 모으면 못 하나를 만들 수 있을까?** | 성인 몸속 철 약 3~4g(확인 필요) · 헤모글로빈 · 철이 산소를 붙잡는 성질 = 제철이 산소를 떼어내는 이유 |
| 밀가루 공장은 왜 폭발할까? | 가루가 되면 표면적이 폭증 → 반응이 폭발적으로 빨라짐(유동환원로가 몇 초 만에 반응하는 원리와 같음) |
| 철은 왜 녹이 슬까? 금은 왜 안 슬까? | 철광석 = 산소와 붙은 철. 녹은 철이 원래 상태로 돌아가려는 것 |
| 수소를 태우면 왜 물만 나올까? | 수소제철 굴뚝에서 수증기만 나오는 이유 |
| 용광로는 왜 한 번 켜면 50년 동안 못 끌까? | 포항 1고로 48년 6개월 · 식으면 쇳물이 굳어 로가 망가짐(확인 필요) |
| 지구 한가운데는 왜 철로 차 있을까? | 무거운 철이 가라앉음 · 지구 자기장 |

→ science 첫 편 후보 추천: **「내 몸의 철을 다 모으면 못 하나를 만들 수 있을까?」** — 몸 관점, 한 줄 질문, 답이 숫자로 딱 떨어짐
