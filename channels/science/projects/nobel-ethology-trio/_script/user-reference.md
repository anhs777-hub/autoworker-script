# 사용자 제공 레퍼런스 (2026-10-11)

> 출처 표기: 책 《과학자의 흑역사》(양젠예 저) 제8장 「노벨상 수상자 세 사람의 이상한 법정 다툼」을 요약한 글(사용자 붙여넣기).
> ⚠️ 이 요약은 검증 전 자료다. 특히 「판사·검사·변호사 역할을 정한 공개 청문회」 「세 사람이 법정에서 원고·피고처럼 다퉜다」는 서술은 1차 기록으로 확인되기 전까지 대본에 쓰지 않는다. 사용자 지시: 책의 제목·구성은 따라 하지 말고 실제 있었던 사실만으로 10분 지식 대본, 마지막에 교훈.

- 주인공: 1973년 노벨 생리의학상 공동 수상 — 카를 폰 프리슈(꿀벌 춤), 콘라트 로렌츠(각인), 니콜라스 틴베르헌(갈매기 행동)
- 요약 글의 주장: 본능·유전 vs 환경·학습(미국 행동주의) 논쟁 → 「법정 공방 형식의 토론」 → 세 사람은 사적으로 친한 동료 → 치열한 비판이 이론을 완성시켰다는 교훈
