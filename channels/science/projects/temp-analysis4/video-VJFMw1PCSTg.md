# 영상 분석 — 울산 시내 땅 밑에서 바다가 나왔습니다 (VJFMw1PCSTg)

- 채널: 심층과학 (구독 3,360) · 2026-10-28 업로드 · 18분 31초 · 조회 4,803 (이틀째, 1.4배) · 좋아요 23 · 댓글 1
- 채널 평소 성적: 같은 채널 최근 14편 중 12편이 2.4만~75.8만 (구독 대비 7~225배). **이 편은 채널 안에서 하위권**
- 성격: AI 내레이션 + AI 재현 이미지, 참고자료 24건 나열 — 우리 파이프라인과 거의 같은 제작 방식의 「땅 밑」 전문 경쟁 채널

## 1. 훅·구조
- 훅(0:00~1:10): 「아파트 단지 강가 흙에서 바다가 나왔다」 → 상식 뒤집기(울산 바다는 동쪽 끝) → 「발밑이 고래가 드나들던 바다」 → 질문 3개(어디까지·누가 지웠나·고래 그림은 왜 줄었나)
- 본문 9챕터: 규조 증거 → 좁은 만 두 개(울산만·굴화) → 최대 진입 구영리 6천 년 전 → 범인은 해수면이 아니라 강(물받침 비유) → 신석기 마을·고래잡이 → 암각화 312점 중 고래 비율 → 바다 시계 vs 바위 시계 → 해발 53~57m vs 사연댐 만수위 60m → 수문 공사(2030)
- 장치: 질문 → 답을 챕터마다 반복, 「범인」 프레임, 시민 생활 공간(삼산동 백화점·터미널, 십리대숲) 앵커, 구독 요청 2회

## 2. 왜 안 터졌나 (채널 히트작과 비교)
| | 이 편 | 채널 히트작 (동해 75.8만·제주 56만·한탄강 33만·서해 13만) |
|---|---|---|
| 무대 | 울산 한 도시 (지역 시청자만 자기 일) | 한반도·동해·제주 — 누구나 아는 땅 |
| 증거 | 규조 껍데기 (눈에 안 보임) | 용암 강·바다 바닥·한라산 밑 (그림이 됨) |
| 감정 | 「내 발밑이 바다였다」 — 울산 시민 한정 | 「지도가 통째로 바뀐다」 — 전 국민 |
| 축 | 옛 바다 + 암각화 + 댐 침수, 셋으로 갈라짐 | 한 축 |
- 제목 공식 「○○ 땅 밑에서 바다가 나왔습니다」는 강원도 탄광 편(9.8만)과 같은 틀 → 반복 피로 + 「울산」이 범위를 좁힘
- 반구대 침수(해발 53~57m vs 만수위 60m)가 이 편에서 가장 단단한 숫자인데 13분 이후에야 나옴

## 3. 키워드
울산 옛바다 · 태화강 · 반구대 암각화(반구천의 암각화) · 사연댐 · 침수 · 해안선 변화 · 규조 · 홀로세 해수면 · 「○○은 원래 바다였다」

## 4. 확장 소재 (지식대학 형식)
| # | 소재 | 썸네일 공식 | 근거 / 경쟁 |
|---|---|---|---|
| 1 | **반구대 암각화 침수** — 세계유산이 해마다 물에 잠기는 이유 | 「세계유산인데 / 왜 해마다 물에 잠길까」 | 해발 53~57m vs 만수위 60m, 연 150일 → 한 달, 수문 2030. 경쟁은 2분 뉴스 클립뿐 (최대 1.6만 KBS 2013 다큐) — **장편 빈자리** |
| 2 | **김해평야는 바다였다** (고김해만) — 가야가 바다 왕국이던 이유 | 「논 한가운데인데 / 왜 배가 나올까」 | 봉황동 선착장·배 부재 출토, 낙동강 퇴적. 경쟁: 설민석 12.4만(역사 각도), 과학 각도 장편 없음 |
| 3 | **강이 만든 땅** — 부산 강서·을숙도는 몇 천 년 된 땅인가 | 「부산 땅인데 / 왜 7천 년 전엔 바다였을까」 | 낙동강 삼각주, 2와 묶거나 분리. 경쟁 약함 |
| 4 | **영산강 내해** — 나주까지 바다가 들어왔다 | 「내륙 도시인데 / 왜 포구가 있었을까」 | 영산포 등대·영산호 하굿둑. 조건부(자료 확인 필요) |
| 5 | **강화평야는 바다였다** (간척) | 「섬인데 / 왜 평야가 넓을까」 | KBS 역사스페셜 77만 — 수요 확인, 과학(간척·퇴적) 각도는 비어 있음 |

- 채널 전체 신호: 「한반도 지도가 통째로 바뀐다」(동해·서해·제주 밑) 축이 가장 셈 → 지식대학도 지역 하나보다 **전국 단위 / 누구나 가 본 곳**으로 잡을 것
- 1번은 「땅 밑」 감정이 아니라 「멀쩡한 국보가 왜」 감정 — 숫자 대비(53·57·60)가 썸네일 한 장으로 설명됨
- 자사 편과 겹침 없음 (반구대·태화강·김해 관련 프로젝트 없음)

## 5. 경쟁 검색 요약
- 「반구대 암각화」: KBS 역사스페셜 39.7만, EBS 10.7만, 캐릭터 채널 8.2만 — 그림 해석 위주, 침수 과학은 없음
- 「반구대 암각화 침수」: 1.6만이 최대, 나머지 수백 회 뉴스 — 비어 있음
- 「울산 옛바다」·「태화강 바다」: 이 영상 외 장편 없음
- 「김해평야 바다였다」: 설민석 12.4만 단독
- 「평야가 바다였다」: 지식해적단 199만(해수면), KBS 강화평야 77만 — 「원래 바다였다」 프레임 자체는 수요 큼
