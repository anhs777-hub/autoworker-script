# 공통 성공 패턴 — 야외에서 볼일을 보면 환경에 해로울까?

> 레퍼런스 5편. 조회수 순: 004 Reactions(120.7만) ≫ 001 14F(4.1만) · 002 LNT 가이드(2.6만) · 003 YTN(1.5만) ≫ 005 NWSI 웨비나(89).
> **터진 영상은 004 하나뿐이다.** 나머지는 구독자 대비 0.3~1.7%라 「무엇이 먹혔나」보다 「무엇이 비었나」의 근거로 쓴다. 005는 1차 연구 수치용 자료다.

## 1. 반복되는 훅 공식

**관찰**
- 004(최고 조회): 해변 → 화장실이 멀다 → 발에 모래가 묻는다, 겪는 순서대로 장면을 깐 뒤 시청자가 속으로만 했던 생각을 화자가 먼저 말한다(「그냥 바다에서 하면 되잖아?」). 민망한 행동을 대신 고백해 주는 **공범 만들기형 공감 훅**이다.
- 002: 「산을 좋아하시는 분들이라면 한 번쯤은 경험」 — 같은 공감형인데 인사·일반론이 앞에 붙어 15초 늦게 나온다. 숫자·의외성이 없어 당기는 힘이 약하다.
- 001·003: 뉴스 리드형. 장면(칸막이 없는 소변기)이나 재난(빙하 붕괴)을 던지고 바로 사실로 들어간다. 질문이 없어 궁금증이 약하다.
- 004의 인트로는 결론(괜찮다)을 15초 안에 준다. 2분 50초 영상이라 가능했다. 9분 영상에서는 이탈을 부른다.

**설계 원칙**
1. 첫 문장은 40~60대가 실제로 겪은 장면 — 등산 중 화장실이 먼 순간 — 을 겪는 순서대로 그린다(채널 공식 「~해 보신 적 있으신가요?」와 일치).
2. 「누구나 해 봤지만 말 안 하는 행동」을 화자가 먼저 꺼내 민망함을 웃음으로 바꾼다. 죄책감을 찌르지 않는다.
3. 결론(괜찮다/해롭다)을 훅에서 주지 않는다. **「괜찮을 것 같은데, 숫자는 다르게 말한다」**까지만 열고, 숫자 받아 주기 → 주제 선언으로 닫는다.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조
  - 004: 결론 → 근거 ① 성분 ② 희석 ③ 오히려 양분 ④ 자연계 비교 → 예외 단서(작은 수역·보호구역·수영장). 예외의 **이유는 설명하지 않았다.**
  - 002: 예방 → 장소 기준 → 캣홀 절차 → 휴지 회수 → 해외 사례. How만 있고 Why가 없다.
  - 003: 숫자 누적(연료 → 소변 → 합계) → 위성 검증 → 과장 누르기 → 대안.
  - 005: 문제 → 원인(고산의 얇은 흙·인파) → 실험 → 결과.
  - 001: 제품 소개(소변 = 비료) 후 주제 이탈.
- 공통 빈칸: **「왜 장소에 따라 답이 달라지는가」**를 설명한 영상이 없다. 004는 바다만, 002는 방법만, 003은 빙하만, 001은 비료화만 다룬다. 소변과 대변을 나눠 비교한 영상도 없다.
- 전달 기법
  - 숫자: 004·003·005 모두 숫자가 주 무기. 004는 「대상끼리의 수치 비교」(사람 소변 vs 바닷물, 사람 vs 참고래)로 비유 없이 체감을 만든다. 003은 「올림픽 수영장 1개 분량」 같은 실물 부피 환산을 쓴다.
  - 사례: 장소 고유명사(에베레스트 베이스캠프, 엘버트산, 휘트니산, 암스테르담)가 신뢰를 만든다.
  - 비유: 거의 없다(001 외형 묘사뿐). 채널 비유 금지 규칙과 충돌할 재료가 적다.
- 리텐션 장치
  - 004: 근거 하나 끝날 때마다 「여기까진 괜찮다」 중간 확인 → 끝에 예외로 뒤집기.
  - 002: 「~보다 더 중요한 게 있어요」 오픈루프(영상에서 가장 강한 장치).
  - 003: 숫자가 이어지다 「특히 눈길을 끈 건 소변」으로 화제 전환.
  - 005: 「모두가 놀랐다」 의외성 → 수치 공개.

**설계 원칙**
1. 뼈대: **뻔한 답(괜찮다: 물·희석·비료) → 그런데 조건이 붙는다 → 소변 vs 대변 → 장소·인원이 바뀌면 → 실천 방법.** 004의 「괜찮다 + 예외」를 확장하되 예외의 이유를 끝까지 설명하는 것이 차별점.
2. 숫자는 「대상끼리 비교」로 쓴다(1인 하루 소변량 vs 몰리는 장소의 총량, 소변 vs 대변의 병원균). 비유로 체감시키지 않는다.
3. 파트 전환 직전에 「~보다 더 큰 문제가 있습니다」 류 오픈루프를 둔다(002 장치 유형).
4. 소변 → 대변 → 휴지 순으로 스테이크를 올린다(댓글이 가장 반응한 건 휴지였다 — 002).

## 3. 감정 증폭 전략

**관찰**
- 댓글 1위 감정 유형
  - 004: **자기 경험담 + 웃음**(「바다에 누다가 파도가 입으로…」 98) — 정보보다 고백에 반응.
  - 001: 실용 수긍(88) + 한국 화장실 비교(60) + 공중화장실 경험담.
  - 002: 「아무도 말 안 하던 주제」(15·12) + 산의 휴지 쓰레기 불쾌감(12).
  - 003: 인간 책임론(합 20) + 소변 양 우스개.
- 감정 순위: ① 민망함을 덜어 주는 웃음·공감 ② 「그거 나도 봤어」 불쾌 경험(휴지·지린내) ③ 의외의 숫자 놀라움 ④ 책임감.
- 감정 흐름 공통: 민망한 공감(초반) → 숫자 놀라움(중반) → 조건부 경각심 또는 안도(후반).

**설계 원칙**
- 초반 30%: 민망한 공감 + 「생각보다 괜찮네?」 안도.
- 중반 40%: 「그런데」 조건이 붙는 놀라움 — 대변의 병원균, 몰리는 장소의 누적량.
- 후반 30%: 휴지 같은 「내가 본 그것」 연결 → 해 볼 수 있는 방법으로 안도하며 닫기.
- 공포·혐오 묘사는 쓰지 않는다(thumbnail-strategy 감정 노트와 일치).

**구조 자산**
- 훅 기법
  - `공범 만들기 공감 훅` — 시청자가 속으로 했던 핑계를 화자가 먼저 말해 민망함을 웃음으로 바꾼다 (004)
  - `겪는 순서 장면 묘사` — 장소 → 불편 → 유혹 순으로 깔아 「내 얘기」로 만든다 (004·002)
- 리텐션 장치 유형
  - `근거별 중간 확인 → 끝에서 예외로 뒤집기` — 안도를 쌓다 조건을 붙여 긴장을 되살린다 (004)
  - `더 중요한 게 있다 오픈루프` — 다음 항목의 가치를 예고해 이탈을 막는다 (002)
  - `화제 전환형 패턴 인터럽트` — 숫자 행렬 중 의외의 대상으로 튼다 (003)
  - `과장 스스로 누르기` — 「근본 원인은 따로」로 신뢰를 지킨다 (003)
- 감정 트리거 유형
  - `민망한 금기 해소` — 아무도 말 안 하던 주제를 꺼내 주는 것 자체가 가치 (002·004)
  - `내가 본 그것` — 산의 휴지, 지린내 같은 실제 목격과 연결 (002·001)
- 데이터 제시 기법
  - `대상끼리 수치 비교` — 비유 없이 크기를 체감시킨다 (004)
  - `실물 부피 환산` — 톤 단위를 실제 시설 부피로 (003)
  - `누적 계산` — 한 사람은 작아도 인원 × 기간으로 커진다 (003·005)
