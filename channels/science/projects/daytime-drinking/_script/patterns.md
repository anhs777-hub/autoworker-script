# 공통 성공 패턴 — 「낮술을 마시면 왜 빨리 취할까?」 (지식대학, 2026-10-08)

> 레퍼런스 5편: 003 사물궁이 「술 마신 다음 날 일찍 깨는」 96.6만 / 004 사물궁이 「구토·홍조」 19.4만 / 001 은근한 잡다한 지식 「낮술」 3.7만 / 002 굿라이프 「낮술」 3천 / 005 김의사박사 「천천히 마시면」 1.7천
> 조회수 가중: 003·004(같은 채널의 「술 궁금증」 질문형)가 검증 신호. 「낮술」을 정면으로 다룬 001·002는 터지지 않았다 — **둘 다 「과학적 근거는 없다」로 허탈하게 끝났다.**
> 인용 규칙: 아래 인용은 근거일 뿐 outline·draft에 옮기지 않는다.

## 1. 반복되는 훅 공식

**관찰**
- 003(96.6만): 통념(「술을 마시면 잠이 잘 온다」)을 먼저 인정 → 경험(「다음 날 일찍 깬다」)과 부딪힘 → 「단순 우연일까요」. 두 문장 만에 모순을 세운다.
- 004(19.4만): 「술자리가 종종 있을 겁니다」 공감 + 통계(1인당 소주 22병)로 「누구나」를 묶는다. 장면이 없어 약하다.
- 001(3.7만): 사전적 정의로 시작해 공감이 늦게 온다. 실질 훅은 「이상하게 낮에 마시면 빨리 취하는 느낌」 + 「부모도 못 알아본다」 속담.
- 002(3천): 「오늘은 방학입니다」 공지형. 첫 5초에 「낮술」이 없다.
- 005(1.7천): 「주량보다 훨씬 전에 뻗은 경험 있으신가요?」 — 경험 질문형(우리 공식과 같음)이나 장면 1문장뿐.
- 공통: 터진 영상은 **통념 vs 체감의 모순**을 첫 문장 근처에 둔다. 낮술 영상 둘은 모순을 세우지 않았다.

**설계 원칙**
- 첫 문장은 profile 공식(「~해 보신 적 있으신가요?」)으로, **평소보다 덜 마셨는데 낮에 더 취한 장면**을 묻는다. 「부모도 못 알아본다」 속담은 장면 뒤 한 줄로만(유래 확인 범위).
- 장면 직후 근거 숫자 1개 → 「숫자 받아 주기」(profile 2-1) → 주제 선언. 숫자 후보: 낮/밤 혈중농도를 직접 잰 연구가 있으면 그 결과, 없으면 「빈속이면 최고 혈중농도가 ○배」 같은 실측.
- **「느낌」과 「실제 측정」을 훅에서부터 나눈다** — 001·002가 섞어서 실패했다.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조:
  - 003: 통념 → 기초 원리(알코올 대사) → 「처음엔 맞다」 인정 → 방해 요인 3개 → 핵심 반전(적응된 수면 주기) → 연구 근거(헨리포드병원) → 권고
  - 004: 분해 경로 → 증상 1 → 증상 2 → 반전 한 줄 → 「그럼 사람마다는?」 파생 질문
  - 001·002: 가설 나열 → 「근거 없음」 자기 부정으로 끝. **답을 주지 않은 구조가 둘 다 실패**
  - 005: 가상 계산 반복(같은 계산 3번) → 숫자 피로
- 전달 기법:
  - 숫자: 003은 숫자 0, 004는 도입 통계만, 005는 가상 숫자. **실측 수치를 쓴 레퍼런스가 없다** = 우리 차별점
  - 생활 연결이 가장 체감됨: 003 「평소 코 안 고는 사람도 술 마시면 코를 곤다」
  - 비유는 거의 없다 — 비유 금지 채널과 결이 맞다
- 리텐션: 003 「문제는 ~」으로 진짜 답을 따로 떼어 강조 / 004 「그런데 조금 의아합니다」 파생 질문 / 002 가설 「탈락」 패턴 인터럽트

**설계 원칙**
- 뼈대(지식대학 기본 흐름에 맞춤):
  1. 뻔한 답 부수기 — 「낮에는 몸이 달라서」(일주기·온도·대사율 가설)를 **연구로 판정**한다. 레퍼가 출처 없이 인용한 쥐 실험의 실제 출처·한계를 밝힌다
  2. 진짜 원리 — 혈중농도를 실제로 올리는 변수: 빈속(위 배출), 마시는 속도(간의 시간당 분해 상한), 짧은 시간에 몰아 마심
  3. 「느낌」의 원리 — 혈중농도가 오르는 중에 취기를 더 크게 느끼는 현상, 낮에는 바로 활동해 취기를 더 의식함, 오후 졸림 시간대와 진정 작용이 겹침
  4. 한 단계 더 — 「그럼 저녁에 마시면 덜 취하나?」(저녁술은 자 버려서 모른다 + 수면 영향) 또는 「술은 마시면 는다?」
  5. 실천 방법 — 대본 속 연구가 뒷받침하는 것만(먹으면서 마시기, 속도)
- 숫자는 **실측 대비쌍**으로(빈속 vs 식후 최고 농도 등), 한 문단 2개 이하. 같은 계산 반복 금지(005 실패).
- 파트 전환마다 「그럼 ~?」 질문 하나로 다음 파트를 연다. 가설을 「탈락」시키는 순간을 패턴 인터럽트로 쓴다.

## 3. 감정 증폭 전략

**관찰**
- 003 댓글 1위 「같이 마셨는데 나만 일찍 깸」(5,000) — 원리보다 **「다들 겪는 일」 확인**에 반응. 「검색해 들어온 1인」(418) — 그 상태에서 검색 유입.
- 004 댓글 1위 「맷집이 늡니다… 간경화라고 하죠」(642) — 「주량은 는다」 속설 블랙유머. 원리 댓글은 TOP 10에 없음.
- 001 댓글: 「다람쥐도 취한다」(51), 「낮술 후 3초 만에 잠」(36), 「낮엔 12시부터 새벽 2시까지 마시니까」(32) — 시청자가 스스로 **「마신 시간이 길다」는 현실 답**을 냄.
- 005 댓글: 「제가 빨리 죽었던 이유를 알았네요」, 「물·이온음료 중 뭐가 좋나」 — 실천 질문.
- 감정 순위: ① 공감(나도 그랬다) ② 의외성(「몸 탓이 아니었다」) ③ 웃음(속담·블랙유머)

**설계 원칙**
- 공감을 훅에서 바로 — 「덜 마셨는데 더 취한」 낮술 장면(회식 점심, 바닷가·등산 뒤 막걸리 등 40~60대 일상).
- 의외성은 중반에 두 번: ① 「낮에는 몸이 달라서」가 아니다 ② 같은 양이라도 빈속·속도로 최고 농도가 크게 달라진다(실측).
- 「낮술 후 졸림」 「저녁술은 자서 모른다」를 받아 주면 001·002 댓글이 원한 답이 된다.
- 흐름: 공감(초반 20%) → 의외성·납득(중반 55%) → 「한 단계 더」 호기심(15%) → 실천·마무리(10%)
