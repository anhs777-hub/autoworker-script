- 같은 질문(「현무암인데 왜 곡창」)을 다룬 영상 없음
- 인접: 심층과학 「옛 한탄강 용암의 강」 33만(용암 흐름·주상절리), YTN 「철원평야를 만든 27만 년 전 사건」 1.7만 → **용암 이야기는 겹치므로 짧게**, 핵심은 흙과 물
- 벤치마크 축(profile 「우리 땅·우리 일상의 숨은 이면」): 제주 땅속 54.6만, 한강 100년 27.4만 — 가 본 한국 장소의 「아래·과거」

## 설계 원칙
1. 축: 「돌밭 황무지·강무장」 → 「같은 현무암, 다른 분출(화산재 흙이 아님)」 → 「현무암이 풍화된 점토가 물을 위에 붙잡는다」 → 「그런데 물은 20~30m 협곡 아래」 → 「봉래호와 끊긴 물길」 → 「양수장·토교저수지」. **흙과 물 두 답**이 주인공
2. 훅은 질문형(실물 시연 불가) — 첫 문장 「~있으신가요?」 → 장면(누런 논 + 아래 현무암) → 흔한 답(제주 한 줄) → 「그런데」 1922 계획서 → 차이 질문 → 선언
3. 1922 계획서 「물빠짐 심함」과 2010 논문 「점토라 물이 잘 안 빠짐」은 **나란히, 이어서 단정하지 않는다**
4. 금지 구역: 쌀 맛·밥맛·현무암 성분 밥맛설·일교차, 봉래호 저수량·「동양 최대」, 용암 정확 연대, 제주 40%·96% 숫자 재사용, 「100년 논농사가 흙을 바꿨다」
5. 일제 수탈은 사실 한두 문장, 정치 논평 없이
