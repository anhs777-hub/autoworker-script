# 소재 확인 — 현무암 위 철원평야는 왜 쌀이 될까 (2026-10-26)

출발: 10/26 개마고원 레퍼런스 분석(temp-analysis3) 확장 소재 3번

## 판정: 각도를 바꾸면 집필 가능 — 「철원 쌀이 왜 맛있나」는 홍보 자료뿐이라 버리고, **「제주도 현무암이라 논이 없는데, 왜 같은 현무암 위 철원은 곡창지대인가」**로 가면 1차 논문이 원리를 받쳐 준다. 직접 경쟁작 없음

### 리서치 뒤 보정 (2026-10-26, verified-data.md)

- 새로 찾은 반전: **1922년 수리조합 계획서가 철원평야를 「지표에 현무암이 많고 물빠짐이 심해 벼농사에 적절치 않다」고 적었다.** 조선 초엔 사냥터(강무장), 1920년대 초엔 돌밭 황무지 → 철원도 원래 「현무암이라 논이 안 되는 땅」이었다
- 그래서 답이 둘: ① 흙 — 현무암이 풍화된 점토층이 물을 위에 붙잡는다(2010 논문) ② 물 — 한탄강은 20~30m 협곡 아래라 저수지로 위에서 끌어와야 했다(1920년대 봉래호 → 6·25 뒤 북한이 물길을 돌려 농토 20~30%만 → 양수장·1978 토교저수지)
- 제주 대비는 훅의 흔한 답으로만 쓰고 본문은 철원 중심 → 제주 물 나이 편과 겹침 최소화
- 썸네일 보정안: 「{현무암} 땅은 물이 빠지는데 / 왜 [철원]은 곡창지대일까」 (원안 「제주는 현무암이라 논이 없는데」는 제주 논 면적 통계 미확보라 예비)

## 썸네일·제목안

- 썸네일: 「{제주}는 현무암이라 논이 없는데 / 왜 [철원]은 쌀이 날까」 (윗줄 = 「구멍 숭숭 현무암, 물 빠짐」 상식 ✅)
- 제목: 「제주도엔 논이 없는데, 같은 현무암 땅 철원은 왜 곡창지대일까」 계열
- 1번 썸네일 장면: 왼쪽 제주 돌담 밭(구멍 난 검은 돌) ↔ 오른쪽 철원 황금 들판, 가운데 땅 단면(위는 붉은 점토, 아래 검은 현무암)
- **맛 비교·「최고의 쌀」 주장 금지** — 원리 소재로만

## 이야기 뼈대

- 질문: 제주는 현무암이라 물이 다 빠져 논이 거의 없다는데, 같은 현무암 위 철원평야는 왜 강원도 제1의 곡창지대일까
- 파트1 — 같은 현무암, 다른 분출: 제주는 화산재를 뿜는 분출, 철원은 갈라진 틈으로 용암만 흘러나온 분출(오리산 680m → 옛 한탄강 길) → 흙의 재료가 다르다
- 파트2 — 현무암이 흙이 되면: 현무암은 빨리 풍화돼 끈적한 점토가 된다. 평평한 용암대지라 쓸려 가지 않고 오래 쌓임 → 점토층이 물을 붙잡아 논이 된다(동송통 — 위만 물이 차고 아래로 안 빠짐)
- 파트3 — 그런데 물은 어디서: 용암이 메운 한탄강은 들판보다 한참 아래 협곡 → 논물을 대려면 저수지·수리조합(1922 중앙수리조합, 산명호·토교저수지) ※ 리서치에서 확인
- 파트4 — 제주로 돌아오면: 화산재 흙은 물이 잘 빠지고, 하천은 평소 말라 있어 논은 용천수 나는 곳에만 → 같은 돌이라도 「어떻게 터졌나」가 농사를 갈랐다
- 차별 2축 = **질문**(제주 vs 철원 대비 — 경쟁작 없음) + **원리**(분출 방식 → 흙 → 물, 1차 논문)

## 약점·주의

1. 「현무암은 물이 빠진다」 상식의 정확한 범위 — 제주 물 빠짐은 현무암 균열·숨골과 화산회토 때문. 「현무암이라 물이 빠진다」를 그대로 맞다고 하지 말고, 흔한 답으로 받은 뒤 「돌보다 흙이 문제」로 정정
2. 파트 3(한탄강 협곡·저수지로 물 대기)은 아직 추론 — 「한탄강이 들판보다 수십 m 아래라 물 대기가 어려웠다」 1차 자료 필요(정승진 2019, 철원군지, 농어촌공사 자료)
3. 제주 논 면적 통계 없음 — 제주도 농업 통계(논 면적 ha·비율) 확보 필요
4. 오대쌀 맛·「6천만 년 전 분출」(홍보 기사 — 논문은 홍적세, 즉 수십만 년 전) 쓰지 않음
5. 지식대학 제주 생수 편(물 나이)·백록담 편과 「제주 물 빠짐」 설명이 겹칠 수 있음 → 기존 편 문장 확인 후 다른 말로
