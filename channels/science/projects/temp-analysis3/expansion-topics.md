## 3. 터진 이유

1. **제목 공식 + 아는 이름**: 「가장 넓은 고원인데 / 왜 비어 있을까」 — 교과서로 다들 아는 이름에 상식과 부딪히는 질문
2. **썸네일이 한 장으로 설명됨**: 지도 위 노란 테두리 = 「여기가 비었다」가 1초에 보임
3. **북한 = 갈 수 없는 땅** 호기심, 그러면서 「정치 아님」을 선언해 거부감 차단
4. **반전 2개**: 「비어 있는 땅이 한 나라 산업의 전기를 댔다」 + 「전기를 먼저 만든 땅이 지금 가장 어둡다」
5. **감정 정점**: 장진호 추위 장면(윤활유·주사약·동상)을 후반에 배치해 15분을 버팀
6. **정직한 화자**: 「확인 안 된 건 확인 안 됐다고」를 4번 반복 → 신뢰감 (단, 과하면 늘어짐)

## 4. 우리 규칙과 다른 점

- 15분·사례 10개 이상 → 우리 10분·사례 6~7과 다름. 비교(티베트 등)·삼수갑산·장진호를 다 넣어 소재가 흩어짐
- 본론 첫 문장이 「~지 아시려면, ○○부터 보셔야 합니다」 형식이 아님(「먼저 ~부터 보겠습니다」로 비슷)
- 클로징 질문이 「무엇을 보게 될까」 상상형 → 우리 지식대학 3단 클로징과 다름
- **사실 오류·약점** (우리가 하면 차별점):
  - 「1955년 해방」 → 1945년 (자막 기준 오기)
  - 「용암이 흘러 만든 땅」: 지리 교과서·연구는 개마고원을 **경동성 융기로 들린 고위평탄면**으로 설명(일부 지역만 용암대지). 백두산 용암대지와 섞은 것으로 보임 → 확인 필요
  - 최저 기온은 기상청 중강진 기록(1933년 영하 43.6도로 알려짐)으로 확인 가능한데 피함 → 확인 필요

## 5. 우리 채널 겹침

- 지식대학: 시베리아 고상 건물(추위), 백록담 vs 천지(백두산) — 직접 겹침 없음
- 조선정책실: **삼수갑산 = 유배지 정책**은 조선정책실 소재 후보(실록 근거 가능)
- 세상의 이유: 「해방 때 공업은 북쪽, 남쪽은 농업」(수풍·부전강 전력) — 경제 소재로 쓸 수 있음
