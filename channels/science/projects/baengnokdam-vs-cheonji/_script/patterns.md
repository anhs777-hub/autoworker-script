# 공통 성공 패턴 — 백록담 vs 천지

> 레퍼 4편: 001 사이언스랩스 천지 물 빼기(64,349) · 002 싸이언스연구소 백두산 반으로(38,606) · 003 숨은 지식 천지 안 마르는 이유(387) · 004 지식뽐내 백록담 물 빼기(8, 오늘 업로드)
> 성과 근거는 001·002뿐. 003·004는 구조·경쟁 확인용. 인용은 근거용 — outline·draft 반입 금지.

## 1. 반복되는 훅 공식

**관찰**
- 001·004: 「물을 다 빼면」 가정형 사고실험으로 연다. 001은 384m를 63빌딩으로 환산해 바로 장면을 만든다
- 002: 썸네일 장면(반으로 자르기)을 첫 문장에서 그대로 실행 + 「겉은 조용한 산 ↔ 속은 다르다」 대비
- 003·004: 역설 — 「계속 쏟아지는데 안 마른다」(003), 「빼기도 전에 저절로 사라진다」(004). 시청자 직관 답(바닥에 샘?)을 질문으로 꺼내 후반에 회수(003)
- 네 편 모두 「흔한 답 → 그런데 부딪히는 사실 → 차이 질문」 구조는 없다. 목차·가정·역설로 끈다

**설계 원칙**
- 우리 훅은 채널 공식(있으신가요? → 장면 → 흔한 답 → 그런데 → 차이 질문 → 선언)을 지키되, **「물을 다 빼면」 가정은 제목·선언에서 쓰고 훅 첫 장면은 시청자가 가 본·본 장면(한라산 정상 등반, 백록담 사진)으로 연다**
- 「그런데」 사실은 숫자 한 개로 그릇 크기 대비가 아니라 **모양·생성 방식의 차이가 드러나는 사실**을 고른다(크기는 단서로만 — 기획 각도)
- 훅에서 던진 사실은 본문에서 반드시 회수(003의 샘 회수, 001의 자가 배수 회수가 각 영상 최고 지점)

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조: 001·002는 **위→아래 하강**(물 → 바닥 → 지층 → 마그마) + 시간 거슬러 가기. 003은 **수지 장부**(나가는 물/들어오는 물 → 계산 불일치 → 지하수). 004는 빼기 → 반전 숫자 → 원리 → 물길 → 비교 → 역사 나열
- 숫자: 천지 수치(9.2㎢, 384m, 20억 t, 지름 약 5km)는 001·002·003 공통. 자료별 차이를 밝힌 002가 신뢰 장치로 작동
- 「어떻게 알았나」(음파 측량·나이테·얼음 속 재·지진파)를 매번 한 줄로 푼 001·002가 신뢰를 얻음
- 비유·의인화는 네 편 모두 과다(우리 채널 금지)
- 001 댓글 「뒤죽박죽」, 004 후반 나열 — 사례를 많이 늘어놓으면 집중이 떨어진다

**설계 원칙**
- 뼈대: **두 그릇의 「만든 방식」을 하나씩 확인하는 비교 구조**. 각 파트는 「모양 → 만든 방식 → 증거(어떻게 알았나)」 순서
- 크기 수치는 단서 파트 하나에 몰고(004·002가 이미 한 「천지 384m vs 백록담 4m」 나열은 피함), 핵심은 형성 과정(분출해 판 자리 vs 비워진 지붕이 꺼진 자리)
- 「어떻게 알았나」 증거는 파트마다 하나씩 전속 배정(시추 코어·연대측정 / 부석층·분출량 / 호수 물길)
- 사례 6~7개 이내, 사례마다 역할 문장. 국경·정치·폭발 시나리오 단락 없음
- 리텐션: 파트 전환마다 질문형 전환(「그럼 ~는 왜 ~일까요?」), 자료별 수치 차이는 밝혀서 말함

## 3. 감정 증폭 전략

**관찰**
- 001 최다 반응은 국경·명칭 논쟁(정치 — 우리는 쓰지 않음), 다음이 「우리한테도 오나?」 체감 궁금증, 「물 빼는 이야기 좋아함」(포맷 매력)
- 감정 흐름 공통: 호기심(물이 빠지며 드러남) → 경이(스케일) → 반전 쾌감(자가 배수·계산 불일치) → 정리
- 002는 불안을 키우고 「가정일 뿐」으로 누름 — 우리는 불안 축 자체를 쓰지 않음(사용자 지시)

**설계 원칙**
- 목표 감정: 궁금증 → 「아, 그래서 다르구나」 납득의 쾌감. 경이는 규모가 아니라 **과정(꺼짐)의 장면**에서
- 40~60대 기억 소환: 한라산 등반·수학여행 백록담 사진 1회(004에 단서) — 장면 하나만 짚고 사실로 복귀
- 「물을 빼면 닮았다 → 그런데 만든 방식이 반대」 반전을 중반에 한 번, 「백록담은 마르고 천지는 안 마른다」를 2차 반전으로

**인기 댓글 모음**
- 001: 국경·명칭 논쟁(좋아요 8, 정치 — 쓰지 않음) / 「백두산 화산재가 한국에 못 온다고 들었는데」(체감 궁금증) / 「물빼는 이야기 좋아하네」(포맷) / 「내용이 뒤죽박죽」(사실 과다)

**경쟁 판정 (확장 소재 차별 설계)**
- 공통으로 한 것: 천지 단독 수치 나열, 물 빼기 가정, 폭발·마그마, 비유. 004는 「천지 384m vs 백록담 4m, 냄비 vs 접시, 폭포 vs 땅」을 한 단락으로 이미 다룸
- 공통으로 놓친 것: **「물을 빼면 둘 다 산꼭대기 그릇인데 왜 이름(화구호·칼데라호)이 다른가」를 영상 전체 질문으로 세운 편 없음** / 백록담 형성 연대·시추 연구(2019~2023)를 출처로 다룬 편 없음 / 칼데라가 「꺼져서」 생긴 과정을 실제 분출량으로 보여 준 편은 002가 한 줄
- 차별 4축: 질문(백록담이 될까 — 비교 질문) / 1차 자료 정정(백록담 나이 1.9만 vs 2.5만, 천지 수치 출처별) / 첫 장면(한라산 정상 등반 장면) / 피드 대조(두 그릇 나란히 단면, 공포 없는 밝은 색) — 4축 모두 다르게 설계 가능

**구조 자산 (기법 라벨 + 효과 원리)**
- 「가정 실험 진행」 — 할 수 없는 일을 머릿속에서 해 보게 해 장면 궁금증을 만든다 (001·004)
- 「전제의 실제 회수」 — 영상 전제(물 빼기)를 실제 일어난 사건으로 되돌려 만족감을 준다 (001)
- 「직관 답 회수」 — 시청자가 떠올린 답을 질문으로 꺼내 뒤에서 「반쯤 맞다」로 돌려준다 (003)
- 「어떻게 알았나 한 줄」 — 측정 방법을 짧게 붙여 숫자의 신뢰를 높인다 (001·002)
- 「자료별 수치 병기」 — 다른 값을 숨기지 않아 신뢰를 얻는다 (002)
- 「수지 장부」 — 들어오는 물/나가는 물을 하나씩 채우다 계산 불일치로 반전 (003)
- 「기억 소환 장면」 — 수학여행·신혼여행 물가 사진으로 40~60대를 영상 안에 넣는다 (004)
- 「연결 환산」 — 앞 숫자를 뒤 숫자의 단위로 재사용 (002: 20억 톤 → 천지 12번 분량)
