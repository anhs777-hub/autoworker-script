## 4. 본문 구조 분석

전반부(깊이 축): 한강 기본 정보 → 수중보 → 5m 더(쓰레기·폭탄) → 10m(다리 기초·케이슨) → 강바닥 아래(5호선 28m, 1995년 침수) → 잠수교
중간 전환: 「깊이는 여기까지. 더 내려가려면 시간을 거슬러」
후반부(시간 축): 1980년대 준설 → 1970년대 매립·섬 소멸 → 1968년 밤섬 폭파(오픈루프) → 1960년대 백사장 → 1925년 대홍수 → 조선
결말: 밤섬 6배 회복 → 요약 → 「덜 파고 덜 버리자」 → 다음 강 댓글 요청

- 배치 패턴: **깊이별 물 빼기(공간) → 전제 소진 → 연대별 역행(시간) → 현재 반전 회수 → 메시지** (2부작 이어 붙이기)
- 전달 기법: 단계형 진행(깊이 숫자 = 챕터), 체감 환산 다수, 의인화 비유(우리 채널 금지), 실제 사건에 날짜·수치, 사진 근거, 속설 깨기(밤섬 돌 3.3%)

**덜 터진 원인 역설계**
1. **전제가 중간에 끝난다** — 「물 빼기」를 접고 후반은 한강 개발사가 됨. 썸네일 기대가 후반에 끊김(추정)
2. **썸네일 핵심 미끼가 빨리 소모** — 지하철은 한 단락. 가장 큰 반전(밤섬 6배)은 썸네일·제목에 없음
3. **15분에 숫자 과밀** — 「숫자 피로」 반면교사
4. **도해 오류·BGM 불만이 댓글로**
5. **인트로 군더더기**

## 6. 댓글 반응 분석

- 시청자 댓글 3개뿐. 향수·기억(「서울 옛 어르신들은 감회가 새롭겠네요」, 「25년을 살았었는데」), BGM 불만(최다 3), 침식·퇴적 도해 오류 지적

- 시청자 포지션: 「내가 살던 한강」을 다시 보는 중장년. 원리보다 장소 기억에 반응
- 적용: 장소 기억 소환(소양호에 가 봤을 지점을 깊이와 연결), 원리 도해 정확성, 고정 댓글은 우리 규칙대로. 「다음에 뺄 강·호수」 요청이 있다는 것은 시리즈 확장 수요 신호 — 소양호는 다음 타자 후보라 비슷한 틀로 보이지 않게 차별이 더 중요

### 8-3. 구조·시각 장치

| 장치 | 우리 처리 |
|---|---|
| 깊이 숫자 = 챕터 | 전제 자체라 버릴 수 없다. **층마다 「이 층이 답하는 질문」 역할 문장**을 둔다. 깊이 숫자만 부르는 진행은 피한다 |
| 공간 → 시간 이어 붙이기 | 쓰지 않는다. 축을 끝까지 「위에서 아래로」 유지 — 이 영상의 약점(전제 소진)을 피하는 길 |
| 수면 가로 단면 컷어웨이 + 하단 검은 띠 | **주의**: 우리 고정 레이아웃과 겉모양이 비슷하다. 이미지까지 「수면 가로선 + 아래 단면」이면 같은 계열로 보인다. 반실사 일러스트·주황 소재명 강조를 지키고, 구도는 다른 장면(내려다보기, 수위 등고선, 시간 겹치기 등)도 검토 |
| 체감 환산(63빌딩·어른 어깨·덤프트럭·건물 눕히기) | 우리 기준(아파트 층수·서울에서 ○○까지·축구장)을 쓴다 |
