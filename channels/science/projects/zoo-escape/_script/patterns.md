# 공통 성공 패턴 — zoo-escape (「어떤 동물이 동물원에서 가장 많이 탈출할까?」)

> 레퍼런스 6편. 조회수 순: 006 BBC 스토펠(3,740만) > 001 랭킹스쿨 TOP4(103.7만) > 002 지식카트 TOP7(28.5만) > 003 궁금한 Y 세로(16.7만) > 005 비디오머그 늑구(10.1만) > 004 KBS 역대 탈출(7.4만)
> 인용은 분석 근거일 뿐 — outline·draft 반입 금지.

## 1. 반복되는 훅 공식

**관찰**
| 영상 | 훅 방식 | 건드린 심리 |
|---|---|---|
| 006 | 사자에게 덤빈 사건을 지나간 일처럼 툭 던지고 바로 「통제해야 했다」 | 캐릭터 제시 + 문제 설정 |
| 001 | 「동물원에서 맹수를 눈앞에서 본 경험, 한 번쯤 있으시죠」 → 「외국 일 같지만 한국에서도」 | 공감 → 통념 반전 → 가까움의 공포 |
| 002 | 「아이와 함께하는 동물원은 평화롭다」 → 날짜·장소 박은 「몇 초 만에 무너졌다」 | 공감 + 대비 |
| 003 | 목격자 육성 「서울 한복판에서 그런 광경을」 → 한 박자 늦게 「얼룩말이었습니다」 | 장면 + 공개 지연 |
| 005 | 동화 문장 → 실제 뉴스로 뒤집기 | 패턴 인터럽트 + 시의성 |
| 004 | 앵커 리드 그대로, 질문 없음 | (약함 — 1:46 이탈 구간) |

- 고성과 3편(006·001·002)의 공통점: **시청자가 아는 평온한 장면(동물원 나들이)이나 이미 아는 캐릭터에서 출발해 「그런데」로 뒤집는다.** 지식대학 훅 공식(흔한 답 → 그런데 → 차이 질문)과 뼈대가 같다
- 국내 이름 있는 동물(세로·꼬마·늑구)은 설명 없이 기억을 소환한다(003·005)
- 인트로 약속이 없는 영상(002·004)은 썸네일 격자·제목 숫자에 기대고, 약속 없는 004는 부진

**설계 원칙**
1. 훅 첫 장면은 **40~60대가 실제로 가 본 동물원·본 뉴스 장면**(세로가 도심을 달리던 장면, 어린이대공원·서울대공원 나들이)으로 연다
2. 「흔한 답」은 시청자가 실제로 떠올리는 답 — 「머리 좋은 원숭이」 「힘센 맹수」 — 으로 꺼낸다(레퍼 6편 모두 맹수·영리한 동물을 주인공으로 삼았다 = 시청자 머릿속의 기본값)
3. 「그런데」는 **기록상 가장 많이 나간 건 새였다**는 장면 있는 사실 하나. 이유는 말하지 않는다
4. 인트로 끝에 반드시 선언(약속)을 둔다 — 레퍼 중 약속 없는 004·002의 약점을 피한다

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- *구조*: 6편 중 5편이 **사건 나열**(랭킹 001·002, 모음 004·005, 에스컬레이션 006). 003만 「가설 세우고 흔들기」 탐문형
- 6편 모두 **「어떤 동물이 가장 많이, 왜」에 대한 통계·기록이 없다** — 빈자리
- 사례 안 배치는 「일시·장소 → 경위 → 대응 → 결말」 고정틀(001·004·005)
- 탈출 원인 분포가 레퍼 안에서도 드러난다: 잠기지 않은 문(001 3건, 004 2건, 005 2건), 울타리 파손(세로), 땅파기(늑구), 홍수·고의 개방(005 해외), 도구·협동(006)
- *전달 기법*: 동물 이름(세로·꼬마·호롱이·늑구·스토펠) + 정확한 시간(28시간·4시간 30분·9일·3시간 반)이 장면을 만든다. 비유는 거의 없다(지식대학과 맞음)
- *리텐션*: 카운트다운(001), 「또?」 반복 원인(005), 착각 반전(002), 가설→증언 뒤집기(003), 대책→재탈출 에스컬레이션(006)

**설계 원칙**
1. 본론은 **「무엇을 세느냐」에 따라 답이 바뀌는 구조** — ① 뉴스 기준 → ② 동물원 기록 기준 → ③ 왜 새인가(구조적 원인) → ④ 맹수는 왜 뉴스가 되나 / 사람 쪽 원인 → ⑤ 그럼 「능력」으로 보면 누가 잘 나가나(스토펠·늑구 땅파기 등)
2. 사례마다 **역할 문장 한 줄**(profile 규칙). 사례 6~7개 이내 — 국내 3~4 + 해외 2~3
3. 사례 서술은 「이름 + 날짜 + 경과 시간 + 탈출 경로」만. 사살·부상 장면 묘사 금지, 결말은 사실 한 줄
4. 「사람 쪽 원인(문 미잠금)」은 레퍼 댓글 1위 반응(001 좋아요 1,200, 005 363, 002 826)과 맞닿는 재료 — 단, **판단·책임 논쟁 없이 기록으로**(「몇 건 중 몇 건이 문이었다」까지)
5. 파트 전환마다 오픈루프 — 특히 「새 다음은?」 「그럼 맹수는 왜 뉴스에 많이 나오나」로 2단 반전

## 3. 감정 증폭 전략

**관찰**
- 댓글 감정 순위(좋아요 가중): ① **동물 편에 선 안타까움 + 관리 쪽 문제의식**(001·003·004·005 공통, 최대 1,200) ② 규칙 위반 사람에 대한 분노(002, 826) ③ 동물이 사람을 이기는 유쾌함(006, 64,000)
- 감정을 만든 장치: 「잠기지 않은 문」 반복, 부모 잃은 세로, 라면 훔쳐 먹은 꼬마, 갈퀴를 사다리로 쓴 스토펠
- 흐름: 황당·웃음 → 긴장 → 안타까움 → 문제의식(국내 뉴스형) / 감탄 → 웃음 → 믿기 어려움(BBC)

**설계 원칙**
1. 지식대학 감정 축은 **놀라움(의외의 1위) → 감탄(동물의 능력) → 「아, 그래서 그렇구나」**. 공포·분노는 쓰지 않는다
2. 가장 크게 퍼진 감정(006 유쾌함)을 **중반 재참여 포인트**로 — 스토펠·꼬마의 라면 같은 가벼운 장면을 무거운 국내 사례 사이에 둔다
3. 안타까움은 사실 한 줄로만(「결국 사살됐습니다」), 동물원 존폐 논쟁 금지
