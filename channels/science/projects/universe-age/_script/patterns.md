# 공통 성공 패턴 — 우주 나이 138억 년 (레퍼런스 4편)

> ⚠️ 이 문서의 인용은 분석 근거일 뿐이다. outline·draft로 옮기지 않는다.

## 1. 반복되는 훅 공식

**관찰**
- 터진 두 편(002 과학드림 143만, 001 리뷰엉이 110만)은 모두 **질문으로 연다.** 001은 「내 건물 → 집 앞 나무 → 지구」처럼 가까운 대상에서 먼 대상으로 나이를 묻는 질문을 계단식으로 올리고(조회율 59%), 002는 거대한 질문 3개를 나열한다.
- 004(구독 대비 3.1배)는 「교과서 숫자가 틀렸을 수도」라는 역설 선언으로 연다. 클릭 기대(138억이 틀렸나?)를 0초에 확인해 준다.
- 003(조회율 8%)은 훅 없이 「알아보겠습니다 + 정의」로 시작하고, 제목이 건 의심을 첫 문장에서 「138억 년으로 추정됩니다」로 스스로 풀어 버렸다.
- 인트로의 공통 역할: **이미 답이 나온 나이(지구 45억·태양 46억)를 먼저 보여주고 「그럼 우주는?」으로 한 단계 올린다**(001).

**설계 원칙**
1. 첫 문장은 채널 공식(「~있으신가요?」)을 지키되, **138억이라는 숫자를 첫 15초 안에 꺼낸다** — 제목·썸네일이 숫자를 걸었으므로 클릭 기대를 즉시 받아준다(004).
2. 인트로에서 **「138억 년이 정답」이라고 단정하지 않는다** — 단정하는 순간 제목의 질문이 죽는다(003의 실패).
3. 인트로 2단계(풀어주기)에 **뻔한 답과 부딪히는 사실 한 줄**을 넣는다: 「우주보다 나이가 많게 나온 별이 있었다」. 001이 본문 중반에야 꺼낸 「지구가 우주보다 늙었다」 유형의 모순을 앞으로 당긴다.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조:
  - 001(최고 조회율): 원리(팽창 되감기) → 첫 시도와 실패(20억 년, 지구보다 젊은 우주) → 경쟁(허블 전쟁) → 결정적 증거(우주배경복사) → 정밀화(플랑크). **숫자가 20억 → 200억 → 100억 → 138억으로 출렁이는 과정 자체가 서사.**
  - 002: 순수 연대기(빅뱅→문명), 138억은 전제로만 씀.
  - 004: 정설 쌓기 → 깨는 관측 → 검증 → 가설 4개 → 반전 → 열린 결말.
  - 003: 교과서 목차 순서 → 리텐션 실패.
- 전달 기법:
  - 비유: 4편 모두 비유를 많이 쓴다(풍선 팽창·타임머신·어머니 우주·아기·압력솥). **지식대학은 비유 금지** → 레퍼런스가 비유로 때운 자리를 「수치·실제 관측 결과」로 채우는 것이 우리 차별점이다.
  - 숫자: 002는 문장마다 숫자 1개. 001은 「허블 상수 50이면 200억 년, 100이면 100억 년」처럼 **입력과 결과를 쌍으로** 줘서 원리를 이해시킨다.
  - 사례: 001 「달빛 1초, 20광년 별은 20년 전 모습」 — 멀리 볼수록 과거라는 사실을 체감 사례로 준다(비유가 아니라 사실이므로 사용 가능).
- 리텐션 장치:
  - 「다 풀린 듯하다가 걸림돌」 오픈루프(001), 「그렇다면 틀렸던 걸까요? 아닙니다」 반전 질문(001), 「시청자 대신 묻기」(001), 번호 매긴 가설과 가장 불편한 것 마지막 배치(004), 「반전처럼 보이는 소식 → 문제는 좁혀졌다」(004).
  - 실패 패턴: 「다음은 ~입니다」 목차 낭독(003), 회수 안 한 떡밥(003·004).
- **사실 오류가 레퍼런스에 많다**(001: 허블 1924·가속 팽창 허블 탓·플랑크 2003 / 003: 플랑크 시대 1조분의 1초 / 004: 허블 텐션 방향 반대·46억 년이 1분). → 정확성 자체가 차별화.

**설계 원칙**
1. 본론 뼈대는 **「한 방법의 계산값 → 그걸 의심하게 만든 모순 → 서로 다른 방법들로 교차 확인 → 아직 남은 문제」**. 001의 「숫자 출렁임 서사」를 쓰되 004처럼 현재 쟁점까지 가서 **결론을 준다**(004의 열린 결말이 「못 믿겠다」 댓글로 이어졌다).
2. 원리는 **입력→결과 쌍**으로 설명한다: 「팽창이 빠르면 → 되감는 시간이 짧다 → 나이가 젊어진다」. 비유 없이 조건과 결과만으로.
3. 「멀리 볼수록 과거를 본다」는 체감 사례(달빛·별빛 도달 시간)를 1회 쓴다 — 사실 사례이므로 허용.
4. 파트 전환마다 「그럼 ~일까요?」 반전 질문을 1개씩 둔다. 목차형 전환 멘트 금지.
5. 레퍼런스 수치는 하나도 그대로 옮기지 않는다 — 모든 수치는 verified-data.md 기준.

## 3. 감정 증폭 전략

**관찰**
- 댓글 감정 순위:
  1. **불신·의심**(004: 「가장 믿을 수 없는 것이 138억년」 좋아요 9, 「인간이 우주를 논하는 것 자체가 말이 안 됨」 9) — 우주 나이 내용에 반응한 댓글 중 가장 뜨겁다.
  2. **비전공자의 공감**(001: 「과학점수 20점인데 우주 영상 즐겨봄」).
  3. **경외·여운**(002: 고정 아웃트로 문구 910, 「왜 울어요」).
  4. **내 시간 감각과의 비교**(003: 「내 나이는 그냥 부끄럽네요」).
- 감정을 만든 장치: 004의 「교과서 숫자가 틀렸을 수도」가 불신을 키웠으나 답을 안 줘서 불신으로 끝났다. 001은 「지구가 우주보다 늙었다」 모순으로 긴장 → 해소.
- 공통 흐름: 호기심 → 긴장(모순·논쟁) → 해소·경외.

**설계 원칙**
1. **시청자가 이미 가진 「못 믿겠다」를 정면으로 받는다** — 「그 숫자, 누가 어떻게 쟀는지 들어 본 적 없죠」. 그리고 근거로 답한다. 불신을 꺾는 것이 아니라 「이렇게 쟀다」를 보여줘 판단하게 한다.
2. 긴장은 **모순 사례 2개**(지구보다 젊은 우주 → 우주보다 늙은 별)로 초반 40% 안에 쌓고, 중반에 「서로 다른 방법들이 같은 숫자에서 만난다」로 해소, 후반에 「그런데 아직 하나가 안 맞는다」로 한 번 더 당긴다.
3. 감정 흐름: 호기심·의심(0~20%) → 긴장(20~45%) → 납득·경외(45~75%) → 새 호기심(75~90%) → 내 몸으로 돌아오는 여운(90~100%).
4. 마무리는 「내 시간 감각」으로 — 내 몸을 이루는 원자의 나이처럼 사실로 연결(003 댓글·002 「별의 후예」 반응 근거).

  - 「숫자 즉시 수령」 — 썸네일·제목의 숫자를 첫 문장에서 받아 클릭 기대를 0초에 확인한다 (004)
  - 「이미 풀린 나이 → 그럼 우주는?」 — 해결된 사례 2개로 질문의 단계를 올린다 (001)
- 비유/메타포 유형 — **지식대학 사용 불가.** 대체: 「입력→결과 쌍」(팽창 속도 → 나이) 수치 제시 (001)
- 리텐션 장치 유형
  - 「다 풀린 듯하다가 걸림돌」 — 해소 직후 새 문제로 긴장 재점화 (001)
  - 「반전 질문 후 부정」(틀렸던 걸까요? 아닙니다) — 예상을 한 번 꺾는다 (001)
  - 「시청자 대신 묻기」 — 떠오를 의문을 먼저 꺼내 이탈을 막는다 (001)
  - 「번호 매긴 후보, 가장 불편한 것 마지막」 — 끝까지 보게 만든다 (004)
  - 「반전처럼 보이는 소식 → 문제는 좁혀졌다」 — 해소와 긴장을 동시에 (004)
- 감정 트리거 유형
  - 「부모보다 나이 많은 자식」형 모순(지구>우주, 별>우주) — 상식 충돌로 긴장 (001)
  - 「교과서 숫자 의심」 — 시청자가 원래 가진 불신을 건드린다 (004)
  - 「거대 척도를 나와 잇기」 — 경외 → 여운 (002)
- 데이터 제시 기법
  - 「출렁이는 숫자 연대기」 — 같은 질문의 답이 시대별로 바뀌는 과정 자체를 서사로 (001)
  - 「멀리 볼수록 과거」 체감 사례 — 빛의 도달 시간 (001)
  - 「오차 범위 공개」 — 정밀도 자체가 경이 (001)
