# 패턴 추출 — 소부장 7년 후 (거울 구조)

> 레퍼런스 1편(우아한 경제 아이폰 듀오, 212,428회). 최소 2편 기준에 못 미치므로 **교차 비교가 아니라 단일 영상 해부 + 채널 profile 규칙(레퍼런스 9편 교차 분석 결과)으로 보강**한다. 소재가 아니라 **구조·톤 참고용**이다.
> 인용은 근거로만. outline·draft 반입 금지.

## 1. 반복되는 훅 공식

**관찰**
- 훅이 **우리 쪽 과거 망신을 제3자가 단정한 문장**으로 연다(2019년 외신 평가). 자랑으로 들리지 않아 방어기제가 안 걸린다.
- 2~3문장 안에 「그런데 7년 뒤 이 문장이 다시 등장할 자리가 생겼다」로 **거울 구조를 선언**한다. 시청자가 「이번엔 상대가 당했구나」를 스스로 예측하고, 그 예측을 확인하려고 남는다.
- 인트로는 오답 소거 → 부분 정답(반전 사실 1개) → 더 큰 의문 순서. 채널 profile의 3박자와 일치.

**설계 원칙**
- 훅 첫 문장은 **2019년 한국이 몰렸던 장면**(재고·공포)을 사실로 단정한다. 결론(한국 승리)·자랑으로 열지 않는다.
- 두 번째 박자에서 **「7년 뒤 같은 자리에 일본이 섰다」**로 꺾는다 — 고유 수치 1개(이트륨 0톤 등)만.
- 득 문장(「끝까지 보시면」)은 넣지 않는다 — 나라·산업 소재. 인트로 끝 질문이 기대감을 맡는다.
- 인트로 부분 정답 = 「같은 수법을 이번엔 중국이 일본에 썼다」 + 결과가 반대로 갈리고 있다는 사실 1개.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조: 현재 사건 → 원리(진짜 급소) → **거울 전환(7년 전 우리)** → 7년의 극복 연대기 → 정면 대결 → 아이러니 → 반론 선제 처리 → 공정성 블록 → 수치 비교 → 수미상관. 현재와 과거를 2~3번 왕복한다.
- 비유는 전부 **집 안 사물**. 숫자는 매번 생활 단위로 환산.
- 리텐션: 거울 전환 문장이 핵심 패턴 인터럽트. 클라이맥스 직후 「진짜 이야기는 지금부터」로 재점화. 반론을 화자가 먼저 꺼낸다.

**설계 원칙**
- 본론 뼈대: (현재 일본) → (진짜 급소: 정제 독점 vs 원료 독점) → (거울: 2019 한국) → (7년 연대기, 연도별 한 줄) → (같은 충격 다른 결과) → (반론·한계) → (다음은 한국인가) → 수미상관.
- 거울 전환 문장은 **영상 전체에 1회 핵심 + 1~2회 변주**. 같은 문장 반복 금지.
- 연대기는 한 칸에 숫자 1개. 파트당 수치 1~2개(profile 수치 과밀 금지).
- 반론(2023 유턴, EUV 감광액, 장비, 경산상 부인)은 화자가 먼저 꺼낸다 — 레퍼런스의 「이런 말씀을 하실 수도 있습니다」형 선제 처리.

## 3. 감정 증폭 전략

**관찰**
- 댓글 1위 감정은 **통쾌함**(상대 조롱 24·19·16 좋아요), 2위는 **「한국 없으면 저쪽은 안 된다」 자긍**(17).
- 감정 흐름: 호기심 → 짠함(우리 과거) → 감탄(7년) → 통쾌 → 냉정(반론·공정성) → 뭉클한 자긍 → 실용.

**설계 원칙**
- 통쾌함은 **구조와 숫자**로만 준다. 조롱은 시청자에게 맡긴다(profile: 특정 집단 비난 금지).
- 2019년 공포는 과거형 회상. 현재 공포의 주어는 일본(profile 자부심 규칙 3).
- 통쾌 정점 직후 반드시 냉정 블록(한국도 희토류 중국 의존 · 일본산 유턴). 마지막에 반 계단만 올려 마감.
- 감정 흐름: 긴장(2019 회상 15%) → 통쾌(일본 현재·결과 비교 40%) → 냉정(반론 25%) → 자긍+경각(20%).
