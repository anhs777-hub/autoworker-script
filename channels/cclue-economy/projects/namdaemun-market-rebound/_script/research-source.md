## 2. 추천 구성 (반전 서사)

1. **훅:** "35년 장사하며 이런 적은 처음입니다." 매출 두 배, 6년 만의 첫 임대 계약 → 그런데 같은 시장의 24시간 도매 건물, 점포 140개 중 불 켜진 곳은 4곳.
2. **질문:** 남대문은 살아난 걸까, 겉만 붐비는 걸까?
3. **600년 압축:** 1414년 나라가 빌려준 가게 → 전쟁·대화재(1954, 1968, 1975, 1977) → 전국 도매의 심장(아동복·안경·수입상가)
4. **몰락:** 도매의 온라인 이동 → 2017 사드 → 코로나(매년 10% 폐업), 2025년 8월 외국인도 -11.5%, 성수로 이동
5. **반전:** 최화정 영상 → 사우나템 성지, 2030의 '디깅' 소비, 스카프 아저씨. 소규모 공실률 9.6% → 6.1%
6. **진짜 구조:** 손님이 바뀌었다 (도매상 → 개인), 작은 가게 vs 큰 건물의 양극화
7. **반론과 리스크:** 유행은 짧다(두쫀쿠 17일), 줄 선 몇 곳 ≠ 시장 전체, 임대료 상승이 원래 상인을 밀어낼 위험(젠트리피케이션), 광장시장 바가지 역풍 사례
8. **내 돈:** 고물가 시대 '천 원~7천 원 사치'(작은 사치), 백화점 대비 가격, 바가지 피하는 법
9. **결론:** 남대문을 살린 건 정책 예산이 아니라 손님 구성의 변화. "줄이 아니라 빈 건물을 보라"

## 3-1. 18.5% 검증 결과 (2026-11-06) — ❌ 미확인
- 18.5%는 **한국데이터경제신문 기사 1건에만** 나온다. 유형(중대형/소규모/집합)·분기 표기 없음. 다른 언론·부동산원 보도에서 같은 수치 재인용 0건.
- R-ONE 원자료 접근 실패: r-one.co.kr 접속 거부, R-ONE Open API는 인증키 없이 5행만 반환, 공공데이터포털 파일은 '지역별 집합상가'뿐(상권별 없음).
- 확인된 남대문 수치는 이것뿐:
  - 중대형 공실률 14.5% (2021년 4분기, inews24 · 부동산원)
  - 중대형 공실률 10.1% → 10.7% (2023년 4분기 → 2024년 1분기, 아주경제 · 부동산원)
  - 중대형 임대가격지수 +2.3% (2024년 2분기, 민들레 · 부동산원)
  - 소규모 공실률 9.6% → 6.1% (2024년 2분기 → 2026년 2분기, 이데일리 · R-ONE)
- 비교: 전국 중대형 14.3%, 소규모 8.5% (2026년 2분기, 부동산원). → 남대문 소규모 6.1%는 전국 평균보다 낮음
- **결론:** 지금 확보한 공식 수치로는 "큰 건물은 비어 간다"를 단정할 수 없다. 대본에서 18.5%는 쓰지 않는다.
- 사용자가 직접 확인하는 법: R-ONE(www.r-one.co.kr) → 상업용부동산 임대동향조사 → 상권별 공실률(중대형 상가) → 서울 도심 › 남대문. 또는 R-ONE Open API 인증키 무료 발급 후 재조회
