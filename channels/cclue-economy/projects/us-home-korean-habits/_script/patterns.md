## 1. 훅 설계 원칙
- 열기 방식: **사실·장면** — 「3.99달러짜리 한국 냉동김밥이 미국 마트에 나오자마자 품절」. 시청자 대부분이 「네, 있어요」로 답할 경험 질문이 아니므로 질문으로 열지 않는다
- **자랑으로 열지 않는다** (pd-guide 함정): 첫 문장은 장면만. 「직원 80명 회사」「마케팅 없이」처럼 **작음·결핍**을 먼저 깔고, 그 뒤에 결과(완판)를 붙인다
- 아픈 데 = 상식 파괴: 「한국 수출 = 반도체·자동차」라는 통념 → 그런데 화장품 최대 고객이 처음으로 미국. 「그런데」로 꺾는 단문
- 훅 안 고유 수치는 1개(3.99달러) — 나머지 숫자는 인트로·파트 1로
- 득 문장: **넣지 않는 소재** — 나라·산업 이야기라 「왜 그렇게 됐을까」가 기대감. 인트로 끝 질문이 기대감을 맡는다 (profile 훅 3단계 「넣지 않는 경우」)

## 2. 본론 구조 (사용자 지정 9단계)
훅(결론 먼저) → ⑤ 고추장 → ④ 냉동김밥 → ③ 비데 → ② 신발 벗기 → ① K뷰티 → 왜 가능했나 → 다음 과제 관세 → 결론
- **top5 카운트다운 = N포인트 해부** → 중반 이탈 위험 높음, 채널 기피 유형(나열형). 보완:
  - 순위가 **숫자 크기 순**(작은 것 → 큰 것)이라 스테이크가 자동으로 오른다 — 매 파트 끝에 「다음은 더 크다」 브릿지
  - 파트 1(⑤)에 「왜 하필 지금?」 질문을 심고 파트 2(④)에서 답 → 파트 간 연결고리
  - 마지막에 **하나의 축으로 꿴다**(profile 규칙 9): 「문화가 먼저, 돈은 뒤」로 다섯 항목을 다시 훑는다
- 제목의 답(파트 1~훅에서 공개) = 「한국이 번 돈의 정체는 기술이 아니라 일상. 화장품은 미국이 최대 고객, 라면은 첫 15억 달러」 — 결론 먼저(brief)
- 원본과의 차별: 원본은 생활습관 예찬. 우리는 **각 습관 → 수출 숫자 → 다음 변수(관세)**

## 3. 리텐션 장치 (자사 규칙에서)
- 재점화 질문 후보: 「왜 하필 지금?」(⑤→④) · 「먹는 것만이 아니다」(④→③ 식품 → 생활가전) · 「물건이 아니라 습관 자체가 건너갔다」(③→②) · 「대망의 1위」(②→①) · 「그럼 이 숫자는 언제까지?」(① → 관세)
- 팩트체크 블록 후보: 「신발 밑창 80%에 대변균」 → 그건 다른 연구 수치. 정확히는 소규모 연구 96%·27% / 또는 「트레이더조 직원 대회」 → 매장끼리 겨루는 대회 / 「미국인 전체가 신발 벗는다」 → 3명 중 2명
- 방어 수치(중반 이전): 비데 보급률 5% 미만(아직 시작 단계) / 비데 단독 수출액 통계 없음 / 신발 벗기는 수출 숫자가 없다
- 대조군(반전 재료): 프랑스(화장품 수입 1위 자리를 내준 쪽) · 중국 시장(비중이 절반 이상 → 14%로 줄어든 쪽) · EU(관세 10% vs 한국 12.5%)
- 자기 반박 85%: 인트로 질문(「미국에서 번 돈, 앞으로도 계속 벌 수 있을까?」류)에 관세·과잉생산 조사·인디 브랜드 부담으로 답
- 시청자 호명 80%: 화장품 공장·식품 공장 다니는 분 / 수출 중소기업 / 자영업(김밥·분식) / 해외 사는 자녀 둔 부모 / 마트에서 장 보는 분

## 4. 자부심 소재 추가 규칙 적용
- 자부심은 화자가 주장하지 않는다 → **USITC(미국 측 통계)·블룸버그·트레이더조 자체 팟캐스트·CBS/YouGov**의 입을 빌린다. 「우리가 떠들면 자랑, 저쪽이 인정하면 자료」 한 번
- 긴장 ↔ 안도 3회 왕복: 휴지 사재기(미국의 불편) / 프랑스가 1위를 내줌 / 중국 시장 급감 / 관세
- 공포의 주어는 남: 관세는 「미국 정책」으로, 우리 쪽 불안을 키우지 않는다
- 감정은 사람에서: 올곧(80명 회사)·한인 모녀·휴스턴 트레이더조 매장 직원들·인디 브랜드
- 정치인·정권 평가 비워 둔다 (관세 협상 공과 평가 금지)

## 5. 클로징
- 첫 장면(3.99달러 김밥)으로 회귀 → 인과 사슬 한 문장: 한국 드라마·K팝이 문을 열었고 → 미국 가정이 한국 일상을 써 보기 시작했고 → 그 결과 화장품·라면 수출 최대 고객이 미국이 됐다
- 대안·위안: 관세 뉴스 볼 때 무엇을 보면 되는지(EU 대비 세율, 과잉생산 조사 결과). 투자 권유 금지
- 화자 판단: 「한국이 판 건 기술이 아니라 우리가 살아온 모습입니다」
- 질문: 「여러분 집에서 '이건 외국에서도 팔리겠다' 싶은 물건, 뭐가 있나요?」 → 3~4지선다로 좁힘 (예: 전기밥솥 / 김치냉장고 / 때밀이 수건 / 보리차)
