# 패턴 정리 — 대한항공·아시아나 합병 후 내 항공권 값

> 이 편은 사용자 지시로 **레퍼런스를 수집하지 않았다** (리서치 파일만으로 진행). 교차 분석할 analysis.md가 0개이므로,
> 이 파일은 레퍼런스 패턴이 아니라 **채널 profile 규칙(동일 장르 9편 교차 분석 결과) + 정본 리서치의 경쟁 현황**으로 대신한다.
> 인용·문장 반입 없음. 구조 참고용.

## 1. 훅 공식 (profile 기준)
- 훅 60~75자, 3단계(열기 → 아픈 데 → 기대감). 첫 문장은 사실·장면으로 연다 — 「180석에 승객 3명」은 대부분 시청자가 겪은 적 없는 장면이므로 질문이 아니라 단정문.
- 훅 안 고유 수치는 사실상 1묶음(180석/3명). 두 번째 숫자(15%)는 인트로 부분 정답으로 넘긴다.
- 인트로 = 오답 소거(「대한항공이 값을 올린다는 얘기가 아니다」) → 부분 정답(15% 싼 선택지가 사라진다) → 더 큰 의문(조건이 끝나는 2034년 이후).

## 2. 본론 구조
- 결론 먼저(파트 1에서 「싼 선택지가 사라진다」 공개) → 합병 조건 3가지를 하나씩 → 각 조건의 부작용(역설) → 진짜 숫자(시너지의 85%) → 반론 → 내 돈.
- 축 하나로 꿴다: **「경쟁을 지키려고 만든 약속이 실제로는 어떻게 굴러갔나」** — 좌석 약속은 빈 비행기를, 노선 이전은 빠져나가는 대체사를, 운임 상한은 첫 점검 적발을 낳았다.
- 대조군(파트별 반전 재료): 해외 슬롯 80% 규칙·유령 비행(추정치 표시), 청주–제주(수요 있는데 좌석 부족), 프랑크푸르트(루프트한자가 계속 운항).

## 3. 감정 전략
- 놀라움(빈 비행기) → 납득(약속의 구조) → 의외(약속이 거꾸로 굴러감) → 경각심(2034년 이후) → 행동(마일리지·노선별 경쟁사 확인).
- 악당 없음. 원인은 구조(독점, 괌 수요 감소, 규칙의 부작용).

## 4. 경쟁 현황 (정본 리서치 7장)
- 빈 비행기(KBS 365만·SBS 52만·서울경제TV 51만), 마일리지(비디오머그 67만) 단편은 관심 검증됨.
- 「합병 조건」 하나로 세 소재를 꿰고 「내 표값」으로 결론 내는 장편 해설은 없음 → 차별 지점.
- 훅 소재(빈 비행기)는 경쟁작과 겹친다 → 첫 장면은 같아도 **「왜 계속 떠야 하나 + 15%」**로 바로 넘어가 차별.

## 5. 썸네일 텍스트 형식
- pd-guide 고정 형식: 1행 12~14자 구어 대사체(노랑) + 2행 16~20자(시안). 제목 따옴표와 다른 문장.
