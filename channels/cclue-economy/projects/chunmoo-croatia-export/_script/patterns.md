# 공통 성공 패턴 & 설계 원칙 — 천무 크로아티아 수출

> 레퍼런스 5편 교차 비교 (조회수 가중). 이 문서의 원문 인용은 **분석 근거일 뿐이며 outline·draft 반입 금지**.

## 1. 반복되는 훅 공식

### 관찰

**훅 원문 비교** (조회수 순)

| 영상 | 조회수 | 훅 유형 | 근거 인용 (1개) |
|------|--------|---------|----------------|
| 005 | 32.6만 | 계보 선언형 | "현대판 신기전이 깨어난다" |
| 004 | 30.2만 | 사건 선공개 + 벽 돌파 선언 | "철옹성 같은 벽을 연이어 뚫어내고 있습니다" |
| 001 | 20.2만 | 사실 충돌형 (A 샀는데 또 B) | "미국제 하이마스를 도입한 데 이어, 크로아티아가 이번엔 한국 천무를 사기로 했다" |
| 002 | 11.6만 | 결론 선통보 | "국산 다연장로켓 천무가 이번엔 크로아티아로 수출됩니다" |
| 003 | 0.7만 | 구어 질문형 + 통설 부정 | "미국산 하이마스를 이미 샀는데 도대체 왜 또 한국의 천무를 찾는 걸까?" |

**공통점 5가지**

1. **인사·자기소개·목차가 5편 모두 0글자.** 첫 문장이 곧 사건이거나 결론이다. "오늘은 ~에 대해 알아보겠습니다" 형태가 단 한 편도 없다.
2. **결론을 아끼지 않는다.** 계약 성사라는 결과를 첫 문장에서 다 공개하고, 궁금증을 "무엇이"에서 **"왜"**로 즉시 이동시킨다. 스포일러가 오히려 훅으로 작동한다.
3. **고성과 3편(005·004·001)은 모두 "충돌 또는 역설"을 첫 문장에 넣는다.** 570년 전 조상의 무기가 현대에 부활(005) / 안 뚫리던 벽이 뚫림(004) / 이미 샀는데 또 삼(001). 상식과 어긋나는 사실 한 쌍이 설명을 요구하게 만든다.
4. **인트로가 영상 전체의 질문 1개를 명시한다.** 004 "세계는 왜 K방산을, 그리고 천무를 선택하고 있는 걸까요?" / 005 "우리나라의 다연장 로켓의 시작은 언제부터였을까요?" / 003 "새로운 무기 구매 공식". 이 질문이 목차이자 오픈루프 역할을 한다.
5. **인트로에서 용어를 한 문장으로 풀어준다** (004·005). "천무=여러 발을 한꺼번에 쏘는 차량형 로켓 발사대" 수준의 정의가 초반 이탈을 막는다. 반대로 001은 CTM-290·PULS·239mm를 설명 없이 써서 일반 시청자 진입 장벽을 만들었다.

**심리 분석**: 이 소재의 시청자는 결과(계약)를 이미 알고 들어온다. 따라서 결과를 숨기면 낚시가 되고, 결과를 먼저 확인시켜준 뒤 **"왜"와 "그래서 뭐"**를 미끼로 걸어야 체류가 길어진다.

### 설계 원칙

- **① 첫 문장은 크로아티아 계약 사실 + 역설 한 쌍으로 쓴다.** "미국 하이마스를 이미 산 나라가, 왜 굳이 한국 무기를 또 샀는가" — 001이 20만 조회로 검증한 결손 구조를 그대로 쓴다. 단 001은 3분이라 답을 곧바로 줬지만, **우리는 25분이므로 답 공개를 중반 이후로 미룬다.**
- **② 인사·목차·자기소개를 쓰지 않는다.** 0초부터 사건.
- **③ 훅 직후 30초 안에 "천무가 무엇인지" 한 문장 정의를 넣는다.** (타겟 40~60대 일반 시청자 / 채널 난이도 규칙)
- **④ 인트로 끝에 영상 전체를 끌고 갈 질문 1개를 명시적으로 던진다.** 그 질문은 클로징에서 수미상관으로 회수한다.
- **⑤ 통설을 먼저 지운다.** "싸서 팔린 겁니다"라는 시청자의 기존 답을 인트로에서 부정해 정보 공백을 만든다 (003 검증).
- **⑥ 훅 다음 순서는 profile 규정대로 구독 유도 멘트 → 본론.** 레퍼런스 5편 전부 CTA가 없거나 약해 이 부분은 채널 규칙을 따른다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 비교**

| 영상 | 정보 배치 순서 |
|------|---------------|
| 001 | 계약 사실 → 미국의 제약 → 결손 → 한국의 대안 → 외부 위협(세르비아) → **스펙 우위(속도·화력)** → 지정학 결론 |
| 002 | 결론 → 계약 팩트 → Before/After 대비 → 구매 이유 → 서수 확장("유럽 네 번째") |
| 003 | 질문 → 사례1(폴란드) → 원인(납기) → 제품 강점 → 사례2(노르웨이) → 사례3(에스토니아) → 산업 구조 해설 → 반론 수용 → 재정의 |
| 004 | 판 깔기(유럽 재무장) → 국가 서사(에스토니아) → 위협 실체 → 선택 → **왜 천무인가 5가지** → 반론 격파 → 확장 전망 |
| 005 | 뿌리(신기전) → 암흑기 → 위협 → 1세대 한계 → 갈등 → 결단 → 시련 → 결실 → **하이마스 대비 우위** → 정신 |

**공통 골격**: `사건 → 상대(국가)의 사정과 위협 → 왜 하필 한국인가 → 우위 증명 → 확장·전망`

**가장 중요한 공통 설계 — 스펙을 뒤로 뺀다**: 5편 중 4편(001·003·004·005)이 성능·스펙 비교를 **본론 후반부**에 배치했다. 먼저 "왜 이게 필요한가"를 세운 뒤 스펙을 붙이면, 같은 숫자가 자랑이 아니라 **논리적 귀결 또는 보상**으로 읽힌다. 002만 스펙을 앞에 뒀는데, 90초 뉴스라 가능했던 예외다.

**전달 기법 공통점**

- **숫자는 반드시 대비쌍으로.** 5편 전부 단독 수치를 거의 쓰지 않는다. 002 "30년 된 소련제 20km ↔ 한국제 300km", 005 "구룡 36km ↔ 천무 80km / 재장전 30분 ↔ 수분", 001·005 "하이마스 포드 1개 ↔ 천무 2개". 대비쌍이 없으면 숫자가 감정을 만들지 못한다.
- **숫자를 던진 뒤 체감 단위로 번역한다** (004). "상비군 600명당 1대", "인구는 우리나라 광역시 규모".
- **비유는 기계 구조를 일상 사물로 치환**한다. 005 "포드=여러 발을 묶어 상자에 담아 끼우는 것", 003 "발사대 판매가 입찰의 시작이라면 탄약 공급망은 실제 경쟁의 본체".
- **국가를 인물로 세운다** (003·004). 계약 상대국을 "판단하는 주체"로 서사화하면 계약이 거래가 아니라 사건이 된다. 004는 에스토니아 독립사를 통째로 깔아 응원 대상으로 만들었다.
- **출처를 문장마다 붙인다** (003 "로이터 보도에 따르면" 7회 이상, 001 3분에 3회). 신뢰의 뼈대이며 채널의 "근거 있는 단언" 규칙과 정확히 일치한다.
- **주어를 상대국에 둔다** (004 최다 추천 댓글로 검증). "우리가 팔았다"가 아니라 **"그들이 골랐다"**. 자화자찬을 피하면서 자부심만 남는 문장 구조다.

**리텐션 장치 배치 패턴**

| 유형 | 배치 위치 | 검증 영상 |
|------|-----------|----------|
| 질문형 오픈루프 (대주제) | 인트로 끝 | 003·004·005 |
| 통설 부정 패턴 인터럽트 | 초반 | 003 |
| 반론형 오픈루프 (시청자 의심 대변) | 핵심 파트 직전 | 004 |
| 격상 전환 멘트 ("더 흥미로운 것은", "~는 더 상징적입니다") | 파트 전환마다 | 003 |
| 기대 배반형 ("처음부터 ~는 아니었습니다") | 중반 | 005 |
| 추가 예고형 ("~것만이 아닙니다") | 후반 | 005 |
| 폄하형 반론 → 반전 격파 | 후반 | 004 |
| 명언형 마무리 | 최후반 | 003·005 |

**004의 최대 특징**: 파트 전환을 내레이터가 하지 않고 **반말 캐릭터가 시비를 걸면 내레이터가 답하는 문답 구조**로 14분을 끌었다. 시청자의 의심을 영상 안에서 먼저 말해버려 이탈 사유를 제거하는 방식이다. (우리 채널은 1인 경어체 톤이므로 캐릭터를 쓰지 않고, **화자가 시청자 질문을 대신 말한 뒤 답하는 형태**로 변환해 쓴다.)

### 설계 원칙

- **① 본문 골격은 `사건 → 왜 크로아티아가 급한가 → 왜 하필 한국인가 → 우위 증명(성능·가성비·비교) → 그래서 우리에게 무엇인가` 순으로 잡는다.** 사용자 요청 순서(전 세계가 원한다 → 성능 → 가성비 → 비교)를 이 골격 안에 배치한다.
- **② 성능·스펙 비교 파트는 반드시 중후반에 둔다.** 앞에 두면 자랑으로, 뒤에 두면 결론으로 읽힌다 (4편 검증).
- **③ 수치는 파트당 핵심 1~2개, 반드시 대비쌍으로.** 레퍼런스 001·002는 90초~3분에 9개 이상을 쏟아붓는데, 25분 대본에 그 밀도를 옮기면 시청자가 지친다 (채널 수치 과밀 금지 규칙).
- **④ 낯선 용어는 등장 즉시 한 문장 풀이.** 천무·하이마스·다연장로켓·유도탄·사거리는 전부 일상 언어로 번역한다.
- **⑤ 사례는 나열하지 말고 각도를 바꿔 재조명한다** (003 검증 · 채널의 나열형 기피 규칙과 일치). 폴란드·노르웨이·에스토니아·크로아티아를 한 번에 늘어놓지 말고, 파트마다 다른 각도로 다시 꺼낸다.
- **⑥ 주장마다 출처를 붙인다.** "~에 따르면" 형태를 파트당 최소 1회.
- **⑦ 문장 주어를 상대국에 둔다.** "우리가 수출했다" → "그들이 한국을 골랐다".
- **⑧ 파트 전환 직전마다 오픈루프 1개, 파트 중간에 시청자 의심 대변 1개.** 2~3분 간격 유지.

## 3. 감정 증폭 전략

### 관찰

**댓글 감정 유형 순위** (5편 TOP10 교차 집계)

| 순위 | 감정 유형 | 근거 |
|------|-----------|------|
| **1위** | **자부심 (압도적)** | 002 TOP10 중 7개, 004 TOP10 중 7개. "유럽에 우리 방산 쫙 깔아라!!!"(77), "한화 에어로스페이스 자랑스럽습니다"(70), "가슴이 웅장해지네요…세계 안보의 표준"(42) |
| 2위 | 격세지감 (역사 대비) | "70년전에 탱크한대도없던나라가 전세계에 무기팔아먹고있다"(39) → 그 아래 한국사 장문 토론이 이어짐 |
| 3위 | 경쟁 우위 확인 (하이마스 비교) | "하이마스을 신속하게 운송할 대형수송선이 없다면…천무가 답이지… 화력도 두배인데"(17) |
| 4위 | 전쟁 시나리오 상상 | "이러다가 천무대 천무로 싸우는 전쟁도 보겠네"(27), "중국산 무기로 무장한 세르비아와 러시아 상대로 싸우겠지"(5) |
| 5위 | 만든 사람에 대한 감사 | "한화 연구진들 자랑스럽습니다. 그대들이 애국자입니다"(7), 005 1위 "수많은 직원들의 노고" |
| 6위 | 경제·내 삶으로의 연결 (소수·중요) | "우리 젊은이들 공대생들 일자리 많이 생기길~~"(7), "후손들 미래 먹거리"(26), "역시 기업들 광고 때릴땐 풀매수"(6) |
| 7위 | 협상력 불안 | "이제 제값받고 배짱장사 좀 해보자.... 프랑스 반만 따라해보자"(3) |

**감정을 만든 장치 역추적**

- 자부심 1위를 만든 것은 스펙이 아니라 **"그들이 골랐다"는 문장 구조**다. 004 최다 추천 댓글이 영상 후반의 "새로운 표준" 표현을 그대로 복창했다 — 후반부 메시지가 시청자 언어로 착지한 증거.
- 경쟁 우위 감정은 **경쟁 제품 대비 배수 표현**(화력 2배, 포드 2개 vs 1개)에서 나온다. 절대 스펙으로는 이 감정이 안 생긴다.
- 격세지감은 **과거와 현재를 나란히 놓는 구도**에서 나온다 (005 신기전↔천무, 002 소련제 20km↔한국제 300km).
- 005는 **개발자 고생 서사**(바다에 빠진 탄을 잠수부가 인양, 자기 의심 고백)로 감정 정점을 만들었고, 1위 댓글이 정확히 그 지점에 반응했다. 감정 엔진은 무기가 아니라 **사람**이다.

**감정 흐름 공통 패턴**

- 001: 의외감 → 답답함(미국이 안 준다) → 위기감(세르비아) → 자부심
- 002: 놀람 → 우월감 → 서늘함(징병제 부활) → 확장된 자부심
- 003: 호기심 → 납득 → 자부심·통쾌함 → **경각심(짧게)** → 자부심 회복
- 004: 놀라움 → 연민·동질감 → 위기감 → 납득·자부심 → 통쾌함 → 사명감
- 005: 자긍심 → 결핍·수치 → 좌절 → 성취 → 우위 확인

**공통 골격**: `놀람/호기심 → 상대의 위기(안보 공포는 자부심의 연료로만 사용) → 납득 → 자부심 → 통쾌함 → (경각심 한 번) → 확장된 자부심`

**핵심 발견**: 003만이 자부심 절정에서 끝내지 않고 **경각심을 한 번 통과시킨 뒤 다시 올렸다**. 조회수는 가장 낮지만 좋아요 비율 6.2%로 5편 중 압도적 1위다. 국뽕으로만 끝나지 않은 구조가 호감도를 만든다.

**반면교사 — 참여율 실패**: 004는 30만 조회에 댓글 85개, 005는 32.6만 조회에 댓글 17개(0.005%). 두 편 모두 **갈등 지점을 지우고 감탄으로 끝냈다.** 003은 반론까지 선제 수용해 논쟁 여지를 0으로 만들어 댓글 2개. 자부심 소재는 감탄하고 조용히 나가기 쉽다.

### 설계 원칙

- **① 자부심을 초반부터 점화하되, 근거는 후반에 몰아준다.** 훅에서 "그들이 한국을 골랐다"로 자부심을 켜고, 성능·가성비·비교 파트에서 근거를 쏟아부어 자부심을 **검증된 것으로 굳힌다.**
- **② 감정 곡선: 의외감(0~3분) → 위기감·연민(3~9분, 크로아티아·발칸 사정) → 납득(9~15분, 왜 한국인가) → 자부심·통쾌함 정점(15~21분, 성능·가성비·하이마스 비교) → 경각심 한 번(21~23분, 이 호황이 흔들릴 조건) → 확장된 자부심 + 우리 삶으로 착지(23~25분).**
- **③ "미국이 못 준 것을 한국이 준다"를 통쾌함의 핵심 장치로 쓴다** (001 검증). 미국의 사거리 제한 → 크로아티아의 구멍 → 한국의 충족을 붙여 배치한다. 단 미국을 조롱하지 않는다 (채널 톤 규칙: 집단 비난 금지).
- **④ 우위는 반드시 배수·대비 표현으로.** "화력 2배", "포드 2개 대 1개" 같은 상대 비교가 자부심의 연료다.
- **⑤ 개발 고생 장면 1~2개를 압축해 심는다.** 바다에 빠진 탄 인양, 시험장을 빌려주는 나라가 없어 해외를 떠돈 이야기 — 사람 이야기가 감정 엔진이라는 것이 005 1위 댓글로 검증됐다. 단 본론은 수출이므로 **한 파트 안에 2~3분으로 압축.**
- **⑥ 안보 공포는 자부심의 무대 장치로만 쓴다.** 세르비아 무장·발칸 긴장은 "그래서 크로아티아가 급했다"를 세우는 데까지만 쓰고, 공포로 끝내지 않는다 (채널 톤: 절망만 남기지 않는다).
- **⑦ 경각심을 후반에 반드시 한 번 통과시킨다** (003 검증, 좋아요율 1위 구조). 유럽 자체 생산능력 회복·EU 역내 우선 정책 같은 리스크를 짧게 짚은 뒤 다시 자부심으로 올린다.
- **⑧ 클로징은 반드시 양자택일 질문으로 좁힌다.** 레퍼런스 5편 전부가 실패한 지점이다. "지금이 정점인가, 이제 시작인가" 같은 두 갈래 질문이 댓글을 만든다.

### 구조 자산 (기법 라벨 + 효과 원리)

**훅 기법**
- `사실 충돌형 훅` — 상식과 어긋나는 두 사실을 붙여 설명 요구를 만든다 (001)
- `계보 선언형 훅` — 과거의 유산이 현재에 부활했다고 단정해 자긍심을 즉시 점화한다 (005)
- `벽 돌파 선언` — 깨질 수 없다던 것이 깨졌다고 재정의해 사건의 격을 올린다 (004)
- `통설 부정` — 시청자가 이미 가진 답(가격)을 먼저 지워 정보 공백을 연다 (003)
- `개념 명명` — 현상에 이름을 붙여 단발 뉴스를 법칙 해설로 격상시킨다 (003)

**비유/메타포 유형**
- `기계→일상 사물 치환` — 낯선 구조를 상자·묶음 같은 사물로 바꿔 이해 장벽을 없앤다 (005)
- `주변부/본체 전도` — 눈에 띄는 것이 아니라 숨은 것이 진짜 승부처라고 뒤집는다 (003)
- `거울 국가` — 상대국을 "작은 한국"으로 포지셔닝해 응원 대상으로 만든다 (004)

**리텐션 장치 유형**
- `질문형 오픈루프` — 영상 전체를 끌고 갈 질문 1개를 인트로 끝에 명시한다 (003·004·005)
- `시청자 의심 대변` — 시청자가 품을 반박을 화자가 먼저 말한 뒤 격파해 이탈 사유를 제거한다 (004)

- `추가 예고형` — "~것만이 아닙니다"로 같은 주제 안에서 한 번 더 끌고 간다 (005)

### 레퍼런스 5편이 통째로 비운 자리 (= 우리 대본의 몸통)

1. **가격 평가** — 계약 금액은 5편 모두 말하지만 **그게 제값인지 아무도 답하지 않는다.** 001 댓글이 직접 지적한 지점. 발사대 1대당 단가, 하이마스 대비 단가로 "가성비"를 숫자로 증명해야 한다.
2. **국내 경제 파급** — 고용·협력업체·수주잔고·주가로 내려온 편이 하나도 없다. 002·004 댓글이 정확히 요구하는 지점이며 **채널 관점(소비자 이해관계)과 정확히 일치**한다.
3. **발칸 정세의 깊이** — 001은 두 문장, 002는 한 줄로 끝냈는데 댓글 반응은 여기가 가장 뜨겁다.
4. **다음은 어디인가** — 002 최다 좋아요 댓글의 요구. 흐름의 다음 후보와 근거.
5. **클로징 CTA·양자택일 질문** — 5편 전부 실패. 우리가 가장 쉽게 이길 수 있는 지점.
