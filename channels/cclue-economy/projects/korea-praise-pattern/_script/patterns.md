# 공통 성공 패턴 — 경제담론 '한국 예찬' 9편 교차 분석

> 레퍼런스: 동일 채널(경제담론, 구독 1만) 9편 / 20~28분 / 2026-08-22 ~ 09-09
> 조회수 편차가 극단적이다(1,172,914 ~ 2,444, 약 480배). 아래 분석은 **009(117만) · 006(29만)의 패턴에 최우선 가중치**를 둔다.
> 인용은 패턴 주장의 근거일 뿐이다 — outline·draft 반입 금지.

## 1. 반복되는 훅 공식

### 관찰

|------|--------|----------------|-------------|
| 009 | 117만 | **자기비하 선공** | "세계 지도를 펼쳐놓고 대한민국을 찾으려면 눈을 좀 크게 떠야 합니다. …손톱으로 가리면 사라지는 크기예요." |

| 002 | 0.2만 | 장면 묘사 후 배신 | 편의점 묘사 3문장 → "그런데 이 사진을 찍은 장소가 서울이 아닙니다." |

**공통 훅 공식 — 9편 전부 예외 없이 동일**

> **`시청자가 동의할 명제/장면을 먼저 세운다 → 3문장 안에 그것을 배신한다`**

배신 방식만 다르다: 자기비하 뒤집기(009) · 상식 파괴(006) · 오답 소거(003·001) · 의미 반전(007·002) · 가정법 반전(008).

**결정적 관찰 — 상위 2편의 공통점: 자랑을 자랑으로 시작하지 않는다**
- 009는 제목이 "모든 축복"인데 첫 문장이 "손톱으로 가리면 사라지는 크기".
- 006은 한국을 3문장 뒤에야 꺼내고, 그 전까지는 **미국·영국이 못 하는 것**만 말한다.
- 반대로 최하위 002는 첫 문장부터 한국 편의점 장면이다.
→ **자화자찬 방어기제를 우회한 편이 압도적으로 터졌다.**

**9편 전부 훅에 있는 것 / 없는 것**
- 있는 것: 단문 3~5개 연타, 구체 고유명사·연도·수치 1개, "그런데"로 꺾는 반전
- 없는 것: 인사, 채널 소개, "오늘은 ~에 대해 알아보겠습니다", 구독 요청

### 인트로가 공통 수행하는 5가지 역할

9편 인트로를 겹쳐 놓으면 아래 5개가 거의 그대로 반복된다.

| 역할 | 하는 일 | 확인된 영상 |
|------|---------|------------|
| ① 오답 소거 | 시청자가 떠올릴 답 2~3개를 먼저 죽인다 ("근면? 아닙니다" / "친절해서가 아니고 정이 많아서도 아니고") | 001·007·003·004 |
| ② 선(先) 자폭 | 제목의 과장을 화자가 **먼저 인정**한다 ("먼저 솔직하게 말씀드리겠습니다") | 003·009·005 |
| ③ 앵글 선언 | 남들 아는 얘기가 아니라는 신호 ("세계은행이 칭찬한 건 소득이었어요. 제가 볼 건 발밑입니다") | 005·002 |
| ④ 완주 보상 예고 | 끝까지 보면 **오늘 밤 무엇이 달라지는지**를 구체적 사물로 약속 | 009(수도꼭지)·005(현관 스위치) |
| ⑤ 2차 오픈루프 | 정답을 공개한 **뒤에도** 남는 미끼를 미리 건다 ("마지막에 불편한 이야기가 있습니다") | 004·005·007·008·006 |

⑤가 이 장르의 척추다. 칭찬 나열형은 중반에 이탈하는데, **"뒤에 반전이 있다"를 인트로에서 계약**해 20분을 붙든다. 9편 중 7편이 이 장치를 쓴다.

### 설계 원칙 (훅·인트로)

1. **첫 문장은 자랑 금지.** 우리 소재가 자랑이면 훅은 **결핍·자기비하·남의 실패**로 연다. 한국이라는 단어는 3문장 뒤에 꺼낸다.
2. **훅은 5문장 이내 단문 연타로 짜고, 4번째 문장에 "그런데"를 넣어 꺾는다.** 꺾는 문장은 10자 안팎 단문으로 쓴다.
3. **인트로에서 오답 3개를 먼저 죽인다.** "A 때문도 아니고 B 때문도 아니고 C 때문도 아닙니다."
4. **인트로에서 제목의 과장을 화자가 먼저 자백한다.** 자백 직후 `다만 ~`으로 논지를 더 좁고 단단하게 재정의한다. (009의 "물 스트레스 국가입니다 → 다만 주권은 100%"가 표준형)
5. **인트로 끝에 오픈루프 2개를 건다.** ⓐ 완주 보상 = 오늘 밤 시청자가 만질 사물 1개 ⓑ 후반 반전 예고 = "마지막에 불편한 이야기를 하겠습니다".
6. **인사·채널소개·구독 요청은 인트로에 0초.** (9편 전부 지킴 — 채널 profile 규칙과 동일)

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰 — 구조

**본론 구조는 두 계열뿐이다.**

| 계열 | 구조 | 해당 영상 | 성적 |
|------|------|----------|------|
| **A. 사이클 반복형** | 동일한 4~6박자 템플릿을 N회 반복 | 009·008·007·001·005 | 009 117만 / 008 0.9만 — **편차 큼** |
| **B. 미스터리 역주행형** | 현재 결과 → 이상 발견 → 통념 격파 → 뿌리로 역주행 → 현재 복귀 | 006·002·004·003 | 006 29만 / 002 0.2만 |

계열 자체는 성패를 가르지 않는다. **가른 것은 아래 3가지다.**

**성패를 가른 요인 ① — "남의 지옥"을 파트마다 재장전했는가**

009(117만)는 파트마다 **`우리 자산 → 숫자 → 그게 없는 나라의 실제 분쟁 → 우리 위치 재정의`** 4박자를 돌린다. 인더스강·메콩강·싱가포르·볼리비아가 파트마다 새 긴장을 공급한다.
006(29만)도 동일 — 미국 조선업 몰락을 자랑 구간 한복판에 박아 넣는다.
반면 002(0.2만)는 22분 내내 우리 이야기만 한다. 긴장 재장전이 없다.

> 자랑 콘텐츠는 자랑만 하면 물린다. **긴장(남의 나라 실패) ↔ 안도(우리)를 최소 3회 왕복**시켜야 자부심의 강도가 매번 리셋된다.

**성패를 가른 요인 ② — 나열을 마지막에 하나의 축으로 꿰었는가**

- 007: 7개 항목 나열 후 → "**두 글자입니다. 시간입니다**" → 앞 7개를 시간 축으로 **전부 재나열**
- 008: 10번째 항목(치안)을 "앞 아홉 가지를 전부 가능하게 만든 토대"로 격상
- 006: P3(미국 몰락)을 20분 뒤 P8(출산율)에서 부메랑으로 회수

→ 나열형이 나열로 끝나면 채널 profile의 기피 유형("나열형")이 되고, **정답 축으로 꿰는 순간 인과형으로 승격**한다. 정답 회수 시 앞 항목을 다시 훑는 것이 핵심 — 중간에 놓친 시청자까지 데려간다.

**성패를 가른 요인 ③ — 자기 반박 블록의 유무와 위치**

9편 중 8편이 후반에 자기 반박 블록을 둔다.

| 영상 | 자기 반박 내용 | 신호 문장 |
|------|--------------|----------|
| 006 | 출산율 0.75, 기술 승계 단절 | "좋은 말로만 마무리하면 그건 정직하지 않은 겁니다" |
| 005 | 한전 30조 적자, 시설 노후화 | "오늘 이야기를 여기서 끝내면 반쪽입니다" |
| 007 | 편의의 청구서를 낸 노동자 | "여기서 끝내면 반쪽입니다" |
| 004 | 1인당 GDP는 아직 일본이 위 | "여기까지 들으시면 기분이 참 좋으실 겁니다. 그런데…" |
| 001 | 오기가 불안으로 변질 → 저출산 | "여기까지 들으시면 기분 좋으실 겁니다. 그런데" |
| 009 | 물 스트레스 국가 (2회 자백) | "이건 짚고 넘어가야 공정합니다" |

**댓글 증거**: 007·008에서 **내용을 언급한 유일한 댓글이 둘 다 이 블록에 반응**했다 ("국뽕 이야기지만 단점도 명확하게 집어 줍니다" / "다른 사람들의 희생이 있다는 걸 새삼 배우고 갑니다"). 항목 10개는 아무도 언급하지 않았다.

> 자기 반박은 겸손 장치가 아니라 **댓글을 만드는 유일한 장치**다.

### 관찰 — 전달 기법

**① 숫자는 반드시 '몸으로 아는 단위'로 2차 환산한다 (9편 전부)**

| 원 수치 | 환산 |
|---------|------|
| 0.07% | "손톱으로 가리면 사라지는 크기" (009) |
| 해안선 15,270km | "서울-부산 38번 왕복" (009) |
| 조수간만 9m | "3층 건물 높이" (009) |
| 20만 명 | "강릉시 인구가 1년 만에 통째로" (003) |
| 5,800만 개 | "하루에 25만 개 꼴" (007) |
| 38.6주 | "9개월입니다" (007) |
| 정전 9분 | "태풍 부는 밤에도 냉장고는 멈추지 않습니다" (008) |

009는 명시적 전환 문구까지 갖고 있다: "숫자로만 들으면 감이 잘 안 오실 수 있습니다. 그래서 이렇게 바꿔 말씀드리겠습니다."

**② 수치 밀도는 성패와 역상관**

- 009(117만): 파트당 핵심 수치 1~2개. 대신 **고유명사(지명·연도·기관)를 촘촘히** 깔아 신뢰를 만든다.
- 006(29만): 수치 과밀. 실제로 댓글에서 수치 신뢰 공격이 나왔다.
- 005: 훅 직후 수치 1개(1960년 소득 1,200달러)가 틀렸고, **그 지적이 1위 댓글이 됐다.**
→ 채널 profile의 "수치 과밀 금지"가 실증된다. 신뢰는 수치 개수가 아니라 **고유명사 + 출처 명시**에서 나온다.

**③ 비유는 흩뿌리지 않고 하나를 4회 변주한다**

002의 씨앗–논–추수(4회 변주)가 가장 정교한 사례. 009는 "수천 년짜리 적금"(갯벌), 007은 "물속의 물고기"를 최종 비유로 단 한 번만 쓴다.
→ **파트별로 다른 비유를 배정하되, 영상 전체를 관통하는 주제 비유는 1개만 두고 3~4회 변주**한다.

**④ 부정 대구법 "A가 아니라 B다" — 9편 전부의 주력 수사**

001 "이 나라의 엔진은 자원도 운도 아니었다. 무시당한 기억이었다" / 007 "원망이 아니었던 겁니다. 후유증이었어요" / 002 "복사한 게 아니라 여기서 자란 겁니다" / 006 "이건 우리끼리 하는 자찬이 아닙니다. 남이 매긴 숫자입니다"
→ 논지 전환·개념 재정의·감정 전환이 전부 이 한 구문으로 처리된다.

**⑤ 팩트체크를 대본 안에서 직접 수행 (신뢰 획득 장치)**

003이 3회, 008이 3회 수행한다. 고정 4박자: `루머 소개 → "그건 사실이 아닙니다" → 정확한 수치 → "하지만 그렇다고 이 숫자가 가벼워지는 건 아닙니다"`
008의 "UN 수돗물 8위" 정정, 003의 "서울 지갑 반환율 90%" 정정이 대표 사례.

**⑥ 통계 뒤에 반드시 사람을 세운다**

005의 선재대교 19시간 케이블 교체 장면, 008의 "태풍 밤 전신주에 오른 사람", 006의 "30년째 용접봉을 잡아온 기술자".
→ 3박자 고정: **숫자 → 장면 → 숫자 재해석.**

**9편에서 확인된 장치 유형과 배치 위치**

| 위치 | 장치 유형 | 확인 빈도 |
|------|----------|----------|
| 인트로 끝 | 장기 오픈루프 2개(완주 보상 + 후반 반전 예고) | 7/9 |
| 파트 1→2 | 격상 예고 ("여기까지는 익숙하실 겁니다. 진짜 이야기는 지금부터입니다") | 9/9 |
| 각 파트 진입 | 서수 카운터 ("세 번째는 ~입니다") = 진행률 표시 | 6/9 |
| 각 파트 진입 | 강도·가치 예고 ("여기서부터 좀 무서워집니다" / "이게 정말 결정적입니다") | 8/9 |
| 파트 중간 | 질문 → **1문장 내 즉답** | 9/9 |
| 중반 | 반론 선점 ("이런 의문이 생기실 겁니다. …맞습니다, 이게 핵심 질문입니다") | 7/9 |
| 중반 | 화자 감정 노출 ("저는 이 대목이 가장 뭉클합니다") | 9/9 |
| 후반 진입 | 자기 반박 신호탄 ("여기서 끝내면 반쪽입니다") | 8/9 |
| 클로징 | 수미상관 신호 ("그래서 다시 첫 사진입니다" / "이제 아까 그 말로 돌아가 보겠습니다") | 9/9 |

**핵심 관찰**: **파트가 바뀔 때마다 예외 없이 메타 문장(지금부터 무슨 얘기를 할지 예고하는 문장)이 하나 들어간다.** 20분 내내 "다음에 뭐가 나오는지"를 시청자가 모르는 순간이 없다.

**전환 문구는 매번 형태를 바꾼다.** "N번째는 ~입니다"만 반복하면 지루해지므로 007처럼 강도 예고 / 공포 예고 / 가치 예고 / 소재 브릿지 / 무자각 지적을 섞는다.

### 설계 원칙 (본론)

1. **본론 뼈대는 "사이클 반복형 + 마지막 통합축"으로 잡는다.** 파트 3~5개, 각 파트에 동일한 4박자를 돌리고, 마지막 파트에서 앞 전부를 하나의 개념으로 꿰며 **앞 항목을 재나열**한다.
2. **파트 4박자 고정**: ① 2인칭 장면 소환 → ② 수치 1~2개 + 출처 → ③ **그게 없는 나라의 실제 사례(긴장 재장전)** → ④ "다만 그늘도 있습니다" 한 줄.
   ③이 이 장르의 심장이다. ③이 없으면 나열형이 되고 조회수가 죽는다.
3. **수치는 파트당 1~2개로 제한하고, 던진 즉시 몸으로 아는 단위로 환산한다.** 신뢰는 수치 개수가 아니라 기관명·연도·지명의 밀도로 만든다.
4. **훅·초반 20% 구간의 수치는 출처와 연도가 확인된 것만 쓴다.** 애매하면 뺀다 (005의 1위 댓글이 초반 수치 오류 지적).
5. **팩트체크 블록을 최소 1회 넣는다.** 널리 퍼진 과장 하나를 화자가 직접 정정한다. 4박자 고정.
6. **자기 반박 블록을 후반 85% 지점에 반드시 배치**하고, 인트로에서 미리 예고한다. 이것이 댓글을 만든다.
7. **"우리가 완전히 앞선 건 아니다"류 방어 수치는 중반 이전에 한 번 더 박는다.** 004는 GDP 방어를 20분 뒤에 뒀다가 "자료가 언제적이냐"는 공격 댓글을 맞았다.
8. **파트 전환 직전마다 메타 문장 1개 + 오픈루프 1개.** 전환 문구는 파트마다 형태를 바꾼다 (강도/가치/공포/소재/무자각 예고를 로테이션).
9. **주제 비유는 1개만 정해 3~4회 변주**하고, 나머지는 파트 전속 비유로 배정한다.

### 관찰 — 감정을 만든 장치 역추적

**가장 뜨거운 감정(자부심)을 만든 장치 — 직접 자랑이 아니다**

9편 전부 자부심을 **외부 시선 경유**로 만든다.
- 제3자 인용: "하버드 교수도 인정한"(006) / "니케이가 짚었습니다"(004) / "세계은행이 108개국 앞에 지목"(005)
- 명시적 정당화 문장이 반복된다: "한국이 잘한다고 우리가 떠들면 그건 자랑입니다. 그런데 일본이 인정하면 그건 자료가 됩니다."(004) / "이건 우리끼리 하는 자찬이 아닙니다. 남이 매긴 숫자입니다."(006)
- 썸네일도 동일 전략: **한국인이 아니라 놀라는 외국인 얼굴**을 쓴 편이 5편(005·007·008·009·006)

**감정 최고점을 만든 장치 — 시청자 본인을 공로자로 승격**

006 P7이 표준형이다. 직업 호명 릴레이(공장·중동 현장·구로공단·시장 좌판 7개)를 깔고 → "이 순위표는 사실상 **여러분의 성적표**입니다"로 소유권을 넘긴다.
001도 동일: "그 일을 해낸 세대가 지금 이 영상을 보고 계십니다."
→ 이 장치를 쓴 001·006에서 **자기 경험 투고형 장문 댓글**이 나왔다.

**감정을 만들지 못한 것 — 산업 성취 나열**

001에서 최다 공감 댓글은 HBM 79%·조선업이 아니라 **"밥은 굶어도 자식 공부는"**(교육 파트)이었다. 002도 현대로템·나스닥 상장이 아니라 1937년 강제이주 파트에 반응했다.
→ **감정은 산업이 아니라 사람에서 나온다.** 성과 나열은 감정 파트의 신뢰를 보증하는 역할만 한다.

### 관찰 — 감정 흐름의 공통 패턴

9편의 감정 곡선을 겹치면 하나로 수렴한다.

```
호기심/자기비하(0~5%) → 놀라움·재발견(5~35%) → 대리 긴장·연민(남의 나라, 35~55%)
→ 안도·자부심(55~75%) → 뭉클함 정점(사람 서사, 75~85%)
→ 냉각·경각심(자기 반박, 85~95%) → 다짐·위안(95~100%)
```

**핵심: 9편 중 8편이 자부심 정점에서 끝내지 않는다.** 정점 직후 의도적으로 온도를 내렸다가 마지막 3문장에서만 반 계단 올려 마감한다. 001은 이를 "감정 3번 꺾기"로 실행해 27분이 평탄하게 느껴지지 않게 만들었다.

### 설계 원칙 (감정)

1. **감정 배분 목표: 자부심 40% / 대리 긴장·연민 20% / 뭉클함 20% / 경각심 15% / 다짐 5%.**
2. **자부심은 절대 화자가 직접 주장하지 않는다.** 제3자 인용·해외 대조·"남이 매긴 숫자" 프레이밍으로만 만든다. "우리가 잘한다"는 문장을 대본에서 금지한다.
3. **긴장 ↔ 안도를 최소 3회 왕복시킨다.** 각 왕복의 긴장 소재는 반드시 **남의 나라 실제 사례**(분쟁·붕괴·비용)로 공급한다.
4. **뭉클함 파트는 산업이 아니라 사람으로 짠다.** 부모 세대·교육·희생 서사에 본론의 가장 큰 분량을 배정한다 (001·002 실증).
5. **후반 80% 지점에 시청자 호명 파트를 둔다.** 직업·시대를 3~5개 나열해 시청자 중 누군가는 반드시 걸리게 하고, 마지막에 소유권을 넘기는 한 문장으로 닫는다.
6. **자부심 정점에서 끝내지 않는다.** 정점 직후 자기 반박으로 온도를 내리고, 마지막에 반 계단만 올린다.
7. **공포·불안은 쓰지 않는다.** 009는 22분 동안 우리 쪽 공포를 한 번도 쓰지 않고 117만을 냈다. 공포의 주어는 항상 남의 나라다.
8. **정치인·특정 집단 평가는 대본에서 비워둔다.** 006은 정치를 한 마디도 안 했는데 최다 공감이 정치 성토였다. 화자가 비워두면 시청자가 알아서 채운다 — 채널 톤(구조/시스템 비판)을 지키면서 같은 반응을 안전하게 얻는다.

- 색채 공통점: **배경은 무엇이든, 텍스트는 예외 없이 노랑 1행 + 시안 2행.** 이것이 이 채널의 사실상 브랜드 컬러
- **고퍼포먼스 비주얼 특징 — 상위 2편만 갖는 것**:
  - ① **한반도 자체가 발광하는 중앙 오브젝트**로 등장 (009 금빛 한반도, 006 형광 초록 한반도). 3~9위는 한반도가 없거나 작다
  - ② **인물이 시청자를 보지 않고 한반도를 본다** — 시선이 주인공(한반도)을 지시한다
  - ③ 009는 원형 인셋 4컷이 **본문 파트 목차 역할**을 한다 (갯벌·강·산·KTX = 실제 파트 소재)
- 모바일 가시성(160×90px): 2줄 34자는 1행만 읽힌다. **1행 13~14자가 상한선**이며, 상위 2편이 정확히 이 범위다

### 관찰 — 제목

**제목 공식 (9/9 동일)**

```
"큰따옴표 인용 대사"(10~20자) + 권위/규모 수식 + 소재 + 감정 형용사 + 오픈루프 종결
```

- **9편 전부 큰따옴표 인용문으로 시작**한다. 출처는 밝히지 않거나(009·005·002) 권위자를 붙인다(006 하버드, 001 40년 외신기자)

- 오픈루프 종결어: `진짜 이유` / `소름 돋는 이유` / `경이로운 가치` / `가장 소름 돋고 위대한 특징`
- 최상급 중첩: 006은 "제일 + 지구상에서 가장 + 희귀한" 3중첩

**썸네일-제목 역할 분담 공식**
- 썸네일 1행 = **감정(짧은 구어 대사)** / 제목 앞 = **감정(더 긴 인용 대사)** — 서로 다른 문장
- 썸네일 2행 = **권위 + 주제 압축** / 제목 뒤 = **정보 + 검색 키워드**
- 예: 009 제목 `"작은 땅에 모든 축복을 쏟아부었다"` ↔ 썸네일 `"신이 한국에만 몰빵했다!"` — 같은 뜻, 다른 문장, 다른 온도

### 설계 원칙 (썸네일·제목)

1. **썸네일 텍스트는 정확히 2개 요소, 2줄.** 1행 **12~14자** 큰따옴표 대사체(구어·감탄), 2행 **16~20자** "세계가/○○이 + 감정동사 + 주제". 총 28~34자.
2. **색은 고정한다.** 1행 형광 노랑 + 두꺼운 검정 외곽선, 2행 시안 + 검정 외곽선, 하단 35~40% 가로 전폭.
3. **비주얼 필수 요소 3가지**: ① 발광하는 한반도(또는 태극) 중앙 배치 ② 놀란 표정의 외국인 1~5인 ③ 인물의 시선이 한반도를 향할 것.
4. **본문 파트 소재를 원형 인셋 3~4컷으로 배치**해 썸네일이 목차 역할을 하게 한다 (009 기법).
5. **제목은 큰따옴표 인용 대사로 시작**하고, 그 대사는 **썸네일 1행과 반드시 다른 문장**으로 쓴다.
6. **제목 뒤에 오픈루프 종결어를 붙인다**: "진짜 이유" / "소름 돋는 이유" / "~한 특징".
7. **역할 분담**: 썸네일=감정 온도, 제목=근거·맥락. 같은 내용을 두 번 쓰지 않는다.

- `대리 긴장 왕복` — 남의 나라 분쟁으로 심박을 올렸다가 우리로 착지시켜 자부심 강도를 리셋한다. 3회 반복 (009)

**데이터 제시 기법**
- `2차 환산 의무화` — 수치를 던진 직후 "숫자로만 들으면 감이 잘 안 오실 겁니다. 그래서 이렇게 바꿔 말씀드리겠습니다"로 장면 번역한다 (008)
- `대본 내 팩트체크 4박자` — 루머 소개 → "그건 사실이 아닙니다" → 정확한 수치 → "하지만 이 숫자가 가벼워지는 건 아닙니다" (003·008)
- `정직 고백 2회` — "완벽하다고 말하면 거짓말입니다" / "이건 짚고 넘어가야 공정합니다". 자백 직후 `다만 ~`으로 논지를 더 좁게 재정의 (009)
- `출처 선행 배치` — 기관명·연도를 문장 앞에 달고 한 문장 해설을 붙인다 ("영국 ONS, 국가통계청이라고 부르는 곳이에요") (003)
- `조롱 인용 후 결과 제시` — 과거의 조롱을 원문 인용한 뒤 결과만 날짜와 함께 붙인다. 반박을 화자가 하지 않고 사실이 하게 만든다 (001·006)
- `수치 절제 + 고유명사 밀도` — 파트당 수치 1~2개로 줄이고 지명·연도·기관명을 촘촘히 깔아 신뢰를 만든다 (009, 117만편의 방식)

## 6. 클로징 — 9편 공통 골격과 우리 채널 규칙 대조

**9편 클로징 공통 순서**

```
① 정리 신호("정리해 볼까요?" / "다시 첫 사진입니다")
② 훅 문장·소품 수미상관 회수
③ 인과 사슬 1문장 압축 (파트별 재요약이 아니라 한 문장)
④ 화자의 판단 한 줄
⑤ 오늘 밤 실행 가능한 행동 1~3가지
⑥ 댓글 CTA
⑦ 구독 요청 (맨 끝 1회만 — 9/9 공통)
```

**②③⑤는 그대로 이식한다.** 특히 ③(파트별 재요약 금지, 인과 사슬 한 문장)과 ⑤(추상 결론을 오늘 밤 만질 사물로 착지)는 채널 profile의 클로징 1·2단계와 정확히 맞는다.

**⑥은 반드시 교체한다 — 9편 전부의 최대 약점**

| 영상 | CTA 형태 | 결과 |
|------|---------|------|
| 001·005·007·009 | "댓글에 대한민국 파이팅 한 줄만 남겨 주세요" | 001은 10개 중 6개가 그 문구 그대로. **댓글 = CTA 문구 1:1 대응이 실증됨.** 다만 구호에는 답글도 좋아요도 안 붙는다(전부 좋아요 0) |
| 003 | "가장 값진 게 무엇이었는지" | 직접 답한 댓글 1개. 회수 실패 |
| 004 | "여러분의 생각도 남겨 주십시오" | 조회 1.2만에 댓글 16개(0.13%) |
| 008 | 질문 2개를 동시에 | 댓글 1개 |
| 006 | **"1970년대, 1980년대 어디서 무슨 일을 하고 계셨습니까? 공장이셨습니까? 사무실이셨습니까? 중동 현장이셨습니까?"** | **32좋아요짜리 장문 경험 댓글 생성 — 9편 중 유일한 성공** |

> **CTA 문구가 댓글 내용을 그대로 결정한다.** 구호를 요구하면 구호가 오고, 개인사를 물으면 장문이 온다. 006만이 **선택지를 3~4개로 제시한 질문**을 썼고 유일하게 토론형 댓글을 얻었다.

**설계 원칙 (클로징)**
1. 채널 profile의 5단계 순서(현상 정리 → 대안·위안 → **화자의 판단** → 시청자 질문 → 아웃트로 고정 문구)를 지킨다. 질문이 결론을 대체하면 판단 회피로 들린다.
2. **③ 인과 사슬 한 문장**으로 본문을 압축한다. 파트별 재요약 금지.
3. **⑤ 오늘 밤 만질 사물 1개**로 착지시키고, 그 사물은 인트로 완주 보상 예고와 동일한 것이어야 한다(수미상관).
4. **CTA는 구호도 열린 질문도 아닌 양자택일 질문 1개**로 좁힌다. 006의 선택지 제시 방식(예/아니오 또는 3~4지선다)을 차용한다.
5. 006의 추가 장치를 차용한다: 질문 직후 **"그 한 줄들이 모이면 그게 바로 ○○입니다"** — 댓글 쓰기를 명예 등재로 프레이밍한다.
6. 구독 요청은 맨 끝 1회. 004처럼 **이유를 붙이면** 설득력이 올라간다("그 하나가 모여서 이런 이야기를 더 깊이 파볼 힘이 됩니다").

## 7. 9편이 아무도 다루지 않은 것 (우리의 차별화 지점)

댓글에서 반복 확인된 **미충족 구간**이다. 우리 대본은 여기를 선점한다.

1. **"자원이 없다 / 석유가 없다"** — 009 반발 댓글의 1순위. 9편 중 정면으로 다룬 편이 없다
2. **"지정학은 축복이 아니라 저주다"** — 침략의 역사를 인정한 뒤 자산으로 전환하는 논리가 없다
3. **"결과론일 뿐, 부모 세대 희생 덕분"** — 지형·인프라만 칭찬하면 노년층이 소외된다. 땅·시스템 + 사람을 반드시 결합
4. **"그래서 나는 뭘 보고 뭘 준비하면 되나"** — 9편 전부 국가 단위 숙제로 끝나고 **개인 행동 지침이 없다.** 006에서 시청자가 그 공백을 각자의 정책 제안(임금 이중화·연금·정치 개혁)으로 메웠다
5. **정치 프레임 선점** — 005는 한전 적자를 원가 구조로 설명했는데 댓글은 정권 책임으로 치환했다. 구조 설명을 먼저 못 박아야 댓글창이 논쟁으로 새지 않는다

→ 4번이 우리 채널의 가장 큰 오버딜리버 기회다. 채널 메시지 방향("그래서 나는 뭘 보고 뭘 준비하면 되는가")과 정확히 일치하며, 9편 전부가 비워둔 자리다.
