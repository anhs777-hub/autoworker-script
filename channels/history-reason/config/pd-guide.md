# PD 전략 가이드: 역사 속 이유

> 파이프라인 도구 파일(`.claude/`·`prompts/`·`scripts/`)은 업데이트 때 덮어써지므로, 이 채널만의 진행 방식은 전부 이 파일에 적는다. 채널 성격의 정본은 `profile.md`.
>
> 2026-10-31 「조선정책실」에서 바꾼 채널이다. 조선정책실 때 확정한 진행 방식(사료 묶음 → 경쟁작 해부 → 차별 설계 → 성과 판독)은 뼈대를 그대로 두고 근현대 전쟁사에 맞게 고쳤다. 이전 판: `config/_archive-joseon/pd-guide.md`

## 1. 레퍼런스 단계 — 자료 묶음 + 경쟁 영상

파이프라인 상태 감지는 `_refs/`가 비어 있으면 COLLECT, `_refs/*/analysis.md`가 없으면 ANALYZE로 멈춘다. 이 채널은 레퍼런스 자리를 아래처럼 채운다.

### 001번 = 자료 묶음 (항상 — PD가 직접 만든다)
- 위치: `{P}/_refs/001/`
- `source.md` — 이 소재의 핵심 기록 10~20건. 기록마다 `날짜 | 출처(문서·쪽·URL) | 핵심 내용 1~2문장 | 쓸 곳(장면/숫자/흐름)`
- `meta.md` — `제목: 자료 묶음 — {소재}`, `유형: 사료`, 조사일
- `analysis.md` — 영상 분석 대신 아래 4가지를 뽑는다
  1. **장면 후보** — 날짜가 붙은 구체적 장면(누가, 무엇을, 어떻게). 훅·파트 첫머리 후보
  2. **숫자 후보** — 대비나 변화가 보이는 숫자. 영상 전체에서 핵심 1~2개만 쓸 것을 전제로 순위
  3. **역설과 이유** — 「유리한 조건」 목록(훅의 역설 쌓기 재료)과 「진짜 이유」 후보 3~5개, 각 이유를 증명하는 기록
  4. **빈 곳** — 아직 근거가 없는 것과 보충 계획

### 002번부터 = 경쟁 영상 (1~2개, 있으면 항상)
- 같은 질문의 영상을 `collect.py`로 1~2개 수집해 평소처럼 분석한다
- 쓰는 목적: **「그 영상들이 다루지 않은 장면·숫자」를 찾는 것**, 그리고 레퍼런스 채널 「역사랑방」 영상이면 훅·구조를 비교하는 것. 문장을 따라 쓰지 않는다

## 2. 자료 조사 (DATA_PREP)

### 역할 나누기
| 누가 | 무엇을 | 방법 |
|---|---|---|
| **PD 직접** | 001 자료 묶음, 핵심 1차 문서 본문 확인 | 브라우저·웹. 6·25: 국방부 군사편찬연구소(imhc.mil.kr) 『6·25전쟁사』 PDF, FRUS(history.state.gov), 미 육군 CMH 공간사(history.army.mil), 정전협정문. 국내 신문 아카이브 |
| **data-researcher (백그라운드)** | 연구 정리, 병력·사상자·물자 숫자의 출처별 차이, 지명의 현재 위치·거리 | 웹 검색. PD가 001의 기록 목록을 함께 넘긴다. 서브에이전트는 파일을 쓰지 못하므로 본문을 반환하고 PD가 저장한다 |

- **대본에 쓰는 숫자·인용은 전부 원문을 연다.** 2차 정리 자료만 보고 쓰지 않는다

### 출처 등급 표시 — `verified-data.md`의 모든 날짜·숫자에 붙인다
| 표시 | 뜻 | 대본에서 |
|---|---|---|
| `[공간사]` | 각국 공식 전사 (서명·쪽) | 「국방부 전쟁사에는…」 또는 사실로 바로 |
| `[1차]` | 당시 문서·회의록·협정문·신문 (문서명·날짜) | 「그날 회의록에는…」처럼 문서 이름을 댄다 |
| `[회고]` | 회고록·증언 (누구·책 이름) | 「○○는 회고록에 이렇게 적었습니다」 — 사실처럼 쓰지 않는다 |
| `[논문]` | 연구 논문 (저자·연도) | 「연구자들은 ○○로 봅니다」 — 원전과 섞지 않는다 |
| `[추정]` | 확인 안 됨 | **쓰지 않는다** |

- `verified-data.md`에 없는 날짜·숫자는 대본에 쓰지 않는다
- 병력·사상자처럼 기록마다 다른 숫자는 둘 다 적고 「기록마다 다름」 표시 → 대본에서는 범위로
- 전근대 소재는 이전 채널 방식(실록 기사 ID, `[실록]`·`[원전]`)을 쓴다 → `config/_archive-joseon/pd-guide.md` 2장

### 패턴 추출 (`patterns.md`) — 레퍼런스가 1개여도 멈추지 않는다
- 파이프라인 기본값은 「analysis.md 2개 이상」이지만, 001 자료 묶음 하나로도 진행한다
- `patterns.md`는 profile 「서사 구조」(훅 → 배경 → 전개 → 중반 이유 세우기 → 이유 확인 사건 → 결말 → 클로징)에 자료의 장면·숫자를 배치한 표로 쓴다. 경쟁 영상(002~)이 있으면 「그 영상이 쓴 장면 / 안 쓴 장면」 열을 더한다

### 자료 확인 지점 — 집필 전에 사용자에게 보여 준다
- DATA_PREP가 끝나면 STRATEGY로 바로 가지 않고, 한 화면으로 요약해 사용자에게 확인받는다
  - 질문 한 줄, 역설 재료 3개, 진짜 이유 ①②③, 장면 후보 상위 5개, 숫자 후보 상위 3개, 빈 곳
- 첫 8편(시험 기간)은 반드시 거친다

## 3. 소재 선정 · 경쟁작 해부 → 차별 설계

**0단계 — 시작 조건** (001 자료 묶음을 만든 직후)
- profile 「소재 선정 규칙」 4개를 통과하는가 (역설 한 줄 · 날짜 장면 5개 · 아는 큰 이름 · 경쟁 조건)
- 하나라도 아니면 3단계 정지선과 같이 처리한다

**1단계 — 경쟁작 해부표** (DATA_PREP 끝, STRATEGY 전 · `_script/competition.md`)
- 소재를 **「{대상} 왜」, 「{대상} 이유」, 「{사건명}」** 세 가지로 검색해 상위 5편(조회 순)을 한 표에 (`.venv/Scripts/python -m yt_dlp "ytsearch15:{검색어}" --flat-playlist --print "%(view_count)s|%(channel)s|%(title)s"`)
- 칸: 제목(단어·형식) · 썸네일(색·구도·문구) · 첫 장면 · 구조·결론 · **댓글**(아직 묻는 질문, 틀렸다고 지적한 부분) · 출처를 댔는가
- 표 아래에 「경쟁작들이 공통으로 한 것」과 「공통으로 놓친 것」 각 3줄 이내
- **역사랑방·호롱의 기록실·기묘한 기록실처럼 같은 문형의 채널**은 질문이 겹치는지 꼭 본다(2026-10-31 조사에서 같은 문형이 빠르게 늘고 있음)
- 조회 1천 회 미만 영상(AI 양산 채널)은 참고로만 올리고 「붐빈다」 판단에는 세지 않는다

**2단계 — 차별 4축** (STRATEGY · concept.md 「차별 설계」) — **최소 2축을 경쟁작과 다르게**
1. **질문** — 경쟁작이 건너뛴 「왜」를 축으로 (예: 「1·4 후퇴는 어땠나」가 아니라 「중공군은 왜 거기서 멈췄나」)
2. **숫자·보급** — 경쟁작이 영웅담·전투 묘사로 간 자리에 숫자·보급·결정을 놓는다(profile 정체성 3)
3. **기록 바로잡기** — 흔히 틀리게 알려진 숫자·일화를 1차 문서로 바로잡는다. 「흔히 ~로 알려졌지만, 기록에는 ~」(경쟁작 이름은 말하지 않는다)
4. **피드 대조** — 경쟁작 썸네일 3~5개 옆에 우리 썸네일을 놓았을 때 **색·구도·문구 형식 중 2개 이상**이 달라야 한다

**3단계 — 정지선** (해당하면 멈추고 사용자에게 알린다)
- 조회 10만+ 대형 채널(방송사 포함)이 같은 질문을 같은 깊이로 이미 다뤘다
- 최근 2주 안에 같은 질문의 1만+ 영상이 3편 이상 몰렸다
- 0단계 시작 조건 미달
- 차별 축이 「엮는 방식만 다름」뿐이다
- **처리: 자동으로 넘어가지 않는다.** 걸린 조건 + profile 「다루는 내용」에서 다음 소재 후보 2개를 같이 보여 주고 사용자가 고른다

## 4. 제목 · 썸네일 문구 (2026-10-31)

### 제목 — 질문형
- 틀: **「{유리한 조건 한 구절}.. {주체}는 왜 {반대 결과}했을까?｜{사건명}」** (레퍼런스 채널에서 90만·75만·38만 회를 낸 문형)
  - 예: `서울까지 다시 빼앗았는데.. 중공군은 왜 더 내려오지 못했을까?｜1·4 후퇴`
  - 예: `국경 비석까지 세웠는데.. 조선은 왜 '간도'를 지키지 못했을까?｜백두산정계비`
- **길이: 권장 35~45자, 상한 50자** (따옴표·공백 포함, `len()`으로 센다) — 끝의 「｜사건명」 때문에 파이프라인 기본값(상한 40자)보다 길게 허용하는 채널 예외. 단 **「?」까지 앞 35자 안**에 들어와야 모바일 목록에서 질문이 잘리지 않는다
- 시청자가 아는 큰 이름(서울·원자폭탄·백령도·진주만)을 앞 20자 안에. 끝의 「｜사건명」은 검색어 자리
- 앞 구절의 사실은 `verified-data.md` 근거가 있는 것만. 숫자는 하나까지
- 금지: 「충격」 「소름」 「진실」 「미스터리」, 인물 평가어, 혐오·멸칭, 오늘 정치 연결

### 썸네일 문구 — 단정형 「~한 이유」
- 제목이 질문형이므로 썸네일은 **「{조건}인데 / ~한 이유」** 단정형으로 역할을 나눈다. 제목과 같은 문장을 쓰지 않는다
  - 예: 「원폭 300발이 있었는데 / 끝내 안 쓴 이유」 · 「옹진은 빼앗겼는데 / 이 섬들만 한국 땅인 이유」
- 줄당 8~13자, 물음표 없음. 디자인은 `thumbnail-strategy.json`

## 5. 훅 (0:00~1:10)과 인트로

> 근거: 레퍼런스 채널의 훅은 60~80초로 길지만, 역설을 세 번 쌓아 질문까지 끌고 가 이탈을 막는다(2026-10-31 분석). 지식대학 이탈 그래프 교훈(2026-10-11) — 훅 직후 기관·직함·서지를 늘어놓으면 1분 유지율이 무너진다. 이 채널에서는 **부대 번호·작전명·계급**이 같은 위험이다.

### 훅 틀 (약 500자, 60~70초)
1. **날짜 장면** — 날짜·장소 + 구체적인 사람과 행동 (「1950년 11월 30일, 워싱턴. 트루먼 대통령의 기자회견에서 한 기자가 묻습니다.」)
2. **어긋남 하나** — 「그런데 이상한 점이 있습니다.」 + 유리한 조건 (원폭 300발 대 5발)
3. **어긋남 둘** — 「더 이상한 건」 + 상황까지 유리했다/절박했다
4. **질문** — 「A도 있었고, B도 있었는데, 왜 ~했을까요?」 이번 편이 끝까지 답할 「왜」 하나
5. **연결 두 문장(고정)** — 「오늘은 그 이유를 알아보겠습니다.」 + 「이야기는 {배경 시점}에서 시작됩니다.」 — 이 두 문장만 진행 멘트 금지의 예외
- **결말은 훅에서 말한다**(역사의 결말은 검색하면 나온다). **이유는 중반까지 숨긴다**

### 훅에서 하지 않을 것
- 부대 번호·작전명·계급·직함을 두 개 이상 늘어놓기 → 전부 파트 1로. 훅의 인물은 이름 하나 + 쉬운 설명(「중공군 사령관 펑더화이」)
- 「충격적인」 「믿기 힘든」 같은 감탄으로 역설을 대신하기 — 역설은 숫자와 사실로 만든다

## 6. 성과 기록 · 시험 기간 판단

### 판독 규칙 (세상의 이유·지식대학에서 가져옴)
- 업로드 **48시간 뒤**: 노출수 · CTR · 조회수 · 평균 조회율 · 30초/1분 유지율(이탈 그래프)
- 48시간 노출이 **1천 미만**이면 CTR은 참고만 하고 **4일 차에 노출을 다시 본다**. 4일 차에도 1천 미만이고 그래프가 평평하면 노출 창이 닫힌 것으로 보고 관리 종료
- 48시간에 **노출 1천+ · CTR 3% 미만**이면 그 자리에서 썸네일을 교체한다
- 날짜별 데이터는 약 2일 늦게 열린다

### 편별 성과표
| 편 (업로드) | 제목 | 썸네일 문구 | 노출 | CTR | 조회 | 30초 | 1분 | 조회율 |
|---|---|---|---|---|---|---|---|---|
| 국군 전차 0대 (11/1 14시, youtu.be/uJjlxv5itVE, 12:44) | 미국은 알고 있었다.. 6·25 아침 국군에는 왜 전차가 한 대도 없었을까? \| 국군 전차 0대의 이유 | 「북한전차 150대 vs 국군 0대 / 국군엔 왜 전차가 없었을까」 + 라벨 「전차 0대」, 흑백 지도·트루먼, A/B 없음 | | | | | | |
| 거제도 도드 (11/2 14시, youtu.be/S5HQSxt34hU, 14:32) | 포로에게 붙잡힌 미군 장군.. 왜 78시간 동안 구하지 못했을까? \| 1952년 거제도 도드 사건 | 「북한군 포로에게 잡힌 미국 장군 / 78시간 동안 못 구한 진짜 이유」 + 라벨 「1952.5.7」「포로 약 15만 명 / 경비 9천여 명」「거제도 포로수용소」「도드 준장」, 흑백 지도·과녁 + 도드 사진, A/B 없음 | | | | | | |

- 거제도 도드 사실 대조(11/2): 5.7 14시 무렵 76수용동(북한군 장교·부사관) → 5.10 21:30 석방 약 78시간, 포로 약 15만(149,704 계산), 경비 9,000여 명 — 모두 verified-data·대본과 일치. 「못 구한」은 무력 진입 없이 콜슨 서한으로 풀려난 것과 맞음. 썸네일은 국군 전차에 이어 「숫자 + 왜 못 했나」 단정형, 흑백 지도 배경 두 편 연속(세상의 이유에서 흑백은 금지 규칙 ⑥ — 이 채널 기준선은 판독 후 판단). 11/4 48시간 판독

### 시험 기간 — 첫 8편
