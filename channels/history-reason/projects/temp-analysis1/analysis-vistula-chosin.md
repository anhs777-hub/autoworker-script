## 3. 전체 구조

**A (25분):** 훅 2분 → 병력 대비(220만 대 45만 · 5:1 · 6:1 · 8:1) → 구데리안 탄력 방어 vs 히틀러 기각 → 1.12 코네프 3단계 포격(15분 미끼 → 107분 본포 → 오후 2시 전차) → 1.14 주코프·선견지대(다리 먼저) → 필리차 강 「적 행렬에 끼어 다리 건너기」 → 독일 네링의 「움직이는 포위망」 250km → 코네프 「황금다리」로 실레지아 공장 무손상 확보 → 힘러 임명 → 동부 방벽 이틀 → 1.31 오데르, 베를린 70km → **「왜 그렇게 빨랐나」 답: 2,700만 명의 복수심** → 군가
- 장면 하나하나가 **「꾀」 하나씩** (미끼 포격, 다리 먼저, 끼어들기, 황금다리) — 시청자가 「오~」 하는 지점이 3분마다

**B (23분, 목차 13개):** 훅(5m 다리) → 125km 길 하나 → 9병단이 먼저 들어와 있었다 → 11.27 밤, 토막 난 길 → 하갈우리 → 장진호 동쪽 붕괴(2,500명 중 385명) → 40%만 만든 활주로(4,312명 후송) → 산 넘은 대대, 79시간 → 고토리까지 38시간 → 하늘에서 내려온 다리 → 1081고지와 5m(전차 양쪽 5cm·지프 1cm) → 흥남 → 다시 황초령 다리(「서 있던 시간은 이틀이 안 됐다」)
