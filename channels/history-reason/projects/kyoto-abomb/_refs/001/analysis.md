# 자료 묶음 분석 — 교토는 왜 원폭을 피했나 (1945)

## 1. 장면 후보 (날짜가 붙은 장면)
1. **1945년 5월 10일, 로스앨러모스** — 과학자·장교들의 표적위원회가 교토에 「AA」. 인구 100만, 「지적 중심지」, 「의미를 더 잘 알아챌」 도시 [회의록] → **훅 1순위**
2. **5월 30일, 펜타곤** — 그로브스의 보고, 스팀슨이 교토를 지우고 지도를 가져오게 함 [회고 — 원문 확인 필요]
3. **7월 21일, 포츠담** — 「장관님의 애착 도시(pet city)」 전문 → 「결정을 바꿀 요인은 없다」 [FRUS d1307·1308]
4. **7월 24일, 포츠담** — 트루먼에게 마지막 설명(소련 쪽으로 기울 우려) + 같은 날 명령 초안에 손글씨 「그리고 나가사키」
5. **8월 9일 11시 2분, 나가사키** — 고쿠라가 가려져 목표가 바뀜

## 2. 숫자 후보 (핵심 1~2개)
1. **17개 도시 → 4개 도시** — 목록이 줄어드는 흐름 (교토는 1순위에서 0으로)
2. **AA 등급 / 인구 100만** — 교토가 왜 1순위였나
3. 결과 숫자(시점 고정): 히로시마 즉시 최소 7만·연말 약 14만 / 나가사키 즉시 최소 3만 9천·연말 약 7만 4천

## 3. 역설과 이유
**역설 재료 (훅 쌓기용)**
- 교토는 표적위원회가 매긴 1순위(AA)였다
- 군과 과학자들은 7월 말까지 교토를 다시 넣으려 했다 — 포츠담까지 「1순위로 원한다」는 전문이 갔다
- 그런데 교토는 끝내 빠졌고, 그 자리를 예약 목록에도 없던 나가사키가 채웠다

**진짜 이유 후보**
1. **결정권이 한 사람에게** — 육군 장관 스팀슨이 직접 지움, 위원회·그로브스·현지 군의 반복 요구를 거절 [FRUS, 일기]
2. **스팀슨이 밝힌 이유는 전후 계산** — 반감 → 전후 일본이 소련 쪽으로 기울 우려, 문화·종교 중심지 [일기 7.24 / 1947 하퍼스]
3. **대통령이 같은 편** — 트루먼 동의(7.22), 「최고 권위자가 확인」(7.23) [FRUS d1310]
4. (해석) 1926·1929년 두 번 머문 기억 — Wellerstein의 해석, 「~라고 보는 연구자도 있다」까지만
5. (배경) 표적 기준 자체가 교토를 1순위로 만들었다 — 이유가 아니라 역설의 재료

**신화 정정(차별 축 3)**: 「신혼여행」 → 결혼 1893년·신혼여행 캐나다, 교토 방문은 1926·1929년
