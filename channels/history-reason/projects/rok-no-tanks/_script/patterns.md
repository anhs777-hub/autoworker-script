# 패턴 추출 — 6·25 첫날, 국군에 전차가 없었던 이유

> 입력: `_refs/001`(자료 묶음, PD) · `_refs/002`(전쟁의 신, 12.8만) · `_refs/003`(KBS 역사스페셜, 7.7만) + 채널 벤치마크(역사랑방, `projects/temp-analysis1/benchmark-yeoksarangbang.md`)
> 이 채널은 pd-guide 2장대로 profile 「서사 구조」에 자료의 장면·숫자를 배치한 표를 함께 쓴다. 원문 인용은 근거용 최소한 — outline·draft에 옮기지 않는다.

## 1. 반복되는 훅 공식

**관찰**
- 002는 결론(훈련)을 암시하는 노르망디 장면으로 열고, 003은 「아군이 끊은 다리」라는 실제 영상의 역설로 연다. 둘 다 **어긋남 하나**로 「왜?」를 만든다
- 두 영상 모두 6월 25일 첫날을 훅에 쓰지 않았고, 「전차 0대」라는 대비 숫자를 훅에 쓰지 않았다
- 채널 레퍼런스(역사랑방 90만·75만·38만)는 날짜 장면 → 어긋남 두 번 → 「A도 B도 있었는데 왜?」로 60~80초를 끈다

**설계 원칙**
- 훅 첫 장면은 **1950년 6월 14일 무초 대사의 전보**(「북한엔 전차가 있고 이곳엔 없다」) — 경쟁작 둘 다 안 쓴 장면이고, 「미국이 알고 있었다」는 역설이 바로 선다
- 어긋남 ① 한국은 8개월 전에 전차 189대를 콕 집어 요청했다 / 어긋남 ② 11일 뒤 북한 전차 150대 이상이 내려왔고 국군은 0대였다
- 질문: 「알고도, 요청받고도, 왜 한 대도 없었을까」. 결말(서울 사흘 만에 함락)은 훅에서 말하고, 이유는 중반까지 숨긴다

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 002: 통념 → 「알고 있었다」 반전 → 미국 사정(재정·지형, 1분) → 「무기는 있었다」 반전 → 실패 사례 → 기술 원인(훈련). 「사실은 ~였다」 반전 쌓기
- 003: 현장 물증 → 전력 격차 → 재연 → 한강 폭파(중심) → 슈퍼 바주카 → 오늘의 교훈. 개요형
- 두 영상 모두 「왜 전차가 없었나」를 **1분 남짓, 한 갈래 원인**(002는 재정·지형, 003은 북진 우려)으로 단정했다. 날짜·문서가 없다

**설계 원칙 — profile 서사 구조에 자료 배치**

| 구간 | 쓸 장면·숫자 (001 기준) | 002가 쓴 것 / 003이 쓴 것 |
|---|---|---|

- 파트 전환마다 날짜로 장면을 연다. 이유는 번호로 세우고 각 이유마다 **문서 하나 + 날짜 하나**만
- 「맨주먹은 아니었다(바주카 1,900정·대전차포 140문)」는 002가 이미 반전으로 썼다 → 우리는 한 문장 사실로만, 반전 장치로 쓰지 않는다

## 3. 감정 증폭 전략

**관찰**
- 002 최다 공감 댓글(116)은 제원이 아니라 **전차를 처음 마주한 병사의 공포**에 반응했다. 「책임자 처벌」 감정도 강하다
- 003 댓글은 감사·추모·가족사(할아버지가 참전용사)가 압도적이고, 내용 질문은 0개다

**설계 원칙**
- 감정 축: 궁금증(알고도 왜?) → 답답함(요청 → 거절의 연속) → 공포(첫날 장면, 숫자로만) → 납득(이유 셋) → 여운(그 뒤)
- 「누구 책임인가」로 가지 않는다(profile 판정 금지). 거절한 쪽도 그때의 정보·선택지로 설명한다 — 지형 판단은 그때 기준으로 근거가 있었고, 결과는 달랐다
- 클로징 질문은 **「기억」형**(집안 어른께 들은 6·25 이야기) — 003 댓글의 가족사 반응과 맞는다

## 4. 반복되는 썸네일 & 제목 패턴

**관찰**
- 002: 거대한 전차 + 겁먹은 병사 얼굴, 대사형 문구 「도저히 격파가 / 불가능합니다.」(흰+노랑)
- 003: 전차(원인) + 폭발하는 다리(결과), 노란 큰 글씨 「한강인도교 폭파의비밀」
- 두 썸네일 모두 **전차 실물 이미지 중심**, 지도는 없다. 숫자 대비도 없다

**설계 원칙**
- 피드 대조(pd-guide 3장 4축): 우리는 **지도 + 숫자 라벨**로 간다 — 어두운 한반도 지도, 38선 아래로 내려오는 화살표 하나, 빨간 라벨 「국군 전차 0대」. 전차 이미지는 작게 또는 없이
- 문구: 「{조건}인데 / ~한 이유」 — 예: 「8개월 전에 요청했는데 / 전차가 0대였던 이유」
- 제목은 질문형 + 「｜6·25 첫날」
