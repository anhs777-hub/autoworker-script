# 자료 묶음 분석 — 거제도 포로수용소장 납치

## 1. 장면 후보 (날짜가 붙은 장면)
1. **1952년 5월 7일 오후 2시 남짓, 76수용동 이중문** — 작업반이 드나들던 자물쇠 없는 문, 도드가 끌려 들어감, 레이븐은 기둥을 붙잡고 버팀 → **훅 1순위**
2. **1952년 4월 19일, 판문점** — 「송환 희망 약 7만」 통보 → 공산측 휴회 → **축 장면**(숫자 하나가 협상과 수용소를 묶음)
3. **1952년 2월 18일, 62수용동** — 심사하러 들어간 병력과 충돌, 포로 77명 사망 → 이틀 뒤 도드 부임 → 「철조망 안으로 들어가지 않는다」의 출발
4. **1951년 1월, 거제도** — 원주민·피란민·포로 합쳐 30만 명 넘게 한 섬에 → 배경
5. **1952년 5월 10일 밤 9시 30분** — 콜슨 서한 서명 후 석방
6. **1952년 6월 10일, 76수용동** — 진압 2시간 30분, 압수한 창 3,000개 → 이유 확인 사건

## 2. 숫자 후보 (핵심 1~2개)
1. **포로 약 15만 대 경비 9,000여 명** (1:16~17) — 대비 숫자
2. **7만** — 판문점 통보 숫자 = 축
3. 보조: 정원 800~1,200 → 5,000~6,500명 / 무장 병력 1만 1천·전차 20대 / 78시간 / 창 3,000

## 3. 역설과 이유
**역설 재료**
- 포로 15만을 가둔 쪽이 수용소장을 빼앗겼다
- 바깥에 무장 병력 1만 1천·전차 20대가 있었는데 사흘 넘게 들어가지 못했다
- 장군 한 명을 되찾으려고 「포로를 죽이고 다치게 했다」는 문서에 서명했다

**진짜 이유 후보 (구조)**
1. **사람이 모자랐다** — 15만 대 9,000, 과밀, 지휘관 잦은 교체 → 철조망 안은 포로 대표가 운영
2. **철조망 안으로 들어가지 않기로 했다** — 2.18 유혈 뒤 강제 진입 중단 → 수용동 내부는 포로 조직이 장악
3. **판문점 숫자가 우선이었다** — 7만 통보 뒤 심사·명부가 최우선 → 소장이 직접 정문에서 대표와 협상 → 자물쇠 없는 문
4. (보조) **무력을 쓸 수 없었다** — 구출 사상자는 판문점 선전 재료 → 기다림 → 서한
5. (보조) **포로 쪽 조직** — 외부 지휘 계통이 있었다는 기록, 4.29 예행연습. 평양 지령 여부는 단정 금지

**이유를 증명하는 뒤의 사건**: 6.10 진압(들어가자 2시간 30분이면 끝났다) + 재편(수용동 하나 500명) → 문제는 병력이 아니라 구조였다

## 4. 흐름
- 배경(1951 섬 → 과밀·경비 부족 → 내부 장악) → 2.18 → 4.19 판문점 7만(1~2분) → 4.29 → 5.7 납치 → 78시간 → 5.10 서한 → 판문점 선전·강등 → 6.10 진압 → 재편
