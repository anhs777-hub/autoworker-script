# 제목: 네 번 없앤 나무 신분증, 조선이 호패를 끝내 다시 만든 이유

## 1. 기획 뼈대
- 핵심 약속: 끝까지 보면, 「또 실패하겠지」 싶은 반복 끝에 다섯 번째 호패가 왜 살아남았는지 납득하면서, 나라가 사람을 세려 할 때 무엇이 통하고 무엇이 안 통했는지 알게 된다
- 타겟 시청자: 「조선판 주민등록증」 정도로만 알던 40~60대, 주민등록증 발급·지문 날인을 겪은 세대
- 썸네일 컨셉: 산으로 가는 인형 무리 위로 솟은 실물 호패 / 피난길 강가에서 타는 장부 + 도장 「폐지」
- 타겟 러닝타임: 15분 (목표 7,050자, 분당 470자 기준 — profile 「기본 러닝타임」. 허용 6,500~7,600자)
- 핵심 메시지: 호패를 남게 한 건 무거운 벌이 아니라 덜 겁나게 바꾼 방식이었고, 그렇게 남은 호패는 처음 목적(숨은 장정 찾기)을 끝내 이루지 못했다
- 톤: 차분한 다큐 내레이터, 조사관이 서류를 한 장씩 넘기듯. 존댓말(-습니다/-요 섞기). 감탄·과장 없음

- 핵심 요약 = **정책실 판정** (「정책실 판정입니다. 첫째, …」 세 줄):
  1. 네 번은 벌을 무겁게 해서 밀어붙였고, 그때마다 사람들은 더 깊이 숨었다(산·섬·양반집)
  2. 다섯 번째는 덜 겁나게 바꿨다 — 종이패, 다섯 집 묶음, 그리고 군인을 뽑는 데서 신분을 확인하는 쪽으로
  3. 그렇게 남은 호패는 처음 목적, 숨은 장정을 찾아내는 일은 끝내 이루지 못했다(18·19세기 평가 `[백과]`)
- 메시지 완결: 위 판정 세 줄이 곧 메시지 — 따로 설교하지 않는다
- 오늘과의 연결: 한 줄까지만(profile) — 「지금 우리 지갑에도 이름과 얼굴이 적힌 카드가 한 장 있습니다」 류. 호패가 언제 사라졌는지는 verified-data에 없으므로 말하지 않는다. 「요즘 ○○와 똑같다」 금지
- CTA: 클로징 질문 「내 경험」형·전 연령(경제·역사 지식 없이 답 가능) — 예: 「처음 신분증을 받던 날, 기억나시나요」 류. 구독·좋아요 유도 금지

## 4. 용어 순화
| 용어 | 처음 나올 때 |
|------|------|
| 호패 | 이름과 신분을 적어 허리에 차던 나무패 |
| 군역 | 군대에 가거나, 대신 베를 내는 의무 |
| 양인 | 양반도 노비도 아닌 보통 백성 |
| 보인 | 군대에 간 사람 대신 집에 남아 베를 내던 사람 |
| 지패 | 종이로 만든 호패 |
| 오가작통 | 다섯 집을 한 통으로 묶어 서로 살피게 한 제도 |
| 직역 | 그 사람이 나라에 지는 일, 신분에 따른 역할 |
| 군포 | 군대에 가는 대신 내던 베 |
| 금고 | 벼슬길을 막는 벌 |

## 5. 차별화 포인트
- 「호패가 무엇이었나」가 아니라 「왜 네 번 거둬들였나」 — 경쟁작 전부가 개요형
- 실록 기사 날짜 장면 4~6개(훅 광해 2년, 태종 13년 12월 1일, 인조 3년 10월 1일, 인조 5년 1월, 숙종 6년 5월 25일)
- 숙종 6년 「실행되지 않은 폐지 명령」 — 백과·경쟁작 어디에도 없는 장면
- 사료 정정: 「조선의 주민등록증」 통념 → 차느니 노비·산을 택한 기록
- 정착 = 성공이 아니라 「남았지만 목적은 못 이룸」으로 판정

## 6. 메시지 설계
- 핵심 메시지: 호패를 남게 한 건 무거운 벌이 아니라 덜 겁나게 바꾼 방식이었고, 그렇게 남은 호패는 처음 목적을 끝내 이루지 못했다
- 복선 배치: 파트 4 — 이식의 「곧 없어질 법」(벌이 무거워도 안 믿으면 안 찬다) / 파트 5 — 종이패와 성격 변화(덜 겁나게)
- 완결 배치: 클로징 — 정책실 판정 세 줄이 사례에서 그대로 나온다. 설교식 나열 금지

## 7. 리텐션 설계
- 감정 아크: 의아함 → 놀람 → 공감 → 긴장·허탈 → 반전·납득 → 씁쓸함
- 재참여 포인트:
  - ~1분 (인트로→파트 1): 「나무패 하나에 뭐가 따라왔나」
  - ~3분 (파트 1→2): 첫날 쏟아진 사람들
  - ~5분 (파트 2→3): 「43년 뒤, 또」 — 반복 리듬 시작
  - ~7.5분 (파트 3→4): 「네 번째는 나라가 가장 세게」
  - ~9분 (파트 4 중반): 226만 → 「이 장부는 반년 뒤 불에 탑니다」
  - ~11.5분 (파트 4→5): 「48년 뒤, 다섯 번째」
  - ~12.5분 (파트 5 중반): 숙종 6년 폐지 명령 → 실행 안 됨 반전
- 스테이크 상승: 감옥이 참(태종) → 노비가 됨(성종·광해) → 숨은 사람 123만·사람이 죽음·왕이 민심을 잃음(인조)
- 참고할 레퍼런스 장치 (patterns.md 구조 자산 — 유형 + 위치만):
  - 결말 공개 + 이유 숨김 훅 — 훅
  - 반복 리듬 — 파트 2~4 전환마다
  - 숨은 사람 > 드러난 사람 — 파트 4 중반 1회
  - 위에서도 알았다 — 파트 2(태종)·파트 3(세조)·파트 4(서성)
  - 피난길의 선택 — 파트 4 끝
