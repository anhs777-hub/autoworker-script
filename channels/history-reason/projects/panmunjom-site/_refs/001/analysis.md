2. **같은 날, 내봉장 탁자** — 높은 의자·낮은 의자(미측 기록 / 중국측 표현), 오후에 더 큰 깃발 [공간사·중국]
3. **8월 4일 점심** — 무장 중국군 1개 중대가 유엔 대표단 숙소 앞을 지나감 (0.5마일 무장 금지 규정) [공간사]
4. **8월 23일 새벽, 개성** — 불려 간 키니 대령, 「이 시각부터 모든 회의 중단」 (양측 주장 병기) [공간사·중국]
5. **10월 24일, 널문리** — 트럭 9대·40명이 천막을 세우고 바닥·난로를 깖, 밤에는 탐조등과 계류기구 [공간사]
6. **10월 4일, 리지웨이 문서** — 「어느 쪽도 단독 통제하지 않는 곳」 [1차 d617]
7. **11월 27일** — 잠정 분계선 합의, 개성은 북쪽에 → 결말

## 3. 역설과 이유
**역설 재료**
- 휴전회담 첫 자리는 38선 바로 남쪽 개성 — 전쟁 전엔 남쪽 땅이었는데 그때는 공산군이 쥐고 있었다
- 유엔 대표단은 흰 깃발을 단 차로 공산군 검문을 지나 들어갔다
- 회담은 63일 끊겼고, 다시 열린 곳은 양쪽 전선 한가운데 진흙집 몇 채의 널문리

**옮긴 이유 (리지웨이 문서 다섯 → 셋으로 묶음)**
1. **통제와 안전** — 이동·통제가 대등하지 않음(10.4 d617), 적 지역을 지나야 회담장(9.21 d574), 8.4 무장 중대
2. **선전** — 흰 깃발, 의자, 깃발, 공산측 촬영 / 반덴버그 「선전이 계속 우리를 겨냥」(9.25 d588)
3. **군사** — 중립지대가 공산군 피난처, 유엔군 작전이 막힘, 보장을 강제할 방법 없음(9.11 d556)

**이유를 확인하는 뒤의 사건**: 9.10 개성 기총소사(유엔 책임 인정) · 10.12 소년 사망(유엔 책임 인정) → 사건이 날 때마다 회담이 흔들림 → 10.4 조건 → 10.7 공산측 판문점 제안 → 10.8 수락 → 10.22 안전 합의 → 10.25 재개
