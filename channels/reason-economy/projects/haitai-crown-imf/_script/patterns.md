# 공통 성공 패턴 — 해태 vs 크라운 (레퍼 5편 교차 분석)

> 레퍼: 002 소비더머니 해태(320.8만) · 004 소비더머니 크라운(116.7만) · 003 누네띠네 해태(67.7만, 구독 대비 22.6배) · 001 무궁화경제 삼립(46.7만, 구독 대비 47배) · 005 흥망일지 크라운(1,886 — 실패 사례)
> ⚠️ 인용은 근거용 최소한 — outline·draft 반입 금지.

## 1. 반복되는 훅 공식

**관찰**
- 002·004(소비더머니): 브랜드명을 숨기고 **시청자가 아는 대중문화**(1988 부라보콘 광고 / 시청률 40% 드라마)로 열어 정답 맞히기를 시킨다. 향수 진입.
- 003: 「재계 24위 제국 … 3조 빚인데도 금융기관이 앞다퉈 빌려줬다」 — **숫자 역설 + 이름 숨기기**.
- 001: 날짜·장면(「1997년 5월 15일 … 문을 닫았다」) → 실명 → 「지금 편의점에서 집는 그 빵」 → 숫자 역설(「1,900억이 3억에?」) → 두 번째 역설(보증 1,420억 = 자기자본 20배).
- 005(실패): 향수 + 인물 역설로 열었지만 썸네일 핵심(「어떻게 해태를 인수?」)이 훅에 없고, 「여정을 따라가 보겠습니다」로 연대기 진입 → 인수까지 9분.
- 공통 역할: 인트로 안에서 **「이렇게 사랑받던 회사가 왜?」 / 「작은 쪽이 왜 큰 쪽을?」**을 한 문장으로 공개해 낙차를 만든다.

**설계 원칙**
1. 첫 15초 안에 **숫자 역설 하나**: 「매출 절반도 안 되는 4위가 2배 큰 2위를 샀다」 + **두 번째 역설**: 「그런데 둘 다 8년 전 같은 IMF에 쓰러졌었다(두 달 반 차이)」. 001의 2단 역설 구조를 따른다.
2. 훅에 **시청자가 지금도 손에 드는 과자**(맛동산·홈런볼·죠리퐁·산도)를 1문장 넣어 현재와 묶는다 — 4편 모두 향수가 1순위 감정.
3. 썸네일·제목의 질문은 훅에서 확인만 하고 답은 주지 않는다(001). 결말(해태 재상장·현재 매출 역전)은 인트로에서 다 쏟지 않는다(001의 약점).
4. 「거슬러 올라가 보겠습니다」 → 1945년 연대기 진입 금지(005 실패, 채널 profile 규칙). 1막은 사건 시점(1997~1998)에서 바로 시작.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰 — 구조**
- 002·003: 추억 소환 → 창업 → 전성기 → 2세 승계 균열 → 본업 이탈 확장 → IMF 붕괴 → 공중분해(누가 뭘 가져갔나) → 교훈. 분량 절반이 「사랑받던 시절」.
- 004·005: 창업 신화 → 제품 연대기 → 위기 → 원점 회귀 부활 → 인수 한두 문장. IMF~인수가 분량의 15%뿐.
- 001: **같은 뿌리 → 갈라짐 → A의 몰락(원인 해부) → B의 역전 → 결과** — 짝 비교 구조. 몰락 원인을 충분히 해부해야 B의 선택이 돋보인다.
- **5편 중 해태·크라운을 짝으로 놓은 영상 0편.** 해태 영상은 「제과는 크라운」 한 줄, 크라운 영상은 「해태 얘기는 다음에」. 크라운의 1998 화의는 해태 영상 어디에도 없다.

**관찰 — 전달 기법**
- 숫자: 001이 가장 촘촘(보증 1,420억 vs 자기자본 70억, 321억, 901억). 002는 재무 숫자 거의 없음 → 해태 쪽 「빚 규모」 숫자가 공백.
- 개념 설명: 001은 지급보증·어음·법정관리를 한 번씩만 일상어로 풀었다.
- 생활 접점: 003 「지금 브라보콘을 사면 돈은 빙그레로」, 001 「오늘 저녁 편의점 삼립빵」.
- 패턴 인터럽트: 003 「과자 회사가 무궁화호 객차를 만들었다」(사실 확인 필요).
- 시청자 갈림길: 001 「여러분이 형이라면?」 중반 2회.

**관찰 — 리텐션**
- 001: 오픈루프(「3억은 방아쇠, 진짜 총알은 따로」) → 중반에 「처음 질문으로 돌아가 보죠」로 회수 → 「진짜 반전은 지금부터」로 B 파트 진입 → 수미상관.
- 005: 「진짜 이야기는 여기서부터」가 8~9분에야 나옴 → 이탈.

**설계 원칙**
1. 뼈대: **훅(역전 인수 + 둘 다 쓰러졌었다) → 1막 해태가 쓰러진 구조 → 2막 해태의 끝(2001 매각) → 3막 크라운이 쓰러지고 일어선 5년 → 4막 왜 갈렸나(판정 + 반론 1블록) → 지금(매출 역전) → 클로징**. 창업사는 각 회사 2~3문장 배경으로 압축.
2. 「쓰러진 이유」는 두 회사를 **같은 잣대(빚의 크기·빚을 쓴 곳·부도 직전 부채)**로 나란히 놓는다. 크라운도 본업 밖 확장을 했다면(레퍼 004·005 주장, 리서치 확인 중) 숨기지 않고 「크기의 차이 / 일어선 방법의 차이」로 판정을 정교화한다.
3. 1막 끝에 「같은 해 크라운도 쓰러졌다」는 오픈루프, 2막 끝에 「그런데 판 상대가 4년 뒤 다시 내놓은 그 회사를 산 게…」 전환, 3막 중반에 「처음 질문으로 돌아가 보죠」 회수.
4. 어려운 개념(화의·법정관리·LBO·종금사)은 등장할 때 **한 번만** 일상어로. 같은 설명 반복 금지.
5. 중반에 「여러분이 이 회사 사장이라면」 갈림길 질문 1회(001 기법) — 결과론 비판(002 댓글 「사람들은 결과를 보고 말한다」)에 대한 장치로도 작동.
6. 시점 정확성: 해태 부도 1997-11-01, IMF 구제금융 신청 1997-11-21, 크라운 화의 1998-01-15 — 001처럼 IMF 전후를 뭉개지 않는다.

## 3. 감정 증폭 전략

**관찰 — 댓글 감정 순위**
1. **분노·훈수(2세 경영)**: 003 1위 602 「2세를 빡세게 키우지 않으면…」, 7위 534; 002 1위 1,700 「부모세대 식품사업 하찮게 보고 폼나는 사업 하려고 무리수」. → 시청자가 이미 가진 답 = 「본업을 하찮게 본 2세의 욕심」.
2. **향수(제품 체험)**: 004 1위 671 「유행 안 타고 오래 사 먹는 과자가 크라운에 많다」, 산도·초코하임·버터와플; 003 10위 「해태껌 아니면 안 씹는다」. 004는 경영 서사 댓글 0개.
3. **승자 현재 논란**: 001 TOP10 전부 SPC 산재 분노 — 승자를 미화하자 현재 논란이 댓글을 점령.
4. **회의론**: 005 「실패한 기업을 인수한 패자의 저주」, 002 「결과론」.

**감정을 만든 장치**
- 분노: 「29살」「18일 만에 이사」 등 2세 특정 숫자(003 제목·본문).
- 향수: 광고 원음, 제품명 연호, 타이거즈 우승.
- 통쾌: 001 「10분의 1로 시작한 동생이 10배 큰 회사를 품었다」, 005 「헐값에 산 외국 자본이 4년 뒤 나가고, 되사 온 건 국내 기업」.

**설계 원칙**
1. 흐름: **호기심(역설 훅) 15% → 향수(제품 1~2회) → 긴장(해태 빚 구조·부도) 25% → 의외(크라운도 쓰러졌다) → 납득(일어선 방법) 30% → 통쾌(4위가 2위를 삼킴) → 균형(반론 1블록) → 여운(지금 매출 역전)**.
2. 시청자가 이미 가진 답 「2세의 욕심」을 **뻔한 답 부정**으로 쓴다: 「욕심 탓이라면 크라운은 왜 같은 해 쓰러졌을까」. 개인 비난 대신 구조(빚을 어디에 썼나)로 분노를 납득으로 전환.
3. 승자(크라운) 미화 금지 — 크라운베이커리 2013 철수·LBO 부담을 반론 블록에 실제로 넣는다(001 교훈).
4. 향수 장치는 두 회사 제품을 **모두** 호명해 클로징 댓글이 양 진영으로 붙게 한다(005).

  - `지금 손에 든 제품` — 과거 사건을 시청자의 현재 소비와 묶는다 (001)
- 구조 기법
