## 4. 본문 구조
관광객 숫자 → 입국 심사 폭증 → 문화 → 배달앱 → 치안 → 의료 → 빨리빨리 → 서울 인프라 → **그림자(자살률·출산율·외국인 절반이 5년 안에 떠남) → 「그런데도 몰려온다」** → 정주 외국인 → 근본 원인(「좁고 척박한 땅이 축복」) → 클로징 「30년 전엔 아무도 몰랐고, 20년 전엔 부끄러웠고, 10년 전엔 조금 알려졌고, 지금 세계가 인천공항에 줄을 섭니다」

- 패턴: 감정 장면 → 숫자 → 「외국은 못 하는데 우리는 당연한 것」 나열 → 자기반박 → 반전 재확인 → 근본 원인 → 세대 회상 클로징
- 기법: 모든 이유를 **한 사람 장면**으로(대부분 출처 없음), 숫자 반복 강조, 도시 대비
- 리텐션: **자기반박 전환(약 70% 지점) — 「이야기가 너무 매끄럽죠. 맞습니다. 이번 한 번만 정말 객관적으로 가겠습니다. 이걸 말 안 하면 5분 뒤에 잊힐 또 하나의 국뽕 영상이 되니까요」 — 이 영상에서 가장 잘 만든 장치**
