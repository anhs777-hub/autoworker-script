## 1. 반복되는 훅 공식

**관찰**
- 고퍼포먼스 4편의 훅은 모두 **「통념 → 뒤집기」**로 연다.
  - 001(105만): 「복지 천국」 이미지에 충격 숫자(EU 총기 사망률 1위)를 바로 들이민다.
  - 003(74만): 이케아·볼보·아바를 떠올리게 한 다음 「갱스터의 천국」을 던진다. 시청자가 스스로 그린 이미지를 깨뜨린다.
  - 002(78만): 콜드 오픈 몽타주로 「모기 피로 검거」, 「DNA로 성씨 추정」 같은 믿기 어려운 구체 장면을 먼저 보여 준다.
  - 004(44만): 실질적인 훅이 「한국 사람들이 착해서 그럴까요 그건 아닙니다」. 뻔한 답을 꺼낸 뒤 바로 부정한다.
- **「착해서가 아니다」 축이 002·004 두 편에 독립적으로 등장한다.** 한국 치안을 설명하는 영상의 공통 반전이다. 우리 확정 방향과 같다.
- 인트로에서는 **일상 공간의 장면**이 공통으로 쓰인다.
  - 003: 쇼핑센터, 저녁 먹으러 나서던 길
  - 005: 카페 자리 맡기, 노트북 두고 화장실
  - 006: 편의점에서 총 사기
  - 002: 밤 9시 이후 귀가(휴스턴), 호신 스프레이(일본)
- 약한 인트로(「오늘은 ~ 알아보겠습니다」)를 쓴 004·005는 조회 성과가 채널 규모나 소재 인지도에 기댔다.

**설계 원칙**
1. 첫 문장은 **「안전한 복지국가 스웨덴」 통념을 숫자 하나로 깬다.** 10만 명당 기준이나 EU 순위처럼 공정하게 비교할 수 있는 숫자 1개만 쓴다. 인트로 전체의 숫자는 3개 이하로 제한한다.
2. 훅 ③(질문)은 **「같은 선진국인데, 한국은 왜 총격이 뉴스가 안 되나」**로 건다. 그 직후 **「한국 사람이 착해서? 아니다」** 부정을 넣어 영상 전체의 오픈루프로 쓴다(답은 「시스템」).
3. 「이민 때문 아니냐」는 질문은 **시청자가 먼저 떠올릴 반응**으로 훅 구간에서 인정만 하고 보류한다. 「그 숫자도 제대로 읽어 보겠다」로 처리한다. 첫 2분 안에 이민을 원인으로 단정하는 문장은 금지한다.
4. 인트로 장면은 **한국인의 일상 하나(카페에 노트북 두고 자리 비우기 등)와 스웨덴의 일상 공간 총격 하나**를 맞세운다. 같은 시간, 같은 종류의 장소에서 대비한다.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰 — 구조**
- 001: 충격 숫자 → 이미지와의 괴리 → 폭탄·갱단 → 원인 후보(이민) → **통계를 인구 비율로 다시 읽기** → 아이 청부살인 → 정치 → 범죄 감소 → 총선의 역설
- 003: 피해 사례 → 규모 → 가해자의 정체(10대) → 세 겹의 원인(이민·실업·제도) → 국경 밖 확산 → 경제 경고 → 열린 질문
- 002: 「착해서?」 → 부정(억제 요인) → 일상 장면 → **시스템 해부(CCTV → 결제·교통카드 → 생활 수사팀 → 출동 → 과학수사)** → 해외 비교 → 프라이버시 반론 처리 → 해외가 배워 간다
- 005: 일상 장면 → 현상 → 표면 원인 3개 → 「그것만으로는 설명이 안 된다」 → 역사 → **제도 허점을 절차 단위로 설명** → 한국과 대비 → 처음 장면 회수
- 004: 「착해서?」 → 연대기 → 강경책의 명암 → 복합 원인. 연대기로 열어서 약점이 됐다.
- 공통 흐름: **현상(몰락) → 원인을 한 겹씩 벗기기(표면 → 구조) → 반대편(한국)의 장치 → 반론 처리 → 처음 장면 회수**

**관찰 — 전달 기법**
- 숫자: 인구 비율 비교(006의 살인율 5.3 대 0.6, 001의 Brå 인구 대비 비율)가 가장 선명하게 먹혔다. 출처 없는 구두 수치가 많다(002의 검거율 80%·3분·6시간, 005의 절도 30% 대 6%). **전부 재검증 대상이다.**
- 사례: 일상 공간의 피해자(003), 할머니의 1천만 원(002), 쓰나미 지문(002)
- **절차 단위 설명**(005의 피해자 출석 요건, 002의 추적 사슬)이 설득력이 가장 높았다. 제도가 한 단계씩 어떻게 작동하는지 따라간다.
- 비유는 6편 모두 거의 없다. 채널 4대 금지와 부딪히지 않는다.

**관찰 — 리텐션**
- 「그것만으로는 설명이 안 된다」(005), 「더 심각한 문제는」(003)처럼 **한 겹 더 들어가는 전환**이 파트 경계마다 있다.
- 002는 가장 신기한 장면(모기 피)을 앞에서 예고하고 후반에 회수해 36분을 버틴다.
- 006은 항목을 나열하는 구조라 오픈루프가 없고 중간에 힘이 빠진다.

**설계 원칙**
1. **4막 뼈대**
   - 1막: 스웨덴의 현재를 숫자와 장면으로 보여 준다.
   - 2막: 스웨덴은 어쩌다 이렇게 됐나. 표면(이민)에서 구조(불법 총기 유통, 갱단의 미성년자 동원, 통합·실업, 사법 절차)로 내려간다. 이민 통계는 **인구 비율로 다시 읽는 장면 1회**로 공정하게 처리한다.
   - 3막: 한국도 원래 안전하지 않았다(조폭·현금 사회). 「소탕만으로는 안 됐다」에서 전환한다.
   - 4막: 매일 작동하는 시스템 해부. 이어서 자기반박과 회수.
2. 한국 시스템은 **「추적 사슬」 하나의 장면**으로 엮는다. 총기 영치 → CCTV·관제 → 블랙박스 → 교통카드·카드 결제 → 112 → 과학수사가 따로 놀지 않고 이어진다는 것을 절차 단위로 보여 준다.
3. 경제 채널의 시선으로 **「해 봐야 남는 게 없는 구조」**를 세운다. 범죄를 비용과 편익으로 보면, 현금이 없고 장물을 팔 곳이 없고 잡힐 확률이 높으면 범죄는 수지가 맞지 않는다. 여기서 「착해서가 아니다」의 답을 경제 논리로 완성한다.
4. 숫자는 **반드시 같은 기준(10만 명당, 같은 연도)의 대비 쌍**으로 제시한다. 레퍼런스의 구두 수치는 verified-data로 확인된 것만 쓴다.
5. 파트 경계마다 **「그것만으로는 설명이 안 된다」류 한 겹 더 들어가는 전환**을 둔다. 문장은 새로 쓴다.
6. 연대기로 열지 않는다(004의 약점). 한국의 과거는 3막 전환부의 짧은 조각으로만 쓴다(1분 30초 이내).

## 3. 감정 증폭 전략

**관찰 — 댓글 감정 순위**
1. **반이민 경계심**(001 1위 685, 003 1위 약 3,500 추정·상위 전부): 수요가 가장 크다. 그러나 우리 채널에서는 차용 금지다.
2. **「한국도 문제 있다」는 반론·냉소**(005 1위 283 「사기는 세계 1등」, 002 1위 「잡는 건 최고인데 형량은…」): 자부심 영상에 붙는 가장 강한 반응이다.
3. **비교 자부심**(004 1위 871 「좌우로 야쿠자·삼합회가 있는데 우리는」): 시청자가 스스로 비교축을 세웠다.
4. 시스템 설명에 대한 동의(004 2위 215 「국가가 소탕한 결과」, 005 8위 「카드라 현금이 없어서」)
5. 폭력·정치 밈(006): 차용 금지다.

**관찰 — 장치 역추적**
- 반이민 정서는 **원인 파트에서 이민을 가장 먼저 꺼내고 결론을 열어 둘 때**(003) 증폭됐다. 영상이 다른 설명 축을 주지 않으면 시청자가 이민으로 빈칸을 채운다.
- 반론 댓글은 **한국 쪽을 한 문장으로 끝냈을 때**(005) 또는 **처벌 이야기를 비워 뒀을 때**(002) 터졌다.

**설계 원칙**
1. 1순위 감정 자리를 반이민이 아니라 **「내가 매일 누리는 것의 정체를 알게 된 놀라움」**으로 대체한다. 이를 위해 이민 외의 설명 축(시스템)을 **2막 중반까지 반드시 깔아 둔다.** 빈칸을 남기지 않는다.
2. **자기반박을 본문에 넣는다.**
   - 다룰 것: 보이스피싱·마약·이상동기 흉기 범죄·전세사기
   - 처리: 「같은 시스템이 비대면 범죄의 통로가 되기도 한다」로 논지 안에서 소화한다.
   - 위치: 4막 후반, 처벌 이야기가 나오기 전
2-1. 처벌 불만은 판사·사법부 비난 없이 **「한국의 강점은 형량의 세기가 아니라 잡힐 확률」**(확실성 대 엄중성)로 정리한다.
3. 감정 흐름: **충격(스웨덴 일상 속 총격, 초반 20%) → 의문(왜? 이민만으로 설명되나, 2막) → 반전(한국도 원래 그랬다, 3막) → 납득·놀라움(시스템 해부, 4막 전반) → 균형(우리 약점, 4막 후반) → 일상으로 회수(아웃트로)**
4. 비교 자부심은 조롱 없이 사실로만 만든다. 스웨덴 비하 금지, 특정 국적 언급 금지.

- 가장 많이 쓴 구도: **A vs B / 상징물**(001·003·006)
- 색채 공통점: 어두운 배경에 노랑·시안 고채도 텍스트
- 고퍼포먼스 특징: **국가 상징(국기) 또는 「같은 나라의 두 얼굴」 병치**, 그리고 002의 **AI 바운딩 박스 CCTV 화면**(시스템을 한 장으로 보여 줌)
- 모바일 가시성: 국기·권총·바운딩 박스는 160×90에서도 인식된다. 002의 국기 라벨 5개는 작은 화면에서 뭉개진다.

**제목**
- 001 「복지 천국 스웨덴은 어쩌다 범죄의 천국이 되었을까」: 「어쩌다」 원인형 + 반전
- 003 「"이러다 망할 판"…스웨덴은 어쩌다 갱스터의 천국이 되었나」: 인용 + 원인형
- 002 「"한국은 세계 최고 수준" 한국에서는 완벽범죄가 일어나지 않는 진짜 이유」: 외부 인용 + 진짜 이유
- 004 「한국의 치안이 좋은 이유 '조폭들의 몰락 범죄와의 전쟁'」: 이유형 + 사건명
- 역할 분담: 썸네일은 반전과 감정(천국 → 지옥, 경탄)을 맡고, 제목은 원인 질문(어쩌다, 진짜 이유)을 맡는다.

**설계 원칙**
- **썸네일 텍스트**: 2행, 요소당 7~10자, 총 17~20자. 1행은 스웨덴 통념이 깨진 사실, 2행은 **한국 쪽 질문/반전**(예: 「한국은 왜 총소리가 안 나나」 류). 「천국」 반전어는 경쟁 3편이 이미 썼으니 피하거나 비틀어 쓴다.
- **제목**: 「같은 선진국, 다른 결과」 대비 + **「착해서가 아니다」류 통념 부정 또는 「진짜 이유」**. 이민이라는 단어는 제목·썸네일에 넣지 않는다(혐오 수요를 끌어오는 신호).
- **역할 분담**: 썸네일 = 대비 장면 + 짧은 반전 / 제목 = 한국이 안전한 「진짜 이유」 질문
- **비주얼**: 좌측 스웨덴(폴리스라인·폭발 현장, 사실 사진 톤) vs 우측 한국(관제센터 모니터 또는 바운딩 박스가 쳐진 밤거리). 국기 라벨은 최대 2개.

**구조 자산** (기법 라벨 + 효과 원리)

*훅 기법*
- 「통념 이미지 세우고 깨기」: 시청자가 스스로 떠올린 이미지를 깨뜨려 낙차를 만든다 (003·001)
- 「뻔한 답 부정」: 시청자의 기본 가설(착해서)을 먼저 꺼내 부정해 「그럼 뭐지」를 영상 전체의 루프로 만든다 (004·002)
- 「믿기 어려운 구체 장면 선공개」: 후반의 가장 신기한 장면을 앞에 걸어 끝까지 보게 한다 (002)

*데이터 제시 기법*
- 「인구 비율로 다시 읽기」: 절대수를 인구 비중과 나란히 놓아 공정성과 반전을 동시에 준다 (001)
- 「같은 기준 대비 쌍」: 10만 명당 수치를 두 나라 나란히 놓는다 (006)

*설명 기법*
- 「절차 단위 따라가기」: 제도가 한 단계씩 작동(또는 실패)하는 과정을 장면으로 보여 준다 (005·002)
- 「추적 사슬」: 서로 다른 시스템이 이어져 한 사람을 찾아내는 과정을 하나의 시퀀스로 엮는다 (002)
- 「남는 게 없는 구조」: 범죄를 수지 계산으로 풀어 사람의 선악 대신 구조로 설명한다 (002)
- 「시스템 하나 빼 보기」: 당연한 장치를 없앴을 때의 장면을 1~2문장으로 상상시켜 가치를 체감시킨다 (006)

*리텐션 장치*
- 「한 겹 더」 전환: 표면 원인 뒤에 더 깊은 원인이 있다고 예고하며 파트를 넘긴다 (005·003)
- 「처음 장면 회수」: 훅의 일상 장면을 결말에서 새 의미로 다시 꺼낸다 (005)

*감정 트리거*
- 「일상 공간의 위협」: 쇼핑센터·식사 길 같은 평범한 장소의 피해로 「나도」를 만든다 (003)
- 「반론 선제 인정」: 시청자가 꺼낼 반례(사기·형량)를 먼저 인정해 신뢰를 얻는다 (005·002 댓글 역추적)
