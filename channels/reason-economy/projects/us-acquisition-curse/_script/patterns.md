**한 줄 결론**: 7편 모두 **단일 사례 장편(15~29분)**이다. 「비싸게 샀다 → 위기 → 역전」은 세 축(밥캣·하만·도시바 몰락) 모두에서 수요가 증명됐지만, **세 사례를 하나의 질문으로 묶고 도시바를 거울로 세운 편은 0편**이다. 고성과작 3편(003·001·006)의 댓글 상위가 공통으로 **「반복·길이」 불만**을 단다 → 우리 편의 무기는 **압축 + 비교 축**이다.

## 1. 반복되는 훅 공식

**관찰**
- 훅은 세 유형으로 갈린다.
  - **당시 평가 인용형**(003·007): 첫 문장이 결과가 아니라 「조롱」이다. 「삼성이 미쳤나? 스피커 회사에 왜 9조를」(003). 비판을 먼저 들려줘 시청자가 자동으로 반전을 기대하게 만든다. 003은 15.7배.
  - **장면 → 정체 공개형**(001·006): 「흰색·주황색 장비가 제자리에서 몸을 돌린다 → 밥캣입니다」. 이름을 감추고 「본 적 있는 그 장비」를 떠올리게 한 뒤 금액(49억 달러)과 붙인다. 두 편 모두 50배 이상. 006은 같은 장면으로 클로징을 닫는다.
  - **날짜 박힌 결말 선공개형**(005): 「2023년 12월 20일, 도시바 상장 폐지」 → 「노트북·낸드를 만든 회사가 왜?」. 결말을 먼저 줘서 궁금증을 「어떻게」로 좁힌다.
- 인트로 공통 역할: **위기 숫자를 2~4개 쌓고(하한가·영업이익 급락·사업 매각) → 「N년 뒤 전혀 다른 모습」 반전은 예고만 → 질문 두 개(「무엇을 샀나 / 왜 놓지 않았나」, 001·006)**로 본문 축을 세운다.
- 약한 인트로의 공통점(002·007·004): 목차 낭독, 구독 요청 삽입, 결론(마스터키·한국 승리)을 인트로에서 다 말해 버림.

**설계 원칙**
1. **첫 문장은 「비싸다」는 당시 평가 또는 그 평가를 받은 장면으로 연다.** 결과(1위)부터 말하지 않는다 — 반전 기대는 조롱이 먼저 와야 생긴다.
2. 훅의 판정 주체는 **외국**(애널리스트의 「far too expensive」, 도시바의 파산)으로 세운다. 003이 「외신」을 판정자로 써서 15.7배를 냈다. 단, 출처 없는 외신 인용은 쓰지 않는다(003의 약점).
3. **도시바 결말(파산)은 훅에서 날짜와 함께 먼저 공개**하고, 한국 세 회사의 결말(1위)은 **예고만** 한다 — 「같은 무렵 비싸다는 말을 들은 한국 회사 셋은?」.
4. 인트로 질문은 **두 개 이하**, 4막에서 그대로 답한다. 목차·구독 요청 금지.
5. 인트로 숫자 3개 이하(pd-script 인트로 제약). 54억 달러·파산 날짜·「세 번」 정도.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰 — 구조**
- 성공 사례 축(001·003·006·007): **조롱/고가 → 위기 숫자(돈) → 위기(사람) → 버틴 결정 → 역전 장면 → 실적 숫자 → (범위 선 긋기) → 수미상관.**
- 몰락 축(002·004·005): **기원·전성기 → 고가 인수 → 공사비·손실 → 사업 매각 행렬 → 결말 → 교훈.** 004는 각 결정 뒤에 「같은 시기 한국은」 블록을 붙이는 **교차 구조**를 썼다.
- 역전의 정점 장면이 겹친다: **「다른 건 다 팔아도 이건 안 판다」**(001 썸네일, 006 「인프라코어는 팔아도 밥캣은 남긴다」). 두 밥캣 영상이 모두 이 장면을 감정 정점으로 썼다.
- 성공 사례가 공통으로 짚은 「버틴 방법」: 추가 출자·만기 연장(밥캣), CEO 유임·사람과 관계 보존(하만, 007). **「왜 버틸 수 있었나」와 「같은 상황에서 무너진 회사는?」은 어느 영상도 다루지 않았다**(006 분석: 원인 분석이 얕다).

**관찰 — 전달 기법**
- **연도별 숫자 사다리**(003): 위기와 반전을 모두 숫자로 그려 납득시킨다. 003의 가장 강한 무기.
- **산 값 vs 판 값 대비**(005·004): 「54억 달러에 사서 지분은 1달러에」, 「1999년 11억 → 2006년 54억」. 가격 하나로 판단의 무게를 보여준다.
- **숫자를 사람으로 바꾸기**(001·006): 475명 해고 → 「월급날·대출 상환일·학비」.
- **스스로 범위 좁히기**(001): 「1위는 스키드 스티어 한 칸뿐, CTL은 3위」 — 과장을 걷어내 오히려 신뢰를 얻었다.
- **상식 뒤집기 한 줄**(003·007): 「스피커 회사가 아니라 차 안의 핵심 파트너」.
- 비유: 고성과작은 비유가 적고 재정의 문장으로 핵심을 전달했다(006). 비유 남발은 저성과작(002: 6~7개)에 몰려 있다.

**관찰 — 리텐션 장치**
- 초반: 「N년 뒤 이 회사는 목록에 없었다」류 오픈루프(001·006).
- 중반: 「이쯤이면 팔고 손실을 끊을 수도 있었다. 하지만 반대로 움직였다」 패턴 인터럽트(006) — 선택의 순간을 세운다.
- 후반: 「이 1위는 어디까지 1위일까요?」 범위 선 긋기(001), 「여기까지 보면 완벽한 승리 같죠?」 반전 오픈루프(002).
- **약점 공통**: 정점 이후(영상 60% 지점 뒤)에 같은 결론을 문장만 바꿔 되풀이 → 댓글 불만으로 직결(006 TOP 10 중 5개, 001 1위, 007).

**설계 원칙**
1. **뼈대 = 질문 하나 + 사례 셋 점층 + 거울 하나.** 도시바(무너진 쪽) → 밥캣 → LS → 하만(가장 큰 숫자) → 4막에서 공통점으로 답. 사례마다 **「비싸다는 말 → 위기 → 역전」 미니 3박자**를 넣되, 각 사례는 핵심 장면 하나만 쓴다.
2. 각 사례의 정점은 **「팔 수 있었는데 안 팔았다 / 사람을 바꿀 수 있었는데 안 바꿨다」 선택 장면**으로 둔다(밥캣=2020 지분 분리, LS=적자 7년, 하만=CEO 유임). 이 선택들이 4막 답의 근거가 된다.
3. **숫자는 대비 쌍으로만**: 산 값 vs 이전 값(도시바 11억→54억), 첫해 이익 vs 최근 이익(하만), 프리미엄 %(LS 50%·하만 28%). 한 문단 숫자 2개 이하.
4. **범위 선 긋기는 사례마다 한 문장**: 「미국 스키드 스티어 판매 1위」「권선 세계 1위」「차량 오디오 세계 1위(삼성 IR, 테크인사이츠 집계)」. 001처럼 스스로 좁혀 신뢰를 얻는다.
5. **정점 이후 반복 금지.** 4막은 새 정보(도시바와 갈린 지점)로 채우고, 같은 결론을 연도만 바꿔 되풀이하지 않는다. 「2008년엔 ~, 2021년엔 ~」 대구는 대본 전체 1회.
6. 파트 전환마다 다음 사례 오픈루프 1개. 「이건 큰 회사라 버틴 걸까요? 훨씬 작은 회사도 같은 길을 갔습니다」(밥캣→LS) 식으로 **앞 사례의 반론을 다음 사례가 받게** 한다.

## 3. 감정 증폭 전략

**관찰 — 댓글 감정 순위**
1. **「당시 비판한 쪽」에 대한 반감 + 통쾌함**(003 1위 227: 「회사돈 9조원을 썼다」던 국내 언론 지목) — 가장 뜨겁다.
2. **경영 판단 책임에 대한 공감**(005 1위 123: 「지휘관이 무능하면 부하는 다 죽는다」) — 원인을 사람의 선택에 두는 프레임에 동의.
3. **반복·길이 불만**(006 1위 15, 001 1위 3, 007) — 고성과작에서도 상위.
4. **회의론**(006: 「비싸게 샀지. 대박은 아니지」, 「그 돈이면 하이닉스도」) — 「정말 성공인가」를 따지는 층이 있다.
5. **결단 감탄**(001: 「그 순간 저라면 뚝심 있게 못 했을 것」) — 선택형 질문이 실제로 통한 지점.
6. **굴욕·분노 탈선**(002: 한수원-웨스팅하우스 합의 「강화도조약」, 004 「노예계약」) — 웨스팅하우스는 한국에도 민감한 이름.

**관찰 — 감정을 만든 장치**
- 통쾌함은 **조롱을 길게 들려준 뒤 숫자로 뒤집을 때**(003 「574억 → 1조」) 가장 크다.
- 긴장은 **「팔 수도 있었다」는 선택지를 먼저 보여준 뒤**(006) 생긴다.
- 감정 흐름 공통: **의심(조롱) → 불안(위기 숫자) → 긴장(팔 것인가) → 통쾌(역전 숫자) → 납득(범위·이유)**.

**설계 원칙**
1. **통쾌함을 세 번, 점점 크게** — 밥캣(첫 역전) → LS(작은 회사도) → 하만(가장 큰 숫자). 각 역전 직전에 「팔 수도 있었다/비쌌다」를 먼저 세운다.
2. **분노는 쓰지 않는다.** 도시바·언론·개인 조롱 금지. 도시바는 무너진 사실과 숫자만(브리프 규칙). 「당시 비판」은 출처 있는 평가만 인용하고 비판자를 공격하지 않는다.
3. **회의론을 4막 재료로 쓴다** — 「비싸게 산 건 맞다」는 시청자에게 도시바 대조로 답한다: 같은 고가 인수가 한쪽은 파산, 한쪽은 1위 → 가른 것은 값이 아니라 산 뒤의 선택. 자기반박 블록은 없음(브리프 결정), 대신 문장 단위 범위어로 「이 세 회사는」을 지킨다.
4. **웨스팅하우스-한수원 분쟁은 꺼내지 않는다**(002·004 댓글 탈선 위험).
5. 감정 배분: 의심·긴장(1막·각 사례 전반 40%) → 통쾌(각 사례 후반 35%) → 납득·여운(4막 25%).
6. 클로징 질문은 001에서 통한 「그 자리라면」형을 쓰되, 메모리 규칙대로 **경제를 몰라도 자기 경험으로 답하는 질문**으로 바꾼다(예: 비싸다는 말을 듣고도 안 놓은 물건·선택).

- 고성과 키워드: **따옴표로 묶은 당시 평가**(「'승자의 저주'」「"무모한 딜"」), **최악↔최고 / 비웃던↔침묵 대구**, **반말 감정 대사**(「다 팔아도 넌 안 판다」「그냥 오디오 회사라 생각했지?」).
- 저성과 패턴: 「통째로 접수」 같은 과장 단정(002), 숫자 라벨 남발(002 스탬프 4개).

**★ 썸네일 비주얼 비교표**

**비주얼 형식 패턴 요약**
- 가장 많이 쓴 구도: **좌우 분할(위기/몰락 ↔ 성공)** 3편 + 상징물 클로즈업.
- 색채 공통: 어두운 쪽(회색·적갈색 연기) vs 밝은 쪽(하늘·청색), 텍스트는 노랑+시안.
- 고성과 특징: **알아볼 수 있는 실물 하나를 크게**(밥캣 로더, HARMAN 로고) + 국기 대비. 005는 실물 대신 「책임자 구도」 상징 그림.
- 모바일 가시성: 밥캣 로더·로고처럼 단일 피사체는 160×90에서도 인식된다. 3분할 콜라주(007)는 작아지면 뭉개진다.

**제목**
- 공통 구조: **[금액/평가 인용] + [시간 경과] + [결과 범위어] + [대비 거인]** (001: 「49억 달러에 산 … 승자의 저주라던 15년 뒤 … 로더 1위 — 캐터필러·쿠보타를 앞에 두고」).
- 「진짜 이유」(004·007)는 저성과작에 몰려 있다 — 단독으로는 약하다. 고성과작은 **결과 선언 + 대비**.
- 판정 주체를 외국에 둔 제목(003 「비웃던 외신들」)이 최고 배율권.

**썸네일-제목 역할 분담**
- 001: 썸네일 = 원화(5조 7천억)+감정 대사 / 제목 = 달러(49억)+결과 범위어(로더 1위)+거인 이름.
- 006: 썸네일 = 숫자+결과(황금알) / 제목 = 과정 질문(어떻게 키웠나).
- 007: 썸네일 = 결과(26배) / 제목 = 의문(진짜 이유).

**설계 원칙**
- **썸네일 텍스트**: 하단 2줄 계층형, 요소 2~3개, 요소당 9~13자, 총 20~30자. 1줄 노랑 = 따옴표로 묶은 당시 평가(「"비싸게 샀다"」류), 2줄 시안 = 결과(「셋 다 1위」류). 감정 대사 박스 1개는 선택. 「세계 1위」 뭉뚱그리기 금지(브리프).
- **제목**: 「비싸다는 말을 들은 미국 회사 인수 + 셋 + 1위」를 넣고, 대비축(도시바)을 이름으로 걸 것인지는 STRATEGY에서 결정. 「진짜 이유」 단독 의존 금지 — 결과 선언과 짝지어 쓴다.
- **역할 분담**: 썸네일 = 감정(당시 평가 → 결과), 제목 = 정보(누가·얼마·몇 곳·대비).
- **썸네일 비주얼**: 좌우 분할 — 왼쪽 무너진 쪽(도시바·원전 냉각탑, 회색 연기), 오른쪽 한국 세 회사의 실물(밥캣 로더 등 하나를 크게) + 맑은 하늘. 인물(총수) 얼굴은 쓰지 않는다(조롱·정치색 회피).

**구조 자산**
- 훅 기법
  - `당시 평가 인용 훅` — 조롱을 먼저 들려줘 반전 기대를 자동으로 만든다 (003·007)
  - `장면 → 정체 공개 훅` — 본 적 있는 물건을 이름 없이 그린 뒤 금액과 붙여 「왜 저렇게까지?」를 만든다 (001·006)
  - `날짜 박힌 결말 선공개` — 결말을 먼저 줘 궁금증을 「어떻게」로 좁힌다 (005)
  - `산 값 vs 이전 값 대비` — 가격 두 개로 판단의 무게를 즉시 보여준다 (004·005)
- 구조 기법
  - `「다 팔아도 이건 안 판다」 정점` — 선택지를 보여준 뒤 반대로 움직인 장면이 감정 정점이 된다 (001·006)
  - `같은 시기 교차 블록` — 한쪽이 무너지는 동안 다른 쪽은 무엇을 했나로 대비를 세운다 (004)
  - `스스로 범위 좁히기` — 1위의 범위를 먼저 밝혀 과장 의심을 끄고 신뢰를 얻는다 (001)
  - `질문 두 개로 축 세우기` — 「무엇을 샀나 / 왜 놓지 않았나」를 인트로에 걸고 본문이 답한다 (001·006)
- 리텐션 장치
  - `「팔 수도 있었다」 인터럽트` — 합리적 대안을 먼저 보여줘 다음 선택에 긴장을 건다 (006)
  - `반전 오픈루프` — 「여기까지 보면 완벽한 승리 같죠?」로 정점 뒤 이탈을 막는다 (002)
  - `복선 회수` — 「기억해 두세요」로 걸어 둔 정체성을 결말에서 회수한다 (004)
- 감정 트리거
  - `숫자를 사람으로` — 해고 인원을 월급날·학비로 바꿔 위기를 체감시킨다 (001·006)
  - `상식 뒤집기 한 줄` — 「스피커 회사」 통념을 「차 안의 파트너」로 바꿔 놀람을 준다 (003·007)
- 데이터 제시 기법
  - `연도별 숫자 사다리` — 급락과 급등을 연도순으로 보여 역전을 납득시킨다 (003)
  - `첫해 이익 vs 최근 이익 배수` — 한 쌍의 숫자로 역전 폭을 압축한다 (007)
- 피할 것(교훈)
  - `정점 뒤 반복` — 고성과작도 반복·길이 불만이 댓글 1위 (006·001·007)
  - `출처 없는 외신 인용·과장어` — 「독과점」「통째로 접수」는 약속 불이행으로 읽힌다 (003·002)
