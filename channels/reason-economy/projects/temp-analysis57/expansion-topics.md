**001 시화호 (25분)** — 훼: 1998 안산 회의실 「저거 터뜨리면 다 감방 간다」, 6,200억 들인 방조제가 똥물 → 「본전이라도 건지자, 프로펠러를 달자」 / 1987 중동 건설 장비 놀리지 않으려 착공 → 1994 완공 축배 → 2년 만에 COD 17.4ppm 「죽음의 호수」 → 몰래 배수갑문 열기 → 1998-11 담수화 포기 선언 / 해수 유통 구멍 1,500억 vs 「발전소 달면 3,500억이지만 명분이 바뀐다」 → 방조제가 이미 있어 건설비 절반 / 유럽 기술진 「양방향이 정석」 vs 한국 「호수 수위 못 올림(안산 침수) → 밀물 단방향 낙차 극대화」 / 2011 254MW, 프랑스 랑스 240MW(45년 1위) 추월 / 수질 1.8ppm·물고기·철새 귀환 / RE100 → 2024-05 삼성전자 직접 구매 계약, 롯데케미칼 / 영국 리버풀 시찰 → 「600억 날리고 감방 안 가려고 머리 짜낸 것」
**002 소수민족 (29분)** — 훼: 발해 세자 대광현에게 왕건이 성을 주고 족보에 올림 → 「그들은 당신 이름 바로 옆 칸에 있다」 / 중국 신분증 민족 칸, 1953년 400여 개 신고 → 56은 「서랍 칸 수」 / 한국 주민등록증엔 민족 칸 없음(UN 2003 권고) / 쉬운 답(삼면 바다·단일 왕조) 세우고 → 일본 아소 발언 철회·아이누 법제화로 반박 / 고려 쌍기·장순룡·설손 → 조선 향화인 대장, 세금 3년·부역 10년 면제, 같은 출신을 여러 고을에 흩어 살게 함 / 세종 1439 「손자부터는 향화인이라 부르지 말라」 = 꼬리표 유효기간 2대 / 사야가 김충선·광동 진씨(시진핑 2014 서울대 연설) / 예외: 재가승·백정·화교 / 거울: 조선족은 중국 서랍에 / 오늘: 창성창본(몽골 김씨·태국 태씨), 귀화 5년 연속 1만+ / 결말: 「가족관계증명서 본관 칸을 보라」
**003 CU (23분)** — 훼: 2012년 여름 하루 300곳씩 간판이 내려옴, 1등이 1등 간판을 왜? ↔ 14년 뒤 몽골 600번째 CU / 같은 날 서울은 「결별」, 도쿄는 「자본 관계 강화」 → 답은 2년 뒤 주식시장 / 로열티는 매출 1만 원당 14원 → 돈이 아니라 「전세집」(키워도 집주인 몫, 분점 못 냄) / 2014 상장 공모주는 전부 일본 훼미리마트 지분 → 손 뗌 / 대가: 점주 소송, 2013년 6개 증가(GS25 562개), 2019 1위 잠시 내줌 / 이란 9개 실패 → 몽골(일본 세븐 컨설턴트 두고도 한국 선택) 6년 만에 흑자 = 1990년 한국 훼미리마트도 6년·360개 / 말레이시아 줄 100m·떡볶이, 현지 훼미리마트 465개 vs CU 167개 「진행 중」 / 돈키호테 전용 매대 / 해외 855개 / 「동네 첫 편의점 간판은?」

## 터진 이유
1. **역설 한 줄 제목** — 똥물 치우다 세계 1위 / 이방인을 받았는데 소수민족 0 / 1등이 1등 간판을 버림. 「A인데 B」 낙차가 제목 안에서 끝난다
2. **5070 기억 소환** — 시화호 냄새·중랑천 간장 물(댓글 16·5), 동네 첫 편의점 간판, 내 족보 본관. 댓글이 「나도 봤다」로 열림
3. **실패·대가를 숨기지 않음** — 001은 실패 인정이 주인공, 003은 소송·6개 증가·1위 상실을 그대로, 002는 쉬운 답을 먼저 세우고 반박. 국뽕인데 선동 의심이 안 걸림(우리 자기반박과 같은 원리)
4. **외국 판정이 결말을 받침** — 프랑스 랑스 추월·영국 시찰 / 시진핑 연설·일본 아소 철회 / 몽골이 일본 대신 한국 선택·돈키호테 매대
5. **일상 비유 하나로 관통** — 서랍 칸(56개), 전세집(로열티), 감방 피하려는 계산(시화호). 숫자보다 비유가 먼저 기억됨
6. **현재 장면으로 닫음** — RE100·삼성 계약 / 창성창본·귀화 1만 / 몽골 600번째 점포·해외 855개 → 옛날이야기가 오늘 뉴스가 됨
7. **002·003은 1차 자료 밀도** — 고려사·실록 날짜, 인구총조사 본관 인원, 공모주 수·경쟁률 337:1. 001은 재연 대화(근거 없는 대사) 비중이 큼 — 우리 금지(가상 인용)
