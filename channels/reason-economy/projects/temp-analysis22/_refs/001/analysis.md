# 레퍼런스 분석 — 001 탁경제 「"배 밑에 공기를 깔았습니다" 25년 기름값이 한국 조선을 다시 움직인 이유」

> 조회 112,858 / 구독 2,340 = **약 48배** · 19:40 · 좋아요 516 · 댓글 28 · **2026-10-03(당일 업로드, 하루 안에 11만)**
> **같은 채널의 「울산 프로펠러」(temp-analysis10, 63배)의 직접 후속** — 「큰 프로펠러와 엔진 이야기는 탁경제에서 했었죠」로 시리즈 연결. 2편 연속 히트
> 자막은 한국어 자동자막

## 1. 주제 요약
배의 평생 기름값이 배값보다 크다(25년) → 선주들이 이미 다니는 배까지 고친다: 배 밑 공기 윤활, 선체 물때 청소 로봇, 선수 구상선수(벌버스 바우) 교체, 날개형 돛 → 그 개조 일감을 한국 조선(HD현대마린솔루션 등)이 받기 시작했다 — 「배를 넘긴 날이 장사의 끝이 아니게 됐다」.

## 3. 훅 (0:00~약 1:30)
- 장면 3연타의 이상한 일: ① 배 바닥 구멍에서 공기 ② 멀쩡한 배의 코를 잘라 새로 붙임 ③ 유조선 갑판에 30m 돛 → 「공기, 코, 돛. 이유는 셋 다 같아요. 기름값」
- 숫자: 큰 컨테이너선 하루 기름 1억 안팎 × 25년 → 평생 기름값 > 배값
- 생활 연결: 수출입 화물 거의 전부가 배 → 물건값
- 반전 예고: 「선주가 배를 고칠수록 일감이 느는 한국 회사가 있다」
- ⚠️ 약 30% 지점 구독 요청

## 4. 본문 구조 (네 가지 개조 → 돈은 누가 받나)
1. **공기 윤활**: 원래 군함 소음 은폐용(2차대전 후) → 마찰 저항(저속 대형선 저항의 70~80%) → 일본이 먼저 상선 적용 → 삼성중공업 2018 최대 컨테이너선 4%+ → 압축기가 절감분의 최대 절반을 다시 씀(정직) → 선주의 장부(배값 3,500억 vs 25년 기름값 5,600억, 4% = 1년치 220억)
2. **물때·따개비**: 0.5mm 물때가 연료 25~30%↑(IMO 참여 보고서), 따개비 최대 60% → 5년 무청소 3천만 달러, 청소 시 약 90억 절감 → HMM의 한국산 수중 청소 로봇(40% 저렴)
3. **선수(코) 교체**: 머스크 칭다오 개조(12일) → 저속 운항(슬로 스티밍) 시대에 고속용 코가 안 맞음 → 2013 현대상선 현대 브레이브 코 성형(68만 달러, 연 60만 달러 절감, 5%) → 머스크 용선 200척 공동 개조
4. **돛**: 2026-01 HMM 유조선에 30m 날개돛(HD한국조선해양, 국내 첫, 기대치 5~20%) · 팬오션 로터세일 · 덴마크 유조선 8% 검증
→ **돈은 누가**: 한국 선박 수출 320억 달러(배를 넘기면 끝) vs 세계 상선 10만 척+(40%가 15년 이상) → HD현대마린솔루션 개조 메뉴판 → 쉐브론 LNG선 2척 개조(재액화 + 공기 윤활), 엔진 재조정 74척 690억 → **냉정 파트**: 개조 매출 1,700억 = 전체 약 2조의 9%, 실제 공사는 중국·베트남 수리 조선소에 맡김, EMSA는 공기 윤활 실효 2% 남짓·「효과 없었다」 선주도 → 「절반만 나와도 반년치 100억」 → IMO 탄소 가격 연말 재논의 → 1974 울산 애틀랜틱 배런 수미상관 → 「몇 척 수주보다 그 배가 평생 얼마 덜 쓰게 하느냐」

- 기법: 프로펠러 편과 동일 — **「탁경제 계산」 명시**, 회사 주장 vs 독립 기관(EMSA·IMO) 구분, 「여기서는 냉정하게」 파트, 생활 비유(고속 맞춘 차를 시내에서만), 장면 3연타 훅
