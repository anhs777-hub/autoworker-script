## 1. 주제 요약
현대차 싼타페 EREV(주행거리 연장형 전기차)가 배터리를 순수 전기차의 절반 이하로 줄이고도 목표 주행거리 966km를 내건 이유 — 자체 설계 고출력 셀(팹리스·파운드리 방식), 발전·구동 겸용 모터, 15년 하이브리드·EV 경험.

## 4. 본문 구조
EREV 개념(하이브리드·PHEV와 차이, 「마차 뒤에 실은 발전기」) → 왜 배터리 크기가 중요한가(가장 비싸고 무거운 부품) → 「작으면 힘도 약해지지 않나?」 → 자체 설계 고출력 셀(출력 2배, 충전 40% 단축, 「수도꼭지 굵기」 비유) → **팹리스·파운드리 전략**(애플·TSMC 비유, 맞춤 양복) → 용도별 배터리(고출력·미드니켈·LFP) → 발전·구동 겸용 모터(「손님 많으면 계산대, 한가하면 창고」) → **복선 회수: 옆면의 문 두 개**(미국 시험차 MX5a) → 미국 가족 하루 장면 → 앨라배마 생산, 가격 전망 → 966km 목표의 이력(2024년 900km+ → 600마일, 「숫자가 줄지 않고 늘었다」) → 「캐즘은 없다」 → 왜 미국 먼저: 중국 EREV 120만 대(+79%)·미국 충전 공백 → 2030 555만 대 계획 → **배터리 수명 증거**: 아이오닉5 2년 9개월 58만km, 배터리 87.7%(연구팀이 차주에게 연락) → 코나 독일 1,026km·마드리드 790km → 제네시스 GV90 1,030km 목표·TRP(열 전이 방지) → **자기반박 4개**(EPA 미인증 목표치 / 결국 휘발유 / PHEV 공백 전략 위험 / 샤오펑 경쟁) → 수미상관(「더 크게가 아니라 덜어 내는 용기」) → **다음 편 예고**(중국 1,000km 인증의 비밀)
