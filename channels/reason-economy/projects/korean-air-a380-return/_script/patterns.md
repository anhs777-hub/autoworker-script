## 1. 훅 설계 원칙
- 원본이 터진 핵심 장치 = **통념(실패작이라 단종) ↔ 현실(아직 가장 긴 노선을 난다)** 의 역설. 우리 편은 같은 역설을 한국 회사 결정으로 옮긴다: 「5년 안에 뺀다」(2021) ↔ 그 5년째(2026) 매일 뉴욕
- 첫 20초 주인공 = 대한항공 A380 (썸네일 주인공). 비교 대상(루프트한자·콴타스·에미레이트)은 훅에서 이름만, 본론에서 펼친다
- 경쟁작이 전부 「단종 역사」로 열었다 → 역사로 열지 않는다. 2026년 인천 출발 장면(현재)으로 연다
- 흔한 답 「A380이 좋아서 돌아왔다 / 승객이 좋아해서」(경쟁작 최다 댓글 297)를 대본 안에서 먼저 꺼낸 뒤 「좋아서가 아니다」로 받는다 — 이 편의 통념 뒤집기

## 2. 본론 구조
- 원본은 「크기 → 역사 → 비행 준비 → 객실 → 위기 → 답」으로 **답을 마지막 3분까지 미뤘다.** 우리 편도 핵심 답(대체기 777-9가 아직 안 왔다)을 중반 이후까지 보류하되, 「왜 버리려 했나」를 먼저 충분히 세워 답의 무게를 만든다
- 과거(2021 발언·2024 해체)는 「왜 지금 이게 이상한가」의 근거로 끼워 넣는다. 과거 한 덩어리 1분 30초 이내
- 비교 축: 같은 기종을 두고 셋이 다른 결정 — 되살린 루프트한자(같은 이유) / 앞당겨 빼는 콴타스(반대 방향, 같은 원리) / 처음부터 계속 쓰는 에미레이트 → 결정 변수 하나(대체기 도착 시점)로 묶는다

## 3. 리텐션 장치 (자사 실측 장치에서)
- 본문 장치 8번 재점화 3~4분마다: 「그 비행기가 지금 뉴욕을 매일 난다」 · 「대신 올 비행기는 어디 있나」 · 「콴타스는 왜 반대로 갔나」
- 반론 대행 후 반박: 「A380이 좋아서?」 → 해체까지 한 회사다
- 모르는 것을 모른다고: 회사는 퇴역 시점 「정해진 바 없다」 — 예측하지 않는다
- 원본의 숫자→생활 비교 장치(날개=축구장 등)는 쓰지 않는다 (사용자 지시: 비유 금지)

## 4. 클로징
- 훅 장면(인천~뉴욕 매일)으로 수미상관 → 이제 보이는 이유 → 「쉽게 말해, ~」 한 문장
- 판단은 시청자 몫: 「앞으로는」 전망 문단 없음
