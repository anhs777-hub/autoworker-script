> **쓰임**: 구조 본보기가 아니라 **3막(한국) 사실 뼈대와 사람 에피소드 공급원** + 창업주 위인전 연대기가 왜 안 터지는지 보여주는 **반면교사**.

## 1. 주제 요약
**가난한 농부의 아들이 세운 자동차 수리공장이 세계 5위권 자동차 기업이 됐다.** 포드 제휴 실패·부도 위기·IMF를 넘었고, 포니 → 엑셀 → 기아 인수 → 제네시스·전기차로 이어졌다.

## 3. 훅 & 인트로 분석
- **훅**: 당시 화제 드라마에 기댄 시의성 훅. 드라마를 본 사람에게만 작동. 역설 없이 정체 공개. 훅 5단의 ①③④ 모두 없음.
- **인트로**: "오늘은 ~ 알아봅니다"형. 미결 질문도 위기 예고도 없다 — **저성과의 1차 원인.**

## 4. 본문 구조 분석
1. 창업주 유년기·가출 → 2. 쌀가게 → 1940 수리공장(화재 → 재대출 → 재기 → 통폐합 폐업) → 3. 1946 자동차공업사 → 건설·조선 → 4. 1966~67 포드 접촉, 2시간 만에 제휴 → 1967 현대자동차 설립 → 5. 임직원 해외 연수(미·일·**호주**) → 6개월 만에 코티나 → 6. **코티나 실패**: 포장도로 전제 설계라 비포장에서 잔고장, 1969 울산 공장 침수로 부도 위기, 1972 사채 동결 조치 → 7. **포드와 결별**: 포드가 현대를 **부품 생산기지**로 두려 해 협상이 끌림 → 독자 개발 → 8. **포니**: 디자인 주지아로, 부사장 조지 턴불(영국 BLMC 출신), 엔진·변속기 미쓰비시. 1974 토리노 데뷔(아시아 두 번째 고유 모델). 1976 첫해 약 1만 대·점유율 43%, 수출 1천 → 1978년 1만 2천 대 → 9. 오일쇼크·산업 합리화 → 10. 엑셀 미국(첫해 16만 대+, 1989 누적 100만) → 품질 문제로 "싸구려" 이미지 → 11. 1980~90년대 차종 → 12. IMF: 기아 부도·인수, 1년 만에 흑자 → 13. 10년 10만 마일 보증·품질경영 → 제네시스 → 14. 2016 누적 1억 대, 2020 글로벌 5위, 전기·수소·로봇 → 15. "보통 사람은 아니었다" + 진행자 개그
- **인물 연대기 → 위기-극복 반복 → 현재 사업 나열.** 중심 질문이 없어 중반 이후 긴장이 떨어진다.

**전달 기법**: 인물 일화가 강점(사람의 선택·행동 장면). 유머형 창작 비유(우리 기준 금지). 숫자에 해석이 거의 없다.

**리텐션**: "기쁨도 잠시"류 반전이 네 번 이상 반복돼 패턴이 읽힌다. 영상 전체를 끄는 큰 오픈루프 없음.

## 5. 감정 트리거
- 존경(집념) / 안도·통쾌(약) / 향수(1980~90년대 차)
- 흐름: 연민 → 존경 → 긴장 → 뿌듯함 → 향수 → 긴장(IMF) → 평탄. **후반 1/3이 평탄**, 해외 대비가 없어 위인전식 존경에 머문다.

## 6. 댓글 반응 분석
- 1위(8)는 진행자 개그 반응(기존 팬).
- 인물 존경 댓글 다수.
- 사진 속 간판 하나에 질문이 붙음 — **1차 기록 이미지가 댓글을 만든다.**
- "MBC 성공시대 보시면 됩니다" — **창업주 서사는 이미 소비된 식상한 소재.**

**우리 영상에서 다룰 것**
- **창업주 위인전으로 빠지지 않는다.** 4막은 「사람이냐 조건이냐」 축 — 창업주는 '사람' 후보의 한 조각일 뿐, 수출 전략·독자 모델·소유 구조 같은 조건과 같은 무게.
- **"사람의 선택" 장면은 살린다**: 포드가 부품기지로 두려 하자 독자 모델을 택한 결정. **호주는 여기서 반대로 갔다**(홀든은 GM, 포드 호주는 포드 본사 자회사로 남음).
- 1차 기록으로 확인되는 구체 장면(토리노 모터쇼, 첫 수출)을 넣는다.

## 7. 핵심 약속 역추적
- **이행**(연대기 정리). "당신이 몰랐을"은 부분 이행. 저성과 원인: 질문 없는 연대기, 해외 대비 부재, 식상한 창업주 서사, 후반 홍보성 나열.

## 우리 영상에 가져갈 재료 (전부 1차 재검증 필수)
- 1967 포드 기술 제휴 → 코티나 조립 → 잔고장 → 1969 침수·부도 위기
- **호주와 갈리는 핵심 지점**: 포드는 현대를 부품 생산기지로 두려 했고 현대는 독자 모델로 틀었다. 홀든·포드 호주는 끝까지 다국적 본사의 자회사로 남았고, 본사가 철수를 결정하자 2017년 생산이 끝났다. → **비교 조건 해명 / 4막 답 ①의 축**
- 포니 조합: 이탈리아 디자인 + 영국 출신 부사장(BLMC) + 일본 엔진. BLMC는 호주에도 공장(레일랜드 오스트레일리아)이 있었고 1970년대 중반 철수 — 검증되면 강력한 교차점
- 1974 토리노, 1976 첫해 약 1만 대·43%, 수출 1천 → 1만 2천 대(1978)
- 엑셀 미국 첫해 16만 대+ → 품질 문제 → 10년 10만 마일 보증
- **임직원 호주 연수 언급**: 사실이면 "호주에서 배워 간 나라가 호주를 넘어섰다". 확인 못 하면 쓰지 않는다.

**반면교사**: 인물 연대기로 열지 않는다(호주 장면으로), "기쁨도 잠시"류 반복 금지, 현재 사업 홍보 나열 금지, 개인 신화를 답으로 삼지 않는다.
