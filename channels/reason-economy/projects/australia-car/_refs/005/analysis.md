## 3. 훅 & 인트로 분석
- **훅**: 1955년 을지로 공장, 세 형제가 드럼통을 망치로 펴 미군 지프 엔진에 차체를 씌움 — **장면으로 연다**(날짜·장소·행동). 다만 대상을 감춘 뒤 공개하는 장치가 없다.
- **인트로**: "70년 뒤 세계 판매 3위" — Before→After 예고, 유일한 오픈루프. 결말을 먼저 말해 "왜?"가 없다. 해외 대비·역설 질문·뻔한 답 부정 전무.

## 4. 본문 구조 분석
1. 1955 시발자동차 → 2. 1960년대 조립 생산기 — 새나라(닛산), 신진(도요타), 현대(포드 코티나, 1967), 기아 브리사(마쓰다, 1974). "남의 차를 조립하고 있었을 뿐" → 3. 1973 독자 모델 선언, 이탈디자인 + 미쓰비시 엔진, 1974.10 토리노 모터쇼 → 4. 이름 공모 에피소드 → 5. 1975.12 울산 양산, 1976 판매(시장 44% 주장), 227만 원, 택시 → 6. 1976.7 에콰도르 수출, 1982년까지 누적 30만 대 → 7. 1986 엑셀 미국 첫해 168,882대, 4,995달러 → 품질 문제 → 8. 마이카 시대(등록 50만 → 100만 → 200만) → 9. 쏘나타 1~6세대 → 10. 2025 현대차그룹 727만 대 세계 3위, 수출 720억 달러 → 11. 가족 몽타주 + 구독 요청
- **순수 연대기 나열**. "왜 성공했나" 구간이 없다.

**전달 기법**
- 유일한 서사 구간: 전문가들이 비웃는데 이탈리아로 날아간 경영자의 결단 장면.
- 체감 환산: 포니 227만 원 vs 변두리 집 한 채 300만 원.
- 데이터: 해석 없이 숫자만 이어지는 구간이 많다.
- **사실 오류·불일치**: 포니 1976 판매 수치 불일치(1,726대 / 726대, 44% 계산과도 불일치), 영화 「택시운전사」의 차를 포니라고 함(댓글이 "브리사"로 정정, 채널 인정), 외환위기 서술 뭉개짐.

**리텐션**: 결말 공개형 루프(약함), "남의 차를 조립하고 있었을 뿐 → 한 사람이 결심" 반전(가장 강함), 엑셀 품질·1세대 쏘나타 실패 반전, 진행 멘트형 전환("이제 숫자로 돌아보겠습니다" — 우리 금지 대상).

## 5. 감정 트리거
- 향수(택시·마이카·가족), 자부심(화자가 직접 자랑 — 자부심 규칙 1번 위반형), 언더독 통쾌함.
- 흐름: 궁핍 → 굴욕(조립만) → 결단(포니) → 좌절(엑셀) → 회복 → 자부심 → 향수. **긴장의 주어가 전부 한국 자신**이라 긴장↔안도 왕복이 얕다.
