# 레퍼런스 분석 — 001 탁경제 「"100톤짜리를 달아놓고 일부러 천천히 돌립니다" 울산 프로펠러가 비싸지는 진짜 이유」

> 조회 134,320 / 구독 2,120 = **약 63배** · 20:31 · 좋아요 465(0.35%) · 댓글 28 · **2026-09-28 업로드(이틀 만)**
> 자막은 한국어 자동자막(오탈자 — 뜻을 살려 읽음)

## 1. 주제 요약
울산(HD현대) 공장의 100톤 프로펠러가 비싼 이유는 무게가 아니라, 배가 25년 동안 덜 태우는 기름 「몇 퍼센트」에 있다 — 크게·천천히 돌리는 설계, 정밀 가공, 축 뒤 소용돌이를 잡는 작은 핀.

## 2. 썸네일 & 제목
| # | 텍스트 | 크기/색상/위치 | 확신도 |
|---|---|---|---|
| 1 | `100톤짜릴 달았는데` | 최대, 흰색, 하단 1행 | 확실 |
| 2 | `더 천천히 돌린다` | 최대, 빨강, 하단 2행 | 확실 |
| 3 | `25년치 기름값` | 소형, 연두, 좌상단 | 확실 |

- 구도: **황금색 초대형 프로펠러 한 개가 화면 80%**, 허브 구멍 속으로 배가 보이는 액자 구도, 왼쪽 아래 작은 작업자(크기 대비). 3분할·국기·인물 없음
- 감정: 경이(크기) + 역설(「달았는데 천천히」)
- 제목: 따옴표 속 **상황 요약 구어**(특정인 발언 아님) + 「진짜 이유」 — 우리 제목 규칙 ①④⑥과 같은 형식
- 썸네일과 제목이 **같은 역설**(무겁다 ↔ 천천히)을 반복 — 약속이 하나로 선명

## 3. 훅 (0:00~약 1:10)
- 첫 문장부터 역설: 「100톤짜리… 아파트 4층 높이. 그런데 선주가 원하는 건 더 빨리가 아니라 더 천천히」 → 「왜 그럴까요?」
- 숫자 즉시: 「하루 기름값 1억 원, 빨리 달리면 2억」
- **오픈루프 3개(숨긴 대상이 다름)**
  | 루프 | 숨긴 것 | 해소 |
  |---|---|---|
  | ① 선주는 무게가 아니라 날개가 얼마나 정확히 깎였는지 본다 | 이유 | 약 55% (선주 장부) |
  | ② 공장이 먼저 손댄 건 사람도 기계도 아니라 **바닥** | 방법 | 약 20% (후란 주형 — 지하 → 지상) |
  | ③ 「2.5%가 왜 돈이 됐을까」 | 숫자의 의미 | 약 75% (×365×25 = 258억) |
- 「이 숫자를 기억해 두세요」(6.5%) → 나중에 2.5%와 비교시키는 **숫자 앵커**
- ⚠️ 약 30% 지점 구독 요청(우리 금지)

## 4. 본문 구조
1985 빌린 기술(고베) 첫 프로펠러 → 주문 폭주·시간 병목 → 시멘트 거푸집의 문제 → **후란 주형(옆 엔진 공장에서 가져옴)** 2주→1주 → 106톤 세계 최대(회사 발표) → **무대 전환: 공장 → 바다** → 크게·천천히의 물리(자동차 기어 비유, MAN 자료 127→100rpm = 6.5%) → 크기의 한계(11m·114톤) → **선주의 장부**(배값 1회 vs 기름값 매일, 운항비 절반 이상, 30년 수명) → 연비 성적표(CII A~E, EU 배출권) → 손실 내역(70%만 추진) → 축 뒤 소용돌이 핀(2014 실선 계측, 최대 2.5%) → ×25년 = 258억 → **자기반박**(일본 PBCF 40년·4천 척, 독립 지침 2~5%, 회사 계산 전제 재계산 → 연 40만 달러) → 「세계 최대」라는 말을 쓰지 않는 이유 → 울산의 진짜 강점(조선·엔진·프로펠러 한 회사) → 수미상관(회사 영상 「황금빛 스크루」) → 다음 편 예고(엔진)

- 패턴: 역설 → 과거(빌린 기술) → 공정 혁신 → **관점 전환(무게 → 몇 퍼센트)** → 돈 계산 → 자기반박 → 회귀
- 기법
  - **채널 자체 계산을 명시**: 「탁경제 계산」「탁경제가 한 번 더 계산했습니다」 — 회사 발표와 자기 계산을 구분
  - **회사 주장 표시**: 「세계 최초라고 발표… 회사 주장으로만 둘게요」「그래서 이 영상은 세계 최대라는 말을 쓰지 않습니다」 → 신뢰
  - 일상 비유: 3단 vs 5단 기어, 목욕탕 배수구 소용돌이
  - 곱셈 연출: 「1%는 100만 원… 1년이면, 25년이면 한번 곱해 보세요」 — 시청자가 직접 계산하게

## 5. 감정 트리거
경이(크기) → 궁금증(역설) → 뿌듯함(빌린 기술 → 세계 1/3) → 「아하」(무게가 아니라 몇 %) → 신뢰(자기반박) → 잔잔한 자부심(「1985년엔 몇 퍼센트를 배웠고, 지금은 그 몇 퍼센트를 판다」)

## 7. 왜 터졌나 (63배, 이틀)
1. **시의성**: 2026-09 HD현대가 올린 「아파트 4층 높이 황금빛 스크루」 영상이 퍼진 직후 — 사람들이 이미 본 장면에 「진짜 이유」를 붙였다
2. **썸네일 한 장면의 힘**: 황금 프로펠러 하나 + 역설 두 줄. 설명 없이 3초에 궁금증
3. **한국 성공담인데 자랑이 아니라 계산**: 회사 주장과 자기 계산을 구분하고 경쟁 장치(일본 PBCF)까지 먼저 꺼내 신뢰를 산다
4. **돈의 단위 전환**: 「14억짜리 쇠덩이 vs 25년 258억 기름값」 — 작은 %를 큰 돈으로 바꾸는 곱셈이 반복

## 우리 편에 주는 것
- **「무게가 아니라 몇 퍼센트」식 관점 전환** — C 유형(매일 쓰는/보는 한국 산업)에서 「크기·물량」 대신 「평생 비용」으로 재는 앵글
- **회사 발표 vs 채널 계산 구분 문장** — 우리 「비교 조건 해명 문단」과 같은 역할. 표현 차용 없이 원칙만
- **숫자 앵커 후 비교**(6.5% → 2.5%) — 훅 루프 설계에 참고
- 썸네일: 단일 거대 사물 + 역설 2줄도 통한다(3분할이 아니어도). 우리 규칙은 3분할 기본 — **C 유형 단일 사물 예외**를 검토할 근거
