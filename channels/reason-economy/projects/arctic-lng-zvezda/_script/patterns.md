## 1. 반복되는 훅 공식

**관찰**
- 001은 숫자 대신 **멈춘 배 한 척**(2023-11 호주 부두, 발전기 네 대 정지)으로 열고, 마지막 문장에서 「중국 조선소에서 만든 배」로 정체를 밝힌다 → 「주문 10척 중 7척은 중국인데 웃는 건 한국」 역설 → 「그 배의 여정부터」 답 보류. 훅 장면이 본론 첫 장면이 된다
- 경쟁작은 전부 「러시아가 한국 없이 해보다 무너졌다」(코리아온 가상 차관 전화) 또는 「뒤로 가는 300m 배」(자성산업) 장면으로 연다 — **러시아 쪽 인도식(사람·날짜·장소가 있는 실제 장면)으로 연 편은 없다**
- 자사 007 북극항로(30초 71%·1분 51%)는 「쇄빙선도 아닌 배가 북극을 통과」 역설 → 답 보류 → **현재 시점의 본 주제 장면**으로 진입

**설계 원칙**
1. 첫 문장은 **2025년 12월 즈베즈다 조선소 인도식 장면** — 러시아 대통령이 직접 나와 「첫 자국산」 쇄빙 LNG선을 넘겨받는다(사람·장소·행동, 날짜는 연·월 하나). 대상(배의 출생지)은 감춘다
2. ② 정체 공개 = 「그 배의 설계도와 첫 선체 블록은 경남 거제에서 왔다」 — 썸네일 주인공(배)과 같은 문장 안에서 한국을 꺼낸다(첫 20초 주인공 유지)
3. ③ 역설 = 원자력 쇄빙선을 굴리는 나라가 왜 얼음 깨는 가스선만은 남의 설계에 기댔나. 「뻔한 답」(제재 때문)을 꺼내 놓고 「제재 전부터 거제였다」로 질문을 옮긴다
4. 1조 원대 청구(2026-09)는 **썸네일에 없는 두 번째 수수께끼**로 인트로 끝에 남긴다 — 답은 4막

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 001 뼈대: 사건 장면 → 통념 반쪽 인정(「반은 맞고 반은 틀렸다」) → 원인 구조 3개 → 같은 충격·다른 선택 → 한국 증거 장면(야말 15척) → 불리한 숫자 뒤집기 → 리스크 → 수미상관 → 사람
- 단락마다 **사람 한 명 + 날짜 + 장소**로 연다(토탈 CEO, 카타르 장관, 견습생)
- 숫자는 대비 쌍(76% vs 15%, 52 vs 37)으로, 결과가 뒤집히는 순간에만 쓴다
- 점층 예고(「더 아픈 건 그다음」)와 가짜 결말(「여기서 끝나면 저녁 뉴스」)로 중반 이탈을 막는다. 같은 전환구를 두 번 쓴 것은 약점
- 경쟁작(자성산업)은 야말 기술 설명(뒤로 가는 배·아지포드·2.1m)에 분량을 크게 썼다 — 이미 소비된 재료

**설계 원칙**
1. 뼈대(각도 확정 수정본): **훅(인도식) → 1막 한국에 맡긴 15척(야말, 2014~2019) → 2막 「다음 15척은 우리 땅에서」(2019 삼성 설계 계약·거제 블록 → 즈베즈다 조립, 2022 제재로 5척분에서 멈춤) → 3막 계획 15척 vs 실제 2척, 2024 공장 두 번 정지 → 반전/균형 「반은 맞고 반은 틀렸다」(중국으로 수출 재개 + 한국도 손해) → 결말 이번 겨울 시험대**
2. 1막 기술 설명은 Arc7 한두 가지(2.1m·뒤로 깨기)만 — 무게는 **「제때 15척을 다 받았다」는 결과와 일정**에
3. 「반은 맞고 반은 틀렸다」는 **한 번만**, 3막 끝 「그럼 러시아 가스는 끝났나」에 쓴다
4. 대비 숫자는 쌍으로: 15척 vs 2척, 2019년 마지막 배 출항 vs 2025년 첫 배 인도
5. 전환구는 파트마다 다르게 — 같은 예고문을 두 파트에서 쓰지 않는다

## 3. 감정 증폭 전략

**관찰**
- MTN 21.8만 댓글: 조롱·통쾌(27·5·4)보다 **반박(16·15·7 — 「제재 때문」「제목 수준」「러시아 위기가 아니라 우리 조선사 손해」)이 합계로 더 크다.** 미답 질문 「쇄빙선 강국 러시아가 기술을 잃은 거냐 생산력을 잃은 거냐」
- 001 댓글 상위도 반박(「지금 중국 70%」) — 몰락 프레임 제목이 사실 반발을 불렀다
- 007 댓글은 개척·응원(67·50·39) — 같은 시청자 풀은 「한국이 해냈다」에 반응하지만, 국가 응원형은 댓글률이 낮았다(0.047%)
- 조롱 프레임 경쟁작(「푸틴 아비규환」「올스톱」)은 전부 부진(40~2천)

**설계 원칙**
1. 목표 감정: **의아함 → 납득 → 은근한 자부심**. 통쾌는 사실(15척 vs 2척)이 스스로 만들게 두고, 화자는 조롱하지 않는다
2. 반박 댓글의 두 축(「제재 때문」「우리도 손해」)을 **본문이 먼저 처리**한다 — 2막(제재 전부터 거제 설계였다)과 반전부(삼성 4.85조 해지·한화 청구)
3. 미답 질문(기술이냐 생산력이냐)을 클로징 「의견」 질문 축으로 쓴다 → 편이 갈리는 질문이라 007의 낮은 댓글률을 보완
4. 감정 흐름: 의아함(인도식·거제 설계) 20% → 자부심(야말 15척) 25% → 긴장(제재·멈춤·2척) 25% → 균형(반쪽 반전·한국 손해) 20% → 납득(이번 겨울) 10%
