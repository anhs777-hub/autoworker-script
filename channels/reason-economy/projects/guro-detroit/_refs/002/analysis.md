## 1. 주제 요약
코피아 몽골 센터가 10년간 양파 기계화·밀 종자·발효 사료를 거쳐 2025년 9월 몽골 40여 년 만의 첫 벼 재배에 성공했고, 이 협력이 한국 농기계·농자재 수출길로 이어지고 있다.

## 3. 훅 & 인트로
- 훅: 「몽골 쌀 100% 수입, 2024년 4만 9,536톤·460억 원」 — 숫자로 연 훅(우리 기준 장면 아님)이나 극단값 하나로 전제를 세움
- 훅 2단 장면: 2025년 9월, 1,800km 떨어진 논, 관계자가 이삭을 만지고 사진 찍고 다시 만지는 **사람 한 명의 행동** → 곧바로 「일본·중국·베트남도 시도했지만 물러났던 자리」 해외 대비(3문장 안)
- 인트로: 「진짜 주인공은 벼가 아니다 — 양파밭의 한국 농기계 한 대」로 **결과를 한 번 내려놓고 썸네일 주인공으로 질문을 옮김**, 「왜 양파가 먼저, 왜 하필 기계」 두 개의 왜를 걸고 보류. 끝의 「여기서부터 이야기를 풀어 보겠습니다」는 우리가 폐지한 진행 멘트 계열

## 4. 본문 구조
몽골의 조건(축산 86%·여름 3개월·영하 40도) → 손 모내기 고통 → 「크고 비싼 기계가 정답은 아니다」(미·유럽 장비 한계) → 코피아(2014, 10명) → 양파 기계화(뻔한 답 「기계 팔아먹은 얘기?」 부정) → 밀 2%→24% → 축산 조사료 16.7%→81.7% → 「원조가 아니었다」 관점 수정 → 2023 벼 요청 → 센터장 한 사람의 분투(1,600m·육묘 40일·1,800km) → 2025-09 수확 → 「돈의 길」(2026-07 MOU에 이식기 수출 품목) → 과장 경계(시험 논 한 번) → 수미상관
- 배치: **결과 장면 → 진짜 출발점 → 숫자가 커지는 사례 사다리(앞 사업의 신뢰가 다음 사업을 부름) → 돈의 길 → 과장 경계 → 수미상관**. 나열이 아니라 인과 연대기로 들림
- 숫자는 전부 「전→후」 쌍(2%→24%, 16.7%→81.7%)
- 리텐션: 주인공 교체 오픈루프 / 이중 질문 / 통념 뒤집기 / 뻔한 답 부정 / 강도 상승(「더 극적인 숫자」) / 관점 수정 / 패턴 인터럽트(「비현실적인 건 거리」) / 마지막 오픈루프(「진짜 핵심 — 돈의 길」) / 신뢰 장치(「과장은 경계」). 「사실 따로 있다」 계열 4회 반복은 말버릇(우리 규칙 위반)
- 가져오지 말 것: 전언체 다수, 「물고기 잡는 법」 상투 비유, 반복 전환구, 진행 멘트, 숫자로 여는 첫 문장

## 5. 감정 트리거
뿌듯함(남이 실패한 자리를 한국이 해냄 — 화자가 아니라 남의 실패·몽골 정부 반응으로 도달) / 호기심(질문이 계속 교체됨) / 따뜻함. 흐름: 결핍 → 경이 → 연민 → 뿌듯함 → 현실적 기대 → 절제 → 여운

- 구로 편 적용: 썸네일 한 줄이 결과 판정을 갖되 사실 보호 안에서 / 결과 장면 → 「진짜 이유는 따로」 전환 / 사례 사다리(공장 이전 → 아파트형 공장 → IT 벤처 → 디지털단지)를 인과로 / 전→후 숫자 쌍 / 과장 경계 한 단락이 신뢰를 지킴 / 「디트로이트는 왜 못 했나」를 한 막 깊게

## 7. 핵심 약속 역추적
- 약속: 한국 농기계가 몽골 땅을 바꾼 과정과 세계가 못 한 이유
- 이행: 부분 이행(「통째로·무릎 꿇은·대풍년」은 본문에 없음, 본문이 스스로 「중간 지표」라 낮춤). 대신 밀·축산·벼·수출까지 **오버딜리버리**로 반발 댓글 없음
