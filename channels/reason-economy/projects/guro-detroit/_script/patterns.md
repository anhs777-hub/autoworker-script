## 1. 반복되는 훅 공식

**관찰**
- 002(최고 배수): 극단값 하나(「쌀 100% 수입」)로 전제 → 날짜·장소·**사람 한 명의 행동** 장면 → 3문장 안에 「남들은 물러났던 자리」 해외 대비 → 「진짜 주인공은 따로」로 결과를 한 번 내려놓고 썸네일 주인공으로 질문 이동
- 003: 「다들 ~하시죠? 근데 정반대입니다」 — **시청자가 이미 가진 통념을 먼저 꺼내고 뒤집음**(4문장). 이어 장면 하나 + 판돈 상향 → 「○○ 앞부터 가보겠습니다」로 본론 첫 장면 지시
- 001: 사물 두 개 병치(색동 비행기 + 파란 장갑) → 「같은 집안 두 형제의 손에서 갈라졌다」. 첫 두 문장이 썸네일 두 사물과 맞물림. 다만 결말 숫자를 훅에서 다 공개(우리 규칙과 반대)
- 공통: **같은 출발 → 갈린 결과를 첫 30초 안에 세우고, 「어떻게 갈렸나」는 미결로 남긴다.** 세 편 모두 첫 장면이 썸네일 그림과 같다

**설계 원칙**
- 첫 장면은 1차 자료로 확인된 **날짜 + 장소 + 행동**(패커드 공장 2022년 9월 철거 — 「철거 장비 집게가 벽돌을 뜯어낸다」). 썸네일 왼쪽 그림과 같은 장면
- **3문장 안에 구로 출근 인파**를 세워 001의 「사물 두 개 병치」를 두 땅의 병치로 쓴다 — 썸네일 3분할의 좌우와 첫 30초가 맞물리게
- 뻔한 답은 003식으로 **먼저 꺼내고**(「흔히 서울이라서라고들 하죠」) 사실 한 문장(「같은 서울에서 20년 가까이 사람이 빠져나가던 곳」)으로 질문을 옮긴다 — 반례로 통념을 「틀렸다」 하지 않는다
- 결말 숫자(18만·1만 8천 개)는 20초 안에 다 꺼내지 않는다. 「무엇이 바뀌었나」를 미결로

## 2. 반복되는 본론 구조 & 전달 기법

**관찰 — 구조**
- 002: 결과 장면 → 진짜 출발점 → **사례 사다리**(앞 단계의 신뢰가 다음 단계를 부름) → 돈의 길 → 과장 경계 → 수미상관
- 001: 공통 기원 → **갈림길(결정 하나)** → 한쪽 추락 → 성적표 대비 → 수미상관
- 003: 통념 반전 → 현장 → 통계 → 이유를 **시간축(과거 → 현재 → 미래)**으로 → (행동지침) → 수미상관
- 003 구로 대목(약 1분 30초): 사람 한 명 장면 → 벌집 이름 유래 → 「그곳이 구로공단」 → 숫자 셋 → 쇠퇴 원인 → 「공장이 떠나자 무엇이 남았나」 — 그리고 **G밸리 전환은 전혀 없음**

**관찰 — 전달 기법**
- 숫자는 전→후 쌍(002 2% → 24%, 001 26조 → 3.4조). 단독 숫자는 드묾
- 어려운 개념 하나를 생활로 푼 장치가 가장 잘 먹힘(001 풋백옵션 = 아파트 손실 보전 약속) — 단 우리는 새 비유 창작 금지, 생활 단위 환산 1~2개까지
- 사람 한 명(002 센터장, 003 증언 인물)으로 중반을 끈다

**관찰 — 리텐션**
- 단계 상승형 오픈루프(001 「끝난 줄 알았는데 더 있다」, 002 「더 극적인 숫자」, 003 「더한 게 있어요」) — 세 편 공통. 단 세 편 모두 같은 전환구를 반복해 말버릇이 됨
- 003 「셋째를 미리 찍어 두기」, 「아까 통계 기억나시죠」 앞 숫자 회수

**설계 원칙**
- 뼈대 = 001의 **갈림길 구조** + 002의 **사례 사다리**: 1막 디트로이트(파산 → 왜) / 2막 빈 땅이 버려진 땅이 되는 구조 / 3막 구로도 똑같이 무너짐(바닥 1997) / 4막 **갈림길 = 1997년 7월 규칙 변경**, 그 뒤 고시 → 시행령 → 1999 시행령 → 감면 → 임대료가 **앞 단계가 다음 단계를 부르는 사다리**로
- 숫자는 같은 단위 전→후 쌍으로만(구로 고용 11만 4천 → 3만 2천 → 지금 / 디트로이트 인구 185만 → 64만). 구로·디트로이트 숫자를 한 문장 배수로 묶지 않는다
- 오픈루프는 파트마다 **문장을 새로** 쓴다. 「진짜 ○○은 따로」 계열은 영상 전체 1회
- 003이 비워 둔 「공장이 떠난 구로의 그 뒤」가 이 편의 본론 — 3막 전환 질문으로 「공장이 떠난 자리에 무엇이 남았나」를 우리 문장으로 다시 세운다

## 3. 감정 증폭 전략

**관찰**
- 댓글 1위 감정: 002 형제국·자부심(판정 문구가 댓글로 반복) / 003 패키징 반감(213 — 동포 축, 이 편에서 버림) / 001 개인 욕심 분노(47)
- 감정을 만든 장치: 002 「남들은 물러났던 자리」(남의 실패로 자부심 도달), 003 「우리 누이·언니들의 청춘」(가족 호칭 향수), 001 「쫓겨난 쪽이 이겼다」(역전)
- 흐름 공통: 호기심 → 긴장/연민 → (역전) 통쾌·뿌듯 → 절제(과장 경계) → 여운

**설계 원칙**
- 이 편엔 악역이 없다 — 분노(001)·불안(003) 엔진은 쓰지 않는다. **궁금증(같은 위기, 왜 갈렸나) → 긴장(디트로이트 빈 땅) → 향수·연민(벌집, 구로도 무너짐) → 안도·뿌듯(다시 찬 땅) → 절제(공실·디트로이트 반등)**
- 자부심은 화자가 주장하지 않는다 — 디트로이트 시가 직접 쓴 「빈 땅은 곧 버려진 땅」(DFC)과 논문의 판정으로 도달
- 향수는 3막 전환부 되묻기 1회(「1970년대 구로공단 벌집, 기억나시나요?」) + 감상 한 문장까지
