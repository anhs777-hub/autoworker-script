## 1. 반복되는 훅 공식

**관찰**
- 001은 숫자 없이 장면 5연타 → 시청자 소유물 소환(버킷리스트) → 「그 뒤에서 주저앉는다」 반전 → 3개국 증거 1문장씩(썸네일과 1:1)
- 인트로 끝에 역설(「하던 대로 한 게 문제였다」) + 정체를 숨긴 미끼(「조건이 하나 붙어 있었다」) → 1막 끝까지 견인
- 물결 제목(빨대 경제의 종말·우리가 알던 유럽·한국에 주는 경고)이 같은 감정 공식: 「동경하던 선진국이 흔들린다」 + 「한국도 남 일 아니다」

**설계 원칙**
1. 첫 15초는 썸네일 주인공(한국의 흑자 기록) 장면 + 같은 문장 안에서 독일·일본 대비. 숫자는 「독일과 일본을 합친 것보다」 대비 하나로 충분하고 정밀 수치는 뒤로
2. 「이 기록을 먼저 세웠던 나라」로 독일을 **이름을 숨긴 채** 세운 뒤 정체 공개(훅 ② 「바로 ○○입니다」 자리)
3. 인트로 끝 역설은 독일 쪽에만 — 「공장을 멈춘 것도 손을 놓은 것도 아니었다」류. 정체를 숨긴 미끼(독일 흑자의 두 축)를 1막 끝까지 보류
4. 제목·썸네일이 약속한 「독일도 그랬다」의 결말(지금 어떻게 됐나)은 훅에서 다 확인해 주지 않는다

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**
- 구조: 돈줄의 정체(과거) → 돈줄이 끊기는 현재 장면 → 스스로 끊은 실험 → 자가진단 → 반전(끝난 건 한 시절)
- 한 단어 프레임(빨대)을 1막에 세우고 2막에서 「두 개」로 쪼갠 뒤 3막에서 회수 — 나열형을 피하는 등뼈
- 독일 파트: 장부의 이상한 한 줄(콜드오픈) → 두 축 요약 → 축 1 가스(단계적 감소) → 축 2 손님(손님이 경쟁자로) → 감각 장면 → 한국 접점 한 줄
- 숫자 쌍 역전(한때 더 컸다 → 지금은)과 단계적 감소(40→20→0)로 숫자를 리듬으로 들려줌

**설계 원칙**
1. 뼈대: **한국 기록(현재) → 거울 독일의 흑자는 무엇으로 벌었나(두 축) → 두 축이 어떻게 흔들렸나 → 흑자가 클 때 따라온 압박 → 한국 장부 펼치기 → 같고 다른 점 → 반전 엔딩**
2. 프레임 단어는 하나(사용자 지정 「빨대」) — 1막에서 중립 정의로 세우고 클로징에서 한 번 회수. 비하 뉘앙스(기생)로 쓰지 않는다
3. 독일 감소는 「단계 숫자 하나 + 결과」로 — 연도별 수치를 표처럼 읽지 않는다
4. 「지도 말고 장부」는 영상당 1회, 1막→2막 전환점(한국 순위 → 구성)
5. 창작 비유(수도꼭지·옆 골목 가게) 금지 — 사실 그대로
6. 리텐션: 파트 전환마다 열린 고리 1개, 3~4분마다 썸네일 주제(한국 흑자·반도체) 재점화

## 3. 감정 증폭 전략

**관찰**
- 최다 반응: 1막 프레임을 시청자가 한 줄로 재요약(779 + 동조 댓글). 그다음 「한국도 남 일 아니다」(391·60·26)
- 레퍼는 한국을 두 번 스칠 뿐 → 「그럼 한국은?」이 비어 있는 채로 댓글에서 증폭

**설계 원칙**
1. 목표 감정: **「납득 + 긴장 → 안도」** — 응징(비하) 대신 「아, 흑자가 이렇게 벌렸구나」 한 줄 요약이 되는 납득
2. 긴장의 주어는 독일(가스 차단·중국 수출 감소·EU·IMF 압박). 한국 쪽 공포 문장 금지 — 한국은 「장부 펼치기」(사실)로만
3. 한 줄 요약 가능한 문장을 1막 끝에 하나 — 「값싼 러시아 가스로 만들고 중국에 팔았다」
4. 흐름: 놀람(기록) → 호기심(먼저 세운 나라) → 납득(두 축) → 긴장(축이 흔들림) → 의외(흑자가 크면 압박) → 긴장(한국 장부) → 안도·재해석(같은 듯 다른 점, 방향을 트는 소리)
