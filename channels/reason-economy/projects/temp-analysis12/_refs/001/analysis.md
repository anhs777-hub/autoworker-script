## 3. 본문 구조 — 「용의자 → 이상한 점 → 진짜 원인 3겹 → 실험 → 청구서」
1. **용의자 1 쿠팡이츠**: 단건배달 → 2024-03 와우 무료배달 → 「금요일 밤 두 앱을 나란히 — 몇 초의 망설임」(시청자 경험 소환) → MAU 883만 → 1,242만(+40%) vs 배민 정체 → 서울 역전 → 배민클럽 반년 늦은 반격 「원조의 무게」
2. **용의자 2 배민의 욕심**: 9.8%(실질 44% 인상, 상생협의체 발표 직후) → 포장 6.8% → 울트라콜 폐지 → 점주 만족도 꼴찌
3. **「이상한 점 3가지」** — 매출 +22%(손님이 떠났다면?), MAU 여전히 2배, **쿠팡이츠도 9.8%·무료배달인데 왜 배민만?** → 「같은 행동에 한쪽만 벌받으면 이유는 행동이 아니라 다른 데」
4. **진짜 원인 3겹**
   - ① 다리의 주인: 2019 독일 딜리버리히어로 4.75조(연 이익의 79년치) → 요기요 매각 조건 → 매출 3배·이익률 20.5%(쿠팡 전체보다 이익 많음) → **배당·자사주 소각으로 3년 1.44조(영업이익의 74%)가 독일로**, 치킨 7,200만 마리 환산, 「10조각 튀기면 7조각이 해외로」 → 9월 국세청 조사(「혐의 단계, 회사는 입장 없음」 명시)
   - ② 1위만 할 수 있는 것: 최혜대우 요구 → 공정위, 동의의결 3,600억 기각 → 차등수수료 2~7.8%인데 실제 평균 8.2%, 2%를 낸 곳은 0 → 「쫓는 자의 욕심은 경쟁, 1위의 욕심은 갑질로 보인다」
   - ③ 1위 유지 비용: 라이더 외주비 3.15조(+41%)인데 건당 기본료 3,000→2,500원 — 「돈은 더 쓰는데 라이더는 덜 받는다」
