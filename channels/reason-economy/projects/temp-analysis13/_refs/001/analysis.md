## 3. 본문 구조

- 패턴: 부당한 결과 → 배경(발주처 사정) → 멈춤과 방치 → 서명 → 배신 → 반소 → 반박 → 버팀 → 승소 → 현재 → 과거(리비아) 대비 → 남은 과제

## 6. 왜 터졌나 (254배)

2. **숫자 낙차 하나**: 820억 vs 8,107억(10배) — 썸네일·제목·훅이 같은 숫자

4. **예상 밖 생활 연결**: 요소수 파란 통 → 「한국 요소 생산 0」

## 우리 편에 주는 것
- **「억울함 → 버팀 → 역전」 감정선** — A 유형(「못 한다더니」)의 변형: 「당했다더니」
- **「사물 하나를 주인공으로」**(서류 두 장) — 훅에서 걸고 결정적 장면에서 회수
- **과거 자기 자신과 비교**(40년 전 리비아 vs 지금) — 외국을 깎지 않고 성장을 보여 주는 대비
