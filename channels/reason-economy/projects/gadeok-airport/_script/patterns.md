## 1. 반복되는 훅 공식

**관찰**
| 영상 | 첫 장면 | 이어지는 장치 |
|---|---|---|
| 008 (128배) | 갯벌에 박힌 장화 한 짝 → 이런 뻘 위에 활주로 | 「어느 나라? … 아니에요, 부산 가덕도」 반전 → 현대 철수(이유는 시간) → 간사이 침하 대비 → 「누가 다시 손을 들었을까」 |
| 007 (54배) | 2025년 5월, 1위급 건설사가 10조 국책사업에서 손을 뗐다 | 뻔한 답 치우기(돈도, 회사 사정도 아니다) → 「이유는 시간」 → 간사이 13.7m → 「가덕도는 더 나쁜 조건」 → 「그런데도 메우기로, 설계는 심의 통과」 → 「누가 어떻게 들어가나」 |
| 005 (당일) | 가덕도 갯벌 장화가 빠지는 감각 → 물 30m + 뻘 40m | 간사이 13m + 현대 손 뗌 → 「그런데도 왜 포기 안 하나」 |
| 004 (91.7만) | 유일하게 손든 회사마저 「못 하겠다」 | 현장 취재 예고, 「단군 이래 최대」 규모 각인 |

- 고배율 3편 모두 **「안 되는 증거 두 개(간사이 침하 + 현대 철수) → 그런데도 누가/왜」** 역설 구조. 훅의 감정 엔진은 「현대도 물러선」이다
- 007은 현대 철수를 첫 문장에, 008·005는 가덕도 뻘 장면을 첫 문장에 둔다. 둘 다 **첫 장면이 가덕도(또는 그 공사)** — 썸네일 주인공에서 출발
- 「이유는 시간」이 007·008 공통의 반전 답(돈이 아니라 시간) — 단 둘 다 「시간」을 훅에서 공개한다
- 약점: 005·008은 20초 안에 썸네일 숫자(70m·13m)와 간사이 대비를 전부 확인시키고, 007·008은 인트로 끝에서 「24년 전 김해 사고」로 연대기 진입

**설계 원칙**
1. 첫 문장은 **가덕도 바다(현장) 장면** — 숫자 없이. 3문장 안에 간사이를 **가덕도와 같은 문장 안에서** 세운다(첫 20초 주인공 유지)
2. 「현대도 물러선」을 훅 ③ 역설의 전반부로, 「그런데 다른 팀이 손을 들었다(설계 적격)」를 후반부로 — 역설 질문은 「왜 다시 손을 든 팀이 있을까요?」
3. **「이유는 시간」은 훅에서 다 말하지 않는다** — 경쟁작이 다 공개한 답이다. 훅은 「돈 문제가 아니었다」까지만(뻔한 답 부정), 「84 → 106」은 1막 본론 첫 장면에서 처음 숫자로 연다
4. 간사이 결말 숫자(13m대)는 훅에서 반쪽만 — 「가라앉았다」는 세우되 정밀 수치는 1막으로
5. 답 보류 뒤 첫 장면은 **현재**(2025-11-21 조건 변경 또는 2026-09 심의장) — 2002 김해 사고로 열지 않는다

## 2. 반복되는 본론 구조 & 전달 기법

**관찰 — 구조**

- 공통 뼈대: **간사이(실패) vs 인천(성공) → 가덕도는 어느 쪽인가 → 바닥/배치 차이 → 그 대가(경계 부등침하)**
- 007의 핵심 수: 현대 철수 전말을 **2/3 지점까지 숨기고** 그 사이 「왜 시간이 중요한가」(뻘·간사이·부등침하)를 먼저 깐다 → 84 vs 108이 나올 때 시청자는 현대 쪽에 이미 납득

**관찰 — 전달 기법**
- 숫자 생활 환산: 13.7m = 5층 아파트(007)·14m 전봇대(008) / 9,600만㎥ = 소양강댐 10개(007) / B/C 0.36 = 1,000원 들여 360원(005·008) / 14.4조 = 1인당 28만 원(008)

- 「You might ~」 시청자 반론 선점 3회(007): 「김해 산 깎으면 되지?」 「미리 높게 지으면?」 「왜 굳이 이 바다에?」
- 1인칭 지인 증언(008) — 출처 불명, 우리 금지

**관찰 — 리텐션 장치**
- 오픈루프 「누가 다시 손을 들었나」를 2/3 지점까지 끌고 감(007·008)
- 「바다로 간 공항이 다 가라앉는 건 아니다」 — 간사이 → 인천 반전 전환이 가장 강한 전환(005·007·008 공통)
- **해법 직후 「이 배치에는 값이 따른다」로 긴장 재상승**(007·008 공통 — 경계 부등침하)
- 「고르지 않게 꺼진다」 고리를 초반에 심고 후반 회수(005)
- 숫자 재호출(008)

**설계 원칙**
1. 우리 4막: 1막 간사이(바다에 지은 공항의 실제 결과) → 2막 왜 가라앉았나 + 현대가 멈춘 이유(공정하게) → 3막 인천(감사원 적자 전망 → 세계 1위) + 거가대교 → 4막 조건 변경 + 설계 차이 + 대가 + 자기반박
2. 007의 「현대 전말 지연」 대신 우리는 **훅에서 현대 철수를 세우고, 1막 첫 장면에서 「106개월」 숫자로 열린 고리를 연다**(「현대가 요구한 건 108개월, 정부가 결국 준 건 106개월」 — 왜 그렇게 됐나는 2막·4막에서 회수)
3. 반론 선점은 3회(김해 확장 / 간사이처럼 가라앉지 않나 / 계약은 됐나) — 각 막에 하나씩 전속 배정
4. 「값이 따른다」 긴장 재상승은 4막 설계 설명 직후 1회(경계 부등침하 30m당 3cm 기준)
5. 숫자 환산은 영상 전체 1~2개만(간사이 침하 아파트 층수, B/C 0.36 1,000원) — 경쟁작처럼 숫자마다 환산하지 않는다

## 3. 감정 증폭 전략

**관찰 — 댓글 감정 순위**
1. **회의·의심**: 008 최다 「현대가 떠나버렸다며」(19) · 003 최다 「현대건설조차 포기한 걸 누가 맡을 건데?」(11) · 007 「아무리 생각해도 가덕도는 무리」(55)·「무리한 공사같은데」(45) — **현대 철수가 시청자 머릿속 최대 사실**
2. 세금·사업성 분노: 「국민혈세 투입 반대」(32)·B/C·공사비 부족 예상(006)
3. 정치 책임론(004·007 다수) — 우리는 정치 축 금지
4. 대안 입지(김해 확장) 반복 — 003·005·007·008 전부
5. 활주로 1개(007 27, 008 답글)
6. 자부심·응원(008 소수)

**감정을 만든 장치**: 간사이 침하·태풍 장면(불안) → 반대 댓글로 직결(007) / 현대 철수(의심) / 008의 인천 역전(통쾌) — 008만 자부심 쪽 감정이 섰다(배율 최고)

**설계 원칙**
- 목표 감정: **통쾌함은 「현대가 틀렸다」가 아니라 「현대가 요구한 시간을 정부가 받아들였고, 그 조건에서 다른 팀이 설계를 보강해 들어왔다」는 납득**에서 나온다. 현대를 깎으면 「현대가 떠나버렸다며」 시청자가 등을 돌린다 → 2막에 현대 판단의 정당성을 공정하게 세운다(자부심의 신뢰 보증)
- 감정 흐름: 긴장(간사이 침하·태풍, 30%) → 납득(현대가 멈춘 이유 — 「틀리지 않았다」, 20%) → 반전·통쾌(인천: 적자 전망 → 세계 1위, 20%) → 안도·자부심(조건+설계 차이 → 심의 적격) → 정직한 숙제(계약·B/C·시험시공) → 납득 마감
- 공포의 주어는 간사이(남). 가덕도 쪽 불안은 4막 자기반박 블록 한 곳에서 「숫자 바로잡기」로만
