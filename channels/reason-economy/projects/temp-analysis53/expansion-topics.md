## 001 경제상담소 「"바가지 때문인 줄 알았습니다" 수백만 명 찾던 대한민국 대표 축제들이 통째로 사라진 진짜 이유」
- 구독 3만 · 2026-10-18 업로드 · **하루 33.5만(약 11배)** · 25:27 · 좋아요 1,647 · 댓글 164
- 썸네일: 한 장면 좌우 대비 — 왼쪽 북적이는 축제 노점(가격표 「어묵 10,000원·바비큐 50,000원·파전 20,000원」) + 놀란 여성 / 오른쪽 같은 거리 텅 빈 천막·「임대」「폐업」 간판·청소부 / 흰 「"비싼 가격, 텅 빈 축제"」 + 하늘색 「절대 안가는 지역축제 TOP5」, 하단 검은 띠
- 구조: 훅 「축제 하면 바가지 떠오르죠, 저도요 → 그런데 사라진 축제는 바가지 때문이 아니었다」 → 200만→25만, 기간 두 배인데 절반, 3년 연속 못 연 겨울축제 → 감소 폭 5위→1위 카운트다운(울산 고래: 고래 만날 확률 5번에 1번→24번에 1번 / 보령 머드 / 평창 송어: 70만→25만, 얼음 / … / 인제 빙어: 소양호 수위로 3년 취소) → 같은 기간 역대 최대 3곳(화천 산천어 187만: 물길 관리 + 숙박 영수증 내면 야간낚시 무료·체험비 일부 지역상품권 / 춘천 막국수닭갈비: 외부 야시장 배제·가격 고정·시내 식당 할인권 → 방문 2배 / 김천 김밥: 김 안 나는 도시, 2년째 시 인구보다 많이 방문·관광객 약 30%↑) → 축제 수는 늘고 1인당 지출은 줄었다 → 「성패는 축제장 밖(숙소·정직한 식당·특산품)」 → 질문 「얼음 없어도 다른 프로그램으로 열까, 조건 될 때만 열까」
- 터진 이유
  1. **제목이 뻔한 답 부정** — 「"바가지 때문인 줄 알았습니다"」. 모두가 떠올리는 원인(바가지 뉴스)을 제목에서 치움 → 우리 profile 「뻔한 답 부정」을 제목으로 끌어올린 형태
  2. **시즌·공분 타이밍** — 10월 축제철 + 바가지 뉴스가 쌓인 시점에 하루 만에 확산. 댓글 상위가 세금·연예인 출연료 분노(112·103·91)
  3. **썸네일 = 한 장면 대비 + 구체 가격표** — 숫자(어묵 1만 원)가 분노를, 텅 빈 천막이 결말을 그림으로 말함. 「TOP5」로 「내가 간 그 축제?」 궁금증
  4. **순위 카운트다운 + 성공 3곳 대비** — D(국내 vs 국내)를 리스트 문법으로. 지명이 나올 때마다 「나 거기 가 봤는데」 체감
  5. **반전 원인이 기후·물** — 고래가 안 오고, 얼음이 안 얼고, 댐 수위가 올랐다 → 바가지보다 의외
  6. **행동으로 착지** — 「다음 주말 어디 갈지 보는 눈이 달라질 것」 약속, 숙박 영수증·가격 고정 같은 구체 처방
- 우리와 다른 점: 해외 비교 없음(국내 단독), 정치 댓글(세금) 유도 위험

## 002 경제 참견소 「"하버드도 놀랐다" 세계 6대 괴물 산업을 한 나라가 모두 장악한 이유… 대한민국의 비밀」

- 구조: 외계인 시점 훅(클린룸 회로 vs 400m 쇠덩이 용접이 차로 두세 시간 거리) → 6대 산업 나열 → 하버드 그로스랩 ECI 20년 넘게 3~4위 → 1960년대 100달러·텅스텐·생사·무연탄 → **3개의 벽**(기술 확보 / 수율·실행 / 신뢰·실증): 현대중 1971 미포만·애플도어·바클레이스 차관·선주문, 64K D램(수율 10~20%)·4M 공정 5개 병행, 고리 1호기 1978 턴키, 1985~86 D램 적자, 삼성바이오 공기 30% 단축, K9 폴란드 5개월 48문 → 위기(신조선 수주 중국 53%) → 사람(HD현대 기술교육원 월 100만 원·마더팩토리) → 「빌리고 견디고 물려주는 반복」 → 질문 「가족 중 그 현장에 계셨던 분?」
- 터진 이유
  1. **검증된 공식 반복** — 「하버드 ECI·6대 산업」은 경제콜렉터 15.5만·경제담론 2.8만·콕 짚는 경제 3.4만·오늘을 말하다 3.4만 등 이미 여러 번 터진 주제. 소형 채널 복제가 다시 55배
  2. **외국 권위 판정 + 놀란 얼굴** — 「하버드도 놀랐다」는 자화자찬을 외부 입으로 돌린 판정형(우리 「자부심 소재 규칙」과 같은 원리)
  3. **훅 한 장면 대비** — 클린룸과 조선소를 한 문장에 붙여 「어떻게 한 나라가?」를 그림으로
  4. **부모 세대 헌사** — 「맨손으로 땅을 파던 부모 세대」 → 5070 자기 이야기. 좋아요율 1.6%
  5. **위기 한 줄 + 사람으로 결론** — 중국 53%로 긴장, 교육원·마더팩토리로 안도
- 우리와 다른 점: 6대 산업 나열형(우리 금지 「나열형」), 놀란 인물·국기 썸네일(우리는 5번 3분할만)
