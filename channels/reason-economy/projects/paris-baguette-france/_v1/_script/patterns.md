## 1. 훅 설계 원칙
- 첫 20초 주인공 = 파리의 파리바게뜨(썸네일 주인공). 비교 대상(프랑스 빵집 제도)은 같은 문장 안에서만 꺼낸다
- 경쟁작이 전부 「샤틀레 앞 줄 → 그런데 50억 적자」로 열었다 → 같은 장면으로 열지 않는다. 확인된 사건 장면(리서치 결과)으로 연다
- 썸네일 숫자를 20초 안에 다 공개하지 않는다. 「흑자 2·적자 5」의 세부(생산 시설)는 4막까지 보류
- 흔한 답 「회장의 자존심」(디코드 댓글 37 좋아요 — 시청자가 실제로 떠올리는 답)을 대본 안에서 먼저 꺼낸 뒤, 「그것만으로 12년은 설명이 안 된다」를 사실 한 문장으로 받는다

## 2. 본론 구조
- 현재(적자 장부)에서 출발해 과거(1998 사무소 → 2006 법인 → 2012 법인 → 2014 첫 매장)를 「왜 이렇게 오래 준비했나」의 답으로 끼워 넣는다. 과거 한 덩어리 1분 30초 이내
- 비교 축: 「불랑제리」 간판 조건(가게에서 반죽·발효·성형·굽기) ↔ 공장 반죽을 받아 굽는 한국식 → 비용 구조의 차이를 문장으로
- 역전 장면: 2002년 한국에 들여온 리나스 → 2022년 본사를 산다
- 장부: 법인별 흑자 2·적자 5, 손실 절반 이상이 생산 시설

## 3. 리텐션 장치 (자사 실측 장치에서)
- 본문 장치 8번 재점화 3~4분마다: 「흑자 두 곳은 어디인가」 · 「손실의 절반은 매장이 아니다」 · 「회사는 왜 남는다고 했나」
- 본문 장치 9-1 당사자 문서: 프랑스 기업 등기의 법인별 숫자 / 회사 발언(출처 있는 것만)
- 본문 장치 6번 반론 대행 후 반박: 「프랑스 사람들이 한국 빵을 안 사서?」 → 매출 851만 €
- 본문 장치 7번 모르는 것을 모른다고: 회사가 밝히지 않은 이유는 단정하지 않는다
- 생활 단위 환산 1회 이내 (핵심 숫자 하나)
