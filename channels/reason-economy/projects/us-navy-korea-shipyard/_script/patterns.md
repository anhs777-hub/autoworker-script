# 공통 성공 패턴 — us-navy-korea-shipyard

> 레퍼런스 5편 (001~005). 조회수 가중: 001(45.6만) > 002(11.3만) > 003(5.9만) > 004(5.3만) > 005(0.2만, 단 구독 대비 3.2배).
> 구독 대비 배수는 모두 낮다(001 0.52배, 002 0.16배, 003 0.44배, 004 0.05배). **수요는 크지만 이 소재로 크게 터진 영상은 없다** — 소재가 포화됐다는 신호이자, 차별화 없이는 묻힌다는 뜻이다.

## 1. 반복되는 훅 공식

**관찰**

| 편 | 조회 | 훅 방식 | 정체 공개 |
|---|---|---|---|
| 001 | 45.6만 | 한국 뉴스(캐나다 잠수함 60조 탈락)의 억울함 → 「진짜 사건은 그 직후」 | 약 1분 뒤 「바로 미국입니다」 |
| 002 | 11.3만 | 주어를 감추고 위용(「민주주의의 병기고」, 세계 모든 배보다 많이) → 0.1% 낙차 | 두 번째 문장 「바로 미국이었죠」 |
| 003 | 5.9만 | 결론 발언 티저(「한국은 이미 하고 있다」, 미 해군 인사의 입) | 즉시 |
| 004 | 5.3만 | 정치 뉴스 복기(마스가·관세 협상) — 제목의 「핵잠수함 10년 정비」가 첫 문장에 없음 | 없음 |
| 005 | 0.2만 | 일상 물건(옷·커피·스마트폰) → 94% 독점 | 「미국도 독일도 아닙니다」 |

- **장면으로 연 편이 하나도 없다.** 5편 모두 뉴스·숫자·일반론으로 열었다. 우리 채널 성과작(수달·리쥬란·고깃집 가위)은 전부 장면으로 열었다 — 이 소재에서 **장면 훅은 비어 있는 자리**다.
- **정체를 감췄다 공개하는 구조**(002 「바로 미국이었죠」, 001 「바로 미국입니다」)가 상위 2편에서 쓰였다. 우리 훅 ②와 같은 모양이다.
- **004는 제목 미끼(핵잠수함 10년 정비)를 첫 문장에서 버렸다** → 대형 채널인데 0.05배. 우리 소재의 1막 재료(정비 대기)를 레퍼런스가 약속만 하고 채우지 않았다.
- **001의 강점은 「실패 → 반전」 숫자 대비(60조 → 1600조)와 「강대국이 한국에 SOS」라는 권력 역전.** 단, 그 인과(탈락 → 미국의 요청)는 성립하지 않는 시간순 병렬이었다.
- **정치로 연 편(004)은 댓글이 정치로 샜다.** 001도 트럼프 한 번 언급으로 친중·정권 논쟁이 붙었다.

**설계 원칙**
1. **첫 문장은 미국 핵잠수함 한 척의 장면이다.** 이름(보이시), 장소(부두), 행동(정비 조선소를 찾아 예인되며 기다림)을 세우고, 숫자(대기 기간)는 장면 뒤에 붙인다. 레퍼런스 5편 누구도 쓰지 않은 훅이다.
2. **정체 공개(②)는 「바로 미 해군의 핵잠수함 ○○입니다」처럼 15초 안에.** 대상을 감추는 방식은 002와 같게, 공개는 더 빠르게.
3. **③ 반전은 한국을 주어로 하되 범위를 좁혀 연다.** 「그런데 같은 시기 한국 거제의 도크에는 미 해군 보급선이 들어와 있었습니다」처럼 **확인된 사실 하나만**. 「미국이 한국에 매달린다」 류 권력 역전 단정은 쓰지 않는다.
4. **첫 1분 안에 정치 인물·정책명(트럼프, 마스가, 관세)을 꺼내지 않는다.** 정책명은 본문에서 사실·금액으로만.
5. **인트로 숫자 3개 이하** — 대기 기간, 잃은 작전일(GAO), 그리고 반대편 숫자 하나.

## 2. 반복되는 본론 구조 & 전달 기법

**관찰**

*구조*
- 002(가장 완성도 높은 인과): 1936년 상선법 보조금 → 2차대전 전성기 → 종전 후 퇴행 → 공법이 일본으로 → 1981년 보조금 절단 → 방산 의존 → 한국·중국 부상 → 존스법 악순환. **제도를 첫머리에 복선으로 깔고 중반에 회수**하는 시간순 인과.
- 001·004·005: 한국 뉴스 또는 대담 흐름에 미국 몰락을 **중간 설명으로만** 끼운다(001은 약 2분, 장면 없음). 004는 Q&A 나열형, 005는 후반이 나열형.
- 003: 미국 몰락 숫자 → 한국 모델 공개 → 원인(상선-함정 병행, 중국과의 경쟁) → 미국 병목(인력·관료제). 4막 요소가 다 있지만 패널 순서를 따라 후반이 산만.
- **정비(MRO)를 몸통으로 다룬 편은 없다.** 004가 제목에 걸고 채우지 않았고, 005는 한 문장, 001은 「수리조차 못해서 몇 년씩 쩔쩔」 한 문장.

*전달 기법*
- **가장 강한 한 줄 대비**: 「세계 최첨단 전투함을 1950년대 조선소에서 만든다」(003, 미 해군 측 발언). 설명 없이 바로 이해된다.
- **통념 부정**: 「미국은 마음만 먹으면 군함 수백 척 찍어낼 것 같지만 수리조차 못 한다」(001), 「군함은 잘 만들면서 왜 상선은?」(005).
- **일상 비유**: 「이 선박은 우리로 치면 쌀 같은 존재」(004 — 협상에서 양보 못 하는 품목), 모듈 공법 = 자동차 조립라인(002), 「우물 안 개구리」(001, 존스법).
- **현장 목격담**: 필리조선소 실사 때 「1년째 지연 중인데 그게 가장 빠른 편」(004) — 레퍼런스 전체에서 가장 생생한 대목.
- **숫자에 출처가 없다**: 0.1%/0.2%/1% 미만(점유율이 편마다 다름), 230배/232배, 1600조, 94%, 4~5배 — 전부 출처·기준 미상. 레퍼런스끼리도 값이 어긋난다.

*리텐션 장치*
- 거의 모든 파트를 「~걸까요?」 질문으로 넘기는 방식(001)은 반복될수록 약해진다.
- 복선 → 회수(002 「처음에 언급했던 1936년 상선법」)가 가장 효과적이었다.
- 004는 설계된 오픈루프가 없어 21분을 대담 흐름에 맡겼다 → 저성과.

**설계 원칙**
1. **1막 = 보이시 한 척의 7년.** 부두 대기 → 잠수 자격 상실 → 정비 포기·퇴역을 시간순 장면으로. 여기에 GAO 수치(잃은 작전일·비용)를 증거로 붙인다. 레퍼런스가 비운 자리를 정면으로 채운다.
2. **2막 = 002식 깔때기 인과를 압축해서.** 「왜 고칠 곳이 없나」의 뿌리를 제도(존스법·보조금 절단) → 상선 수요 소멸 → 조선소·숙련공 소멸 → 정비 적체로 좁힌다. 원인을 존스법 하나로 몰지 않는다(인과 한 단계 낮추기).
3. **「1950년대 조선소」 발언은 제3자 판정으로 쓴다** — 단 발언자 이름·직함·날짜·행사를 1차 자료로 확인한 뒤.
4. **3막 = 한국이 실제로 맡은 범위만.** 보급선·지원함 MRO 수주(선명·날짜), 한화 필리조선소 인수. 핵잠수함 정비와 잇지 않는다. 이 선을 **대본이 먼저 말하는 것** 자체가 레퍼런스들과의 신뢰 차별화다.
5. **숫자는 1차 출처가 확인된 것만, 레퍼런스끼리 어긋나는 점유율 수치는 한 기준으로 통일.**
6. **복선 → 회수 장치를 한 번 이상 설계한다** (예: 1막의 「고칠 곳이 없었다」를 3막 거제 도크 장면에서 회수).

## 3. 감정 증폭 전략

**관찰**

*댓글 감정 순위 (좋아요 기준)*

| 순위 | 감정 | 대표 반응 | 편 |

| 2 | **해설자 신뢰** | 「타일러는 진짜 천재… 어려운 내용을 알기 쉽게」(183) | 001 |
| 3 | **해군과의 연결 욕구** | 「미국하면 해군인데 조선업이 이러면… 이래서 마스가」(156) | 002 |
| 4 | **부활 불가능 판정** | 「미국의 조선업 부활은 불가능하다」(29) | 003 |
| 5 | **이용당할까 불안** | 「건조하는 시스템을 날로 먹겠다는 거죠」(20), 「노하우 카피하고 버리면」 | 003, 004 |
| 6 | **정치 성토** | 친중·정권·트럼프·방위비 | 001, 003, 004 |
| — | **과장 자기 교정** | 「핵잠수함 지통실은 보안구역인데 한국인 수리직원이 접근불가」 | 004 |

*감정을 만든 장치*
- 1위 반론은 002가 「그 선택이 합리적이었나」를 판단하지 않고 끝나서 생겼다 — 시청자가 빈칸을 채웠다.
- 3위는 002가 해군·정비를 다루지 않았는데 시청자가 스스로 연결했다 — **이 소재의 수요가 정확히 「해군」 쪽에 있다.**
- 과장 교정 댓글은 004가 제목에서 핵잠수함과 한국 조선을 붙인 결과다 — 우리 가드레일의 실측 근거.
- 인력 반론(「한국도 협력사·외국인 노동자로 돌아간다」 25)은 003의 인력 파트에서 나왔다.

*감정 흐름*
- 001: 억울함 → 통쾌 → 의외성 → 자부심 → 경각심(한국이 주어) — 우리 규칙과 반대로 끝이 불안.
- 002: 경외 → 흥미 → 답답함 → 허탈 → 자부심 → 경각심 → 해소 없이 종료.

**설계 원칙**
1. **1위 반론을 본론의 입구로 쓴다.** 「상선은 포기해도 계산이 맞았을지 모른다. 그런데 해군 함정은 남에게 맡길 수 없다」 — 반론을 먼저 말하고 보이시로 받는다.
2. **과장 교정을 대본이 먼저 한다.** 「한국이 고치는 건 핵잠수함이 아니라 보급선이다」를 3막 초입에 둔다. 004 댓글 유형을 선제 차단한다.
3. **「이용만 당하는 것 아니냐」 불안에는 사실로 답한다** — 한화가 미국 조선소를 소유·운영한다는 구조, 앞으로 볼 지표(추가 수주 건수·법 개정). 단정 대신 지표.
4. **인력 반론(외국인 노동자·협력사)은 비교 조건 해명 문단에서 먼저 인정한다.**
5. **정치 0.** 정책명은 사실·금액만. 정권·대통령 평가는 한 줄도 없다.
6. **흐름**: 긴장(보이시 7년, 1막) → 납득(구조, 2막) → 반전(거제 도크의 미 해군 보급선, 3막) → 안도(왜 한국이었나, 4막) → 자기 반박(한계·인력·중국) → 반 계단 올려 마감. 공포의 주어는 끝까지 미국 쪽.

*비주얼 형식 패턴 요약*
- 가장 많이 쓴 구도: 인물 + 상징물(3편), 대비 분할(1편)
- 색채 공통점: 어두운 바다·저채도 배경 + 노랑/형광 문구 + 빨강 포인트
- 고퍼포먼스 비주얼: **잠수함이라는 오브젝트**(001)와 **낡음의 증거**(002 녹슨 선체). 004는 「노후」를 말하면서 멀쩡한 함정을 써서 문구와 그림이 어긋났다.
- 모바일 가시성: 002의 빨간 화살표·좌우 분할, 001의 대형 잠수함은 160×90에서도 식별된다.

*제목*
- 001 `60조 놓쳤더니 1600조가 굴러왔다? 미국이 한국 조선업에 다급히 SOS 친 이유` — 숫자 대비 + 권력 역전 + 이유
- 002 `막강했던 미국 조선업은 왜 붕괴됐을까?` — 정점어 ↔ 붕괴 + 왜
- 003 `울산 조선소를 다녀온 미국 해군 고문, 한국에서 뭘 배웠길래?` — 권위자 방문 + 역할 역전 동사 + 지명
- 004 `미국 핵잠수함 10년째 정비 지연...트럼프가 한국 조선업에 매달리는 이유` — 기간 숫자 + 정치인 + 매달리다
- 005 `조선업 최후의 전쟁: 세계 선박 94%가 韓中日 독점? 미국 유럽의 패배 이유` — 과장 프레임 + 숫자

*썸네일-제목 역할 분담*
- 001: 썸네일 = 사건(탈락 → 움직임), 제목 = 숫자(60조 → 1600조)
- 002: 썸네일 = 구체 장면(하루에 배 한 척), 제목 = 추상 대비(막강 ↔ 붕괴)
- 004: 제목(핵잠수함 10년)과 썸네일(2027 위기설)이 서로 다른 훅이라 분산됐다

**설계 원칙**
- **썸네일 텍스트**: 핵심 2행, 요소당 6~12자, 총 20자 안팎, 끝은 질문·반전 부호. 숫자 배지 하나(대기 기간). 금지어(충격적) 없이.
- **제목**: 주인공은 **보이시 잠수함**(이름 또는 「미국 핵잠수함」). 「한국」·「SOS」·「잭팟」을 앞세우지 않는다. 구조는 **기간 숫자 + 멈춘 결과 + 이유 질문**. 정치인 이름 금지.
- **역할 분담**: 썸네일 = 멈춘 잠수함 장면과 기간 숫자, 제목 = 「세계 최강 해군에 무슨 일이」 류 이유 질문. 004처럼 두 훅을 흩뜨리지 않는다.
- **썸네일 비주얼**: 낡음·멈춤의 증거가 보이는 한 장면(부두에 묶인 녹슨 잠수함) + 빨간 기간 배지. 가능하면 002식 좌우 대비(멈춘 미국 잠수함 ↔ 한국 도크의 미 해군 보급선).

**구조 자산**

*훅 기법*
- `주어 감추고 위용 먼저` — 누구나 아는 강자를 이름 없이 세운 뒤 공개해 낙차를 키운다 (002)
- `실패 → 반전 숫자 쌍` — 잃은 것과 얻은 것을 숫자 두 개로 붙여 한 줄에 반전을 만든다 (001)
- `결론 발언 티저` — 권위자의 결론 한 마디를 맨 앞에 끌어와 3초 안에 약속을 확인시킨다 (003)

*비유/메타포 유형*
- `양보 못 하는 품목 = 쌀` — 협상에서 절대 못 내주는 산업이라는 무게를 한국 생활감으로 전달한다 (004)
- `모듈 공법 = 자동차 조립라인` — 공법 차이를 익숙한 공장 장면으로 바꾼다 (002)

*리텐션 장치 유형*
- `제도 복선 → 중반 회수` — 첫머리에 깐 제도를 중반에 「처음에 언급했던」으로 받아 인과를 각인시킨다 (002)
- `통념 부정 인터럽트` — 「마음만 먹으면 찍어낼 것 같지만」으로 시청자의 전제를 깬다 (001, 005)
- `현장 목격담` — 실사 현장의 한 장면(1년 지연이 가장 빠른 편)으로 추상 구조를 체감시킨다 (004)

*감정 트리거 유형*
- `제3자 자기비판` — 미국 쪽 인사가 스스로 「1950년대 조선소」라고 말하게 해 자부심을 화자 대신 외부가 만든다 (003)
- `권력 역전` — 도움 주던 쪽이 도움 받는 쪽이 되는 구도가 통쾌함을 만든다 (001, 003) — 단 과장하면 반박 댓글
- `반론의 빈칸` — 판단을 비워 두면 시청자가 반론으로 채운다(336) — 우리는 먼저 말하고 받는다 (002)

*데이터 제시 기법*
- `정점 → 현재 비율` — 「세계 모든 배보다 많이」에서 0.1%로, 낙차를 한 쌍으로 준다 (002)
