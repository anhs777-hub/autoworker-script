## 1. 주제 요약
파독 송금(1965~75 1억 153만 달러)은 실재한 기여였지만, 「임금을 담보로 서독 차관을 받았다」는 속설은 2008년 진실화해위원회가 사실이 아니라고 결론 냈다.

## 3. 훅 & 인트로
- 훅: 담보설 제시 → 「국제시장, 다큐, 신문에도 나왔다」 → 「2008년 진실화해위가 사실이 아니라고 결론」 → 「누가 우리를 속였을까요?」 — 속설 부정형. **해외 비교 없음, 「속았다」 프레임이 파독 세대를 기리는 시청자와 충돌** → 저조한 조회 원인으로 추정
- 인트로: 「처음부터 따라가 보겠다」형

## 4. 본문 구조
속설 → 1963 김포·빈곤 → 경쟁률 → 1964 함보른 → 임금·송금 → 속설 반박(협정문·KfW 공문) → 속설 발원자 → 대가(사망·귀국 후·간호사 비방) → 지원법 지연 → 생존자 현황 → 숫자 총정리 → 가족 사연 댓글 유도

- 좋은 기법: 경쟁률 비유 「92:1 — 지금 9급 공무원 약 30:1의 3배」, 「한 달 월급(160달러)이 당시 1인당 연소득(100달러)의 1.6배」, 「외화가득률 100% — 원자재 수입이 필요 없는 가장 순수한 외화」, 속설 발원자에 대해 **「거짓말했다고 단정할 근거는 없다」 — 비난 없는 교정**(우리 톤과 일치)
- 약점: 같은 수치 반복, 해외 대비 없음
