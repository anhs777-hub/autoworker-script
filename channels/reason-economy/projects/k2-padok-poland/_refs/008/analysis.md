## 4. 본문 구조
1. 2차 계약 발표 — 65억 달러 ≒ 8조 8천억, 「KF-21 개발비(8조)보다 크다」로 환산
2. 계약 구성 — K2GF(갭 필러 = 「땜빵」) + K2PL + 지원 차량
3. 원래 틀 — 1,000대 = 180대 직도입 + 820대 면허생산
4. 갈등 — PGZ가 820대 전량·핵심 부품까지 요구 → 실사 → 「인프라 엉망」 → 정부가 PGZ 「뒤통수」
5. 전차 라인 증설은 어렵다 — 「천하의 독일도 3년째 지지부진」
6. 가격 비교(레퍼 주장)
7. 독일이 못 만드는 이유 — **냉전 후 군축 → 저속 생산 → 하청이 유럽 각국으로 거미줄화 → 단가 상승·병목**
8. 동유럽 수요 — T-72/T-80을 우크라이나에 보내 공백 → 한국으로
9. 「핵심 부품은 전부 현대로템」 → 「앉아서 버는 구조」 → 낙관

- 배치: **최대 계약 → 갈등 → 경쟁자 약점 → 수요 공백 → 미래 낙관**. 경쟁자 결함으로 「왜」를 설명하는 논증형

**전달 기법**: 큰 금액을 아는 사업비로 환산(8.8조 ≒ KF-21), 쉬운 말 번역(「갭 필러… 땜빵」), 비유(하청 「거미줄」, 부품 「자동차 완제품 vs 수리 부품」), 반전(「200억 비싸다… 아니야, 여러분」)

**리텐션 장치**: 도입 오픈루프 / 예상 반박을 먼저 말하고 뒤집기 / 전환 멘트 / **선제 반박**(「폴란드가 마음대로 팔아제끼는 거 아니야? … 아닙니다」)

## 우리 편(K2 + 파독)에 주는 것
**가져올 것**
1. 「자국 업체보다 한국」 = 외국의 판정 앵글이 164만 — 유형 B 수요 확인. 단 이 계열은 포화 → 우리 차별점(파독 역전, 멈춘 라인)을 흐리지 말 것
