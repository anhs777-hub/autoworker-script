## 1. 주제 요약
일본 다이소산교에 지분 34%를 내주고 이름까지 빌려 시작한 한국 다이소가, 22년 뒤 그 일본 2대 주주가 이사회·배당 요구로 경영에 들어오자 약 5,000억 원에 지분을 전부 되사들였다 — 「거래가 끊길까 걱정하던 쪽이 내준 지분을, 같은 회사가 제 손으로 걷어들였다」.

## 3. 훅 (0:00~약 1:20) — 우리 훅 ⑤와 같은 구조
1. **2019년 여름 불매운동** — 「우리는 일본 기업이 아니라고요?」 해명부터 해야 했던 회사(시청자 기억 소환)
2. 의심의 근거: 2001년부터 일본 기업이 지분 34%
3. 반전: 4년 뒤 그 지분을 전부 되삼 — 약 5,000억, 「물건값이 비싸 봐야 5,000원인 회사가」
4. **이상한 시점**: 불매운동으로 가장 곤란하던 때도 그대로 두던 지분을, **매출이 처음 3조를 넘긴 해에** 정리
5. 정체 공개 → 「왜 하필 그해에 끝냈을까요? 오늘은 그 이야기를 쉽고 재미있게 풀어 드리겠습니다」 → **바로 새 장면**(2023년 연말 명동 12층 매장, 리들샷 3,000원) — 답 보류 + 새 장면 전환
- 구독 요청은 맨 끝에만

## 4. 본문 구조
2023 매장 장면(명동 12층·상품 3만 종·리들샷 품절) → 12-12 지분 인수 보도(이미 대금 납입) → 5,000억의 크기(1,000원짜리 5억 개, 영업이익 2년치) → 「매장이 늘지 않는 돈 — 이익을 누가 나누느냐가 바뀜」 → **이름의 기원**(大創, 일본 회사명) → 박정부 창업(1988 한일맨파워, 일본 연수 주선 → 1990 첫 주문 헤어액세서리 100만 엔) → 일본 다이소 납품으로 성장(15배), **고객이 단 한 곳뿐인 위험** → 1997 천호동 13평 「아스코 이븐 프라자」, 외환위기 → 2001 **일본이 독점 납품 요청 → 박 회장이 「4억 엔 투자」 조건** → 34% + 이름(로열티 없음) — 「고객을 주주로 묶어 둔 것」 → 2004 박리다매 장부(1,000원에 18원 남음, 「만 개 팔아 만 원 남는 장사」) → 대량 주문·현금 결제 → 매장 대형화 → 2012 용인 남사 허브(물류비 5%대 → 3%대 = 1,000원당 20원, 순이익과 맞먹음) → 2019 부산 허브 → **2019 불매운동**(해명: 로열티·인적 교류·경영 참여 없음, 일본 상품 매출 3%) → 그래도 남은 것: 배당 150억 → 2019 영업이익 급감(불매 탓만은 아님 — 캠페인 비용 명시) → 2018 일본 창업주 퇴진, 차남 취임 → **2022-03 일본 측 이사 2명·감사 1명 선임**(1년 넘게 알려지지 않음) + 배당 증액 요구 → 「경영 참여 없다」는 해명이 무너짐 → 반년 뒤 전량 인수 → 일본 쪽 계산(38억 → 5,000억, 130배) → **일본 다이소 해외 매장 25개국 967개 < 한국 다이소 혼자** → 「2대 주주의 경영 참여 자체는 정당한 권리」 선 긋기 → 2024 세종 허브 착공 → 2025 매출 4.5조·영업이익 4,424억(1,000원당 97원, 2019년엔 34원) → 수미상관

- 기법
  - **「1,000원짜리 하나로 환산」을 끝까지 유지**: 순이익 18원 → 물류비 절감 20원 → 2019년 34원 → 2025년 97원 — 숫자 하나의 성장 곡선
  - **공정한 선 긋기 반복**: 불매 탓만은 아니다 / 2대 주주의 권리는 정당하다 / 금액은 회사 미확인·복수 매체 보도
  - **「의외의 기원」**: 다이소 = 일본 회사명, 창업자가 일본 연수 주선 회사로 시작
  - 문장이 짧고 뉴스 인용형(「~라는 보도였어요」) — 해설보다 기록 재구성
