## 제목·썸네일
- 제목: `"고기를 식탁 위에서 바로 굽는다고?" 차가운 스테이크 먹던 서양인들이 한국산 휴대용 버너에 눈물 흘리며 줄 서는 이유` — **약 64자** (자사 상한 40자)
- 구조: 외국인 반응 인용 → 서양의 결핍(식은 고기) → 한국 물건 → 「이유」
- 썸네일: 좌(어두운 식당, 식은 고기) / 우(뉴욕 거리 긴 줄) 분할 + `식은 고기만 먹던 미국인들.. / 결국 한국 버너에 줄서는 이유`. **이미지는 AI 생성**(간판 「SEOUL GARDEN」, 실제 장면 아님)
- 쓸 만한 것: **「결핍 → 한국 물건」 대비 구도**. 자사 규칙(해외 앵커 → 한국)과 방향이 같다

## 대본 구조 (나열형)
1. 훅: 음식이 가장 맛있는 온도 → 서양인은 식은 스테이크
2. 서양 식문화·소방 규제 → 마당 바비큐뿐
3. 코로나 홈쿡 → 인덕션·환기 한계 → 한국 버너가 구원자
4. **오픈루프**: 「까다로운 서양 가스 규제당국이 왜 한국 버너는 허용했나」
5. 폭발방지 캔 기술 → **세계 점유율 80%**
6. 버너 압력감지 안전장치 → 캠핑 → 레스토랑 → 식탁 문화 → 불꽃 모양 → 중국 모조품 → 디자인
7. 마무리: 오늘 저녁 식탁의 파란 불꽃을 다시 보라

- 출처·연도·기업명 **0건**. 시간순 인과 없이 장점 나열 → 자사 「기피: 나열형」 그대로
- 과장·검증 불가 주장 다수: 「불에 던져도 **절대** 폭발하지 않는다」, 「강철 두께를 100mm 단위로 조정」(단위 오류), 「미국 소방법이 실내 불 사용을 법으로 금지」, 「아마존 베스트셀러」 — 자사 대본에 옮기면 안 됨
- 건질 장치 1개: **불 속에서 캔이 터지지 않고 촛불처럼 타는 시연 장면** — 1차 영상(제조사·UL 시험) 확보 시 훅 장면 후보
