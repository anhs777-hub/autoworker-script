# 레퍼런스 분석 — 001 경제를 알리자 「전 세계가 매년 100조를 쓸 때 한국만 0원인 진짜 이유 — 세종대왕이 600년 전 심어놓은 공짜 시스템의 정체」

> 조회 88,861 / **구독 235 = 약 378배** · 18:59 · 좋아요 207 · 댓글 19 · 2026-09-26(일주일)
> **같은 채널이 「한국이 선진국이 된 7가지 비밀」(temp-analysis16, 300배)도 냄** — 구독 200명대 채널이 국뽕 늘 통하는 소재로 연속 300배+
> 자막은 한국어 자동자막

## 0. 핵심 관찰
- 소재: 한글 — 시의성은 **한글날(10/9) 직전**(댓글 「곧 한글날이네요」)
- 같은 채널의 두 히트작 공통점: **늘 통하는 국뽕(한강의 기적·한글) + 「세계 vs 한국」 대비 숫자 + 감동 결말**, 사실 검증은 느슨함
- 이대표 경제학의 C 유형 흥행 목록에도 「한글」이 있다 — **한글은 검증된 C 유형 소재**

## 1. 썸네일 & 제목
| # | 텍스트 | 크기/색상/위치 | 확신도 |
|---|---|---|---|
| 1 | `"세계는 매년 100조"` | 최대, 흰색 따옴표, 하단 1행 | 확실 |
| 2 | `한국은 0원인 이유` | 최대, 시안(0원 강조), 하단 2행 | 확실 |
| 3 | `"한국은 진짜 왜 그래?` | 중형, 연두, 좌상단 | 확실 |
| 4 | `공짜!` | 말풍선 | 확실 |
- 이미지: 좌 = 청구서에 파묻혀 당황한 외국인 4명(다인종), 우 = 빛나는 한반도 야경 + 웃는 태극기 캐릭터 + 상승 화살표 — **청구서 vs 공짜** 대비
- 첫 줄 = 외국 쪽 상황 요약형(숫자) — 형식은 우리 규칙과 같음. **그러나 「100조」는 근거 없는 숫자**
- 제목: 「전 세계 100조 vs 한국 0원」 + 「세종대왕이 심어 놓은 공짜 시스템」

## 2. 훅 (0:00~약 0:50)
「한글 만든 거 모르는 사람 없죠? 그런데 그 한글이 매년 수십조 원을 벌어다 준다는 건 모르셨을 겁니다」 → 「전 세계가 글자 때문에 돈을 쏟아붓는데 우리만 0원」 → 「글자값이라는 게 뭔지부터」 — 아는 것(세종) → 모르는 것(돈) 전환

## 3. 본문 구조
세계 7천 개 언어 중 고유 문자는 극소수 → 영어 철자(knee의 k, ea 발음)·스펠링비·난독증 교육비 → 중국 한자(수천 자, 병음 입력 후 후보 선택) → 일본(상용한자 2,136자, 문자 세 종류) → 「세계가 치르는 글자값」(금액 근거 없음) → 한국: 문맹률 최저, 「아침 글자」 → 600년 전 조선(한자 독점, 억울한 백성) → 신하들의 반대 상소 → 세종의 단독 연구·발음기관 본뜬 자음·눈병 → 훈민정음 서문 → **반전: 디지털 시대**(천지인 자판, 입력 속도, IT 강국) → 외국 학자 찬사(제레드 다이아몬드·로버트 램지·펄 벅·영국 작가) → 유네스코 기록유산(1997)·세종대왕 문해상 → **찌아찌아족**(2009 한글 도입, 2020 사전, NYT 2024 보도 주장) → 수미상관 「600년 동안 로열티 한 푼 없는 선물」

- 기법: 외국 문자의 불편을 구체 예로(knee, 병음 입력) / 「아침 글자」 별명 / 감동형 결말(애민 정신 → 지구 반대편 부족)
- 리텐션 장치: 「그런데 여기서 정말 흥미로운 반전이 하나 남아 있습니다」(디지털), 「마지막 장면」 예고

## 4. 사실 문제 (우리가 따라 하면 안 되는 이유)
- **「세계 100조·한국 0원」**: 산출 근거 없음. 한국도 국어 교육·문해 교육에 예산을 쓴다 — 「0원」은 사실 아님
- 「문맹률 세계 최저」: 성인 문해력(OECD PIAAC) 지표로는 다른 그림 ❓ — 반박 위험
- 학자 인용(펄 벅·「영국 언어 작가」 등) 원문 미확인 ❓ — 일부는 출처 불명 인용으로 흔히 떠도는 문장
- 찌아찌아: 2012 세종학당 철수 등 굴곡 생략 ❓, NYT 2024 보도 ❓ 확인 필요
- 「IT 강국의 배경이 한글」: 인과 단정

## 5. 댓글
감정형(「세종대왕 만세」), 실사용 증언(「중국 직원들 병음 입력 답답」 — 9추천), 「영어가 아니라 로마자」 지적, 사대주의 반대 신하 비난 — 정보 반박은 적음

## 6. 우리 채널 판정
- 한글 = **검증된 C 유형**(이대표 흥행 목록) + **한글날 고리(10/9, 엿새 뒤)**
- 그러나 이 영상식(근거 없는 100조, 출처 불명 찬사)은 우리 원칙과 충돌 — **같은 소재를 검증 가능한 숫자 하나로** 다시 세워야 함
- 같은 채널이 연속 300배+ — 「늘 통하는 국뽕 × 세계 vs 한국 대비」 수요가 시의성 없이도 크다는 반복 신호
