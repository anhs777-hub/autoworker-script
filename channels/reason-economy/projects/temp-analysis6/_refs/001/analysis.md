## 1. 성과
| 지표 | 값 | 판정 |
|---|---|---|
| 조회수 / 구독자 | 120,015 / 2,080 → **배수 57.7배** | 매우 높음 (업로드 11일 차) |
| 좋아요율 | 913 / 120,015 = **0.76%** | 보통 (자사 007 1.11%) |

## 2. 제목·썸네일
- 제목: `처음부터 끝까지 혼자 다 만드는 미친 나라 대한민국, 하버드가 한국을 극찬한 진짜 이유` — **약 47자**
  - 공식: **[과장 수식] + 대한민국 + [해외 권위]가 극찬한 + 진짜 이유**
- 썸네일: AI 생성 **하버드 교수(과장된 놀란 얼굴)** + 하버드 문장 + 태극기 + 삼성·SK하이닉스 칩 + 현대 차량 + 조선소 + K2 전차
  - 문구 `"혼자 다 해내는 미친 나라" / 하버드가 한국을 극찬한 이유` — 노랑/하늘색 2단
  - ⚠️ **실존 기업 로고 + 가짜 인물**. 자사는 쓰지 않을 방식
- 참고할 점: **「해외 권위 + 극찬」**이 5070 클릭을 강하게 당긴다. 자사 규칙 「제3자 판정 인용」과 같은 재료를 **제목에서** 쓴 사례

### 자사가 가져올 수 있는 것
1. **5070 세대 경험 직접 소환**(IMF 금 모으기, 보릿고개) — 자사 「3막 향수 앵커」와 같은 원리. 금 모으기는 35~65세 전원이 기억한다
2. **「비웃음 → 추월」 패턴** — 인텔의 「과대망상」, 미쓰비시 보고서처럼 **해외가 한 말**을 1차 인용하면 「제3자 판정」이 된다
3. **다음 편 주제 투표** — 댓글에서 편이 갈리게 만드는 장치. 자사 원인 추론형 질문과 함께 쓸 수 있는지 검토할 만하다

### 자사가 버릴 것
- **나열형 3가지 이유** · 권위 3연타 → 「왜」보다 「누가 칭찬했나」가 중심 (자사 기피)
- **「우리가 잘한다」 직접 주장** 전편 (「처음부터 끝까지 우리 손으로… 여기까지 온 겁니다」) — 자사 「자부심 소재 규칙」 1번 정면 위반
- **해외 앵커 없음** — 남의 실패 없이 자랑만 30분. 긴장 ↔ 안도 왕복 0회
- 「뭉클하지 않으십니까」 · 「이보다 더 극적인 반전이 또 있을까요」 — 감정 강요형 진행 멘트
- 구독 유도, 정치인 이름(박정희) 직접 언급
