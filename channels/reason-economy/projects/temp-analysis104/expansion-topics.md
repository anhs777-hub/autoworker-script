## 2. 왜 터졌나

- **배수**: 채널 최근 25편이 대부분 수백~수천 회. 1만 넘는 편은 「중국 노숙자 5천만」(3.1만), 「일본 아나운서가 본 한국」(6.2만), 「대만 방송 한국 칭찬에 중국 패널 흥분」(11.1만), 「일본이 한국을 부러워」(18.6만) 정도 → 이 편 20.7만이 채널 최고권. 「대만 방송」 소재가 연속으로 터짐
- **감정**: 국뽕(외국이 한국을 인정한다) + 일본보다 위라는 서열 쾌감
- **키워드**: 대만 방송 · 서양과 아시아 · 유일한 나라 · 일본보다
- **구도**: 한국 vs 일본, 「제3자(대만)가 판정해 준다」
- **한계**: 댓글 상위가 「3~4년 된 영상 재탕」(27), 「사골 곰탕」(24) 비판. 좋아요는 많지만 신뢰는 낮은 조회

### 8-3. 비교 축 (프랑스 빵집 제도)

- **「불랑제리」 이름 제한**: 1998년 5월 25일 법률(loi n° 98-405). 가게에서 직접 반죽·발효·성형·굽기까지 해야 「불랑제리(빵집)」 간판을 달 수 있음. 위반 시 벌금 최대 3만7,500유로 또는 징역 2년 이하(출처마다 표기 차이, 레지퓌랑스 원문 확인 필요)
  → 중앙 공장에서 반죽을 받아 굽는 한국식 프랜차이즈 방식과 정면으로 부딪히는 규칙. 파리바게뜨가 장인 단체에 가입하고 매장에서 굽는 방식을 강조한 이유를 설명할 수 있는 장치
- **프랑스 빵집 수**: 약 3만~3.5만 곳(민간 추정, 공식 통계 아님). 2024년 창업 1,764곳·폐업 2,144곳이라는 자료와 「비슷하게 유지」라는 자료가 엇갈림 → 쓰려면 INSEE·제빵 연맹(CNBPF) 수치로 다시 확인
- **한국 쪽**: 파리바게뜨 국내 매장 약 3,000곳(2016년 기준 기사). 최신 국내 매장 수는 공정위 가맹사업 정보공개서로 확인 필요

### 8-4. 쓰면 안 되거나 확인이 더 필요한 것

- SMU 사례의 「파리바게뜨가 쿠프 뒤 몽드 드 라 불랑제리(제빵 월드컵)에서 우승, 올랑드 대통령 참석」 → 다른 출처로 확인되지 않음. 확인 전 사용 금지
- SMU 사례의 「프랑스는 바게트를 1유로 미만에 팔아야 하는 가격 통제」 → 프랑스 빵값 통제는 1978~1986년에 풀린 것으로 알려짐. **오류 가능성 높음, 사용 금지**
- 「파리바게뜨가 파리 올림픽 공식 파트너」 → 아님. 대한체육회 후원사로 현지 매장에서 한국 메달리스트 축하 케이크를 만든 것뿐
- 첫 매장 날짜(2014년 4월 vs 7월) → 대본에는 「2014년」까지만
- 원본 영상의 「파리바게뜨 현재 5호점」 → 2022년 기준. 등기상 매장 법인은 6곳 + 생산 시설 1곳 → 2026년 매장 수는 회사 매장 찾기 페이지로 확인
