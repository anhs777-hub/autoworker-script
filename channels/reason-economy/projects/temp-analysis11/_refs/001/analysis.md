# 레퍼런스 분석 — 001 경제솔로몬 「한국이 49억 달러에 산 미국 공장, 승자의 저주라던 15년 뒤 미국 공사장 로더 1위가 됐습니다 — 캐터필러·쿠보타를 앞에 두고」

> 조회 100,324 / 구독 4,420 = **약 23배** · 25:39 · 좋아요 705(0.7%) · 댓글 27 · **2026-09-29 업로드(하루 만)**
> 자막은 영어 자동번역본(고유명사 깨짐 — 뜻으로 읽음)

## 1. 주제 요약
2007년 두산이 빚 80%로 산 미국 밥캣은 금융위기로 「승자의 저주」가 됐지만, 팔지 않고 버틴 끝에 그룹을 쪼갤 때 가장 먼저 지킨 자산이 됐다 — 두산이 산 건 공장이 아니라 「시간(딜러망)」이었다.

## 2. 썸네일 & 제목
| # | 텍스트 | 크기/색상/위치 | 확신도 |
|---|---|---|---|
| 1 | `5조 7천억 '승자의 저주'` | 최대, **형광 노랑**, 하단 1행 | 확실 |
| 2 | `밥캣, 두산의 황금알 됐다` | 최대, **시안**, 하단 2행 | 확실 |
| 3 | `다 팔아도 넌 안 판다` | 중형, 연두 박스, 우상단 | 확실 |

- **우리 채널 [B] 레이아웃과 사실상 같다**(노랑 따옴표 + 시안 결론, 검정 외곽선) — 같은 시장에서 레이아웃 차별은 이미 없다
- 첫 줄: 숫자 + 과거의 평가(「승자의 저주」 — 신문이 붙인 이름 = 특정인 발언 아님) → 우리 제목 규칙 ⑤ 「과거의 멸시·오판」과 같은 구조
- 이미지: 성조기(좌상) · 흙을 퍼 올리는 밥캣 로더(중앙 대형) · 두산 간판·태극기(우상) — 인물 없는 **사물 중심 좌우 대비**
- 말풍선형 한 줄 「다 팔아도 넌 안 판다」 — 사물에게 하는 말(인물 발언 아님)
- 제목: 매우 길다(약 70자). 앞 = 숫자 사실(49억 달러) + 과거 평가(승자의 저주) + 결과(1위), 뒤 = 비교 대상(캐터필러·쿠보타) — 「외국 강자 이름」을 제목에 넣어 판정 구조를 만든다

## 3. 훅 (0:00~약 1:40)
1. 「아무도 좋은 인수라고 하지 않았습니다」 — 부정으로 시작
2. 장면: 옥수수밭 사이 노스다코타 공장, 아파트 공사장 구석의 작은 장비(시청자가 본 적 있는 것)
3. 숫자 연타: 49억 달러 = 5.7조(당시 한국 기업 해외 인수 최대) · 인수 주체 자산의 두 배 · 1년 안에 주택시장 붕괴(착공 1/5) · 이틀 연속 하한가 · 3년 적자 1.2조 → 「승자의 저주」
4. 반전: 「14년 뒤 그룹을 쪼개 팔 때, 가장 먼저 팔릴 것 같던 회사가 목록에 없었다. 오히려 안쪽으로 먼저 옮겨졌다」 + 신규 스키드로더 10대 중 3대
5. 이중 질문: 「돈이 없어서였나, 돈으로 못 사는 게 있었나?」「두산은 2007년에 도대체 무엇을 샀나?」
6. ⚠️ 바로 구독 요청(우리 금지)

- 좋은 점: **「이상한 점」 = 그룹 해체 때의 서류 순서**라는 구체적 장면을 훅에 둬서 결말의 핵심 장면을 미리 판다
- 답 보류: 「무엇을 샀나」의 답(시간·딜러망)은 약 20% 지점에서 공개

## 4. 본문 구조
1957 미네소타 헛간(기둥 사이에서 도는 기계) → 이름의 유래(스키드 스티어) → **「이 이야기에 한국의 출발점은 없다」 선언** → 시장 주인들(캐터필러·쿠보타·디어·JCB) → 판 쪽의 사정(잉거솔랜드: 좋은 사업이지만 경기 민감 → 팔고 공조를 샀다) → 두산의 10년(코카콜라·OB맥주 팔고 공장 기업 사들임) → **「공장이 아니라 시간을 샀다」**(딜러 2,700곳) → 증명: 두산 자체 북미법인 8년에 지점 3곳 vs 밥캣 1,500곳, **미국 주법이 딜러를 보호** → 단서: 하락 중인 1위(41%→32%), 자기자본 20% LBO → 주택 착공 −79% → 1조 추가 출자·이틀 하한가 → 처음처럼 매각 → 비스마크 공장 폐쇄 475명(390명 이동, 85명) → **버틴 3가지 결정**(추가 출자 / 2011 차입 만기 연장, 8배 주문 / 팔지 않음) + 대가(중국법인 투자 소송 10년) → 2011 흑자 → 100만 번째 기계를 고객에게 → 2016 상장 실패(경쟁률 0.29:1) → **2020 그룹 해체: 밥캣 지분을 먼저 떼어 안쪽으로**(집 팔 때 먼저 빼놓는 것) → 2021 밥캣이 두산 지게차 인수(방향 역전) → 사상 최대 이익 → **자기반박 블록**(1위는 스키드로더 한 칸뿐·트랙로더는 쿠보타 1위·전체 11위 / 시총은 아직 인수가 미달 / 판 쪽이 더 벌었다(시총 30배) / 만든 건 미국인, 설계는 지금도 비스마크) → 2023 두산 이름을 지우고 밥캣으로 통일 → 2026 관세 환급·멕시코 공장·CES AI → **애쉬 3대 55년**(할아버지 운전석 설계 → 손자 자율주행) → 한국 지게차 54% → 질문

- 패턴: 역설 훅 → 기원 → 판 쪽 사정 → 산 이유 → 위기(숫자+사람) → 버틴 결정 → 반전 장면 → 결과 숫자 → 자기반박 → 사람 이야기 → 한국 연결 → 질문
- 기법
  - **「~를 분명히 해 두겠습니다」 선 긋기 5회 이상** — 한국 기원 부정, 하락 중인 1위, 1위 범위, 시총 미달, 판 쪽이 더 벌었다 → 자화자찬 차단의 교과서
  - **숫자 → 사람 환원**: 「475는 숫자지만 475가구의 대출 상환일·학비」, 390명 이동/85명 실직까지 정정
  - 생활 비유: 「집 팔 때 먼저 빼놓는 것이 가장 귀한 것」, 「빚은 사라지지 않고 달력의 빨간 날짜를 뒤로 옮겼다」
  - 수미상관: 1950년대 헛간 기둥 사이 → 지금 아파트 공사장 틈

## 7. 왜 터졌나 (23배, 하루)
1. **A 유형 정석**: 「승자의 저주」(과거의 오판) → 1위 — 제목·썸네일 모두 이 낙차 하나
2. **이미 아는 브랜드**(흰·주황 밥캣, 공사장에서 본 장비) + 모르는 사연
3. **자기반박이 신뢰를 만든다**: 1위 범위·시총 미달·판 쪽이 더 벌었다까지 먼저 말함 — 국뽕 반감층도 끝까지 본다
4. **사람**: 475명, 100만 번째 고객, 3대 엔지니어 — 기업 인수 이야기를 사람 이야기로 닫음
5. 시의성: 2분기 실적(관세 환급)·멕시코 공장 완공 등 올해 뉴스로 「지금」을 붙임

## 우리 편에 주는 것
- **「과거의 평가(승자의 저주) + 숫자」 첫 줄** — 우리 썸네일 첫 줄 규칙(외국 쪽 상황 요약)의 변형: **당시 언론이 붙인 이름**은 특정인 발언이 아니라 통과
- **「판 쪽의 사정」 막** — 외국이 왜 팔았나(나쁜 사업이라서가 아니라 전략이 달라서)를 존중하며 설명 → 외국 비하 없이 대비
- **증명 장면**: 「돈으로 못 사는 것」을 주장하지 않고, 두산이 직접 해 봤더니 8년에 3곳이었다는 사실로 증명
- **선 긋기 문장의 배치**: 결과 숫자 직후에 범위를 좁힌다 — 우리 자기반박 블록 위치 참고
- 클로징 양자택일 결단 질문 → 우리 pd-guide 「두 갈래 + 짧은 답」과 일치
