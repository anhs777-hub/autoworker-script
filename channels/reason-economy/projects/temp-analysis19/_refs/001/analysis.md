## 0. 핵심 관찰 — 국뽕도 시의성도 아닌 「생활 미스터리」가 438배

- 시의성: 금값 고공(1월 고점 → 9월 하락, 1년 전 대비 +16.5%) 정도. 사건 뉴스 없음
- 채널 힘 0(구독 635) → **소재 호기심 + 시청자 집 서랍(돌반지)이라는 개인 연결**만으로

## 2. 훅 (0:00~약 1:30)
1. 장면: 금은방 앞을 지날 때 — 진열장엔 수천만 원어치 금, 안엔 손님 없음, 주변 가게는 몇 번씩 바뀌는데 10년째 그 자리
2. **시청자 소환**: 「집 서랍에 돌반지 하나쯤 있으시죠?」 + 숫자(지난해 국민이 판 금 약 6.9조)
3. **사물 하나를 끝까지 따라간다**: 「돌반지 하나를 들고 동네 금은방에 갔다고 해 보겠습니다… 장사는 손님이 나간 그때부터 시작됩니다」 → 「오늘은 이 돌반지 하나를 끝까지 따라가 보겠습니다」
4. 초반 댓글 질문(「팔아 본 적 있나요? 팔아봤다/아직이다」)

## 3. 본문 구조 — 「돌반지 한 개의 여정」
저울·돋보기(무게·순도만 본다, 브랜드·디자인·산 가격은 안 본다) → 순도 표시(24K·18K·14K, 18K 매입가는 순금의 약 73.5%) → 「세공비는 왜 안 돌려주나」(녹일 거니까) → 시세판 vs 실제 매입가(빠지는 세 가지: 녹는 손실·순도 재조정·가게 몫, 몫은 공개 기준 없음) → 대형 거래소 두 곳 순금 매입가 차이 0.14% vs 은 5.3% → 종로 25년 사장 인터뷰(경쟁 많으면 몫 작다) → 파는 요령(무게·순도 먼저, 2~3곳 문의, 신분증) → **미국 전당포는 녹인 금값의 절반쯤, 한국은 훨씬 높다** → 같은 날 사고 바로 팔면 11.9만 원이 사라짐(82.7만 → 70.8만) → 그중 부가세 7.5만 → 본전까지 금값 약 17% 상승 필요 → **손님이 나간 뒤**: 진열장 재판매 vs 녹이기(정련) → 「팔리지 않는 재고가 원재료로 돌아가는 유일한 가게」 → 도매상·정련 공장 → 새 제품에 세공비 다시 → 교환·수리 손님 → 장롱 금 730톤(한국은행 보유의 약 7배) → 결론: 금은방은 「작은 금 유통소」 + 재고 손실 가능성(1월 98.9만 → 9월 82.7만) 정직하게 → 질문 「지금 파시겠어요, 두시겠어요?」

- 기법
  - **한 사물 추적(돌반지)** — 구조 전체의 뼈대, 나열 없이 순서가 자연스럽다
  - 시청자가 직접 겪을 장면(저울 숫자 흔들림, 돋보기)
  - **실용 정보**(파는 요령, 물어볼 질문) — 저장·공유 동기
  - 숫자를 생활 단위로(11.9만 원이 문 앞에서 사라짐, 117만 원이 돼야 본전)
  - 자기반박(「주인이 다 가져가는 건 아니다 — 부가세」, 「재고 손실 없는 건 아니다」)

- **그러나 채널 전략상 중요한 신호**: 「누구나 지나치는 일상 장소의 수수께끼 + 시청자 집에 있는 물건」이 시의성·채널 힘 없이 438배. 우리 C 유형(매일 쓰는 한국 시스템)과 같은 결 — **C 유형에 외국 비교 한 막을 붙이면 우리 소재가 된다**
