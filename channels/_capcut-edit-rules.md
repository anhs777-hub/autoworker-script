# 캡컷 편집 규칙 (세상의 이유 · 지식대학 공통)

> 정리: 2026-10-16. 근거는 세상의 이유 「세탁기 관세」 편집본(v1~v4)과 지식대학 「동물원 탈출」 편집본 작업에서 사용자가 정한 것.
> 각 편 기록: `projects/{프로젝트}/_script/capcut-edit-qa.md`

> **지식대학은 파트 카드만 넣는다 (2026-10-21 사용자 결정)** — 팝업 그래프(3절)와 효과음(5절)은 지식대학에 쓰지 않는다. 지식대학 편집본에서 추가하는 것은 **파트 카드 트랙 1개뿐**이다. 아래 3·5절과 9절의 팝업 관련 검수는 세상의 이유에만 적용된다

## 1. 무엇을 바탕으로, 무엇을 지키나
- 바탕은 영상 제작 사이트에서 받은 `[완성] …_capcut_인트로_여운.zip`. **원본 zip은 건드리지 않고**, 복사해서 새 프로젝트(새 ID, 이름 `…_편집본`)를 만든다
- **인트로 구간(훅 + 채널 인트로 영상)은 손대지 않는다.** 원본 트랙(장면·전환·자막·고정 문구·로고·오디오)도 그대로 두고, 새 트랙만 추가한다 — 세상의 이유: 팝업 영상 1(파트 카드 포함, 효과음 없음) / **지식대학: 파트 카드 영상 1(효과음 없음)**
- 결과물은 두 곳: 캡컷 프로젝트 폴더에 설치 + 바탕화면 `[편집] …zip`

## 2. 쓰는 것 / 쓰지 않는 것
| 쓴다 | 쓰지 않는다 |
|---|---|
| 직접 그린 팝업 PNG(1920×1080 투명, PIL·맑은 고딕) | 외부 유료 API(이미지·음성 생성 등) |
| 캡컷 기본 키프레임(크기·투명도·위치)으로 만든 움직임 | 캡컷 스토어 효과·애니메이션 새로 추가(유료 여부 확인 불가) |
| | 효과음 — 2026-10-21 두 채널 모두 삭제 |
| | 강조 문구(키워드 자막 팝업) — 2026-10-16 동물원 편에서 전부 삭제 |
| | 대본에 없는 수치·문구 |

## 3. 팝업 그래프 (세상의 이유만 — 지식대학은 2026-10-21부터 쓰지 않음)
- **분량**: 전체 장면 수의 5~10%
- **길이**: 최대 10초
- **시작**: 그 수치를 말하는 자막이 시작하는 순간에 맞춘다
- **문구**: 짧게. 번역체 서술 대신 「제목 + 태그」 구조로 쓴다. 예) 「뉴스 속 탈출 순위」 + 「워싱턴포스트 집계 · 134건」
  - 기준·범위(평균, 근삿값, 집계 기준, 연도)는 태그나 출처 줄에 남겨 정확도를 지킨다
- **수치**: 대본·verified-data 그대로. 근삿값이면 「약」이나 「근삿값」 표시
- **출처**: 카드 아래에 한 줄
- **움직임**: 크기 0.86 → 1.03(0.2초) → 1.0(0.36초) + 투명도 0 → 1(0.2초)로 등장하고, 끝 0.3초 동안 사라진다
- **그림을 함께 넣는다 (2026-10-16 사용자 결정 — 모든 편·두 채널 공통)**: 팝업 그래프는 숫자만 두지 않고, **그 편의 대본과 영상에 나오는 대상을 그림으로** 함께 넣어 그림 그래프로 만든다. 동물에 한정하지 않는다
  - 무엇을 그릴지는 매 편 대본을 읽고 정한다 — 그래프 항목·축이 가리키는 실제 대상: 동물(원숭이·새), 제품·사물(세탁기·건조기·컨테이너·공장), 나라·지역(국기·지도 핀), 사람 무리(소비자·노동자), 시간(달력·시계), 돈(동전·지폐), 탈것(배·비행기) 등
  - 같은 그래프 안 비교 대상마다 서로 구분되는 그림을 둔다. 예) 세탁기 편 「생산지 이동」 → 국기 🇨🇳 / 🇹🇭·🇻🇳 + 세탁기 그림, 「세이프가드 관세」 → 1·2·3년차 달력 / 동물원 편 「뉴스 속 탈출 순위」 → 🐒🐆🐄🦜
  - 그림 소스(외부 API·유료 리소스·다운로드 없음): ① Windows 기본 컬러 글꼴 `C:/Windows/Fonts/seguiemj.ttf`(Segoe UI Emoji, PIL `embedded_color=True`) ② 맞는 그림이 없으면 그 편 영상의 장면 이미지(`Resources/scene_*`)에서 대상 부분을 잘라 원형·둥근 사각 배지로 넣는다(영상과 그림체가 같아진다) ③ 그래도 없으면 PIL로 단순 도형을 직접 그린다
  - 실제 기업 로고·상표 그림은 넣지 않는다(이름 글자로 대신)
  - 아이콘은 크게(지름 50~100px) 둔다. 막대 그래프는 막대 끝 점을 그림으로 바꾸는 방식이 효과가 좋다(동물원 편: 원숭이·표범·소·앵무새가 기록만큼 달려 나간 모양)
  - 같은 대상은 한 편 안에서 같은 그림을 쓰고, 대본에 나온 대상과 맞는 그림만 쓴다(예: 대본 속 플라밍고 492번 → 🦩). 그림이 수치를 과장하거나 다른 뜻을 주지 않게 한다(검수 때 확인)

## 4. 파트 카드 (두 채널 공통 — 지식대학은 이것만 넣는다)
- 파트가 시작할 때마다 3.5초, 화면 왼쪽 위
- 카드 문구는 그 파트의 챕터 제목(03 업로드정보 타임스탬프 제목)과 같게. 시작 시점은 그 파트 첫 자막이 시작하는 순간
- 움직임: 투명도 0 → 1(0.2초) + 가로 위치 -0.06 → 0(0.36초)으로 밀려 들어온다

## 5. 효과음 — 쓰지 않는다 (2026-10-21 사용자 결정, 두 채널 모두)
- 팝업 그래프·파트 카드 어디에도 효과음을 넣지 않는다. 효과음 오디오 트랙을 만들지 않는다
- 이전 기록(세탁기·동물원 편): 그래프 「뿅」(sfx_pop)·파트 카드 「휙」(sfx_whoosh), 음량 0.30~0.35

## 6. 배치
- 자막(화면 아래 y=-0.8)을 가리지 않는다 — 카드 아래 끝 760px 이하
- 오른쪽 위 채널 로고, 맨 위 고정 문구(AI 활용 고지)를 피한다 — 카드 위 끝 110px 이상
- 카드는 반투명, 그림자는 카드 바깥에만. 출처 같은 작은 글씨는 배경에 묻히지 않게 진하게

## 7. 채널별 디자인 — 서로 겹치지 않게
| | 세상의 이유 | 지식대학 |
|---|---|---|
| 카드 | 흰 반투명(약 75%) | 그라파이트 유리(약 93%) + 얇은 흰 테두리 |
| 색 | 파랑(LG 진한 파랑·삼성 밝은 파랑) + 주황 | 앰버(강조) + 세이지민트(답) + 슬레이트(나머지) |
| 태그 | 파란 칩 | 자간 넓힌 앰버 글씨 |
| 그래프 모양 | 얇은 가로 막대 · 세로 막대 · 고리 도넛 · 표 | (2026-10-21부터 그래프 없음 — 이전 편 기록: 막대사탕형 · 반원 게이지 · 점 띠) |
| 파트 카드 | 「PART n」 흰 카드 + 파란 세로줄 | 「PART 0n」 유리 카드 |
- 한 채널에서 쓴 색·모양을 다른 채널로 가져오지 않는다

## 8. 기술 주의 (팝업이 안 나오는 사고 방지)
- **경로 ID 통일**: 캡컷은 프로젝트를 처음 열 때 재료 경로의 `##_draftpath_placeholder_<ID>_##` 값을 바꾼다. 추가한 팝업·파트 카드 경로를 그 파일의 `audio.mp3` 경로와 같은 ID로 맞춰야 화면에 나온다
- **고칠 파일 전부**: 캡컷이 한 번 연 프로젝트는 아래 파일을 모두 함께 고친다. 하나라도 빠뜨리지 않는다
  - 루트·`Timelines/<ID>/`의 draft_info.json · draft_content.json · .bak · template-2.tmp
  - 클립을 지울 때는 draft_meta_info.json(재료 목록) · draft_virtual_store.json · attachment_id_mapping.json에서도 지운다
- **고치기 전**: 캡컷에서 해당 프로젝트를 닫는다. 백업은 프로젝트 폴더 밖에 둔다(zip에 섞이지 않게)
- 이미지만 바꿀 때는 Resources의 PNG를 같은 이름으로 교체하면 된다(JSON 수정 불필요)

## 9. 검수 (끝나기 전에 반드시)
- **지식대학**: 파트 카드 전부를 실제 장면 + 로고 위에 합성한 미리보기로 오타·겹침·잘림을 확인하고(`output/capcut_preview/partcards_all.jpg`), 구조 검사에서 「효과음 트랙 0 · 팝업 그래프 0 · 파트 카드 수 = 파트 수」를 함께 확인한다
- **오타·겹침·잘림**: 팝업 전부를 실제 장면 + 로고 + 자막 위에 합성한 미리보기로 확인 → `output/capcut_preview/popups_all.jpg`
- **카드 밖 넘침 자동 검사 (2026-10-16 추가)**: PNG를 만들 때마다 카드 사각형 밖에 밝은 픽셀(글자·그림)이 있는지 스크립트로 검사해, 하나라도 있으면 실패로 처리하고 고친다. 미리보기 축소본만으로는 놓친다 — 동물원 편에서 「평균 92일」이 카드 밖으로 나간 채 반영됐던 사고
- **구조**: 스크립트로 아래를 확인한다
  - 원본 트랙 동일, 참조 누락 0, 중복 ID 0
  - 트랙 내 겹침 0, 인트로 침범 0, 10초 초과 0
  - 경로 ID 하나로 통일, 리소스 파일 존재
  - 효과음 오디오 트랙 0 (두 채널 공통, 2026-10-21)
