## 2. 훅 공식 (pd-guide 5번 틀에 사료 대입)

**관찰**
- 경쟁작 첫 장면은 모두 패 모양·「신분증」 정의로 시작 → 정보는 주지만 질문이 없다
- 사료에서 「장면 → 어긋남」이 가장 짧게 붙는 조합: #15(산속 도피, 사람 주어·날짜 있음) + 결말 숫자(네 번 폐지·다섯 번째 정착)

**설계 원칙**
1. 장면은 #15 — 주어는 「전라도 감사」와 「백성들」, 관청 이름(호패청·비변사) 없음
2. 어긋남은 「나무패 하나」의 작음과 「260년·네 번」의 큼 — 결말을 여기서 공개
3. 질문은 「왜」 하나. 이유(군역·불신·숙종 대 변화)는 숨겨 판정까지 끌고 간다
4. 대안 장면: #27 강가 장부 소각(피난길이라 장면이 강하지만 앞에 두면 클라이맥스가 빈다 → 결말용으로 아낀다)

## 3. 본론 구조 & 전달 기법

**관찰**
- 시행 5회를 전부 같은 무게로 다루면 나열형이 된다(profile 기피). 장면 밀도는 1차(태종)·4차(인조)·5차(숙종)가 높고 2·3차는 기사 1~3건
- 반복 자체가 뼈대(profile: 「시행과 폐지를 여러 번 반복한 소재는 반복 자체를 뼈대로」)

**설계 원칙**
- 뼈대: **1차(태종, 첫 실패의 원형) → 2·3차는 「같은 일이 또」로 압축 → 4차(인조, 가장 세게 밀고 가장 극적으로 무너짐) → 5차(숙종 — 숙종 6년 폐지 명령까지 나왔는데 왜 이번엔 남았나)**
- 숫자: 영상 전체 핵심 1개 = 226만(숨은 사람 123만이 드러난 사람 103만보다 많음). 보조 1개 = 네 번·260년(훅에서 이미 사용). 1만 6,297은 쓰더라도 226만과 같은 파트에 두지 않는다
- 기사 날짜 장면 열기 4~6회 후보: #4, #15(훅), #20 또는 #25, #27, #33
- 리텐션: 각 폐지 직후 「그리고 몇 년 뒤, 또」로 다음 시행을 예고 — 반복 리듬이 오픈루프 역할. 2·3차 압축 구간 끝에 「네 번째는 달랐습니다 — 나라가 가장 세게 밀어붙였습니다」류로 4차 진입

## 4. 감정 흐름

**관찰** (댓글 데이터 없음 — 옆 소재 「신분증」 영상의 수요(크랩 191만·지식 브런치 168만)와 사료 장면의 성격으로 판단)
- 사료가 만드는 감정: 의아함(왜 이렇게까지) → 백성 쪽 공감(노비가 되기를 택함) → 허탈(피난길 장부 소각) → 납득(정착의 조건)
- 「신분증을 왜 그렇게 싫어했나」는 시청자 본인 경험(주민등록증·지문 날인)과 바로 이어지는 질문 — 댓글 유발 지점은 클로징 한 줄

**설계 원칙**
- 초반 30%: 의아함 — 작은 패, 큰 저항
- 중반 40%: 공감 — 원인을 백성의 계산(군역을 피하려면 숨는 게 이득)으로 보여 준다. 조선 비하 금지 → 태종 #4·세조 #9처럼 위에서도 부작용을 알았던 기록을 같이
- 후반 30%: 허탈 → 납득 — #27을 감정 정점으로, 숙종 대는 차분한 설명

## 5. 썸네일 & 제목

**관찰** (competition.md)
- 경쟁작 썸네일: 호패 실물 사진·교과서풍, 「조선판 주민등록증」 문구
- 경쟁작 제목: 「호패란」 「조선시대 신분증」 정의형. 「왜 네 번」을 묻는 제목 없음

**설계 원칙**
- 제목: pd-guide 4번 「사실 단정 + 이유」, 40자 이하, 앞 20자 안에 「조선」+「호패」. 사실 구절 후보 = 「네 번 없애고 또 만든 신분증」 / 「차라리 죽겠다며 산으로 간 백성」
- 썸네일 문구: 질문형(제목과 역할 분담), 제목과 같은 문장 금지
- 비주얼: 실물 사진 대신 디오라마(강가에서 타는 장부 / 산으로 가는 인형 무리) — 피드 대조에서 색·구도·문구 형식 2개 이상 차이

## 6. 레퍼런스 핵심 자산

**퍼포먼스 순위표** — 해당 없음(사료 묶음). 같은 소재 경쟁작 최고 조회는 EBS 30,307회(개요형) → `competition.md`

**인기 댓글 모음** — 해당 없음

**구조 자산**
- `결말 공개 + 이유 숨김 훅` — 역사의 결말은 검색되므로 공개하고, 「왜」만 끝까지 미룬다 (pd-guide 5번)
- `반복 리듬` — 시행→폐지→「또」가 세 번 이상 이어지면 시청자가 다음 실패를 예상하고, 숙종 6년 폐지 명령(#32)에서 「또」를 예상하게 한 뒤 실행되지 않고 이어진 5차가 보상이 된다 (#8·#13·#17·#27 → #32 → #33)
- `숨은 사람 > 드러난 사람` — 226만 한 숫자로 「왜 싫어했나」의 규모를 증명 (#23)
- `위에서도 알았다` — 왕이 부작용을 알고 조심한 기록으로 「무능한 조선」 프레임을 피한다 (#4·#9·#28)
- `피난길의 선택` — 전쟁 한가운데서 왕이 먼저 법을 버린 장면이 정책 실패의 가장 강한 증거 (#26·#27)
