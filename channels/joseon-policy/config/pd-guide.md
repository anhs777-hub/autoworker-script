# PD 전략 가이드: 조선정책실

> 이 채널은 유튜브 레퍼런스가 아니라 **사료(실록 기사)** 에서 출발한다. 파이프라인 도구 파일(`.claude/`·`prompts/`·`scripts/`)은 업데이트 때 덮어써지므로, 이 채널만의 진행 방식은 전부 이 파일에 적는다. 채널 성격의 정본은 `profile.md`, 소재 카드는 `topic-research.md`.
>
> 작성: 2026-10-20 사용자와 섹션 1~6을 하나씩 확정. 순서는 파이프라인이 읽는 순서(레퍼런스 → 자료 조사 → 경쟁작 → 제목 → 훅 → 성과)

## 1. 레퍼런스 단계 — 영상 대신 사료 묶음으로 시작한다 (2026-10-20 사용자 결정)

파이프라인 상태 감지는 `_refs/`가 비어 있으면 COLLECT, `_refs/*/analysis.md`가 없으면 ANALYZE로 멈춘다. 이 채널은 참고 영상이 없는 소재(호패법 등)가 강점이므로, 레퍼런스 자리를 아래처럼 채운다.

### 001번 = 실록 사료 묶음 (항상 — PD가 직접 만든다)
- 위치: `{P}/_refs/001/`
- `source.md` — 이 소재의 핵심 기사 10~20건. 기사마다 `날짜 | 기사 ID | 기사 제목 | 핵심 문장(국역문 1~2문장) | 쓸 곳(장면/숫자/흐름)`
  - 실록 기사 ID는 `https://sillok.history.go.kr/id/{ID}`로 열린다. 실록 밖 원전(일성록·문집·통신사 기록 등)은 한국고전종합DB 자료 ID와 서명·권차를 적는다
  - `topic-research.md`에 이미 카드가 있는 소재는 그 카드에서 출발하고, 빠진 기사만 더 찾는다
- `meta.md` — `제목: 실록 사료 묶음 — {소재}`, `유형: 사료`, 조사일
- `analysis.md` — 영상 분석 대신 아래 4가지를 뽑는다(ANALYZE 단계의 산출물 자리)
  1. **장면 후보** — 날짜가 붙은 구체적 장면(누가, 무엇을, 어떻게). 훅·파트 첫머리 후보
  2. **숫자 후보** — 변화가 보이는 숫자(전→후). 영상 전체에서 핵심 1~2개만 쓸 것을 전제로 순위
  3. **흐름** — 도입 배경 → 시행 → 문제 발생 → 대응과 재시도 → 결말이 기사로 이어지는지, 끊기는 곳은 어디인지
  4. **빈 곳** — 실록에 없어서 보충 원전·논문이 필요한 것(총계·물가·공사비 등)

### 002번부터 = 경쟁 영상 (있을 때만, 1~2개)
- 같은 소재의 경쟁 영상이 있으면 `collect.py`로 1~2개 수집해 평소처럼 분석한다
- 쓰는 목적은 하나: **「그 영상들이 다루지 않은 장면·숫자」를 찾는 것.** 구조·말투를 따라 하지 않는다(경쟁 채널 대부분이 수백 회에 머물러 있다 — 2026-10-20 경쟁 조사)
- 경쟁 영상이 없으면 001번만으로 다음 단계로 간다

## 2. 자료 조사 (DATA_PREP) — PD가 사료를, 서브에이전트가 연구를 (2026-10-20 사용자 결정)

### 역할 나누기
| 누가 | 무엇을 | 방법 |
|---|---|---|
| **PD 직접** | 실록 기사 본문, 한국고전종합DB(일성록·승정원일기 국역·문집·통신사 기록), RISS 논문 초록 | 브라우저. 실록은 사이트 안에서 `fetch('/search/searchResultList.do', POST)` 검색 → `/id/{기사ID}` 본문 (curl로는 0건이 나온다 — 2026-10-19 확인). 고전종합DB는 `db.itkc.or.kr/search/group?q=query†{검색어}`, 본문은 `dir/item?itemId=BT#/dir/node?dataId={자료ID}` |
| **data-researcher (백그라운드)** | 공개된 연구 정리, 실록에 없는 총계 숫자(발행량·공사비·물가), 지명의 현재 위치, 단위 환산 근거 | 웹 검색. 실록 사이트는 열 수 없으므로 PD가 001 사료 묶음의 기사 목록을 함께 넘긴다. 서브에이전트는 파일을 쓰지 못하므로 본문을 반환하고 PD가 저장한다 |

- **대본에 쓰는 실록 기사는 전부 본문을 연다.** 제목만 보고 쓰지 않는다 — 2026-10-19 당백전 「7개월」을 본문 확인 후 「약 5개월」로 정정한 사례

### 출처 등급 표시 — `verified-data.md`의 모든 날짜·숫자에 붙인다
| 표시 | 뜻 | 대본에서 |
|---|---|---|
| `[실록]` | 실록 기사 (기사 ID 필수) | 「○○ ○년 ○월 ○일, 실록에는…」 |
| `[원전]` | 실록 밖 조선 기록 (서명·권차·자료 ID) | 「○○의 일기에는…」처럼 기록 이름을 댄다 |
| `[논문]` | 연구 논문 (저자·연도) | 「연구자들은 ○○로 봅니다」 — 원전과 섞지 않는다 |
| `[추정]` | 확인 안 됨 | **쓰지 않는다** |

- `verified-data.md`에 없는 날짜·숫자는 대본에 쓰지 않는다
- 고종실록·순종실록 기사는 승정원일기·일성록·당시 신문으로 **교차 확인된 것만** `[실록]`으로 올린다. 확인이 안 되면 `[추정]`
- 기록끼리 숫자가 다르면 둘 다 적고 「기록마다 다름」 표시

### 패턴 추출 (`patterns.md`) — 레퍼런스가 1개여도 멈추지 않는다
- 파이프라인 기본값은 「analysis.md 2개 이상」이지만, 이 채널은 001 사료 묶음 하나로 진행한다
- `patterns.md`는 영상 패턴 대신 **profile 「서사 구조」(도입 배경 → 시행 → 문제 발생 → 대응과 재시도 → 결말 → 정책실 판정)에 사료의 장면·숫자를 배치한 표**로 쓴다. 경쟁 영상(002~)이 있으면 「그 영상이 쓴 장면 / 안 쓴 장면」 열을 더한다

### 사료 확인 지점 — 집필 전에 사용자에게 보여 준다
- DATA_PREP가 끝나면 STRATEGY로 바로 가지 않고, 아래를 한 화면으로 요약해 사용자에게 확인받는다
  - 장면 후보 상위 5개(날짜·한 줄), 숫자 후보 상위 3개, 흐름이 끊기는 곳, 빈 곳과 보충 계획
- 사용자가 확인하면 STRATEGY로 진행한다. 첫 8편(시험 기간)은 반드시 거친다

## 3. 소재 선정 · 경쟁작 해부 → 차별 설계 (2026-10-20 사용자 결정)
세상의 이유의 같은 이름 섹션(2026-10-19)을 이 채널에 맞게 옮겼다. 경쟁 영상이 있어도 소재를 버리지 않는다 — 대신 사료로 더 깊게, 다르게 만든다.

**0단계 — 시작 조건** (001 사료 묶음을 만든 직후 판정)
- 날짜가 붙은 장면이 **5개 이상**인가 (profile 「소재 선정 규칙」)
- 「조선 정부가 벌인 일」인가 (조선 건국 ~ 대한제국)
- 둘 중 하나라도 아니면 3단계 정지선과 같이 처리한다

**1단계 — 경쟁작 해부표** (DATA_PREP 끝, STRATEGY 전 · `_script/competition.md`)
- 소재를 **대상 이름 + 「조선」** 으로 검색해 상위 3~5편(조회 순)을 한 표에 펼친다 (`.venv/Scripts/yt-dlp "ytsearch10:{대상 이름} 조선" --flat-playlist --print "%(view_count)s|%(upload_date)s|%(channel)s|%(title)s"`)
- 칸: 제목(단어·형식) · 썸네일(색·구도·문구) · 첫 장면 · 구조·결론 · **댓글**(아직 묻는 질문, 틀렸다고 지적한 부분) · 출처를 댔는가(실록 날짜가 있나, 야사인가)
- 표 아래에 「경쟁작들이 공통으로 한 것」과 「공통으로 놓친 것」을 각 3줄 이내로
- **조회 1천 회 미만 영상**(AI 양산 채널이 대부분)은 표에 참고로 올리되 3단계 「붐빈다」 판단에는 세지 않는다
- 경쟁 영상이 하나도 없으면 「경쟁작 없음 — 검색어·날짜」 한 줄만 남기고 넘어간다

**2단계 — 차별 4축** (STRATEGY · concept.md 「차별 설계」 섹션) — **최소 2축을 경쟁작과 다르게**
1. **질문** — 경쟁작이 건너뛴 「왜」를 축으로 (예: 「저화가 무엇이었나」가 아니라 「왜 처벌로도 못 살렸나」)
2. **사료 정정** — 경쟁작들이 흔히 틀린 숫자·이야기를 실록 기사로 바로잡는다. 대본에 「흔히 ~로 알려졌지만, 실록에는 ~」 장치로 넣는다(경쟁작 이름은 말하지 않는다). 야사를 사실처럼 쓴 경쟁작이 많아 이 채널의 가장 강한 무기다
3. **첫 장면** — 경쟁작이 안 쓴 기사 날짜 장면으로 연다
4. **피드 대조** — 경쟁작 썸네일 3~5개 옆에 우리 썸네일을 놓았을 때 **색·구도·문구 형식 중 2개 이상**이 달라야 한다

**3단계 — 정지선** (해당하면 멈추고 사용자에게 알린다)
- 조회 10만+ 대형 채널(방송사 포함)이 사료 수준까지 이미 다룬 소재
- 최근 2주 안에 같은 소재 1만+ 영상이 3편 이상 몰렸다
- 0단계 시작 조건 미달
- 차별 축이 「엮는 방식만 다름」뿐이다
- **처리: 자동으로 넘어가지 않는다.** 어느 조건에 걸렸는지 + `profile.md` 「다루는 내용」에서 다음 소재 후보 2개를 같이 보여 주고 사용자가 고른다

## 4. 제목 (2026-10-20 사용자 결정)

### 제목 길이
- **권장 30~38자, 상한 40자** (따옴표·공백 포함, `len()`으로 실제로 센다) — 파이프라인 기본값과 같다

### 형식 — 「사실 단정 + 이유」
- 틀: **「{체감되는 사실 한 구절}, 조선이 {소재 이름}에 {실패/성공}한 이유」** 또는 그 변형
  - 예: `종이돈 안 쓰면 재산 몰수, 조선이 저화를 50년 만에 포기한 이유` (35자)
  - 예: `네 번 없애고 또 만든 신분증, 조선이 호패에 매달린 이유` (32자)
  - 예: `들여오자마자 사라진 고구마, 조선이 고구마 보급에 실패한 이유` (34자)
- **앞 20자 안에 「조선」과 소재 이름**이 들어간다 — 검색어이자 모바일 목록에서 잘리지 않는 자리. 소재 이름이 낯설면(저화·직전법) 앞 구절에 쉬운 말(「종이돈」 「공무원 땅」)을 먼저 둔다
- 앞 구절의 사실은 `verified-data.md`의 `[실록]`·`[원전]` 근거가 있는 것만. 숫자는 하나까지
- **질문형 금지** — 썸네일 문구가 「~인데 / 왜 ~했을까」 질문형이므로 제목은 단정형으로 역할을 나눈다. 제목과 썸네일 문구에 같은 문장을 쓰지 않는다
- 금지: 「충격」 「소름」 「진실」 「미스터리」 「실록이 숨긴」, 인물 평가어(「폭군의」 「성군의」), 오늘 뉴스 연결(「요즘 ○○와 똑같은」), 「지금 돈으로 ○억」
- 성공 편은 「~이 결국 자리 잡은 이유」 「~이 100년 걸린 이유」처럼 버틴 과정을 이유로 둔다

## 5. 훅 (0:00~0:30)과 인트로 (~1:00) (2026-10-20 사용자 결정)

> 근거: 지식대학 고양이 편은 훅 직후 연구팀·학술지 서지를 늘어놓아 1분 유지율 26.3%, 대학 이름 편은 57.6% (2026-10-11 이탈 그래프). 이 채널에서는 **연호·관청·관직명**이 같은 위험이다.

### 훅 틀 (약 230자, 30초) — 장면 → 어긋남 → 질문
1. **장면 하나** — 기사 날짜 + 구체적인 사람과 행동. 관청 이름보다 사람(감사·백성·상인·노인)이 주어
2. **어긋남** — 좋은 뜻·평범한 제도였는데 결과가 이상했다. **결말은 여기서 말한다**(「네 번이나 거둬들였습니다」 「50년 만에 포기했습니다」) — 역사의 결말은 검색하면 나오므로 숨기지 않는다
3. **질문** — 이번 편이 끝까지 답할 「왜」 하나. **이유는 숨긴다** — 정책실 판정에서 푼다
- 예 (호패법): `광해군 2년, 전라도 감사가 조정에 보고를 올립니다. 백성들이 산속으로 들어가고 있다는 겁니다. 차라리 죽을지언정 호패는 차지 않겠다면서요. 호패는 이름과 사는 곳을 적은 나무패 하나였습니다. 나라는 이걸 260년 동안 네 번이나 거둬들였고, 다섯 번째에야 겨우 자리를 잡았습니다. 나무패 하나가 왜 이렇게까지 됐을까요.` (2026-10-20 실록 본문 확인으로 횟수 2차 정정 — 숙종 6년 폐지는 명령만 나오고 실행되지 않음. `projects/hopae-law/_script/verified-data.md` 「PD 실록 재확인」)
- 반전이 아주 큰 소재(고구마 — 정부가 아니라 백성이 퍼뜨림)는 반전 쪽을 숨기고 결말 일부만 말해도 된다. 그 경우 concept.md에 이유를 한 줄 적는다

### 연도 표기
- 훅·장면에서는 **왕 연호만** (「광해군 2년」 「세종 4년」). 서기 연도는 파트 1에서 처음 한 번만 병기(「태종 13년, 1413년」)
- 같은 왕 안에서 이어지는 장면은 「그로부터 3년 뒤」처럼 상대 시점으로 — 연호를 문장마다 반복하지 않는다

### 인트로 (0:30~1:00)에서 하지 않을 것
- 관청·관직 설명, 연호 풀이, 제도의 법조문 설명 → 전부 파트 1로
- 「오늘은 ~을 알아보겠습니다」 「함께 살펴보겠습니다」 같은 진행 멘트
- 인트로는 「이 정책이 무엇을 노렸나」를 한두 문장으로만 — 노린 것과 결과의 차이가 영상 전체의 긴장이 된다

## 6. 성과 기록 · 시험 기간 판단 (2026-10-20 사용자 결정)

### 판독 규칙 (세상의 이유·지식대학에서 가져옴)
- 업로드 **48시간 뒤**: 노출수 · CTR · 조회수 · 평균 조회율 · 30초/1분 유지율(이탈 그래프)
- 48시간 노출이 **1천 미만**이면 CTR은 참고만 하고 **4일 차에 노출을 다시 본다**(지식대학 야외 소변: 1일째 41 → 4일째 5.4만). 4일 차에도 1천 미만이고 그래프가 평평하면 노출 창이 닫힌 것으로 보고 관리 종료
- 48시간에 **노출 1천+ · CTR 3% 미만**이면 그 자리에서 썸네일을 교체한다. 하루 노출이 수백으로 줄어든 뒤의 교체는 효과가 없었다(지식대학 대학 이름 편)
- 날짜별 데이터는 약 2일 늦게 열린다 — 교체 다음 날 하루치는 이틀 뒤 확인

### 시험 기간 — 첫 8편
- **확산 신호**: 8편 중 **한 편이라도 노출 1만+ 그리고 CTR 5%+** (새 채널이라 세상의 이유 기준 CTR 7%·조회율 25%보다 낮게 잡음)
  - 있으면 → 계속. 업로드 주기를 늘릴지 검토
  - 없으면 → **대본은 그대로 두고 제목·썸네일 형식만 바꿔 4편 더**(9~12편). 12편에서도 신호가 없으면 **중단**하고 세상의 이유·지식대학에 여력을 돌린다
- 첫 두 편 완성 영상으로 **분당 글자수를 실측**해 profile 「기본 러닝타임」의 470자를 고친다
- 5~6편 뒤 이탈 그래프로 15분 길이가 맞는지 다시 본다
